## 현재 진행 상황
- MK02 전체는 미완료다. BoatDurability의 서버 내구도·난파 코드와 BoatController → PlayerController SyncVar → HFSM 연결이 있다.
- Unity 컴파일과 Play 모드의 난파 처리 메서드 직접 호출로 Downed 전환·입력 잠금·사격 차단을 확인했다. 서버 피해 전체 경로와 원격 동기화 통과를 뜻하지 않는다.
- 난파한 플레이어는 기존 배 앵커에 유지한다. 잔해·화물 손실·구조·배 복구는 MK04 연계 범위다.

## 해야 할 일 — 권장 순서
1. 개발용 서버 피해 수단과 네트워크 시험 씬 준비. 호스트/원격 배에 시험 피해를 적용해 내구도 일치, 난파 한 번, 이동·사격·재탑승 차단을 검증한다.
2. 배 소멸 시 서버 난파 처리 연결을 검토한다. 기존 클라이언트 SetDowned 호출은 서버 상태를 확정하지 못한다.
3. TW02 몬스터 공격 → 배 피해 연결. 암초 피해는 지훈 합의 안건 7의 서버 겹침 검사 제안 확인 후 연결한다.
4. MK02 배 수리 비용·조건·회복량을 정하고 JH02 RepairBoat와 연결한다. 자원 차감·회복 한 번, 최대 내구도 상한과 실패 시 차감 없음을 검증한다.
5. 대포 요청·서버 재장전 검증 → 발사·명중 → TW02 몬스터 체력/처치를 연결한다.
6. MS04 배 물리·날씨/파도 충격, 배 모듈·JH04 등대 보상의 속도/대포 피해 적용·해제를 연결·검증한다. 최후 전투에서 기존 보상 유지, 신규/중복 지급 없음을 확인한다.
- 단계별 코드 예시·변경 내용을 먼저 설명하고, 사용자 수정 요청 범위에서만 코드를 편집한다. 이 목록 자체는 구현 실행 승인이 아니다.
