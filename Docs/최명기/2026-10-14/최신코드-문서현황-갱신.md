## 요청과 목표
최명기 작업을 바탕으로 문서를 최신 코드·팀 결정과 맞추되 구현·미연결·미검증을 구분한다.

## 진행 과정과 결정 이유
- 작업 pointer → MK02 원문·연결 인수인계 → 설계/문제 대장 → 실제 코드·프리팹·빌드 설정을 대조했다.
- 사용자 기존 암초 피해·반동·회복 코드를 구현 현황에 반영했다.
- 사용자 범위 정정에 따라 이번에 추가했던 투표·타 담당 현황 변경은 되돌렸다. 최명기 Player·배 작업과 본인 측 연결 과제만 남겼다.
- 입력 정합 → MK02 멀티 검증 → 수리·대포 연결을 다음 순서로 제시했다. 기획 수치·피해 계약·직군 배정 시점·동시 승패 우선순위는 확정하지 않았다.
- 타 담당 코드·씬·설정·과거 인수인계는 수정하지 않았다. 커밋·푸시·게시 없음.

## 합의 안건·작업 방향 재대조 (2026-10-14)

최명기 합의 안건 전체, 이동 권위 영향, 로비/게임 씬 전환 공지, 네트워크 권위와 지훈 시스템 설계의 최명기 경계를 대조했다. 아래는 본인 측 작업 목록이며 김지훈 원문의 확인란이나 팀 합의를 대신 확정하지 않는다.

| 범위 | 현재 기준·확인한 상태 | 최명기 다음 행동 |
|---|---|---|
| 상호작용 입력·대상 탐지 | Player는 키 이벤트만 발행하고 김지훈 Interaction 컴포넌트가 대상 탐지·Relay 요청을 맡음. 현재 Interaction 폴더는 요청 DTO/enum만 확인 | JH02 컴포넌트 제공 뒤 직군 플레이어 프리팹에 부착. Player에서 별도 대상 탐지 구현을 중복하지 않음 |
| 배 대상 등록 | 김지훈 대상 컴포넌트가 스스로 등록/해제. 대상 ID는 netId가 아닌 TargetId+Generation | 컴포넌트 제공 뒤 배 프리팹에 부착. 배 스포너에서 장부 등록을 중복하지 않음 |
| 채집·구조·메뉴 UI | 지속 상호작용 수명은 Interaction, 시간·취소 조건과 수리/구조 비용은 기능 담당 | MK03/04 시간·취소 조건, MK02 수리 비용/조건 준비. 메뉴 UI는 대상·Action·인자를 Relay로 전달 |
| 직군 프리팹·배정 | 매니저 선택 훅 제공/Player 선택 로직 분리 방향. 현재 매니저는 playerPrefab 직접 생성, 선택 훅 구현은 확인되지 않음. 배정 시점은 미정 | 로비 선택/시작 시 배정 결정을 먼저 확인. 주석의 무작위 프리팹 코드를 확정 기능으로 되살리지 않음 |
| 판 진행 여부 | 합의 안건 3의 'MK06이 제공'은 같은 문서 4절 주석 및 후속 팀원 공지에서 김지훈 세션 단계로 대체됨 | 세션 진행 여부 공급 기능을 별도 만들지 않음. MK06은 낮밤·의식·최후 전투 등 판 내부 단계 시작/중단 연결 |
| 로비·종료 화면 | 첫 화면·로비 준비·로딩·종료 사유는 김지훈 담당 | 본인 인게임 UI·게임 상태 중단에 집중 |
| 배 생성 이벤트 | ActorJoined는 게임 플레이어 생성 직후 판당 한 번, 로비 플레이어 제외. PlayerBoatSpawner가 구독 | 게임 씬에서도 자기 배 한 척만 생성되는지 검증. ActorJoined를 전체 월드 준비 완료로 간주하지 않음 |
| 판 시작/끝 이벤트 | MatchStarted/MatchEnded는 서버 전용. 명단 리스트는 재사용됨. 시작 시점은 현재 씬 로딩만 대기, 월드 준비 연결 TODO | MK06 시작/중단 연결 설계. 명단 보관 시 복사. 실제 배정 초기화는 합의 후 본인 코드에서 연결 |
| 암초·대포·부력 | 암초 서버 겹침 피해는 본인 코드에 있음. 대포 서버 요청/명중·파도 보고·부력 주인 PC 실행은 합의 확인란 미체크 | 코드 구현·담당 확인·멀티 통과를 구분. 암초 M2부터 확인하고 나머지 항목은 별도 합의/연결 |
| 강제 이동·배 간 충돌 | ServerTeleport 사용, 배 간 피해/밀기 없음은 합의 대기 제안 | 자동 구조/강제 이동 연결 시 호스트/원격 검증. 제안을 채택 완료로 적지 않음 |

### 아직 본인이 확인할 사항
- 물리·피해 안건 7의 각 항목에 동의/수정 의견을 명시할 필요가 있다. 암초 코드가 제안과 같다는 이유로 동의 체크를 대신하지 않았다.
- 직군 배정 시점·방식, 수리/구조 비용·조건, 채집/구조 시간·취소 조건은 미정 또는 합의가 남아 있다.
- 초기 문서 갱신 때 후속 공지의 대체 계약까지 충분히 반영하지 못했다. 이번에 본인 기록에 보완했으며 다른 담당 인수인계 원문은 수정하지 않았다.

## 검증
- 실행한 확인: 실제 코드/프리팹 텍스트 대조, 변경 문서 상대 링크 존재 검사, git diff --check.
- 실행하지 않은 확인: Unity 컴파일·Play·호스트/원격 M2·다른 PC M3. 문서 변경이며 게임 기능 통과를 주장하지 않는다.

## 남은 일과 차단 조건
MK01 입력 설정·실제 콜백 확인, MK02 피해/난파 멀티 검증, 수리 비용과 JH02·TW02 연결, 난파 상태→투표 연결, 월드 준비 신호·MK06 본편 단계 통합. 미정 기획·API 합의는 각 기준 문서를 따른다.
