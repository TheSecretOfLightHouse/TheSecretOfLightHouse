## 실행 증거의 의미
- 본인 2026-10-13 기록: Unity 컴파일 성공 및 단일 Play에서 난파 메서드/훅 직접 호출로 Downed·입력 잠금·사격 차단 확인. 서버 피해 전체 경로·네트워크 전송은 시험하지 않았음.
- JH07 원문: MKTestScene의 에디터 호스트 단독 tech 생성·ActorJoined 회귀 확인(M0). 암초 피해·난파 원격 동기화 시험 결과가 아님.
- 현재 커밋의 MK02 M2/M3 통과 기록은 조사한 문서에서 미발견. Builds 디렉터리도 현재 없음. 사용자의 별도 시험 결과가 있으면 실행 환경·인원·피해 수치·반복 횟수·클라이언트 관찰 결과를 추가할 수 있음.
- 이번 Unity 컴파일·Play·콘솔 조회·CLI 업데이트·M2/M3·빌드는 전부 미실행.

경로 주의: 디스크는 Docs이고 Git 추적에는 docs 공유 문서와 Docs/최명기 개인 기록이 혼재한다. 일괄 이동·추적 경로 변경은 하지 않았다. 새 파일의 Git 경로 정리는 별도 커밋 준비 시 확인한다.

### 2026-10-14 경로 정리 후속
- 사용자 요청으로 Git에 `Docs/`로 남아 있던 MK02 원문과 `POINTER.md`의 추적 경로를 `docs/`로 변경했다. 이번 확인에서 디스크 폴더 이름은 이미 `docs`였다.
- 임시 경로를 거쳐 `git mv`를 수행했다. 두 파일의 이동 전후 SHA256이 일치해 기존 미커밋 본문 변경 보존을 확인했다. 경로 변경만 스테이징됐으며 기존 본문 수정은 미스테이징 상태로 유지했다.
- `git diff --check`와 `git diff --cached --check`를 통과했다. 커밋·푸시는 하지 않았다. 게임 기능의 미검증 상태는 그대로다.
