> 2026-10-13 갱신: 로비 씬·게임 씬 전환 방식으로 `ActorJoined`·`ActorLeft`의 발생 시점이 "게임 씬의 게임 플레이어 기준, 판당 한 번"으로 바뀌었고 `MatchStarted`·`MatchEnded`가 추가됐다. [로비·게임 씬 전환 방식 팀원 공지](판시작종료-로비게임씬전환-팀원공지.md)를 따른다.

## 결정 내용

2026-10-13 김지훈이 아래 두 가지를 결정했다.

1. `LighthouseNetworkManager`의 `ActorJoined`·`ActorLeft` 이벤트와 `Connections`(ConnectionDirectory) 조회를 **공용 계약으로 고정**한다. 바꿀 때는 미리 공지한다. [최명기 합의 안건 4번](최명기-합의안건.md#4-actorjoinedactorleft-공용-계약)에서 시작했지만 투표 코드도 같은 계약을 써서 함께 알린다.
2. **판 진행 중 참가자가 한 명이라도 끊기면(호스트 포함) 판을 종료한다.** [승패·투표 결정 §8](../../../design/win-vote-decisions.md#disconnection)의 "끊긴 캐릭터를 허수아비로 남김"을 이렇게 바꿨다. 로비 이탈은 자리만 비우고, 판 시작 후 새 접속은 거절한다. 재접속은 10/25 이후 선택 범위다.

| 계약 | 시점·의미 | 값 |
|---|---|---|
| `ActorJoined(uint actorId, NetworkConnectionToClient conn)` | 서버 전용. `AddPlayerForConnection` 성공 직후, `conn.identity`가 플레이어 객체 | ActorId는 1부터 발급, 0은 무효 |
| `ActorLeft(uint actorId, NetworkConnectionToClient conn)` | 서버 전용. 연결 해제 처리에서 플레이어 객체를 정리하기 전 | 호출 직후 `Connections`에서 해당 연결이 빠진다. 판 진행 중이면 이어서 판 종료가 일어난다 |
| `Connections.TryGetActorId(conn)` | 연결 → ActorId. Command 송신자 확인용 | 해제된 연결은 false |
| `Connections.TryGetConnection(actorId)` | ActorId → 현재 연결. TargetRpc 대상 찾기용 | 끊긴 참가자는 false |
