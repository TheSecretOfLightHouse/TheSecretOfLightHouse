# 판 시작 신호와 월드 시계 연결 — 강민서 확인 요청

작성자: 김지훈
수신자: 강민서(ri-ver-1)
작성일: 2026-10-13
기준: 김지훈 `feature/jihun` `6f5d154` + 미커밋 JH07 변경, 강민서 코드는 `origin/develop` `018b927`(N1 `72b5a89`·`1f5bd74`)

## 요약

JH07(판 시작·종료)에서 서버가 전원 로딩 완료를 확인한 뒤 판 시작 신호 `MatchStarted`를 한 번 낸다. 지금 `WorldStateNet`은 서버가 켜지자마자 `BeginMatch()`로 시계를 시작하므로, JH07 게임 씬에 그대로 두면 **아직 로딩 중인 사람이 있는데 시계가 먼저 간다.** 시계 시작을 `MatchStarted`에 맞춰 주길 요청한다. 김지훈 코드와 강민서 코드는 파일이 겹치지 않아 병합 충돌은 없다.

## 판 진행 흐름 (JH07, 구현·같은 PC 4인 시험 완료)

로비 씬에서 전원 준비 → 서버가 게임 씬으로 전환 → 각 PC가 게임 씬 로딩을 마치면 서버에 알림 → **전원 완료 시 `MatchStarted` 1회** → 판 진행. 판 진행 중 누가 나가면 판이 끝나고 전원 첫 화면으로 돌아간다.

| 계약 (`LighthouseNetworkManager`) | 의미 |
|---|---|
| `MatchStarted(uint matchId, double startTime, IReadOnlyList<uint> roster)` | 서버 전용. 전원 로딩 완료 직후 한 번. `startTime`은 `NetworkTime.time` |
| `MatchEnded(uint matchId, SessionEndReason reason, uint actorId)` | 서버 전용. 판 종료 시 한 번. 직후 호스트가 종료된다 |
| `Phase` | 서버 세션 단계 `Lobby`·`Loading`·`InProgress`·`Ended` |

접근: `LighthouseNetworkManager.Instance` (서버에서만 이벤트가 발생).

## 확인된 문제

| 근거 | 내용 |
|---|---|
| `02.World/WorldState/Net/WorldStateNet.cs` `OnStartServer` | `_isBeginOnStartServer`가 true(기본값)이면 `BeginMatch()`를 바로 부른다 |
| JH07 게임 씬 흐름 | 게임 씬의 씬 오브젝트는 서버가 게임 씬을 불러올 때 `OnStartServer`가 불린다. 이때는 `Loading` 단계라 원격 PC가 아직 로딩 중이다 |
| 결과(추론) | 게임 시계 시작 시각이 판 시작보다 앞서고, 로딩이 느린 사람은 시작 몇 초를 잃은 상태로 들어온다. 로딩 시간 초과(60초)로 판이 끝나도 시계는 이미 시작된 상태다 |

## 요청

1. JH07 게임 씬에서는 `_isBeginOnStartServer`를 끄고, 서버에서 `MatchStarted`를 구독해 `BeginMatch()`를 불러 주세요.
   - 시작 시각은 `MatchStarted`의 `startTime`을 써 주면 모든 기능이 같은 시각을 기준으로 삼을 수 있습니다. 지금 `BeginMatch()`는 호출 시점의 `NetworkTime.time`을 쓰므로 거의 같지만, 시각을 인자로 받는 형태를 제안합니다.
   - 구독 위치(WorldStateNet 안 또는 별도 연결 컴포넌트)는 강민서가 정해 주세요. 김지훈 코드는 바꿀 필요가 없습니다.
   - 강민서 시험 씬(`WorldNetSandbox`)은 지금처럼 켜 둔 채로 써도 됩니다. 로비 설정이 없는 매니저는 `MatchStarted`를 내지 않습니다.
2. 판 종료 시 시계 정리: 판이 끝나면 호스트가 곧바로 종료되어 `OnStopServer`/`OnStopClient`가 불립니다. 지금의 `ReleaseClock()`으로 충분해 보이지만 확인 부탁합니다.

## 확인할 것 (결정 필요)

| # | 질문 | 이유 |
|---|---|---|
| 1 | 맵 시드(`MapSeed`)는 언제 정해야 하나 | 지금은 `BeginMatch()`에서 시드도 함께 만든다. 맵 생성이 이 시드를 쓰게 되면, 시드는 **로딩 중**(판 시작 전)에 필요하다. JH07은 "월드 생성 완료"를 기다린 뒤 판을 시작할 예정이라, 시드가 판 시작에야 정해지면 서로 기다리게 된다. 시드 배포(로딩 시작 시)와 시계 시작(판 시작 시)을 나누는 것을 제안한다 |
| 2 | 월드 생성 완료 신호의 형태 | 김지훈이 4명 모두의 완료를 확인한 뒤 `MatchStarted`를 내도록 시작 조건에 추가한다(JH07 코드 TODO). 각 PC가 서버에 알리는 방식(메시지·Command 등)과 이름을 알려 주세요 |
