## 결정 내용 (2026-10-13 김지훈)

| # | 결정 |
|---|---|
| 1 | 로비 씬에 **로비 전용 플레이어**(`LobbyPlayer`)를 만들고, 4명 모두 준비하면 게임 씬으로 바꾼다. 게임 씬 로딩이 끝난 PC부터 게임 플레이어를 만든다 |
| 2 | 판이 끝나면(누가 나감, 로딩 시간 초과) 전원 **연결을 끊고 첫 화면**으로 간다. 로비로 돌아가지 않는다 |
| 3 | `ActorJoined`·`ActorLeft`는 **게임 플레이어에 대해서만 판당 한 번** 발생한다. 로비 플레이어는 발생시키지 않는다 |
| 4 | 판 시작 순간 서버 전용 `MatchStarted(matchId, startTime, 참가자 명단)`을 낸다. 판 종료 시 `MatchEnded(matchId, 사유, 나간 ActorId)` |
| 5 | 로비 프리팹이나 게임 씬을 지정하지 않은 매니저는 **기존 단일 씬 방식 그대로**다. 기존 시험 씬(JH01·투표·MK)은 설정을 바꾸지 않으면 영향이 없다 |

## 공용 계약 (갱신)

[이전 계약](접속이벤트계약-박태욱-작업영향.md)의 시그니처는 그대로이고, 발생 시점만 아래처럼 바뀐다.

| 계약 | 시점·의미 |
|---|---|
| `ActorJoined(uint actorId, NetworkConnectionToClient conn)` | 서버 전용. 게임 씬에서 그 사람의 게임 플레이어가 생성된 직후. 판당 한 번 |
| `ActorLeft(uint actorId, NetworkConnectionToClient conn)` | 서버 전용. `ActorJoined`를 받은 사람이 끊길 때, 플레이어 정리 전. 판 진행 중이면 이어서 판이 끝난다 |
| `MatchStarted(uint matchId, double startTime, IReadOnlyList<uint> roster)` | 서버 전용. 전원 로딩 완료 직후 한 번. `startTime`은 `NetworkTime.time`. 명단 리스트는 재사용되므로 보관하려면 복사 |
| `MatchEnded(uint matchId, SessionEndReason reason, uint actorId)` | 서버 전용. 판 종료 시 한 번. 직후 호스트가 종료된다 |
| `Connections.TryGetActorId` / `TryGetConnection` | 변경 없음. ActorId는 로비에서 발급해 게임 씬에서 그대로 유지 |

클라이언트 쪽: `ClientState`(단계·판 번호·로딩 수), `ClientStateChanged`, `SessionEnded`, `LastSessionEnd`(첫 화면에서 종료 사유 표시용), `LeaveSession()`.
