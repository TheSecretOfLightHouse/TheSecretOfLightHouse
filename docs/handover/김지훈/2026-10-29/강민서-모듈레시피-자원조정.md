## 한 줄 요약

자원 총량에 맞춰 **모듈 8종의 재료 종류·수량을 강민서 님이 직접 정하고 바꿔도 됩니다**(사용자 김지훈 결정). 현재 값은 모두 시험값입니다. 코드 수정 없이 레시피 에셋 인스펙터의 `Ingredients`만 바꾸면 됩니다.

## 바꿀 에셋

경로: `Assets/02.Prefabs/Lighthouse/Data/`. 실제 게임 씬(MainGame·MK_MainGame·JH04TestScene·`MainIslandWorkbench.prefab`)이 쓰는 `Trial/ModuleRecipeCatalog_JH04Trial`에 들어 있는 8개입니다.

| 에셋 | 모듈 | 현재 재료 | 존재 상한 |
|---|---|---|---|
| `Trial/ModuleRecipe_Frame_JH04Trial` | 기반 프레임 | 돌5 나무5 철2 | 3 |
| `Trial/ModuleRecipe_Gear_JH04Trial` | 기어 장치 | 철3 섬유3 | 3 |
| `ModuleRecipe_Lens` | 렌즈 모듈 | 유리3 철2 수정2 | 1 |
| `ModuleRecipe_LightCore` | 광원 코어 | 수정3 유리2 | 1 |
| `Boat/ModuleRecipe_BoatSearchlight` | 탐조등 | 유리3 철2 | 0(무제한) |
| `Boat/ModuleRecipe_BoatDash` | 대쉬 | 철3 섬유3 | 0 |
| `Boat/ModuleRecipe_BoatObstacleAlarm` | 장애물 경보 | 철2 유리1 수정1 | 0 |
| `Boat/ModuleRecipe_BoatStabilizer` | 선체 안정기 | 나무4 철3 섬유2 | 0 |

등대 8칸(프레임3·기어3·렌즈1·코어1)을 다 채우는 데 지금 드는 자원은 **돌15 나무15 섬유9 철17 유리5 수정5**입니다. 배 모듈 수량은 여기에 따로 더해집니다.

## 바꾸는 방법

1. Project 창에서 에셋을 선택하고 인스펙터의 `Ingredients`에서 `Resource`·`Amount`를 고칩니다.
2. 자원 에셋은 `Assets/02.Prefabs/World/Data/MapGeneration/ResourceDefs/Resource_*.asset`을 넣습니다.
3. Ctrl+S로 저장합니다. `.asset` 파일을 텍스트로 직접 고치지 않습니다.

## 지킬 것

- `Amount`는 1 이상이어야 하고, 한 레시피에 같은 자원을 두 줄 넣지 않습니다. 둘 중 하나라도 어기면 카탈로그 전체가 거절됩니다.
- `Id`·`Is Boat Module`·`Boat Module Type`·`Icon`은 바꾸지 않습니다.
- `Max Existing`은 바꾸지 않습니다. 프레임·기어 3은 등대 8칸 구조에 맞춘 값입니다. 바꿔야 하면 김지훈과 먼저 상의합니다.
- 이름에 Trial이 없는 `ModuleRecipe_Frame`·`ModuleRecipe_Gear`는 옛 `Workbench.prefab` 전용입니다. 실제 게임에는 영향이 없으므로 맞추는 것은 선택입니다.
