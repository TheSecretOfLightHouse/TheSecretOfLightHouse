경로: `Assets/01.Scripts/04.Lighthouse/Workbench/Editor/WorkbenchModelSetup.cs`, `Assets/00.Scenes/Jihun/JH04TestScene.unity`

브랜치: feature/jihun
담당 파트: Lighthouse(작업대) — 김지훈

## 1. 목표
- 최종 상태: 사용자가 JH04TestScene에 배치한 `wooden_workbench_3d_model_low`가 작업대 본체가 된다. 모델에 콜라이더가 붙고, 기존 네모 상자(`WorkbenchBox`)와 루트 BoxCollider는 빠지며, 모델 가까이 가면 작업대 상호작용이 된다.
- 근거: 2026-10-23 사용자 요청. 상호작용 거리는 `InteractionTarget`이 붙은 `Workbench` 루트 위치 기준이다(`InteractionSelector.FindNearest`, `InteractionRouter`, `InteractionTarget.Position`). 모델 위치가 아니다.

## 7. 다음 세션의 첫 행동
1. Unity MCP 연결을 확인한다(`manage_scene get_active`). 안 되면 사용자에게 메뉴 실행을 요청한다.
2. JH04TestScene이 열렸는지 확인하고 `Lighthouse/Workbench/Use Wooden Model In Open Scene`을 실행한다.
3. 콘솔 로그의 절반 길이와 범위 3.5m를 비교한다. 절반 길이가 3.5m에 가까우면 작업대 InteractionTarget `_range`를 올릴지 사용자에게 묻는다.
4. Hierarchy에서 `Workbench` 아래에 모델·`WorkbenchRack`이 있고 `WorkbenchBox`·루트 BoxCollider가 없는지 확인한 뒤 씬을 저장한다.
5. 플레이(M0)로 모델 가까이에서 작업대 화면이 열리는지, 모델 콜라이더에 막히는지 확인한다.
6. 결과를 `docs/김지훈/2026-10-23/` 원문에 기록하고 pointer를 갱신한다.

## 8. 주의
- 되돌리면 안 되는 변경: 사용자가 배치한 모델의 씬 위치·회전·스케일(메뉴는 월드 자세를 유지한 채 부모만 바꾼다)

- 루트를 옮기면 자식 `WorkbenchRack`도 함께 움직인다. 선반을 모델 위나 옆에 따로 둬야 하면 실행 뒤 조정한다
