## 한 줄 요약

모듈 쪽 생성·줍기·만료는 **구현했습니다**. 강민서 님께 부탁할 일은 **모듈도 가장 가까운 섬 해안으로 가게 `ShoreIslandSelector`를 바꾸는 것** 하나입니다. 요청서와 다르게 정한 곳이 3개 있으니 아래 표를 봐 주세요.

## 부탁할 일

| # | 할 일 | 이유 |
|---|---|---|
| 1 | `ShoreIslandSelector.TrySelect`에서 `DebrisKind.Module`이 **자원과 같은 규칙(가장 가까운 열린 섬)**을 쓰게 바꾸기 | 지금은 모듈이면 무조건 등대섬(0번)을 돌려줍니다. 사용자(김지훈)와 강민서가 이야기해 "모듈도 가장 가까운 섬"으로 정했습니다. 김지훈 코드는 돌려받은 좌표에 놓기만 하므로 이쪽 수정은 없습니다 |

## 요청서와 다르게 정한 것 (2026-10-22 사용자 결정)

| 요청서 항목 | 요청서 내용 | 정한 것 |
|---|---|---|
| 3-1 호출 형태 | `TryCreateGroundModule(moduleId, position, out drop)` | `ModuleInteractionHandler.TryDropCarriedToShore(actorId, wreckPosition)`. 플레이어 쪽은 moduleId를 모르기 때문입니다(보유 기록은 서버 작업대에만 있음). 위치 요청(`IShoreDropLocator`)도 이 함수 안에서 합니다 |
| 3-2 상한 | 해안 모듈도 제작 상한에 포함 | **포함하지 않습니다.** 떨어진 순간부터 같은 레시피를 다시 만들 수 있습니다. 다시 만든 뒤에도 옛 모듈은 주울 수 있고, 등대는 칸이 차 있으면 장착을 거절합니다 |
| 3-3 물속 거절 | 물속이면 줍기 거절 | 게임에 물속 상태가 없어(`PlayerController`는 쓰러짐·배 탑승만 있음) **배 탑승 중 거절**로 대신했습니다. 물속 상태가 생기면 알려 주세요 |

## 결정 3건 답

1. 구조됐는데 뽑힌 모듈 → **장부에서 지웁니다**(해안 생성 안 함).
2. 해안 모듈이 만료되면 → **장부에서 지웁니다**(분해와 같음). 이미 상한에서 빠져 있으므로 다른 처리는 없습니다.
3. `lighthouse-module-decisions.md` 갱신 → **반영했습니다**(존재 기준, 구조 못 받음, 해안의 모듈, 시간 제한, 담당).

시간 제한은 `DebrisConfig` 모듈 값 **기본 120초 가안 그대로** 씁니다.

## 구현된 것 (김지훈)

| 요청 | 구현 |
|---|---|
| 3-1 생성 | `TryDropCarriedToShore`: 위치 요청 → `GroundModule` 생성 → 장부 `OnGround` → `IDebrisTracker.Register(ground, DebrisKind.Module)`. 위치 실패·생성 실패·서비스 없음이면 아무것도 바꾸지 않고 `false`. 모듈이 없으면 `false`라 두 번 불러도 하나만 생깁니다. `slot`은 그 시점 해안 모듈 수입니다 |
| 3-2 장부 | `ModuleState.OnGround = 6` 추가. `ModuleLedger`가 이 상태를 상한 개수에서 뺍니다 |
| 3-3 줍기 | 새 행동 `PickUpModule = 18`(자원 `PickUp` 7과 별도). 1인 1개, 쓰러짐·배 탑승 거절, 서버 거리 검증(라우터 공통). 주운 사람에게만 `OwnCarriedRecipe`로 알립니다 |
| 3-4 만료 | `GroundModule`이 `IExpirableDrop` 구현. 줍기와 만료 중 먼저 온 쪽만 처리합니다. 풀을 쓰지 않고 매번 새로 만들고 지워서 세대 번호가 겹치지 않습니다. 판 종료 때 구독을 정리합니다 |
| 3-5 부식 낙하(JH05) | **이번 범위 아님.** JH05가 아직 없습니다. 해안 생성으로 맞출지는 JH05 설계 때 정합니다 |

`IShoreDropLocator`나 `IDebrisTracker`가 없으면(원격 클라이언트, 월드 맵이 없는 씬) 생성하지 않거나 만료 없이 둡니다.

## 강민서 님이 알아 둘 것

- **JH04 시험판**: JH04TestScene에는 월드 맵이 없어서 `99.Dev/Modules/ShoreDropStub`이 정해 둔 지점으로 `IShoreDropLocator`를 대신하고, `DebrisLifetimeTracker`를 `LocalClock`과 시험 설정(`DebrisConfig_JH04`, 모듈 20초)으로 직접 돌립니다. **진짜 서비스가 이미 등록돼 있으면 건드리지 않습니다.** World 코드는 수정하지 않았습니다.
- **월드 맵 씬 연결**: 모듈 처리기(`ModuleInteractionHandler`)와 월드 맵이 함께 있는 씬이 생기면 김지훈이 메뉴 `Lighthouse/Modules/Set Up Ground Module In Open Scenes`로 프리팹을 연결합니다. 그 씬이 정해지면 알려 주세요.

## 검증 상태

- 확인함: 오프라인 컴파일 오류 0, 장부 단위 점검 8건 통과, 에디터 설정 메뉴 실행(프리팹·씬 연결).
- 아직 안 함: JH04 플레이(M0), 원격 확인(M2), 실제 월드 맵 해안에서 생성. 요청서 6절 검증은 1번 수정과 최명기 연결 뒤 같이 합니다.
