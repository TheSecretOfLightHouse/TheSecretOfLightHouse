# 모듈 운반·배 장착 연결 요청

작성자: 김지훈  
수신자: 최명기  
작성일: 2026-10-21  
목적: 작업대 모듈을 손으로 꺼내 등대·배에 장착하는 김지훈 쪽 코드를 알리고, Player 쪽에 필요한 작업을 요청한다.  
기준: [모듈 운반과 난파·구조 결정](../../../design/lighthouse-module-decisions.md#모듈-운반과-난파구조-2026-10-20-결정), [배 모듈 기획](../../../design/boat-module-decisions.md) 9절.

## 이미 만든 것 (김지훈, 코드 작성·Unity 실행 검증 전)

| 항목 | 내용 |
|---|---|
| 흐름 | 작업대 보관 → `TakeModule`(16, Arg0=레시피 ID)로 손에 듦 → 등대 또는 자기 배에 `InstallModule`(5, Arg0=레시피 ID). `ReturnModule`(17)로 작업대에 되돌림 |
| 한도 | 1인 1개(등대·배 합산). 시민·마피아 모두 꺼낼 수 있음 |
| 보유 표시 | 비공개(2026-10-21 결정). 본인 PC만 `WorkbenchNet.OwnCarriedRecipe`(레시피 ID, 없으면 0)로 안다. 바뀌면 `WorkbenchNet.Changed`. 다른 PC에는 보내지 않는다 |
| 배 레시피 | 101 탐조등(`Searchlight`), 102 대쉬(종류 없음 → 장착 거절), 103 장애물 경보(`DepthAlarm`), 104 선체 안정기(`Stabilizer`). `ModuleRecipe.IsBoatModule`·`BoatModuleType`로 구분. 재료는 기획 9절 시험값, 제작 상한 없음 |
| 배 장착 | 자기 배 탑승 중 배(`BoatController`의 netId)를 대상으로 `InstallModule`을 보내면 `ModuleInteractionHandler`가 손 모듈을 확인하고 `BoatModuleEquipment.TryInstall(player, type)`을 부른다. 성공할 때만 손에서 빠지고, 실패하면 손에 그대로 남는다. `BoatModuleEquipment` 코드는 수정하지 않았다 |
| 난파 | `BoatDurability.Wrecked`(서버)를 구독해 그 배에 장착된 모듈을 장부에서 지운다(레시피 다시 제작 가능). 배 쪽 장착 목록 초기화는 기존 `HandleWrecked` 그대로 |

## 요청 (최명기)

1. **Boat.prefab `InteractionTarget`에 `InstallModule`(5) 허용 추가.** 지금은 `RepairBoat`(10)만 있어 배 장착 요청이 `ActionNotSupported`로 거절된다. 직접 하거나, 동의하면 김지훈이 에디터 메뉴 `Lighthouse/Modules/Allow Module Install On Boat Prefab`로 넣는다.
2. **대쉬 종류 추가.** `BoatModuleType`에 대쉬 값 추가, `IsSupported`에 포함. 값이 정해지면 레시피 102 에셋의 `Boat Module Type`만 바꾸면 된다(김지훈).
3. **모듈 효과.** 대쉬·장애물 경보·선체 안정기 효과(탐조등은 기존). 김지훈 쪽은 종류만 넘긴다.
4. **정식 인벤토리 화면의 모듈 표시와 배 장착 입력.** 손 모듈은 `PlayerInventory` 자원 수량에 넣지 않는다. 화면은 `WorkbenchNet.OwnCarriedRecipe`를 읽어 표시한다. 장착 입력은 위 요청 형식을 보내면 된다. 지금은 JH04 시험 패널(`TowerTestPanel`) 버튼이 대신한다.
5. **구조/미구조 재스폰 처리(기존 결정).** 구조되면 자원·모듈 중 랜덤 1개 소실, 미구조 재스폰 시 전부 떨어뜨림. 손 모듈을 지우는 서버 함수는 `ModuleInteractionHandler.DiscardCarried(actorId)`가 있다. 떨어뜨려 줍는 물건으로 바꾸는 함수는 아직 없으니 호출 시점·형식을 맞추자.

## 아직 정하지 않은 것

- 배 모듈 장착 화면·키(Player 입력 담당).
- 미구조 시 떨어진 모듈 줍는 물건의 형식(김지훈)과 섬 가장자리 위치(강민서).
