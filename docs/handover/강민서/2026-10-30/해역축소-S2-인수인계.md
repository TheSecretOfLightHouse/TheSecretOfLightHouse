## 4. 현재 저장소 상태
커밋·브랜치 변경 없음. 신규: S2 원문, `docs/강민서/2026-10-30/SeaS2/`, 이 인수인계. 갱신: 설계 S2 행, pointer 해역 항목. 게임 C#·씬·SO·프리팹·meta 변경 없음. 기존 Clock/Ocean/Mirror 변경과 WaterF3 등 미추적 파일은 보존한다.

## 5. 검증 현황
에디터 순수 계산 질의 성공(진단 0, 유효 200/200, 고유 138). 시간은 가감속 모델이며 파도·선회·우회·접안 미반영. 실제 Play·4인·성능·UI·수신자 합의 미실행.

## 6. 차단 조건
M1~M6은 에디터 Play 사용 허용 후 시작한다. 시작 전 `editor_status`와 활성 씬을 확인하고 다른 작업의 Play를 임의로 중지하지 않는다. S3는 D1·D2(최소), D5 필요. Final 에셋은 Git 미추적(SVN 공유 대상) — 다른 PC는 지문부터 확인.

## 7. 다음 세션의 첫 행동
1. AGENTS→pointer→설계11절→S0→S1→S2 원문을 읽는다.
2. branch/HEAD/status와 `route-query.cs` 입력(S1 부두 값, 설정 에셋)이 바뀌었는지 확인한다.
3. 사용자가 (a) 실측 또는 (b) D1~D3 결정 후 S3 중 무엇을 요청했는지 따른다.
4. 시작 문구(실측): “해역 설계와 S0~S2 결과를 읽고 S2 실제 항해 측정(M1~M6)만 진행해줘. 에디터 Play 사용 가능 여부를 먼저 확인해줘.”

## 8. 주의
- 표의 시간은 모델이며 실제 항해 시간이 아니다. 목표 수치를 이 문서가 정하지 않았다.
- `IslandPlacement.Radius`는 지도 아이콘 크기로 쓰면 3~5배 크다. 변경하면 `NavigatorRouteMapData`(Player)와 LayoutHash가 영향을 받는다.
- Zone.forward는 진입 방향이 아니다. 직선의 19.8%가 우회 필요(근사). 출발·도착 섬 몸체 차단은 미검사.
- 커밋 적기: docs 제안 `docs: 해역 축소 S2 항해 모델과 지도 계약 초안 추가`. S0·S1·설계 문서 미커밋 상태와 함께 검토, pointer 해역 hunk만, `git add .` 금지. PR은 S4 후(선택적 Draft 안내는 S2 원문 참조).
