# 환경 사운드 할당 인수인계 (2026-11-01)

## 현재 상태

- 코드는 구현됨(미검증). Unity 컴파일과 플레이 확인은 하지 않았다.
- 2026-11-01 갱신: wav 6개를 SVN 체크아웃에서 `Assets/ThirdParty/OceanSound`로 복사하고 `WorldAudio.asset`에 아래 표대로 할당했다(에디터 컴파일 확인, 플레이 청취는 미검증). `_ambienceMixer`는 비어 있다.
- `Assets/ThirdParty/`는 git ignore 대상이라 wav는 커밋에 들어가지 않는다. 다른 기기에서는 SVN 업데이트로 받아야 `WorldAudio.asset`의 클립 참조가 살아난다. 아래 순서의 2~3단계는 SVN으로 받지 못했을 때만 한다.

## 이번에 바꾼 코드 (모두 `Assets/01.Scripts/02.World/Weather/View/`)

| 파일 | 변경 |
|---|---|
| `WorldAudioView.cs` | 로컬 플레이어가 `IsOnBoat`이면 섬 파도(레이어 3)를 0으로 만든다. 섬 파도 음량에 `ShoreVolumeRatio`를 곱한다 |

- 섬 파도는 `WorldIslandAudioZone`이 붙은 생성 섬(등대섬·자원섬)에서만 난다. 특수 섬은 대상이 아니다.
- 항해 바다 소리는 별도 시스템이며 건드리지 않았다.

## 다른 기기에서 연결하는 순서

1. `git pull`로 위 코드 변경을 받는다(이 PC에서 먼저 커밋·푸시 필요).
2. Unity 계정으로 로그인한 뒤 Package Manager > My Assets에서 아래 세 팩을 Download·Import한다. 필요한 wav만 골라도 된다.

| 팩 | 필요한 파일 |
|---|---|
| Ambiences_Sounds | `Ambience_Wind_Intensity_Soft_Loop`, `Ambience_Rain_Intensity_Medium_Loop`, `Ambience_Thunder_One_Every_30_Seconds_Loop` |
| Ultimate SFX Bundle - HD Remaster | `Natural Ambiances Pro - HD Remake/Ambiance_Thunderstorm_01` |
| Gamemaster Audio - Pro Sound Collection | `Animals_Nature_Ambiences/beach_waves_ocean_water_soft_loop_01`, `beach_waves_ocean_water_strong_loop_01` |

3. 쓰는 wav 6개만 `Assets/ThirdParty/OceanSound/`로 복사한다. 복사는 Unity 에디터 안에서 하고 `.meta`도 함께 둔다. 원본 팩 폴더는 프로젝트에 남기지 않거나 SVN에 올리지 않는다.
4. `Assets/01.Scripts/02.World/Weather/Resources/WorldAudio.asset`을 인스펙터에서 열어 아래 표대로 클립을 넣는다.

| 날씨 항목 | 슬롯 | 클립 |
|---|---|---|
| `_calm`, `_overcast` | `_wind` | `Ambience_Wind_Intensity_Soft_Loop` |
| `_rain` | `_rain` | `Ambience_Rain_Intensity_Medium_Loop` |
| `_storm` | `_rain` | `Ambiance_Thunderstorm_01` |
| `_maelstrom` | `_wind` | `Ambience_Thunder_One_Every_30_Seconds_Loop` |
| `_maelstrom` | `_rain` | `Ambiance_Thunderstorm_01` (최후 전투에 비가 올 때만 들린다) |
| `_calm`, `_overcast` | `_shore` | `beach_waves_ocean_water_soft_loop_01` |
| `_rain`, `_storm`, `_maelstrom` | `_shore` | `beach_waves_ocean_water_strong_loop_01` |

- 슬롯 `_sea`는 비워 둔다(항해 바다 소리가 따로 있다).
- `_ambienceMixer`가 비어 있다. 프로젝트의 앰비언스 믹서 그룹이 있으면 연결한다.
- 최후 전투 비 여부는 `WeatherRainView`의 노출값이 `_rain` 레이어를 조절한다. 최후 전투에 비가 오지 않으면 `_maelstrom._rain`만 비운다.

## 확인 방법 (메인 씬 `Main/MainGame.unity`, 플레이 중)

1. 맑음에서 배에 탄 채로 섬에 접근한다. 섬 파도가 들리지 않아야 한다.
2. 하선한다. 해안선 근처에서 파도 소리가 페이드인되고, 섬 안쪽으로 걸어 들어가면 줄어 무음이 돼야 한다.
3. 다시 승선하면 파도 소리가 페이드아웃돼야 한다.
4. 날씨를 비·폭풍우·최후 전투로 바꿔 날씨 소리가 주가 되고 섬 파도가 그 아래에서 섞이는지 듣는다.
5. 파도가 너무 크거나 작으면 `_shoreVolumeRatio`, 안쪽 무음 범위는 `_shoreInlandRatio`로 조절한다.

## 주의

- `Assets/ThirdParty/`는 SVN이다. `OceanSound`는 SVN에 올려야 다른 팀원 환경에서도 소리가 난다. git만 받은 환경에서는 `WorldAudio.asset`이 가리키는 클립이 비어 소리가 나지 않는다.
- 클립 GUID는 기기마다 다르다. 다른 기기에서 에디터로 복사한 `OceanSound` 파일을 쓰고, 이 PC의 `.meta`와 섞지 않는다.
- 하선 판정은 `NetworkClient.localPlayer`의 `PlayerController.IsOnBoat`를 읽기만 한다. Player 영역 코드는 수정하지 않았다.
