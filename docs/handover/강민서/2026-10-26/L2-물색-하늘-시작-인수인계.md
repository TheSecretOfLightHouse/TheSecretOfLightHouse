## 5. 검증 현황

- L1(정적·모델): 파도 데이터 5종, 표류 경사 재계산 통과.
- L2(실행): `WorldSessionGame` 1인 Play에서 파도 6개 적용, Maelstrom 시각, SMAA 비교 캡처. 멀티플레이 등급 M0.

1. [POINTER](../../../강민서/POINTER.md)와 위 근거 문서를 읽고 `git status --short`, `git log --oneline -5`로 HEAD가 `b639a9c7`인지 확인한다.
2. 사용자에게 AI 직접 작성 허용 여부와 해역별 파형 결정(차단 조건)을 확인한다. 답이 없으면 색·투명도 중심으로 진행한다.
3. `WorldSessionGame`을 연 채 Play(퀵스타트는 이 씬을 열어 둔 채로만 동작한다)해 기준 캡처를 남긴다. Game 뷰 렌더 해상도가 작으면(캡처 시 548×454였다) 뷰를 키운다. 날씨는 `WeatherWaveBridge.HandleWeatherChanged`에 `WeatherSnapshot.TryCreate` 결과를 넣어 바꿀 수 있다.
4. L2 계획을 제시하고 확인을 받는다: `ClearOcean.shader`에 수심 그라데이션(터콰이즈→코발트), 투과 광택, 스파클, `OceanOpticsProfile` 낮 팔레트(청록→모아나 터콰이즈 0.1/0.8/0.75 안팎), 낮 하늘 수평선 연보라·구름 형태를 한 세트로. 셰이더가 커지면 `Include/`로 나눈다.
5. 단계 끝마다 같은 장면 캡처로 레퍼런스와 비교하고, 결과를 [L1 결과 문서](../../../강민서/2026-10-26/L1-파형-결과.md) 또는 새 L2 문서에 기록한다.

## 8. 주의

- 되돌리면 안 되는 변경: 기존 미커밋 시각·해안·광학 작업 전체(`WorldSessionGame.unity`, `OceanOpticsProfile`, `OceanShaderBridge` 등), 이번 세션의 L1 데이터·셰이더·AA 변경.
- Unity 에디터 사용: `Tools/World/Quick Start From WorldSessionGame`은 토글이다. MCP 호출 실패가 Error Pause를 걸 수 있으니 `editor_pause`로 해제한다. Play 직후에는 에디터가 바빠 5초 타임아웃이 난다. `eval`은 `using` 없이 전체 이름을 쓴다.
- 다른 사람이 병행 작업 중: `Assets/00.Scenes/Main/`(MainGame), 몬스터·마피아·플레이어 코드는 읽기만 한다. `Boat.prefab`·`ShipPhysicsProfile`은 수정 금지.
- 레퍼런스 이미지는 영화 스틸이라 저장소 밖으로 게시하지 않는다.
- 게임 규칙·난이도 수치에 닿는 변경(날씨 진폭, 표류 계수)은 사용자에게 먼저 묻는다. 발광 연출은 L4이며 플레이어에게 반응하는 물 연출은 만들지 않는다.
