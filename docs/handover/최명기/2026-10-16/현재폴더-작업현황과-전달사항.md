## 4. 현재 저장소 상태
- 최근 로컬 병합 이력: #43 Player, #44 몬스터 애니메이션, #45 월드 시드·해시/준비·시계. 원격 실시간 상태는 미조회.
- 작업 시작부터 있던 변경: E키 작업 원문, 최명기 pointer, 10/15 김지훈 인수인계 미추적 파일. 보존했으며 이번 세션의 신규 성과가 아니다.
- 이번 변경: 기존 조사 원문·반동 원문·pointer 갱신과 이 인수인계 추가. 코드·씬·프리팹·ScriptableObject 수정 없음. 커밋·푸시 없음.
- 현재 체크아웃에서 확인한 사실이며 다른 브랜치·PC에 같은 구성이라고 보장하지 않는다.

## 5. 검증 현황
- L1: 문서/코드 읽기, 호출자 검색, Git 이력·변경 확인. 문서 링크·공백 검사 결과는 조사 원문에 기록.
- L2: 이번 세션 미실행. 기존 픽업 호스트 결과는 픽업 원문 참조.
- L3 / M2·M3: 이번 세션 미실행. 박태욱 기록의 배 연결 검사는 통제된 M1 API 검사이며 실제 원격 돌진 통과가 아니다.
- Unity Editor의 현재 프로젝트·Console·Play 상태는 도구로 확인하지 않았다. 컴파일·빌드·SVN 업데이트도 실행하지 않았다.

## 6. 차단 조건과 전달사항
- 김지훈에게: [10/15 채집·픽업 인수인계](../2026-10-15/김지훈-채집픽업-Interaction-연결.md)를 먼저 읽도록 전달한다. E키 PlayerPickupInput과 PlayerInteractionInput을 동시에 부착하면 중복 요청 위험이 있다. 월드 준비 신호는 이제 코드에 있으므로 과거 '신호 없음' 대신 소비 연결을 확인한다.
- 강민서에게: HarvestSpot 잔량/SpotId·실패 복구 계약과 MapStateNet 준비 범위(레이아웃/콘텐츠 해시 일치와 실제 월드 생성 완료의 관계)를 확인한다. 맵 해시 일치만으로 모든 게임 오브젝트 준비 완료를 단정하지 않는다.
- 박태욱에게: 실제 배 대상·내구도 연결과 반동은 별도 경로다. 원격 탑승→돌진→피해/반동→난파→하선·재탑승을 같이 확인하고 마피아 난파 상태 API 연결을 맞춘다.
- 최명기: 인벤토리 소비·용량, 구조 비용/복귀 상태(W10~W13), 직군 배정, K01·K02 등은 미정/통합 후속이다. 이번 문서가 수치·API 합의나 새 구현 승인이 되지는 않는다.
- 공유 문서 갱신 후보: 기술설계 §6의 VoteService int ID/역할·자기표·잠금 미검사 설명, 시스템 개요 §6의 단절 상태 보존 설명. 최신 코드/결정과 대조해 담당 검토 후 수정한다. 다른 담당자 pointer의 과거 완료·병합 대기 표기도 현재 상태 확정 없이 덮어쓰지 않았다.

## 7. 다음 세션의 첫 행동
1. git status와 이 문서의 기준 커밋을 대조하고, 로비에서 InProgress로 진입하는 2인 시험 환경과 Spawnable Prefabs의 stone 등록을 확인한다.
2. 원격 획득·동시 획득·잘못된 자원/제거된 대상 재요청을 시험하고 서버 수량·본인 수량·양쪽 드롭 제거를 기록한다.
3. 월드 준비 게이트와 본편 채집 계약을 각 담당자와 맞춘 뒤 연결 작업을 나눈다.
4. 몬스터 원격 정지 배 시험과 난파 상태 전달을 확인한다. 이후 단계·승패·HUD 통합을 진행한다.
5. v4의 10/16 정기 4인 시험은 예정 기준이다. 실제 시험 실시 여부와 실패/미검증을 기록한다. 기능 동결 10/25·최종 11/1도 달성 상태와 구분한다.

## 8. 주의
- 현재 채집→드롭→E키 지급 흐름과 서버 결과 판정을 보존한다. 소유 클라이언트 이동 권위를 모든 PC의 중복 물리 실행으로 바꾸지 않는다.
- 기존 사용자 문서 변경을 덮어쓰거나 시험 편의로 공용 Router의 InProgress·거리·송신자 검증을 제거하지 않는다.
- 문서 작성만으로 담당자에게 전달·합의·런타임 검증이 완료되지 않는다. 이 문서는 로컬 전달 자료이며 메시지는 보내지 않았다.
