- 저녁 지도 앞 E 4인 준비→시간제 공동 편집→강제 종료→M 열람을 실제 호스트1+원격3에서 확인한다.
- [결정](../../../design/shared-map-decisions.md) → [작업 원문](../../../최명기/2026-10-30/공유지도-저녁4인-공동편집.md) 순서로 읽는다.

## 4. 현재 저장소 상태
- 기준 커밋 13df7a10. 이번 작업 커밋/푸시 없음.
- 새 SharedMap 코드·설정·문서와 PlayerInteractionInput의 5줄 연결이 미커밋이다.
- 수정/저장한 기존 씬 없음. 설정 에셋은 Unity API 생성: `Assets/02.Prefabs/UI/SharedMap/Resources/SharedMapSettings.asset`.
- 병행 변경 VFX2개·World mesh/shader/material meta3개·Windows Build Profile은 보존했다.

## 5. 검증 현황
- 스타일/그림판 후속: 작업 원문 마지막 절을 읽는다. 기존 UI 스킨 재사용·둥근 래스터 붓·3단계 굵기·즉시 미리 보기·50ms/최대16점 묶음 전송으로 바뀌었다. 묶음/샘플 식별 필드가 추가돼 참가자 모두 같은 변경본이 필요하다. 붓 연속성/묶음 직렬화 및 임시 그림 응답/롤백 검사는 통과했고 실제4인 지연/겹침/장시간 성능은 남았다.
- L1: 컴파일 오류0·최종 신규 콘솔 오류/경고0·해당 diff 공백 확인.
- 격리 기능: 규칙/직렬화80·복원/만료/커서14조건 PASS, 샘플 그림 렌더 확인.
- L2 실제 담당 씬 조작 종단 및 L3/M2~M3 원격 통합: 미실행. 격리 검사로 대체하지 않는다.

## 6. 차단 조건
- [ ] 호스트1+원격3 테스트 환경/인원을 준비한다.
- [ ] 실제 회의 장소를 확인하고 필요하면 World 소유자와 합의해 `SharedMapTable` 앵커를 연결한다.
- [ ] 저녁 준비가 늦어도 편집60초를 보장할지는 후속 결정이다. 현재 Dusk 종료 우선.

## 7. 다음 세션의 첫 행동
1. 기존 미커밋 변경과 원문을 대조하고 MK_MainGame에서 실제 등대섬과 임시 테이블 위치를 확인한다.
2. 네 명 모두 저녁에 3m 안에서 E를 누른다. 중복 E/거리 이탈 후 준비 숫자를 확인한다.
3. 동시 그리기·다른 작성자 선 지우기·만료 강제 닫기·M 읽기 전용·다음 저녁 유지·새 판 초기화를 확인한다.

## 8. 주의
- 항해사 판별 삭제/환영 3D 구현은 승인된 작업으로 확대하지 않는다.
- 본편의 이탈 시 판 종료 규칙은 유지한다. 청크 복원 코드를 본편 재접속 지원 완료로 설명하지 않는다.
- Inspector 설정60초는 최대값이다. Dusk가 먼저 끝나면 더 짧게 종료한다.
- 서버 메모리 저장이며 앱 종료 후 보존하지 않는다. 원격 검증 전 완료(검증됨)로 올리지 않는다.
