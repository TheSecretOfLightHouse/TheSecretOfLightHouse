## 배 모듈 구성

개인 배를 보조하는 제작 장비로 탐조등·대쉬·장애물 경보·선체 안정기 4종을 사용한다. 직군의 전문 능력과 과도하게 겹치지 않도록 관찰·순간 기동·위험 인지·조종 안정에 역할을 나눈다.

4종 구성과 공통 장착·난파 규칙은 확정이다. 아래의 새 사용 방식·효과 수치와 재료 수량은 초기 기획안/시험값이며 최종 밸런스는 아니다.

| 모듈 | 역할·효과 방향 | 상세 사용안 | 1개 제작 재료 — 시험값 |
|---|---|---|---|
| 탐조등 | 전방을 비춰 야간 관찰을 돕는다. 빛은 다른 플레이어에게도 보인다 | 배 전방 고정, 장착 후 자동 점등. 조사 거리35·전체 조사각80도부터 시험 | 유리3 + 철2 |
| 대쉬 | 짧은 시간 전방으로 가속해 위험 회피·접근에 사용한다 | 수동 발동, 0.8초간 평상시 전진 최고속도1.8배, 쿨다운12초부터 시험 | 철3 + 섬유3 |
| 장애물 경보 | 진행 방향의 충돌 위험을 미리 알려 직접 회피하게 한다 | 암초·해안·고정 구조물을 감지해 방향/위험 단계 표시. 충돌 예상2초 이내 주의·1초 이내 위험, 대쉬 중 감지거리 확대안 | 철2 + 유리1 + 수정1 |
| 선체 안정기 | 파도로 생기는 배의 좌우·앞뒤 기울기와 흔들림을 완화한다 | 탑승 조종 중 자동 적용, 같은 파도에서 롤·피치 진폭 약30% 감소 목표 | 나무4 + 철3 + 섬유2 |

### 효과의 경계
- 탐조등은 조명 보조다. 환영 섬의 진위를 알려주거나 자원·몬스터를 자동 탐지하지 않는다.
- 대쉬는 가속안이며 순간이동·무적·장애물 통과·추가 공격 피해는 제공하지 않는다. 취소 조건과 정확한 입력 키는 상세안 검토 후 정한다.
- 장애물 경보는 자동 회피를 하지 않는다. 첫 감지안은 고정 충돌 지형이며 몬스터·다른 배·자원·연속 수심 측정은 포함하지 않는다. 환영 섬의 진위를 간접 노출하지 않도록 범위를 검토한다.
- 선체 안정기는 속도 증가·보호막·직접 피해 감소·자동 수리를 제공하지 않는다. 큰 파도와 환경 위협은 남긴다.

## 제작 방식

등대 모듈과 같은 작업대 제작 흐름을 기준으로 한다.

1. 작업대에서 원하는 배 모듈 레시피를 선택한다.
2. 필요한 재료를 가진 만큼 부분 투입한다. 여러 플레이어가 나눠 채울 수 있고 레시피별 진행도를 따로 둔다.
3. 재료가 모두 채워지면 제작 버튼을 눌러 모듈1개를 즉시 완성한다. 별도 제작 대기시간은 두지 않는 안이다.
4. 완성품은 담당자가 결정한 보관 위치로 보관 또는 지급한다.
5. 자기 배에 탑승해 장착한다. 구체적인 장착 화면·접근 조건은 보관 방식 결정 후 맞춘다.

배 모듈의 전체 제작 개수는 우선 제한 없음으로 시험한다. 등대 모듈의 종류별 전체1개 상한을 배에 그대로 적용하지 않는다. 기존 자원만 사용하고 새로운 재료나 중간 제작품은 추가하지 않는다. 수정이 필요한 장애물 경보의 제작 시점과 등대 재료 경쟁은 실제 수급을 보고 조정한다.

## 공통 장착·난파 규칙

| 항목 | 기획 |
|---|---|
| 대상 | 자기 개인 배 |
| 장착 조건 | 자기 배에 탑승 중일 때 장착, 하선 중 장착 불가 |
| 장착 개수 | 종류별 전용 슬롯1개, 서로 다른 종류는 동시 장착 가능. 현재 최대4종 |
| 중복 | 같은 종류 중복 장착 불가 |
| 완성품 소비 | 장착 성공 시1개 소비, 실패 시 보존 |
| 난파 | 장착 모듈 전부 소실. 배 복구 시 자동 복원·반환 없음 |
| 부식 | 등대 모듈 부식을 배 모듈에 추가하지 않음 |
| 탈착·교체 | 미정. 첫 버전에서 수동 탈착·반환을 제공하지 않는 안이 있으나 확정 아님 |

## 김지훈 결정 필요 — 완성품 보관

**완성품을 작업대에 보관할지, 제작 후 플레이어 개인 인벤토리에 바로 넣을지는 미정이다. 작업대 담당 김지훈이 결정한다.**

| 선택지 | 결정 후 함께 정할 내용 |
|---|---|
| 작업대에 보관 | 공유/제작자 소유 여부, 완성품 선택과 배 장착 방법, 작업대 근접 조건 |
| 플레이어 인벤토리에 바로 지급 | 지급받는 플레이어, 인벤토리 표현·보유 한도, 배에서 장착하는 방법, 난파 시 미장착품 처리 |

현재 어느 쪽도 확정하지 않는다. 작업대 근처에서만 장착한다는 제한이나 개인 운반을 제외한다는 규칙도 확정하지 않는다. 보관 위치 결정 후 최명기와 장착 흐름을 맞춘다.

## 기획 상태

- 배 모듈 종류·기본 규칙과 초기 제작 재료를 전달하는 문서다.
- 효과 상세안·재료 수량·제작 상한은 시험과 후속 검토로 조정한다.
- 구현 요청 목록이나 API 계약서가 아니며 구현 완료·플레이 검증을 뜻하지 않는다.
