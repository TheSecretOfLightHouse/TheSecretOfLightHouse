# 등대 시스템 개요

> 기획 기준: [승패·투표 결정](design/win-vote-decisions.md)(2026-10-10)이 [게임 기획서 v4](design/references/game-design-v4.md)(2026-10-09)와 충돌하는 부분보다 우선한다. 이 문서는 개요이며 세부 규칙은 두 기준 문서에서 관리한다. 미결 항목은 새 결정 문서, v4 13장과 [설계 문제 대장](07-design-issue-register.md)을 본다. 원문의 가안·미정은 임의 확정하지 않는다.

## 1. 프로젝트 정의

PC 3인칭 4인 호스트-클라이언트 마피아 게임이다(Unity 3D·URP, Mirror 서버 권위). 네 명 모두 직군을 가지며 한 명이 마피아를 겸한다. 시민 셋은 메인 등대 활성화를, 마피아는 활성화 저지를 목표로 한다. 한 판 길이는 30~40분이다. 크툴루 신화 분위기의 폭풍우 치는 바다 연출이 가장 중요하다(v4 1장).

## 2. 경험의 중심

- 각자 배로 섬을 오가며 자원을 모으고, 작업대에서 모듈을 만들어 개인 배와 공유 등대에 장착한다.
- 채집 한도는 원본별 공유 잔량이다. 돌 원본 하나는 전원 합계 3회이며, 한 명이 모두 캐면 다른 사람은 더 캘 수 없다. 소진 후 원본 유지와 상세 범위는 [자원 채집 결정](design/resource-gathering-decisions.md)을 따른다(2026-10-22, 코드 전환 전).
- 바다 몬스터·밤·날씨(파도 충격·토네이도)가 파밍을 방해한다. 누가 언제 어디에 있었는지가 추리 단서가 된다.
- 마피아의 우선 목표는 정체를 숨기는 것이다. 괴물 소환은 끝까지 숨은 마피아의 마지막 한 수다.
- 배는 난파되지만 플레이어는 죽지 않는다. 행동 불능이 되어 잔해 위에서 표류하며 조명탄과 비밀 투표만 할 수 있다. 동료가 구조하거나, 일정 시간 뒤 가까운 섬으로 떠밀려 자력 복귀한다(v4 9.1).
- 인게임 보이스·배 무전은 없다. 밤 회의 토론 수단은 v4 13장의 결정 필요 항목이다.

## 3. 배경과 범위

중앙 등대 섬과 매 판 랜덤 배치되는 자원 섬·난파선·특수 기능 섬이 무대다. 해역은 내해 → 중간 해역(전체 일수의 1/3) → 외해(2/3) 순으로 해금되며 잠긴 구역은 폭풍벽으로 막는다(v4 8장). 메인 등대 하나만 사용하고 보조 등대는 삭제됐다. 연료는 10/8 회의에서 삭제됐으나 v4 4.4·8.3 문구에 남아 있어 재도입 여부가 미결이다([V09](07-design-issue-register.md#2-기존-문서와-달라진-규칙)). 결정 전에는 연료 기능을 추가하지 않는다.

## 4. 코어 루프

숨은 단계의 낮·밤 반복 → 파밍·제작·수리와 시민의 비밀 투표(한 판 시민당 2회) → 수리도 100% 후 누구나 등대 상호작용으로 60초 점화 의식 시작 → 의식 결과로 종료하거나, 확인에 성공한 마피아가 소환해 최후 전투로 전환한다. 마피아의 투표·자기 지목·철회는 금지하며 같은 대상 재클릭은 횟수를 차감하지 않는다. 숨은 단계의 게임 기한은 기본 5일이며 설정값으로 조절한다. 숨은 단계에서 기한에 도달하면 마피아 승리로 종료한다. 마지막 날 밤의 정확한 마감 시점은 아직 결정하지 않았다.

의식 시작 시 게임 기한을 정지하고 표 변경을 잠근다. 의식 중에는 모듈 낙하가 발생하지 않으며 마피아의 확인·소환은 가능하다(난파 중에는 불가). 소환 없이 60초를 완료하면 시민 2명 이상이 마피아를 지목한 경우 시민 승리, 그렇지 않으면 기한이 남아 있어도 즉시 마피아 승리로 종료한다. 의식 실패에 따른 심해 게이지 증가나 의식 재시도는 없다.

소환하면 기존 의식 타이머와 게임 기한을 제거하고 최후 전투용 수리 진행도를 0%로 시작한다. 날씨는 해제되지 않는 심연으로 고정된다. 새로운 수리 진행도 100%와 등대 HP 0 중 먼저 도달한 조건으로 각각 시민·마피아 승리를 한 번만 확정한다. 별도 점화나 기한 종료를 기다리지 않으며 등대 괴물은 처치할 수 없다.

등대 최대 HP는 고정 설정값이고, 소환 시 현재 HP는 `기본 HP + (최대 HP − 기본 HP) × 소환 전 수리도 비율`로 환산한다. 전투 중 자원 투입은 새 수리 진행도만 올리며 HP를 회복하거나 최대 HP를 높이지 않는다. 소환 전 획득한 수리 보상은 유지하고 최후 전투 진행도로 새 보상을 지급하지 않는다. 괴물의 힘은 공격력이며, 시민별 투표 유지 시간과 완료된 하루의 심해 충전분을 소환 시 정산하고 최소값을 보장한 뒤 고정한다. 계산·공개 범위는 [새 결정 §6·§7](design/win-vote-decisions.md#6-봉인오투표와-괴물-공격력--r12r13)을 따른다.

게임 기한과 월드 시간은 같은 계약으로 취급하지 않는다. 의식 중 월드 시간 진행, 최후 전투의 일일 효과, 억제한 모듈 낙하의 후속 처리와 같은 시점의 승패 경합은 [설계 문제 대장](07-design-issue-register.md)에서 남은 결정으로 추적한다.

## 5. 시스템 연결

| 시스템 | 연결되는 기능 |
|---|---|
| 플레이어·배 | 이동·승하선·파도 흔들림·내구도·난파·조명탄·구조·직군 능력 |
| 자원·제작 | 개인 인벤토리·작업대 투입/인출 기록·배/등대 모듈·모듈 부식과 표류 회수 |
| 등대 | 숨은 단계 수리도·구간 보상·점화 의식·최후 전투용 수리 진행도·현재/최대 HP |
| 마피아·투표 | 시민 투표 2회 제한·정체 확인과 10초 소환 권리·숨은 방해·비공개 심해 게이지/봉인·소환 시 공격력 고정 |
| 월드 | 낮밤·일차·비율 해금·랜덤 섬·특수 기능 섬·유령선·환영 섬·몬스터 스포너 |
| 날씨·바다 | 날씨 5종(최후 전투 전용 심연 포함)·구름형 안개·폭풍벽·파도 충격·토네이도 |

## 6. 범위와 우선순위

v4 12장의 필수 기능은 유령선, 특수 기능 섬 3종, 최후 전투 전용 날씨, 부식 모듈 표류·회수다. 토네이도는 일반 우선순위, 거대 파도는 여유 우선순위이며 일정이 모자라면 가장 먼저 빠진다. 해상 인양은 v4에 없으므로 범위에 넣지 않는다. 직군 세부·모듈·레시피·구조 비용 등은 v4의 가안·미정 표기를 따른다. 일수·낮밤 길이·귀항 알림·해금 비율은 설정값 한 곳에서 바꾸며 기본값은 5일, 낮 5분·밤 2분이다. 접속 단절 시 캐릭터와 참가자 상태를 보존하는 방향을 우선하며 재접속 기능은 시간 여유가 있을 때 검토한다([새 결정 §8](design/win-vote-decisions.md#8-접속-단절과-재접속--n11n12)). 이 문서에서 수치·직군·기능 범위를 새로 확정하지 않는다.

## 7. 팀과 통합 책임

기능별 담당자·계정·코드 경계는 [담당표](CODE_OWNERSHIP.md)를 따른다. v4 12장에 따라 네트워크 전담 역할은 없고 각 담당자가 자기 기능의 서버 동기화까지 맡는다. 김지훈이 공용 접속과 4인 테스트를 리드한다. 시스템&UI는 최명기가 맡는다. 김민성은 다른 팀에서 온 일시 AX 지원만 맡는다. 작업별 수정할 씬·파일 범위는 [작업 브리프](ai/02_TASK_BRIEF_TEMPLATE.md)에 적고 공유 씬은 동시에 저장하지 않는다.

## 8. 품질과 일정

기존 플레이어 코드와 맵 계약의 파일 상태는 [아키텍처](04-architecture.md), 작업별 검증 조건은 [구현 로드맵](05-implementation-roadmap.md)에 기록한다. 단독 플레이와 호스트·원격 클라이언트 검증을 구별한다. v4 일정은 정기 4인 테스트 10/13·10/16·10/21·10/24·10/26~27, 기능 동결 10/25, 최종 마감 11/1, 마일스톤 M01~M09다. 원본 일정이며 달성 여부는 검증된 사실이 아니다.
