# 마피아 미니판 데모 (CrewMultiplayer 확장)

- 작성일: 2026-10-17
- 위치: SVN `_Demo/Jihun/CrewMultiplayer/` (git 밖). 상세 조작·흐름은 데모 README의 "마피아 미니판" 절
- 성격: 마피아 규칙의 유불리·재미 감을 잡기 위한 시험 데모. 확정 기획 아님

## 왜
마피아 시스템의 유불리가 문서만으로 감이 오지 않는다는 사용자 요청. 같은 날 분석에서 "의식 중에도 확인할 수 있고 투표는 잠기므로, 마피아가 의식 시작 후 확인만 하면 시민의 의식 승리가 사실상 불가능하다"는 가설이 나왔다. 규칙 시뮬레이터(A)·탁상 플레이(B) 전에 직접 해 보는 판(C)을 먼저 만들기로 사용자가 결정했다.

## 결정과 이유
- 투표·확인·소환 권리·심해 게이지는 본편 `07.Mafia` Rules(`VoteService`·`IdentityCheckService`·`AbyssGaugeService`, 박태욱 담당)를 읽기 전용으로 호출. 데모가 규칙을 따로 흉내 내면 실제 코드와 다르게 체감할 수 있어서다. 본편 코드는 수정하지 않았다
- 새 데모 폴더 대신 CrewMultiplayer를 확장. 방·준비·채집·등대 동기화를 다시 만들지 않으려고
- 비교 옵션: 들킴 기준 1/2표(v4 시작값과 현재 코드 기본값의 차이), 의식 중 확인 허용/금지(분석에서 나온 제안안). 제안안은 승인된 규칙이 아니다
- 종료 후 숨은 정보(마피아, 표, 봉인·오투표, 공격력, 시간순 기록)를 전원에게 공개. 감을 잡는 것이 목적이라서
- 축약: 배·몬스터·환영 섬·날씨·부식·유령선 없음. 방해는 등대 자원 빼내기와 상자 삼키기로 대신. 마감은 N일차 밤 끝(K02 미정을 데모에서 임의로 정함). 최후 수리는 기본 자원(본편은 모듈, 결정 미정 4번)

## 실제 검증
- Unity 6000.0.83f1 컴파일 요청 후 Crew 관련 에러·경고 0(콘솔 필터 확인). Mirror Weaver도 같은 컴파일에서 통과한 것으로 봄
- 주의: 컴파일을 요청했을 때 에디터가 JH03TestScene 플레이 모드였다. 도메인 리로드로 그 플레이 세션에서 `PlayerController.FixedUpdate` NRE가 반복됐다(데모 코드와 무관, 리로드 영향으로 추정). 그 뒤 HUD 선택 버튼 버그를 고쳤으며, 이 수정분은 아직 다시 컴파일하지 않았다
- 미실행: 패치 메뉴 실행, 플레이(1인·MPPM 4인), 실제 판 흐름

## 남은 일
1. 플레이 모드 종료 → 재컴파일 확인 → 메뉴 `TheLightHouse/Demo/CrewMultiplayer/Add Mafia Round To Built Scene`
2. 방장 혼자 + 개발자 정보로 흐름 확인 → MPPM 4인 → 팀원 4명 판(의식 중 확인 허용/금지 각각 2판 이상)
3. 판 결과로 A(시뮬레이터)·B(탁상) 필요 범위 결정, 제안안은 박태욱·팀에 공유(결정은 사용자·팀)
4. SVN 커밋(사용자)
