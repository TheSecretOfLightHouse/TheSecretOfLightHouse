## 사용자 결정 (2026-10-17)
- 작업대 구조: 공유 작업대 1개, 진행 레시피 1개, 등대(공유) 모듈 레시피만. 배(개인) 레시피는 배 장착 계약 후.
- 완성 모듈: 장착 전까지 작업대에 보관. 장착(InstallModule)은 후속.
- 레시피 선택: 누구나 가능, 투입이 시작되면 완성까지 변경 잠금.
- `Arg0` = 자원 ID, `Arg1` = 요청 수량. 서버가 남은 필요량 이하로 제한. 김지훈이 정하고 최명기에 통지.
- 레시피 재료 출처: [자원·섬·맵 생성 결정](../../design/world-resource-island-decisions.md) 4장 모듈 후보(미정 제안). 사용자가 루트에 임시로 둔 문서를 `docs/design/`로 옮김.
- 시험 레시피 수량(A안): 기반 프레임 돌5+나무5+철2, 기어 장치 철3+섬유3, 렌즈 모듈 유리3+철2+수정2, 광원 코어 수정3+유리2. 모두 `시험값`.
- 보관: 종류별 보관, 보관 중에도 다음 레시피 시작 가능. 투입 시점: 판 진행 중 낮·밤 모두, 쓰러짐·탑승 중 거절.
- 같은 모듈 반복 제작: "종류별 1개 평생" 아님. 분해되면 다시 만들 수 있어야 함(아래 존재 기준).
- 등대 구조(최종): 1·2·3층에 층별 다른 모듈만 장착. 기본 자원은 등대에 넣지 않고 작업대에서만 사용. 기획 문서 [등대·작업대 모듈 결정](../../design/lighthouse-module-decisions.md) 신설, 충돌 문서(승패·투표 결정 5절, 공용 인벤토리 결정)에 안내 문장 추가, 문제 대장 V11 추가.
- 제작 상한: 레시피별 "현재 존재 개수" 상한(데이터, 0 = 제한 없음). 시험값은 처음 기반 프레임 3·나머지 1로 정했으나, 이후 "층별 다른 모듈" 결정으로 4종 모두 1. 존재 = 서버 모듈 기록이 분해 전인 것(제작 중·보관·장착·표류·건져 든 상태 모두 포함, 부식 여부 무관). 분해될 때만 개수 감소 → 재제작 가능.
- 분해 기준(v4 7.4 "일정 시간 안에 회수 못 하면 분해"의 가안, JH05 구현): 표류 시작 시 서버 타이머 시작, 가안 120초(데이터), 건지면 종료, 다시 표류하면 재시작, 잠긴 구역·폭풍벽 밖으로 밀리면 경계 안쪽으로 복귀. 분해 결과(자원 드롭/완전 소멸)는 미정 유지.
