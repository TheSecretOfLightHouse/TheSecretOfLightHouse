# JH04 등대 시험안 — 8슬롯·차례 장착·등실 재점화

작성일: 2026-10-19
담당: 김지훈
상태: **시험안(확정 아님)**. 사용자 요청으로 [등대·작업대 모듈 결정](../../design/lighthouse-module-decisions.md)에는 기록하지 않고, 플레이로 느낌을 본 뒤 바뀔 것을 전제로 따로 진행한다. 같은 날 다른 세션의 [등대 3층 기획 제안 데모](JH04-등대3층-기획제안-데모.md)(SVN `LighthouseFloors`, 4슬롯·탐조등 고발)와는 별개 안이다.

## 시험안 내용 (2026-10-19 사용자 선택)

| 항목 | 시험안 |
|---|---|
| 등대 구조 | 1·2·3층 + 꼭대기 **등실** |
| 배치 A안(시험 대상) | 1~3층: 각 기반 프레임 + 기어 장치 / 등실: 렌즈 모듈 + 광원 코어. 슬롯 8개 |
| 배치 B안(대안 후보, 기록만) | 1층 프레임 / 2층 프레임 / 3층 프레임+기어 / 등실 렌즈+광원. 슬롯 6개 |
| 장착 순서 | 1층부터 차례대로. 아래층 슬롯이 모두 차야 위층 장착 가능. 같은 층 안의 순서는 자유 |
| 수리도 | 모듈 단위. A안은 1개당 12.5%. 2개 25%(배 이동 속도), 4개 50%(자원 파밍량), 6개 75%(배 대포 피해), 8개 100%(점화 의식 가능) |
| 레시피 존재 상한 | 시험 카탈로그: 기반 프레임 3, 기어 장치 3, 렌즈 1, 광원 코어 1. 기존 카탈로그(각 1)와 JH03 시험은 그대로 |
| 마피아 인출 | 작업대에 넣은 기본 자원만 뺄 수 있다. 완성 모듈(작업대 보관)과 장착 모듈은 뺄 수 없다. 이유: 상한 1인 모듈을 마피아가 들고 있으면 재제작이 막혀 시민이 이길 수 없는 판이 된다. 모듈 방해는 부식(JH05)이 맡는다 |
| 최후 전투 | **등실 재점화**: 소환 시 불이 꺼지고 장착 모듈은 남는다. HP는 확정 R10 환산, 기존 보상 유지. 최후 게이지는 등실에 점화 연료(최후 전용 모듈)를 넣을 때마다 25%, 4개면 시민 승리. 점화 연료 = 심연 결정(소환 뒤 심연 날씨에서만 나옴) + 기본 자원 약간. 미리 모은 기본 자원은 속도를 올리지만 심연 결정은 소환 뒤에만 얻어 최후 전투를 건너뛸 수 없다. 소환 뒤에는 일반 모듈 장착을 닫는다 |

## 이 안을 고른 이유와 남은 위험
- 8슬롯이면 모듈 하나가 12.5%라서 v4 6.1 보상 구간(25·50·75%)과 정확히 맞는다.
- 최후 전투에서 8칸을 다시 채우는 방식(모듈 파손 후 재장착)은 반복 노가다이고, 미리 쟁여 두면 최후 전투가 무의미해진다는 사용자 지적으로 제외했다.
- **밸런스 위험(미해결)**: 수리도와 괴물 공격력이 모두 시간에 따라 오르면 "일찍 소환(HP 낮음·공격력 낮음)"과 "늦게 소환(HP 높음·공격력 높음)"의 버티는 시간이 비슷해질 수 있다. 차이를 만드는 요소는 봉인(정답 투표 유지), 같은 날짜의 수리 속도, 보상, 특수 종료 기준이다. 조정 수단은 기본 HP와 최대 HP의 차이(김지훈), 봉인 효과(박태욱), 점화 연료 개수(김지훈)다. 플레이 테스트에서 경우별로 "버티는 시간 vs 최후 게이지 완료 시간"을 기록한다.
- 확인 성공 기준 코드 기본값은 2표(`IdentityCheckSettings._requiredVoteCount`)로, 의식 성공 조건(2표)과 같다. 최후 전투가 자주 나올 수 있다(박태욱 설정값, 플레이 테스트 때 확인).
- 투표 타이밍 손익을 유저가 알 수 있도록 규칙 안내 UI가 필요하다(최명기·박태욱 전달 후보).

## 구현 단계
1. **1단계(이번)**: 등대 슬롯·차례 장착·수리도·보상 구간, 작업대 보관 모듈 장착, 시험 씬과 개발자 자원 지급.
2. 2단계: 의식 60초(확정 규칙 3·4절), HP 환산(R10)과 박태욱 촉수 HP 연결.
3. 3단계: 등실 재점화(점화 연료·심연 결정). 심연 결정 생성은 강민서 영역이라 우선 시험용 생성으로 대체.

## 2~3단계: 판 하나가 끝까지 돌아가게 (2026-10-19 사용자 요청 "끝까지 돌아가게, 테스트는 나중에")

### 흐름
판 시작(호스트가 마피아 선택) → 낮 시계·기한 5일 → 수리 100% → **점화 의식 60초**(기한 정지, 투표 잠금, 마피아는 확인·소환 가능) → 끝날 때 마피아 지목 시민 2명 이상이면 시민 승리, 아니면 마피아 승리.
마피아 정체 확인 성공 → 10초 안에 소환 → **최후 전투**: HP = 300 + (1000 − 300) × 수리도, 일반 장착 닫힘, 기한 없음, 공격력이 특수 종료 기준(100) 이상이면 즉시 마피아 승리. 아니면 심연 결정 6곳 등장 → 시민이 주워 등실에서 점화(결정 1 + 철 1 + 유리 1) 4번이면 시민 승리, HP 0이면 마피아 승리. 기한 5일 끝 → 마피아 승리.

### 시험용 단순화 (본편 결정 아님)
- 심연 결정은 공용 자원 카탈로그(강민서)에 넣지 않고 등대가 사람별 개수를 센다. 점화 연료 제작은 등실 점화 행동에 합쳤다.
- 박태욱 `BossTestEnvironment`는 HP가 고정 설정값이라 R10 환산을 넣을 수 없어 쓰지 않았다. HP는 등대가 갖고, 피해는 시험 대역이 넣는다. 촉수 연출 없음.
- 역할 배정·날짜·기한·최종 결과 확정은 시험 연결 코드가 한다(본편은 MK06·World 시계).
- 들킨 마피아의 인벤토리·직군 비활성은 없다. 결정 줍기·점화만 막는다. 보상 효과(속도 등)는 표시만 한다.
- 혼자면 "무작위"로 시작 시 마피아 없이 시민으로 한다(투표 꺼짐). 의식은 표가 없어 항상 실패한다.
- 의식 성공 2표는 확정 규칙 그대로라 2인 시험에서는 항상 실패한다. 2인으로 의식 성공을 보려면 설정 에셋의 `_ritualRequiredVotes`를 1로 바꾼다.

## 실행 방법
1. `Assets/00.Scenes/Jihun/JH04Offline.unity`를 열고 Play(게임 씬을 바로 Play하면 네트워크가 시작되지 않는다).
2. 첫 화면에서 호스트 시작 → 로비에서 준비. 시작 인원이 1이라 호스트가 준비하는 순간 시작되므로, 여럿이면 모두 들어와 준비한 뒤 호스트가 마지막에 준비한다.
3. 가운데 위 "판 진행" 패널에서 판 시작(마피아 무작위 / 내가 마피아 / 다른 사람이 마피아).
4. 오른쪽 위 "개발자: 자원 받기" → "전부 받기"(누를 때마다 각 10개).
5. 왼쪽 작업대 패널에서 레시피 투입·제작 → 등대 근처로 가서 오른쪽 등대 패널에서 "장착"(서버가 고를 칸만 버튼이 켜짐).
6. 100%면 판 진행 패널의 "점화 의식 시작". 마피아는 판 진행 패널의 정체 확인·괴물 소환. 최후 전투에서는 보라색 결정 근처로 가서 "가까운 심연 결정 줍기", 등대 근처에서 "등실 점화".
7. 개발자 버튼: "다음 날로"(기한·심해 아침 정산 확인), "소환 강제"(정체 확인 없이 최후 전투).
