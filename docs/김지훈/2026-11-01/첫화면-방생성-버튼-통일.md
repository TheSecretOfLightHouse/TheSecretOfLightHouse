## 요청과 목표
- 첫 화면의 노란 방 생성 버튼을 아래 방 참가 버튼과 같은 디자인으로 변경한다.

## 진행 과정과 결정 이유
- 메뉴의 두 버튼은 서로 다른 배경 스프라이트를 사용했다. Unity 프리팹 API로 첫 화면 `Title/Menu/CreateButton`에 참가 버튼의 배경과 크기를 적용하고, 라벨을 참가 버튼과 같은 폰트·색상의 텍스트로 바꿨다. 문구는 방 생성으로 유지했다.
- 기존 타이틀 로고와 메뉴 음악 등 미커밋 변경을 보존했다. 방 입력 패널의 생성 버튼은 요청 대상이 아니므로 유지했다.
- 접속·로비의 N12·N13은 이 외형 변경과 무관하며 확인한 범위에서 게임 규칙 충돌은 없다.

## 변경 파일과 결과
- `Assets/02.Prefabs/UI/Session/SessionEntryScreen.prefab`: 첫 화면 버튼 배경·크기·라벨 변경.

## 검증
- Unity 에디터 API로 저장 후 두 메뉴 버튼의 스프라이트, 크기, 폰트, 폰트 크기, 색상 일치를 확인했다. 문구는 각각 방 생성·방 참가다.
- 격리 렌더를 시도했으나 UI가 보이지 않아 시각 검증으로 인정하지 않았다. 실제 플레이·클릭 및 마우스 오버는 미확인이다. 기존 씬에 미저장 변경이 있어 씬 저장이나 플레이 전환은 하지 않았다.

## 남은 일과 차단 조건
- MainOffline에서 시각 표시와 버튼 클릭·하이라이트 확인. 별도 기능 차단 조건 없음.
