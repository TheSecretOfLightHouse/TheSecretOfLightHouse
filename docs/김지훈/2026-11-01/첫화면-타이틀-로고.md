# 첫 화면 타이틀 로고 배치

작성일: 2026-11-01

## 요청
첫 화면(MainOffline) 중앙보다 조금 위에 "THE SECRET OF LIGHTHOUSE" 로고를 놓고, 방 생성·방 참가를 누르면 꺼졌다가 메인으로 돌아오면 다시 켜지게 한다.

## 수행
- 사용자가 준 로고 PNG(2172×724, 알파 있음)를 `Assets/03.Images/SessionUi/TitleLogo.png`로 복사, Sprite·밉맵 끔·최대 4096으로 임포트.
- `SessionEntryScreen.prefab`의 `Title/Menu` 첫 자식으로 `TitleLogo`(Image, 비율 유지, 레이캐스트 끔) 추가. 중앙 앵커, 위치 (0, 240), 크기 1200×400.

## 결정 이유
- 코드 수정 없이 `Title/Menu` 아래에 둔다. `SessionTitleView.OpenEntry`가 방 생성·참가 버튼에서 `_menu`를 끄고, `ShowMenu`(뒤로·Esc, `OnEnable`)가 다시 켠다. 로비·로딩·인게임에서는 `SessionScreen`이 `Title` 전체를 끈다. 그래서 로고는 메뉴 버튼과 같은 시점에만 보인다.
- y 200은 로고 아래 끝이 등대 불빛과 겹쳐 240으로 올렸다.

## 검증
- 실행: 프리팹 인스턴스를 1920×1080 카메라로 렌더해 메뉴 상태 화면 확인(y 200 기준), Unity 콘솔 error 0.
- 미실행: 플레이 모드에서 방 생성·참가 클릭 → 로고 꺼짐, 뒤로·로비 나가기 → 로고 켜짐. 다른 해상도 비율.
