# 유령선 등장 사운드
작성일: 2026-11-01

## 요청
유령선이 나올 때 `freesound_community-haunted-ghost-ship-77461`과 `638914__lennartgreen__low-rumble-loopable-ambiance`를 동시에 재생하고, 다 떠오르면 `floraphonic-fog-horn-3-183969`를 재생. 최명기의 SoundManager를 사용.

## 결정
- 클립 길이(Unity 측정): 유령선 소리 58.66초, 럼블 59.75초, 무적 5.11초. 본편 `GhostShipConfig`는 떠오름 7초·배회 25초·가라앉음 7초라 그대로 두면 배가 사라진 뒤 약 20초 더 들린다.
- 사용자 선택(2026-11-01): SoundManager에 특정 클립만 멈추는 `StopEffect(AudioClip)`을 추가하고, 가라앉기 시작(또는 Hidden)하면 두 앰비언스를 멈춘다. 기존 SoundManager 동작은 바뀌지 않는다(메서드 추가만).
- 재생 시점: `GhostShipPhase.Rising` 진입에 앰비언스 2개, `Rising → Roaming` 전환에 무적 1회. 늦게 들어온 클라이언트가 이미 배회 중인 배를 처음 받을 때는 무적을 울리지 않는다(직전 단계 기준).
- 2D(`PlayEffect`)로 모두에게 같은 크기로 재생한다. 유령선 출현은 판 전체 이벤트라 거리 감쇠를 두지 않았다. 볼륨은 각 1.0.

## 2026-11-01 후속: 볼륨 감소·가라앉을 때 서서히 줄이기
- 요청: 유령선 소리 전체 0.9배, 무적은 더 작게. 가라앉기 시작할 때 바로 끊지 말고 대각선으로 내려가며 서서히 줄이다가 배가 완전히 안 보일 때 멈춤.
- 볼륨: 유령선 소리 0.9, 럼블 0.9, 무적 0.5(사용자가 "좀 더"라고만 해 0.5로 정함). 코드 기본값과 `GhostShip.prefab` 저장값 모두 변경. 씬 오버라이드 없음.
- 줄이는 방식: `Sinking` 진입부터 매 프레임 `1 - 깊이 / _hideDepth`(현재 10)로 두 앰비언스 볼륨을 곱한다. 배가 숨는 깊이(`_hideDepth`)와 같은 기준이라 안 보이는 순간 0이 되어 정지한다. 파도로 선체가 잠깐 올라와도 다시 커지지 않게 최솟값만 유지. `Hidden` 신호가 먼저 와도 정지.
- SoundManager에 `SetPlayingEffectVolume(AudioClip, float)` 추가(재생 중인 해당 클립의 볼륨만 변경, 추가만 하는 변경). 최명기 알림 대상에 포함.
- 검증: 재컴파일 후 새 메서드 반영과 프리팹 값(0.9/0.9/0.5, hideDepth 10) 확인. 실제 청취·원격 미검증.

## 2026-11-01 후속 2: 배에 붙인 3D 소리
- 요청: 거리와 상관없이 전체에 들리지 말고 유령선 오브젝트에서 나서 멀면 안 들리게.
- SoundManager 효과음 칸은 재생 시작 위치에 고정되고 거리 범위(2~40m)가 모든 칸에 공통이라 움직이는 큰 배에 맞지 않는다. `GhostShipView`가 Awake에 배 루트(움직이고 숨지 않음, `_visualRoot`가 숨는 쪽)의 자식으로 AudioSource 3개(HauntAudio·RumbleAudio·HornAudio)를 만들어 직접 재생한다. 런타임 생성이라 프리팹 계층은 바뀌지 않는다.
- 감쇠: 선형, 앰비언스 15m까지 최대 → 90m에서 무음, 무적 20m → 150m(배회 반경 55~118m, 배 길이 약 28m 기준으로 정함). 인스펙터 값으로 조정 가능.
- 볼륨 설정: 매 프레임 `SoundManager`의 `MasterVolume × EffectVolume`(음소거면 0)을 곱한다. SoundManager가 없으면 프리팹으로 만든다. 출력 믹서 그룹은 SoundManager 프리팹에서 비어 있어 따로 두지 않았다.
- 가라앉을 때 깊이에 따른 감소·숨으면 정지는 그대로 유지(이제 자체 AudioSource 볼륨으로 적용).
- SoundManager의 `SetPlayingEffectVolume`은 쓰는 곳이 없어져 제거. `StopEffect`는 작업대 투입 사운드가 써서 유지.
- 검증: 재컴파일 후 새 메서드 반영·`SetPlayingEffectVolume` 제거·뷰가 프리팹 루트에 있음 확인. 실제 청취(거리감, 원격 클라이언트, 리스너 위치) 미검증.
