# T34 해안 모듈(난파 잔해) — 상호작용 쪽 구현

작성일: 2026-10-22 · 담당: 김지훈 · 상태: 코드 작성, 오프라인 컴파일·장부 단위 점검 통과, 사용자가 설정 메뉴 2개 실행·씬 저장. 플레이 미실행, 미커밋

## 요청과 범위
- 강민서 PR #80(develop 병합, 2026-10-22)이 난파 잔해를 바다 표류에서 **섬 해안 생성**으로 바꾸고 해안 위치(`IShoreDropLocator`)·만료 타이머(`IDebrisTracker`)를 서버 서비스로 넣었다. 강민서가 개인 문서 `T34_상호작용_전달문.md`(git 제외, 사용자에게 복사로 전달)로 모듈 쪽 구현을 요청했다.
- 이번 범위: 해안 모듈 아이템 생성·줍기·만료, 장부 상태, JH04 시험 대체 서비스. 최명기의 구조/재스폰 처리 연결과 강민서 위치 서비스 수정은 범위 밖.

## 사용자 결정 (2026-10-22, 이 대화)
1. 구조됐는데 모듈이 뽑히면 **지운다**(기존 41행 유지). 이미 있는 `DiscardCarried`를 쓴다.
2. 해안에 떨어진 모듈은 **떨어진 시점부터 제작 상한에서 빠진다**(만료 때가 아니라). 다시 만든 뒤 옛 모듈을 **주울 수 있다**. 등대는 칸이 차 있으면 거절하고, 작업대 되돌려놓기는 허용(A안). 일부러 난파해 예비를 모으는 길이 생기는 점은 사용자가 감수.
3. 시간 제한 **기본 120초 가안**(World `DebrisConfig`).
4. 모듈도 자원처럼 **가장 가까운 섬 해안**으로 간다(사용자가 강민서와 이야기함). 현재 강민서 코드(`ShoreIslandSelector`)는 모듈을 항상 등대섬(0번)으로 보내므로 **강민서가 수정**한다. 지훈 코드는 받은 좌표에 놓기만 해서 영향 없음.
- 물속 거절: 게임에 물속 상태가 없어(`PlayerController`에 `IsDowned`·`IsOnBoat`만 있음) 배 탑승 거절로 대신했다. 사용자 명시 답 없음 — 추천안으로 진행했다고 알림.

## 구현 전 코드 확인 (근거)
- E키는 선택된 대상의 `InteractionTarget.DefaultAction`을 보낸다(`InteractionSelector.cs:66`). 새 행동도 최명기 입력 수정 없이 동작. 선택은 거리와 `Interaction` 레이어(3번) 기준.
- 라우터는 행동당 처리기 하나(`InteractionRouter.cs:19`), `PickUp`(7)은 최명기 자원 줍기가 사용 → 새 `PickUpModule`(18). 14·15는 재사용 금지.
- 라우터 공통 검사: 참가자·진행 단계·번호·대상·지원 행동·서버 거리. 쓰러짐·탑승은 `ModuleInteractionHandler.Handle`이 검사.
- 보유 기록은 작업대별(`WorkbenchNet._carriedModules`)이고 본인 알림도 작업대가 보낸다. 기존 모듈을 손에 넣는 API가 없어 추가.
- 장부 개수는 생성 +1·삭제 −1만 하고 상태 변경에 반응하지 않았다 → 상태별로 세도록 수정. 상한 검사 호출은 `WorkbenchNet.cs:195` 한 곳.
- JH04TestScene에는 `GameClock`·`DebrisWorldHost`·맵이 없다 → 시험용 대체 서비스 필요. `WorldServices.Register`는 public.
- 네트워크 생성 프리팹은 `NetworkManager.spawnPrefabs`에 있어야 한다. JH04의 매니저는 JH04Offline 씬에 있다.

## 계약 (최명기 연결용)
- 구조됨 + 모듈 뽑힘 → `DiscardCarried(actorId)`.
- 구조 못 받음 → `TryDropCarriedToShore(actorId, wreckPosition)`. 위치 서비스 없음·위치 실패·생성 실패면 아무것도 바꾸지 않고 `false`(모듈은 손에 남음 → 재시도 가능). 들고 있는 모듈이 없으면 `false`라 중복 생성 없음.
- 슬롯은 현재 해안 모듈 수로 넘겨 같은 해안에서 겹치지 않게 했다.
- World 타이머가 없으면 해안 모듈은 줍기 전까지 남는다.

- Unity 번들 Roslyn으로 `Lighthouse.Runtime`(디스크의 런타임 .cs 548개)과 `Lighthouse.Workbench.Editor` 오프라인 컴파일: 오류 0. 결과 DLL에 새 타입·메서드 포함 확인. Mirror Weaver는 돌지 않았다(에디터 컴파일에서 확인 필요).
- 장부 단위 점검 8건 PASS: 운반 중 계산, 해안 시 상한 제외, 재제작, 상한 넘어 줍기, 해안 중복 전이, 만료 삭제, 일반 삭제, 이중 삭제.
- 이후 사용자가 에디터에서 메뉴 2개 실행: 로그 "1 module handler(s) and 1 network manager(s)", "Added ShoreDropStub with 3 shore points". 에디터 컴파일 오류 없음.
- `HasCarried` 추가 뒤 오프라인 재컴파일 오류 0.
- 미실행: M0 플레이, M2, 실제 맵 해안.
