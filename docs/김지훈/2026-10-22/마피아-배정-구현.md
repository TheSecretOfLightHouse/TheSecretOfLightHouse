# 마피아 배정 구현 (2026-10-22)

## 배경과 결정 이유

- 마피아/시민 구분 코드는 박태욱 투표·확인·심해가 `InitializeVoting(roster, mafiaActorId)`로 받기만 하고, 정하는 코드는 `99.Dev` 시험 코드뿐이었다. `08.Systems`·`09.UI`에는 C# 파일이 없다. 직군 배정도 미구현이다(`PlayerAbilityKind`에 `None`만 있음).
- 문서상 직군 배정·시스템&UI는 최명기 확정이지만, 마피아 배정은 입력(`MatchStarted` 명단·ActorId·연결)과 비밀 전달이 모두 김지훈 세션 코드 안에 있어 김지훈이 맡는 편이 다른 사람 코드를 덜 건드린다고 판단했다(사용자와 검토). 직군 정의·적용은 최명기에 남긴다.
- 사람 식별자는 ActorId로 통일하자고 제안한다. 바다 소환(박태욱, develop)은 netId를 쓰는데, 플레이어 객체는 판마다 새로 생겨 netId가 바뀌기 때문이다.
- 2026-10-22 최명기·박태욱 합의 완료(사용자가 직접 받음). 요청 문서: [최명기·박태욱 합의 요청](../../handover/김지훈/2026-10-22/최명기-박태욱-마피아배정-합의요청.md).
