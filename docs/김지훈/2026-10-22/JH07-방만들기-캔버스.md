# JH04Offline 첫 화면 교체 — "방 만들기" 시안 적용

작성일: 2026-10-22 · 담당: 김지훈 · 상태: 프리팹 적용, 1인 플레이(M0) 확인. 미커밋

## 요청과 범위
- 사용자 요청: 제공한 "방 만들기" 시안(1672×941)을 아틀라스로 잘라 방 생성 UI Canvas를 만든다. 이후 "JH04Offline 기존 UI 캔버스를 아예 바꾸라"고 범위를 바로잡음.
- 처음에는 별도 씬 `JH07CreateRoom.unity`에 화면만 만들었으나(기능 없음) 요청과 달라 삭제했다. 이어서 첫 화면 앞에 "방 만들기 단계"를 끼우는 코드(`SessionCreateRoomView`)도 작성했다가, 교체 지시에 맞지 않아 되돌렸다.
- 시안에는 참가(주소 입력)가 없다. 그대로 바꾸면 원격 참가가 불가능해서 사용자에게 물었고, **시안 패널 안에 주소칸을 추가**하기로 했다(사용자 선택).

## 결정과 이유
- JH04Offline은 `Assets/02.Prefabs/UI/Session/SessionScreen.prefab`(틀 버전)을 쓴다. 씬 override는 RectTransform 위치뿐이라 프리팹을 직접 고쳤다. **같은 프리팹을 쓰는 JH07Offline 첫 화면도 같이 바뀐다.**
- 교체 내용(`Title`): 기존 Panel·우상단 QuitButton 삭제 → 시안 패널. `SessionTitleView` 참조를 다시 연결했다. 런타임 코드는 그대로다.
  - `_host` = [방 생성], `_quit` = [뒤로](기존 종료 확인 대화창), `_join`/`_joinLabel` = 새 [참가하기] 버튼과 Text(연결 중 "연결 취소"로 바뀜), `_address` = 새 주소칸(마지막 주소 PlayerPrefs 유지), `_status` = 패널 아래 상태 문구.
  - 시안의 안내문("방을 만든 뒤…")과 가로줄은 주소칸 자리를 만들려고 뺐다. 플레이 인원 줄은 한 줄로 줄였다(아이콘 0.75배).
  - 닉네임 칸은 표시만 한다. 이름 동기화 기능이 없어 로비 이름은 여전히 `플레이어 {ActorId}`.
- 배경 `Background/Sea`(RawImage)를 시안 배경으로 바꿨다. 로비·로딩에도 같은 배경이 쓰인다.
- `SessionScreen.HandleEscape`: 첫 화면에서 Esc → 종료 확인(`HandleQuit`). 시안의 "Esc 뒤로" 안내와 [뒤로] 버튼이 같은 동작이다.
- 고정 글자(제목·부제·라벨·버튼 글자·`4명`)는 시안 글씨를 투명 스프라이트로 뽑았다(한글 폰트 에셋 없음). 새로 넣은 "호스트 주소"·"참가하기"·입력 글자는 레거시 Text이며 실행 시 `_useOsFont`로 맑은 고딕이 된다.
- 슬라이스: 시안을 1920×1080으로 확대한 뒤 잘랐다(Canvas 좌표 1:1). 패널 안쪽은 행·열 테두리 스캔으로 정하고 글자·아이콘을 지운 뒤 주변색으로 채웠다(처음엔 flood가 Esc 틈으로 새서 안쪽이 투명해지고 원래 글자가 남는 결함이 있었음). 입력칸·버튼은 9-slice 30px. 리니어 색 공간에서 보이는 낮은 알파 노이즈는 강한 획 3px 밖에서 0으로 잘랐다. 가공 스크립트는 세션 scratchpad에서 실행했다.
- 텍스처 임포트·프리팹 수정은 Unity MCP 에디터 API로 했고 YAML은 직접 편집하지 않았다.

## 2026-10-22 갱신: 선원 대기실(Lobby) 시안 적용
- 사용자 요청: 대기실도 제공 시안(선원 대기실, 1672×941)에 맞게 Canvas를 구성하고 기능을 연결.
- 구성: `SessionScreen.prefab`의 `Lobby` 자식을 모두 지우고 다시 만들었다(`SessionLobbyView`는 유지).
  - 전용 배경 `Lobby/Background`(시안에서 패널·제목·Esc 안내를 지운 이미지)가 공용 `Background/Sea`를 덮는다. 방 만들기 배경은 가운데가 흐리게 메워져 있어서 대기실 제목 뒤로 비쳤기 때문이다.
  - 제목·부제·로고, 왼쪽(로고, 접속 주소+[주소 복사]=`_hostAddress` 그룹(호스트만), 승선 인원 `n / 필요`, 작은 선원 아이콘, [방 닫기/나가기]), 오른쪽(함께할 선원+"선원 n명 승선", 카드 4장, 밧줄, `준비 r / c`, 준비 원 4개, 안내문, [준비하기/준비 취소]), 아래 Esc 나가기, 위쪽 오른쪽 승선·하선 알림, 핑.
  - 카드: 틀(일반/빈 자리 점선 교체), 나 강조(금색 틀), 방장 왕관, 아바타(빈 자리는 기존 코드대로 반투명), 이름, 상태 점(대기=노랑 점, 준비=초록 체크)과 문구.
  - 준비 취소 스프라이트는 노란 버튼을 점토색으로 바꿔 같은 어두운 글자가 읽히게 했다.
- 코드(선택 필드만, 비어 있으면 기존 동작):
  - `SessionLobbySlot`: `_frame`·`_frameSprite`·`_emptyFrameSprite`(빈 자리 틀 교체), `_emptyState`(빈 자리 문구, 이 프리팹은 "선원을 기다리는 중"). 빈 자리 상태 색은 `_emptyColor`.
  - `SessionLobbyView`: `_pipEmptySprite`(빈 자리 원을 흐린 원 대신 빈 원으로), `_crewCount`(`n / 필요`), `_crewSummary`("선원 n명 승선"), `_crewIcons`+`_crewIconJoined/_crewIconEmpty`. 필요 인원 밖의 아이콘·원은 숨김.
  - `SessionScreen.HandleEscape`: 로비에서 Esc → `HandleLeaveLobby`(호스트는 방 닫기 확인, 참가자는 바로 나감 — 버튼과 같음).
- 파일: `Assets/03.Images/SessionUi/Lobby/LobbyAtlas.png`(2048², 조각 32개 `Lobby_*`), `LobbyBackground.png`(1920×1080).
- 검증(M0, 에디터 1인 JH04Offline 플레이): [방 생성] → 대기실 표시(주소 172.30.1.51, 1 / 1, 방장 왕관, 대기 중, 빈 자리 점선 카드 3장, 준비 0 / 1) → [준비하기] 클릭 → 출항 로딩 진입. 플레이어 생성 전 "입장 중…" 상태도 화면 확인. 컴파일·콘솔 오류 0.
- 미실행: 원격 참가자 화면(주소 그룹 숨김, 카드 2~4 채움, 핑), 2~4인 M2, 준비 취소 스프라이트 표시(1인은 바로 출항), Esc 실제 키.
- 남은 일: 로딩·대화창도 같은 톤으로 바꿀지, 로딩 배경(방 만들기 배경의 흐린 가운데) 처리.

## 추가 수정 (2026-10-22, 사용자 보고 2건)

- 입력칸 커서가 클라이언트 창에서 안 보임 → 원인: `SessionScreen.prefab` Nickname·Address 입력칸 `caretWidth` 1px이라 작은 창에서 캔버스 축소 시 사라짐. 프리팹 에디터 API로 두 칸 모두 3px로 변경(씬 재정의 없음 확인).
- 대기실 승선 인원이 `4 / 1`로 표시 → 원인: JH04Offline `_startPlayerCount` 1(혼자 시험용)을 분모로 씀. `SessionLobbyView.ShowCrew`가 분모·승선 아이콘 수를 배 좌석 `MaxPlayers`(4)로 쓰도록 변경. 준비 원(pip)·안내 문구는 기존대로 출항 기준 인원 사용.
- 검증: 플레이 중 닉네임 칸 포커스 + 커서 4px 임시 적용 화면 캡처로 커서 표시 확인(M0). 스크립트 재컴파일·원격 클라이언트 창 실제 확인·대기실 표시 확인은 미실행(에디터 플레이 중이라 컴파일 대기).

## 닉네임 연결 (2026-10-22, 사용자 보고: 입력한 닉네임 대신 "플레이어 n" 표시)

- 원인: 프리팹 `Title/Panel/Nickname` 입력칸이 어떤 코드에도 연결되지 않았음.
- `LobbyPlayer`: `[SyncVar] _nickname`, `LocalNickname`(첫 화면 입력값, static), `OnStartLocalPlayer`에서 `CmdSetNickname` 항상 전송. 서버가 제어 문자 제거·Trim·12자(`MaxNicknameLength`) 제한, 비면 `플레이어 {ActorId}`로 채움. `DisplayName`·`HasNickname` 공개.
- `SessionTitleView`: 선택 필드 `_nickname`·`Nickname` 속성, 글자 수 제한 설정, 연결 중 비활성. `SessionScreen`: PlayerPrefs `Lighthouse.Session.Nickname` 복원, [방 생성]·[참가하기] 때 저장·`LocalNickname` 지정.
- `SessionLobbySlot`: 카드 이름에 `DisplayName`. `SessionLobbyView`: 이름 변경 시 다시 그림, 승선 알림은 이름이 도착한 뒤에 띄우고 하선 알림은 마지막 이름 사용.
- 범위 밖(그대로 "플레이어 n"): 판 종료 사유 문구(`SessionEndText`, 로비 플레이어가 이미 사라진 뒤), 게임 씬 안 이름 표시.
- 검증: 스크립트 컴파일 오류 0(Editor.log에 error CS 없음). **프리팹 `SessionTitleView._nickname` 연결 미완료** — 컴파일 뒤 Unity MCP 응답 없음. 플레이·M2 미실행.
