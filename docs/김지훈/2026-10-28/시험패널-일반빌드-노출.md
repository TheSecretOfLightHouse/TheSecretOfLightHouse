# 시험 OnGUI 패널 일반 빌드 노출

작성일: 2026-10-28
담당: 김지훈(Network·Interaction·Lighthouse)

## 배경

- JH04 3인 시험용으로 일반 빌드(Development 끔)를 했더니 OnGUI 시험 패널이 하나도 뜨지 않았다. 작업대 선반과 화면 UI도 동시에 보였다.
- 원인: `99.Dev` 패널 파일 전체가 `#if UNITY_EDITOR || DEVELOPMENT_BUILD`로 감싸져 있었다. 선반/화면 전환을 하는 `TowerTrialPanel`도 빠져서 씬에 있던 두 UI가 모두 켜진 채로 남았다.
- 사용자 결정: 다른 개발자가 일반 빌드를 해도 패널이 나와야 한다(패널이 없는 줄 오해하지 않도록). 범위는 김지훈 작성 파일로 한정한다.

## 변경

`Assets/01.Scripts/99.Dev/` 아래 9개 파일에서 첫 줄 `#if UNITY_EDITOR || DEVELOPMENT_BUILD`와 마지막 줄 `#endif`만 삭제했다. 본문은 그대로다.

- `DevPanelSwitch.cs`, `Modules/ShoreDropStub.cs`, `Network/OwnRoleOverlay.cs`, `Network/SessionTestPanel.cs`
- `Tower/DevResourceGrant.cs`, `Tower/TowerTestPanel.cs`, `Tower/TowerTrialPanel.cs`, `Tower/TowerTrialRound.cs`(`TowerTrialPanel`이 참조)
- `Workbench/WorkbenchTestPanel.cs`

그대로 둔 것:
- 박태욱 작성 `Voting/VotingTestPanel.cs`·`VotingTestPlayer.cs`: 사용자 지시로 제외했다. 박태욱 합의가 필요하다.
- 화면 표시가 없는 자동화·프로브 스크립트, `LighthouseNetworkManager`·`InteractionRelay`의 시험용 API, `MockServicesInstaller`
- `InventoryDebugPanel`의 `Debug.isDebugBuild` 차감 테스트 부분(최명기 담당)

## 검증

- 실행함: 에디터 컴파일 에러 0. 일반 빌드(`BuildOptions.None`, 씬 `JH04Offline`→`JH07Lobby`→`JH04TestScene`, 출력 `Builds/JH04/TheSecretOfLightHouse.exe`) 성공. 이로써 9개 파일이 개발 심볼 없이도 컴파일되는 것을 확인했다. 창 3개를 띄웠고 시작 로그에 Exception·error가 없다.
- 미실행: 패널이 실제 화면에 보이는지와 선반/화면 전환 동작은 사용자가 3인 시험에서 직접 확인한다. JH04 이동 M0·M2도 미실행이다.
- 빌드 설정(`EditorBuildSettings`)은 바꾸지 않았다.
