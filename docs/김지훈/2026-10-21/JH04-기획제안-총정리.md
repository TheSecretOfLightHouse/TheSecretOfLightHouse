## 2. 출발점 — 사용자가 짚은 문제

모든 제안은 아래 문제에 대한 답이다(사용자 메모와 각 원문의 요청 절).

| 문제 | 내용 |
|---|---|
| 0% 리셋 딜레마 | 소환 뒤 최후 전투에서 수리도를 0%로 리셋하면 (1) 8칸 재채우기 = 반복 노가다, (2) 석판 같은 새 수리 시스템 = 목표·UI가 바뀌어 직관성이 깨지고 외해 렌즈를 얻을 이유가 사라진다 |
| 스피드런 | 진행을 이어가면 100% 근처에서 들켜도 바로 끝난다. 쟁여 둔 자원으로 최후 전투가 무의미해진다 |
| 마피아 은신 동기 | 들켜야 소환(괴물 카드)이 열려 "숨는 게 최우선"(v4 1.1)과 충돌 |
| 최후 전투 발생 빈도 | 100% 오는 결말인가, 30%쯤 나오는 방해인가 |
| 추리 근거 비공개 | 비밀 투표·확인·봉인·심해 게이지가 숫자로만 있어 토론 재료가 안 됨. 토론 수단도 미정(R21) |
| 물자 체감 | 작업대가 UI 숫자라 마피아가 뭘 가져갔는지 안 보임 → 선반형·실물 1개 운반 |
| 기타 메모 | 개인 인벤토리 다음날 초기화, 배 수리로 시작, 청사진, 폭탄 길뚫기, 디펜스 전환 |

## 3. 제안별 요약

### 1) 등대 3층 (10-19, SVN 데모)

- 1층 기반 프레임, 2층 기어, 3층 렌즈+광원(4슬롯). 켜진 층 수 = 진행도, 장착자 명판.
- 마피아: **검은 녹**(장착 모듈이 밤에 깜빡이다 새벽에 낙하, 장착자·제작자 공지), 빼돌리기.
- 소환: 밤마다 속삭임으로 의심 인원 확인, **촉수 수 = 일차 − 의심 수**.
- 최후 전투: 리셋 없음, 장착 모듈이 곧 체력. 촉수가 슬롯을 뜯어 해안으로 던지고 시민은 작살·회수·재장착.
- 의식: 비밀 투표 대신 **탐조등 고발**(빔이 모두에게 보임).

### 2) 8슬롯 시험안·등실 재점화 (10-19, 본편 코드)

- 1~3층 프레임+기어, 등실 렌즈+광원 = 8칸(A안). B안 6칸은 기록만. 1층부터 차례 장착, 1개 12.5%, 25·50·75% 보상.
- 최후 전투: 불만 꺼지고 장착은 유지. HP = 300 + 700 × 수리도. 심연 결정(소환 뒤에만 생성)으로 점화 연료 4번 → 시민 승. 소환 뒤 일반 장착 닫힘.
- 마피아 인출은 기본 자원만(모듈 상한 때문에 판이 막히지 않게).
- 남은 위험: 일찍 소환·늦게 소환의 버티는 시간이 비슷해질 수 있음(미해결).
- 현재 JH04 시험 판(`TowerTrialRound`)이 이 안으로 돌아간다. 다른 제안을 채택하면 이 시험판을 개편한다.

### 3) 작업대 선반형 (10-20, 표현 시험)

- 서버 규칙·통신 형식은 그대로, 표현·입력만 변경. F 올리기·제작, 마피아 G 1개 빼기(빈 자리 4초 빨간 깜빡임, 누가 뺐는지는 숨김).
- 화면 UI와 패널 버튼으로 전환해 비교. `Workbench.prefab`에 `Withdraw` 지원 행동이 없어 서버가 인출을 거절하는 문제 발견(JH04 씬 인스턴스에만 추가).
- 4~7번 제안이 모두 이 선반을 재사용한다.

### 4) 점화의 밤 (10-20)

- 진단: 문제의 뿌리는 "들킴 → 소환 → 최후 전투" **모드 전환**.
- 등실 2칸은 점화 필수, 1~3층 6칸은 방어 강화(선택). 설치 영구, 마피아는 설치 **전** 물자만 공격.
- 심연: 숨은 밤 +1, 오투표 +1, 끝까지 숨으면 +2. 정답 투표 시 동결.
- 점화의 밤: 등실이 차면 아무 밤이나 개시, N일차 자동. 90초 방어, 몬스터 = 1 + 심연.
- 스피드런 차단: 렌즈·광원 재료는 외해에만, 외해는 4일차(폭탄으로 3일차).
- 대안 B 디펜스 전환(범위 과다), C 현행 유지(문제 잔존).

### 5) 마지막 불빛 (10-20) — 4번 확장판

- 4번에 투표·경제·맵까지 넓힘. 채택 시 4번 대체.
- 비밀 투표·확인 → **공개 구금 투표**(밤 회의, 3표 이상, 1일차 없음). 구금자는 다음 낮 섬 안 작업만, 정체 공개.
- **공개 심연**: 숨은 밤 +1, 무고 구금 +1, 끝까지 숨으면 +1. 점화의 밤 촉수 수 = 1 + 심연.
- 점화는 3일차 밤부터 **시민 3명 동시 레버**. 5일차 밤 자동, 등실 미완성이면 마피아 승.
- 배 부서진 채 시작(튜토리얼), 가방 새벽 소실, 출력대 실물 1개, 마피아 인출 하루 2개, 암초 장벽·폭탄, 청사진 보류.
- 등대 HP = 100 + 25 × 모듈 수. 일정을 1~3단계로 분할.

### 6) 불침번 (10-20)

- 핵심: "다 끼우면 끝"을 **"다 끼우면 시작, 지켜내면 끝"**으로.
- 8/8에서만 점화. 마지막 밤 시작은 점화 / 마피아의 **심연의 부름**(1회, 즉시 정체 공개) / 기한 자동.
- 촉수가 K초마다 가장 아래층 모듈을 바다로 떨어뜨림 → 배로 건져 재료 없이 재장착. 등실 2칸이 있으면 빛 150초 충전, 제한 240초. **등대 HP 없음**(8칸이 HP).
- 투표는 비밀 2회 지목 **유지**, 효과만 공개 D 새벽 정산(지목 합계로 거짓말 추리). 확인·10초 권리 삭제.
- 박태욱 코드 변경량이 가장 작음(Voting Rules 유지, D·부름·촉수 콜백). 표류 회수가 늦으면 해안 낙하로 대체.

### 7) 빛의 항로 (10-20)

- 8/8 = 출항 허가. 시민 3명 점화 → 폭풍벽에 출구, **고정 거리(60~80초) 탈출 항해**, 시민 2명 이상 통과 시 승.
- 출구 유지 = 150 − 10 × 심연. 등대 피해 없음(영구), 층 보상은 전부 항해 능력.
- 공개 고발(2일차 밤부터, 2명 찬성). 오고발은 무고 공개 + 심연 +2.
- 들킨 마피아는 **유령선 선장**(심연 고정 수치로 사냥, 부활). 항해 중 숨은 채 자기 공개 시 +2 → "끝까지 숨는 것"이 최선.
- 가방 새벽 소실 채택 권장.

### 8) 시험 점등 (10-21)

- 4~7번의 "심연 수치 + 공개 고발 + 피날레 방어" 틀을 버리고 **장착 자체를 추리 장치로** 씀(아발론 원정 구조).
- 층별 칸 1·2층 2, 3층 3, 등실 3. 한 층에 한 사람 한 칸 → 등실은 4명 중 1명 제외 = 사실상 지목. 장착자 이름 공개.
- 마피아만 **불량 장착**(F 대신 G, 연출 동일). 층이 차면 시험 점등 → **불발 개수만** 공개, 실패 층만 소실.
- 3층 점등 = 외해 개방 → 시간 게이트 불필요.
- 승패: 등실 점등 성공 = 시민 / 기한 또는 등실 2회 불발 = 마피아. 기준선 시민 약 50%.
- 투표·확인·소환·심해·HP·환영 섬·날씨 변경·부식 폐기. 손잡이는 기한·등실 시도 횟수·재료량 3개.

## 4. 이미 결정된 것 (제안과 무관하게 유지)

[등대·작업대 모듈 결정](../../design/lighthouse-module-decisions.md)과 [모듈 운반 결정 원문](../2026-10-20/모듈-인벤토리운반-난파구조-결정.md):

- 등대에는 모듈만, 기본 자원은 작업대에서만. 작업대는 레시피별 동시 진행·제작 버튼·존재 상한.
- 작업대 보관 → **개인이 꺼내 1개만 보유** → 등대·배에 장착. 되돌려놓기 가능, 보유자는 본인만 앎(10-21 비공개로 변경).
- 구조되면 랜덤 1개 소실(모듈 포함), 미구조 재스폰 시 전부 떨어져 섬 가장자리로 이동, 공동 자원 소모 폐기. 배 장착 모듈은 난파 시 소실(10-21 정정).
- 마피아 소환 시 손에 든 모듈 소멸. **소환을 폐기하는 제안(5~8)을 채택하면 이 항목은 다시 정해야 한다.**
- 10-21 코드 반영(꺼내기 16·되돌리기 17·손→장착), 설정 메뉴·플레이 미실행.

결정 문서의 미정 1~5(층 배치, 장착 순서, 수리도 환산, 최후 전투 진행도, 마피아 등대 회수)는 어느 제안을 고르느냐로 함께 정해진다.

### 제안들이 공통으로 수렴한 것

- **장착은 영구, 0% 리셋 없음** — 2번 이후 모든 제안.
- **마피아 방해는 설치 전 물자·시간만** — 4~7번.
- **승리 경로 하나로 일원화**(최후 전투 모드 전환 폐지) — 4~8번.
- **렌즈·광원은 외해 재료**로 자연스럽게 마지막 → 스피드런을 시간 게이트로 막음 — 4~8번.
- **작업대 선반형 + 1인 1개 실물 운반** — 3번 이후 전부 재사용, 운반은 이미 결정.
- **가방 새벽 소실** — 4~7번이 채택 또는 권장(결정 아님).
- **숨을수록 마피아가 강해지는 구조** — 4~7번(심연), 8번(마지막 한두 번의 불량 기회).

## 6. 정해야 할 것

1. 어느 안을 기준으로 갈지(또는 2번 현행 시험판 유지). 5번은 4번을 대체한다.
2. 채택 안의 수치: 기한 일수, 결말 시간(90/150초·항해 거리), 심연 증감, 등실 시도 횟수, 재료량.
3. 투표 방식: 현행 비밀 투표 유지(2·6) / 공개 구금·고발(5·7) / 폐기(8). **박태욱 TW03~05 합의 필수.**
4. 가방 새벽 소실 여부와 비율(최명기).
5. 토론 수단(R21) — 공개 정보를 쓰는 안일수록 필요.
6. 소환을 폐기할 경우 "소환 시 손 모듈 소멸" 결정 재정리.
7. 선반형 채택 시 결정 문서의 "보는 레시피는 각자 화면" 문구와 `Workbench.prefab` `Withdraw` 반영.

일정: 기능 동결 10/25, 최종 마감 11/1. 4~8번은 모두 다른 담당(박태욱·최명기·강민서) 코드를 바꾸므로 동결 전 결정이 필요하다.
