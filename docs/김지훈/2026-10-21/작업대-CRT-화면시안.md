# 작업대 CRT 화면 시안

작성자: 김지훈
작성일: 2026-10-21
갱신일: 2026-10-21
상태: 완료(이미지 생성·육안 확인), 요청 해상도 미충족
브랜치·기준 커밋: `feature/jihun`, `5a8a4f3`

## 요청과 목표

사용자가 제공한 영문 프롬프트를 바탕으로 구형 CRT 작업대 화면 이미지 시안을 생성한다. 황색 픽셀 글자, 3열 구성(레시피·제작·보관함), 재료 부족 빨간 표시, 모듈 운반·반환 영역을 포함한다. 요청 해상도는 1920×1080이다.

## 진행 과정과 결정 이유

- 2026-10-21: 사용자가 기록 담당자를 김지훈으로 확인했다. 전체 pointer, 김지훈 pointer와 모듈 운반 구현 원문을 읽었다. 기존 pointer의 미커밋 변경과 `.vscode/` 미추적 파일을 확인했다.
- 제공된 문구와 구성을 유지하고 이미지 생성 도구 내장 모드(`image_gen`)로 1장을 생성했다. UI 구현이나 확정 게임 규칙 변경을 요청한 것이 아니므로 시안만 작성했다.
- 생성 프롬프트: 사용자 원문을 `ui-mockup` 형식으로 정리했다. 1920×1080, 화면이 대부분을 차지하는 정면 CRT, 어두운 작업실 가장자리, #FF9A2E·#FF3B30, 모든 지정 영문 문구와 3열 배치, 목재는 화면 바깥에만 표시하도록 지정했다. 추가 카피나 컨트롤은 금지했다.

## 변경 파일과 결과

- [생성 이미지](images/workbench-crt-concept-v1.png): 검토용 시안. Unity 에셋·씬·프리팹에는 적용하지 않았다.
- 이 원문과 담당자 pointer 완료 이력에 생성 결과를 기록했다.

## 검증

- 실행: 생성 이미지 육안 확인. CRT 스캔라인, 황색 선택 막대, 3열 구성, 재료 `1/3` 빨간 표시, 보관함 3×2와 운반·반환 영역 확인.
- 실행: System.Drawing으로 실제 이미지 크기 확인: **1672×941**. 프롬프트에 지정한 1920×1080과 다르다.
- 미실행: Unity 적용·플레이 검증. 이번 결과는 정적 시안이다. 커서 깜빡임은 밑줄이 켜진 한 프레임으로 표현했다.

## 남은 일과 차단 조건

요청 해상도 1920×1080 산출물은 확보하지 못했다. 게임 화면 채택과 구현은 별도 요청 범위다.
