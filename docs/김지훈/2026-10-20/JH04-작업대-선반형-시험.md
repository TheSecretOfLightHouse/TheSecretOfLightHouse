# JH04 작업대 선반형(신발장) 표현 시험

작성일: 2026-10-20
담당: 김지훈
상태: **시험안(확정 아님)**. 코드 작성만 완료, Unity 컴파일·씬 배치·플레이 미실행(에디터 꺼져 있음, UnityMCP 연결 거부).

## 요청
작업대를 화면(UI)으로 두지 말고, 모듈 표지판마다 판자·철근 같은 재료를 실제로 올려놓는 선반(신발장 느낌)으로 바꾼다. 마피아가 가져간 것이 잘 보이고, 쌓는다는 느낌이 들게 한다. 매번 UI에서 수량을 세지 않게 한다.

## 결정·범위
- 서버 규칙(부분 투입·제작 버튼·마피아 전용 인출·존재 상한)과 통신 형식은 **그대로**다. 바뀐 것은 표현과 입력뿐이다. 선반은 `WorkbenchNet`의 공개 상태(레시피별 투입량·보관 개수)만 따라 그린다.
- 레시피마다 칸(bay) 1개: 위에 표지판(모듈 이름, 재료가 다 차면 노란색·"제작 가능"), 재료마다 선반 1단, 필요한 수량만큼 빈 자리 표시. 넣은 만큼 조각이 올라가고, 완성 모듈은 칸 위에 놓인다(최대 3개 표시).
- 입력: 칸 앞에 서면 머리 위 안내. **F** = 가진 재료 중 필요한 것 전부 올리기(재료별로 한 번씩 순서대로 요청), 다 차면 F = 제작. 마피아는 **G** = 가장 위 선반에서 1개 몰래 빼기.
- 마피아가 빼면 그 빈 자리가 모든 PC에서 4초 동안 빨갛게 깜빡인다. 누가 뺐는지는 표시하지 않는다. 제작으로 비는 경우(같은 동기화 묶음에서 보관 개수 증가)는 깜빡이지 않는다.
- 판자·철근 모델이 없어 기본 도형으로 대신한다: 나무=판자(납작한 상자), 철=철근(가는 막대), 돌=블록, 섬유=두꺼운 막대(밧줄 뭉치), 유리=세운 판, 수정=구.
- JH04 시험 씬만 바꾼다. JH03 씬·작업대 프리팹·`WorkbenchScreen`은 그대로 둔다.
- **두 방식 모두 유지(2026-10-20 사용자 요청)**: 화면 UI는 삭제하지 않는다. 판 진행 패널 맨 위 버튼으로 내 PC에서만 "선반 ⇄ 화면 UI"를 바꾼다(기본 선반). 둘 다 F키를 쓰므로 한 번에 하나만 입력을 받는다. 선반 모양은 작업대 본체로 두 방식 모두 보인다. 화면 방식에서는 마피아 빼기가 기존 패널 버튼으로 돌아온다.

## 발견
- `Workbench.prefab`의 `InteractionTarget._supportedActions`가 `SelectRecipe·Deposit·Craft`뿐이라 서버 `TargetResolver`가 `Withdraw`를 `ActionNotSupported`로 거절한다. 2026-10-19 시험 패널의 마피아 인출도 같은 이유로 실패했을 가능성이 높다(그때 미검증 항목). 설정 메뉴가 JH04 씬 인스턴스에만 추가한다. 채택 시 프리팹 반영 여부 결정 필요.
- 선반 방식에서는 누가 어느 레시피를 채우는지 위치로 보인다. 확정 규칙의 "보는 레시피는 각자 화면에서만"은 화면 기준 결정이라, 채택 시 결정 문서 문구 갱신 필요.
- 공용 인벤토리 결정의 "인출 이력 공개 범위"는 미정이다. 이번 시험은 "빈 자리는 모두에게 보이고 누가 뺐는지는 숨김"을 시험값으로 쓴다.

- 미실행: Unity 컴파일, 설정 메뉴 실행, 1인 스모크(F 올리기·제작·장착), 2인(마피아 G 빼기·빨간 깜빡임이 다른 PC에 보이는지), M2, 직접 조작 느낌.

## 진행 기록
- 2026-10-20: 사용자가 설정 메뉴(첫 버전)를 실행하고 플레이함. Editor.log에 `Rack set up on Workbench`가 남았고 컴파일 오류(`error CS`)·예외는 0건. 사용자 보고: 화면 UI로 전환하면 다가가 상호작용할 물체가 없음(메뉴가 작업대 큐브를 숨김).
- 수정: 화면 UI 방식이면 선반을 숨기고 작업대 자리에 **상자 `WorkbenchBox`(2×1×1)**를 보여준다. 상자 앞에서 F를 누르면 화면이 열린다(화면의 거리 판정은 작업대 위치 기준이라 상자 위치와 같다). 선반 방식이면 상자를 숨긴다. 설정 메뉴는 다시 실행해도 되게 바꿈: 선반은 없을 때만 만들고, 상자 추가와 패널 연결(`_screenBox`)은 항상 한다.
- 미실행: 수정본 컴파일, 메뉴 재실행, 두 방식 전환 플레이.
- 2026-10-20 사용자 보고: 전환해도 상자가 안 나옴. 확인 결과 메뉴 재실행 기록이 없고(Editor.log 설정 로그 1건), 저장된 씬은 **첫 버전 메뉴 결과**: `WorkbenchScreen` 비활성, `TowerTrialPanel._workbenchScreen`·`_screenBox` 미연결. 그래서 상자도 화면도 켜질 수 없었다. 조치: 패널이 `_screenBox`가 비어 있으면 실행 중 상자를 직접 만든다(`EnsureScreenBox`). 화면 연결은 런타임 Find 금지 규칙 때문에 메뉴 재실행으로만 고친다.
