# 게임 전체 재기획 제안 — 「빛의 항로」(켜는 게 끝이 아니라, 켜고 빠져나가야 끝난다)

작성일: 2026-10-20 · 상태: **제안(확정 아님, 결정 문서 미반영, 코드 무변경)**

## 요청

사용자 메모: JH04 8슬롯(등실 렌즈·광원 + 1~3층 기반 프레임·기어 장치)에서 들킴 뒤 수리도 0% 리셋을 하면 (1) 재채우기 = 반복 노가다, (2) 석판 같은 새 수리 시스템 = 목표·UI가 바뀌어 직관성이 깨지고 외해 렌즈를 얻을 이유가 사라진다. 진행을 이어가면 100% 근처에서 스피드런이 된다. 개인 인벤토리 다음날 초기화도 검토. **확정 기획 전부 반려·무시**하고 게임 전체 흐름, 마피아의 들키기 전 행동, 일찍 들켰을 때, 들킨 뒤 행동, 왜 안 들켜야 하는지까지 포함한 새 기획 제안.

같은 날 「점화의 밤」·「마지막 불빛」·「불침번」 제안이 있다. 이 문서는 별도 대안이며 차이는 9절에 둔다.

## 1. 진단

- 스피드런·노가다 딜레마의 뿌리는 **"8/8 = 결승선"** 과 **"들킴 = 모드 전환"** 이 겹친 것이다. 들키는 순간 남은 일이 "남은 칸 채우기"뿐이면, 진행도가 높을수록 결말이 시시해진다.
- 해법: 8/8은 끝이 아니라 **출항 허가**다. 등대를 켜면 빛이 폭풍벽에 길(항로)을 연다. 시민은 그 길로 **배를 몰고 빠져나가야** 이긴다. 항해 거리는 고정이라 진행도가 100%여도 결말 길이가 줄지 않는다.
- 들킨 마피아는 직군을 잃고 바다에서 **유령선 선장**이 되어 사냥한다. 힘은 **들키기 전까지 숨어 지낸 밤 수**로 정해지고 들키는 순간 멈춘다.

## 2. 한 줄 요약

> 8칸을 모두 끼우면 등대를 켤 수 있다. 등대 빛은 폭풍벽에 출구를 열고, 시민은 그 출구가 닫히기 전에 배를 몰고 빠져나가야 한다. 마피아는 숨어 있는 밤마다 심연을 키우고, 들키면 그때까지 키운 힘으로 유령선을 몰아 사냥한다. 끝까지 숨으면 같은 함대 안에서 마지막에 배신한다.

## 3. 판 흐름(기본 5일, 낮 5분 + 밤 2분)

| 시점 | 일어나는 일 |
|---|---|
| 1일차 | 등대 섬 출발. 근해 파밍 → 작업대 선반에 적재 → 1층 모듈 제작·장착을 한 번 경험 |
| 매일 낮 | 흩어져 파밍. 마피아는 숨어서 방해 |
| 해 질 녘 | 귀항 알림 |
| 밤 회의 | 전원 등대 섬 집결, 토론 → 2일차 밤부터 **공개 고발**(5절) |
| 새벽 | **가방에 남은 자원은 파도가 쓸어간다**(7절). 심연 정산(+1/숨은 밤) |
| 2일차~ | 중해 개방, 2·3층 제작 |
| 4일차~ | 외해 개방. 렌즈·광원 재료는 외해에만 → 등실이 자연히 마지막 |
| 8/8 이후 아무 때나 | 시민 3명이 등대 점화대에 10초 동시 상호작용 → **점화 → 탈출 항해** 시작 |
| N일차 밤 회의 종료 | 점화 못 했으면 폭풍벽이 완전히 닫힘 → 마피아 승 |

## 4. 등대와 결말

### 4.1 8슬롯 — 의미는 그대로, 리셋 없음

```
등실 : [렌즈 모듈] [광원 코어]      ← 점화 필수. 외해 재료
 3층 : [기반 프레임] [기어 장치]    ← 완성 보상: 대포 피해 ↑
 2층 : [기반 프레임] [기어 장치]    ← 완성 보상: 선체 내구 ↑
 1층 : [기반 프레임] [기어 장치]    ← 완성 보상: 배 속도 ↑
```

- 장착은 **영구**. 누구도(들킨 마피아 포함) 장착된 모듈을 떼거나 리셋할 수 없다 → 반복 노가다 없음.
- **8칸 전부**가 점화 조건 → "다 모아서 켜고 탈출한다"는 목표가 처음부터 끝까지 하나. 새 자원·새 UI 없음. 렌즈·광원은 끝까지 필수.
- 층 보상은 전부 **항해 능력**이다. 탈출 항해에서 그대로 체감된다.

### 4.2 탈출 항해 — 유일한 결말

| 항목 | 규칙(가안) |
|---|---|
| 시작 | 8/8 + 시민 3명(아무 3명) 점화대 10초. 마피아 1명이 빠져도 시작 가능 → 마피아 거부권 없음 |
| 출구 | 빛줄기가 폭풍벽의 무작위 지점에 출구를 연다. 등대에서 직선 약 60~80초 항해 거리(고정) |
| 출구 유지 시간 | 150초 − 10초 × 심연(최소 70초) |
| 바다 | 날씨는 폭풍 고정, 낮밤 정지, 몬스터 = 1 + 심연 ÷ 2 무리 |
| 난파 | 기존 난파·구조 규칙 그대로. 동료를 구하면 시간이 든다 |
| 시민 승 | 출구가 닫히기 전 시민 **2명 이상** 통과 |
| 마피아 승 | 출구가 닫힐 때까지 통과한 시민이 1명 이하, 또는 N일차 밤까지 점화 실패 |

**스피드런 답:** 들킨 시점이 7/8이든 8/8이든, 남는 것은 "마지막 칸 + 점화 + 고정 거리 항해"다. 그 항해는 마피아 힘이 가장 큰 순간에 치러진다. 결말이 짧아질 수는 있어도 생략되지 않는다.

## 5. 마피아

### 5.1 심연(공개 수치)

- 바다 색·폭풍 세기로 모두에게 보인다. 계산이 결정적이라 공개해도 정체 정보가 새지 않는다.
- +1: 마피아가 숨은 채 넘긴 밤 회의 1회마다
- +2: 무고한 사람을 고발했을 때
- 마피아가 들키면 **그 자리에서 고정**(더 오르지 않음)
- 효과: 유령선 체력·대포, 몬스터 수, 출구 유지 시간

### 5.2 들키기 전 — 시민인 척 시간을 빼앗는다

| 행동 | 내용 | 흔적 |
|---|---|---|
| 정상 기여 | 파밍·제작·장착을 실제로 한다(신뢰 쌓기) | 없음 |
| 선반 인출 | 혼자 있을 때 선반 재료 1개를 몰래 뺀다(쿨다운) | 선반 수량 감소는 모두 보임, 누가인지는 안 보임 |
| 모듈 부식 | 장착 전 모듈을 부식(한 판 1~2회). 부식 모듈은 장착하는 순간 부서져 재료가 날아간다 | "부식 모듈" 공개 알림. 운반자·제작자·선반 접근자가 용의 선상 |
| 가방 흘리기 | 외해 희귀 재료를 일부러 늦게 들고 와 새벽에 잃는다 | "운이 없었다"로 위장 가능 |
| 바다 몬스터 소환 | 약한 개체, 자연 스폰과 구분 어려움 | 자주 쓰면 "그 사람 근처에만 몬스터" 증거 |
| 말 | 거짓 위치 보고, 고발 유도 | 증언 모순 |

방해는 전부 **설치 전 물자와 시간**만 건드린다. 설치된 진행은 지킨다.

### 5.3 고발(공개 투표)

- 2일차 밤 회의부터, 밤마다 1회. 고발당한 사람을 뺀 3명 중 **2명 이상** 찬성이면 성립.
- 마피아가 맞으면 → **정체 공개**(5.4).
- 틀리면 → 그 사람의 무고 공개, 심연 +2, 그 사람은 다음 낮 직군 액티브 봉인.
- 결과가 공개라 소거법이 작동한다. 시민은 "확신을 기다릴지, 심연 +2를 감수하고 빨리 찍을지"를 고른다. 마피아는 오고발을 유도할수록 강해진다.

### 5.4 들킨 뒤 — 유령선 선장

- 직군·선반·작업대·등대 상호작용 상실. 등대 섬 안전지대에는 들어갈 수 없다(등대 빛 결계).
- 자기 배가 **유령선**으로 바뀐다(체력·대포 = 고정된 심연). 침몰해도 30~40초 뒤 먼 바다에서 부활.
- 목표: **가방을 든 배를 침몰시키기**(가방 내용은 바다에 떨어져 잠시 건질 수 있음), 외해 렌즈·광원 원정 차단, 탈출 항해 사냥.
- 바다 몬스터 소환 강화(들키기 전보다 공격적, 쿨다운 유지).
- 플레이어가 구경꾼이 되지 않는다. 들킨 뒤에도 끝까지 할 일이 있다.

### 5.5 자기 공개(심연의 부름)

- 마피아는 언제든 스스로 정체를 드러내 유령선이 될 수 있다. **탈출 항해 중에 숨은 채 공개하면 심연 +2 보너스**와 함께 시민 함대 한가운데서 변신한다.
- 이것이 "끝까지 숨은 마피아의 마지막 한 수"다.

### 5.6 일찍 들켰을 때

- 예: 2일차 밤 정답 고발 → 심연 1에서 고정. 유령선이 약하고, 선반·부식·인출을 영영 못 쓴다.
- 시민은 남은 3일 동안 위협을 알고 함대로 움직이면 된다. 마피아는 외해 원정 매복 정도만 남는다 → 시민이 크게 유리. **일찍 들키는 건 마피아에게 확실한 손해**다.
- 그래도 할 일은 있다(5.4). 탈출 항해에서 한 번 더 기회가 온다.

### 5.7 왜 안 들켜야 하는가 — 정리

| 숨어 있을 때 | 들켰을 때 |
|---|---|
| 심연이 밤마다 오른다 | 심연 고정 |
| 선반 인출·부식·가방 흘리기·거짓말 | 전부 불가 |
| 시민이 함대를 나누고 마음 놓고 흩어진다 → 사냥감이 많다 | 시민이 경계하고 뭉친다 |
| 오고발 유도로 심연 +2씩 | 고발이 끝났으니 없음 |
| 탈출 항해 중 기습 공개 +2 | 기습 없음, 처음부터 경계됨 |

마피아의 최선: **끝까지 숨어 심연을 최대로 키우고, 항해 한가운데서 공개.** 시민의 최선: **확신이 생기면 빨리 찍어 심연을 멈추기.** 둘이 정면으로 부딪힌다.

## 6. 시민의 판단 축

- 언제 고발할까: 일찍(심연 낮게 고정 vs 오고발 +2)
- 언제 점화할까: 8/8 직후(마피아가 아직 숨었으면 항해 중 기습) vs 고발로 정체를 먼저 밝히고 점화
- 누구와 외해에 갈까: 혼자 가면 빠르지만 가방 손실·매복 위험

## 7. 개인 인벤토리 새벽 초기화 — 채택 권장

- 규칙: 새벽에 가방에 남은 자원은 소실. 작업대 선반에 올린 것만 공용 자산. 들고 있는 실물 모듈은 예외.
- 효과
  - 매일 귀항·적재 강제 → 밤 회의 집결이 자연스럽다.
  - 쌓아 두었다 한 번에 넣는 스피드런 차단.
  - 공용 물자가 선반에 보이므로 인출·부식이 "보이는 사건"이 된다(추리 재료).
  - 마피아의 "가방 흘리기" 같은 위장 가능한 방해가 생긴다.
  - 유령선의 "가방 든 배 사냥"에 목표가 생긴다.
- 위험: 초보 손실감 → 해 질 녘 알림 + 가방 칸 수 표시 + 선반 근처에서 한 번에 올리기로 완화.

## 8. 삭제·변경 목록(현행 대비)

- 삭제: 비밀 투표 2회·확인·봉인, 점화 의식 투표 조건, 괴물 소환·최후 전투 모드, 0% 리셋, HP 환산, 등대 내구도.
- 변경: 심해 게이지 → 공개 심연. 등대 점화 → 탈출 항해 시작 조건.
- 추가: 공개 고발, 유령선(들킨 마피아 조작), 폭풍벽 출구·탈출 판정, 가방 새벽 소실.

## 9. 다른 제안과의 차이

| | 점화의 밤 | 마지막 불빛 | 불침번 | **빛의 항로** |
|---|---|---|---|---|
| 결말 | 등대 방어 90초 | 등대 방어 90초 | 떨어진 모듈 회수·재장착하며 빛 충전 | **배로 출구까지 탈출** |
| 들킨 마피아 | 약화 | 구금 | 부름 시 공개 | **유령선 조작(계속 플레이)** |
| 등대 피해 | HP | HP | 모듈 낙하 | **없음(영구)** |
| 스피드런 차단 | 외해 게이트 | 외해 게이트 | 빛 150초 | **고정 항해 거리 + 외해 게이트** |

## 10. 영향과 리스크

- 재사용: JH04 Tower 8슬롯(점화 조건만 교체), 작업대·선반(`WorkbenchRack`), 배 이동·난파·대포, 바다 몬스터.
- 담당 합의 필요: 박태욱(투표·확인 → 공개 고발, 심연 공개화, 유령선·몬스터), 강민서(폭풍벽 출구·외해 해금), 최명기(가방 새벽 소실, 침몰 시 가방 낙하, 들킨 뒤 직군 비활성).
- 일정: v4 기능 동결 10/25. 유령선은 "마피아 배 외형·스탯만 교체"로 축소 가능, 출구는 "폭풍벽에 통과 판정 박스 1개"로 시작 가능.
- 미정: 시민 통과 기준(2명/전원), 출구 시간·거리, 유령선 수치, 고발 성립 기준, 부식 횟수.
