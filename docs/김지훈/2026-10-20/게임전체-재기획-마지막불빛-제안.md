# 게임 전체 재기획 제안 — 「마지막 불빛」

작성일: 2026-10-20 · 상태: **제안(확정 아님, 결정 문서 미반영, 코드 무변경)**

## 요청

사용자 메모(JH04 8슬롯 0% 리셋 딜레마, 스피드런, 마피아 은신 동기, 최후 전투 발생 확률, 작업대 선반형·실물 1개 운반, 인벤토리 다음날 초기화, 배 수리로 시작, 청사진, 폭탄 길뚫기, 디펜스 전환)를 근거로 **확정 기획 전부를 반려·무시하고**, JH04만이 아니라 **게임 기획 전체를 보고** 새 기획을 제안.

같은 날 쓴 [「점화의 밤」 제안](JH04-재기획-점화의밤-제안.md)은 등대 범위 중심이었다. 이 문서는 투표·마피아·경제·맵·시간까지 넓힌 통합안이며, 채택하면 「점화의 밤」을 대체한다.

## 1. 진단 — 게임 전체에서 본 문제의 뿌리

| # | 뿌리 | 드러나는 증상 |
|---|---|---|
| 1 | **승리 경로가 둘로 갈라지는 모드 전환**(점화 의식 ↔ 들킴→소환→최후 전투) | 0% 리셋 딜레마(노가다 vs 스피드런), 목표가 바뀌는 직관성 문제, HP 환산·최후 수리 0%·특수 종료·K01/K04 같은 예외 규칙 누적 |
| 2 | **들킴이 마피아의 보상**(들켜야 괴물 카드가 열림) | v4 1.1의 "숨는 게 최우선" 목표와 정면 충돌. 봉인·오투표·심해 게이지·10초 권리 같은 보정 장치를 겹겹이 붙여야 했다 |

| 4 | **진행이 시계에만 묶임**(1/3·2/3 해금, 5일 기한) | 플레이어 행동으로 진행을 당길 수단이 없고, 마피아 방해의 결과가 "시간이 모자라 패배" 하나로만 수렴 |
| 5 | **물자가 UI 숫자로만 존재** | 마피아가 무엇을 가져갔는지 체감되지 않고, 협동(운반·호위) 장면이 생기지 않는다 |

## 2. 제안 한 줄

> 4명이 부서진 배로 등대 섬에서 시작해, 바다를 뚫고 나가 등대를 한 층씩 영구히 세운다. 판의 끝에는 **반드시** "점화의 밤"이 온다. 한 명은 심연의 끄나풀이며, **숨어 지낸 밤마다 심연이 차올라 점화의 밤이 그만큼 어려워진다.** 시민은 매일 밤 회의에서 한 명을 구금해 심연을 멈출 수 있지만, 틀리면 일손을 잃고 심연이 더 찬다.

## 3. 판 흐름(기본 5일, 낮 5분 + 밤 2분)

| 시점 | 일어나는 일 |
|---|---|
| 1일차 시작 | 전원 등대 섬, **배가 부서진 채** 시작. 섬에서 돌·나무 채집 → 선반 → 수리 키트 제작 → 들고 가서 배 수리(약 60~90초). 이 한 번으로 채집→선반→제작→운반→설치 고리를 전부 익힌다 |
| 낮 | 흩어져 파밍. 가방은 작고(가안 8칸), 등대 섬 선반에 올려야 공용 물자가 된다 |
| 해 질 녘 | 귀항 알림. **새벽에 가방에 남은 자원은 바다가 가져간다** → 매일 귀항·적재 강제 |
| 밤 후반 회의 | 전원 집결, 토론 60초 → **공개 구금 투표**(1일차 밤은 투표 없음) |
| 새벽 | 심연 정산(아래 5절), 구금 해제·새 구금 적용, 섬 매장량 일부 회복 |
| 3일차~ | 등실 2슬롯이 차 있으면 밤 회의 뒤 **점화 개시 가능**(시민 3명 동시 레버) |
| 5일차 밤 | 점화의 밤 **자동 개시**. 등실 미완성이면 즉시 마피아 승리 |

## 4. 승패 — 경로 하나

| 진영 | 승리 |
|---|---|
| 시민 | 점화의 밤 90초 동안 등대 HP가 0보다 크면 점등 → 승리 |
| 마피아 | 점화의 밤에 등대 HP 0, 또는 5일차 밤에 등실 미완성 |

삭제: 점화 의식의 투표 조건, 의식 실패 즉시 패배, 괴물 소환 카드, 최후 전투 모드, 최후 수리 0%, HP 환산, 특수 종료, 기한 정지·제거.

**최후 전투의 위상(메모 "100%냐 30%냐"에 대한 답):** 점화의 밤은 **매 판 100% 오는 피날레**다. "방해"가 아니라 게임의 결말 구조이며, 마피아가 바꾸는 것은 발생 여부가 아니라 **난이도(심연)** 다. 발생 확률을 30%로 맞추는 설계는 들킴을 보상으로 만드는 구조를 되살리므로 채택하지 않는다.

## 5. 마피아 — 숨을수록 강하고, 들키면 약하다

### 5.1 심연(공개 수위)

- 심연은 **모두에게 보이는** 값이다(등대 섬 앞 바다의 녹색 수위·하늘색으로 표현). 결정적으로 계산되므로 공개해도 마피아 정보가 새지 않는다.
- 새벽마다: 마피아가 구금된 적 없으면 **+1**. 무고한 사람을 구금하면 **+1 추가**. 점화의 밤까지 한 번도 안 걸렸으면 개시 순간 **+1**.
- 마피아가 구금되면 **영구 동결**.
- 숨은 채 5일 끝까지 가면 대략 5~6, 3일차에 잡히면 2에서 멈춘다 → **숨는 쪽이 항상 유리**하다.

### 5.2 숨어서 하는 방해(설치 전 물자만, 상한 있음)

| 방해 | 제한 | 남는 단서 |
|---|---|---|
| 선반 슬쩍(1개씩) | 하루 2개 | 빈 자리 빨간 깜빡임 + 사라진 시각 공지 → "그 시각 등대 섬에 누가 있었나" |
| 바다 몬스터 소환 | 쿨다운 90초(v4 유지) | 빈도·누구 옆에서 |
| 부식 | 한 판 1회, 선반 위·운반 중 모듈에 | 설치 다음 새벽 슬롯에서 떨어져 등대 섬 앞에 표류 → 건져 재설치(재료 불필요, 시간만). 기술자 하루 1회 확인 |
| 환영 섬·날씨 변경 | v4 유지 | 예보 불일치, 항해사 |
| 운반자 공격 | 소환 몬스터로 폭탄·모듈 운반 배를 노림 | 누가 호위를 빠졌나 |

**설치된 모듈은 절대 사라지지 않는다.** 메모의 "마피아 공격력을 높여 자원을 손상시켜 다시 모으게" 안은 설치 **전** 물자에만 적용하고 하루 상한을 둘 때만 성립한다. 마피아의 힘을 키우는 손잡이는 진행 삭제가 아니라 **심연**이다.

### 5.3 구금된 마피아

정체가 공개되고 심연 동결, 선반 접근·부식·환영 섬·날씨 불가. 바다 몬스터 소환은 쿨다운 2배로 유지해 끝까지 플레이할 거리를 남긴다.

## 6. 투표 — 비밀 투표·확인을 공개 구금 투표로

| 항목 | 제안 |
|---|---|
| 시점 | 밤 회의(밤 후반), 하루 1회. 1일차 밤은 정보가 없어 투표 없음 |
| 방식 | 4명 모두 공개 투표(마피아 포함, 기권 가능). **3표 이상**이면 구금 |
| 구금 | 다음 낮 동안 배 탑승 불가, 등대 섬 안에서 채집·제작·운반만. 구금 순간 정체(마피아/시민) 공개 |
| 무고 구금 | 일손 하루 손실 + 심연 +1 → 아무나 찍는 비용이 크다 |

삭제: 판당 2회 지목, 확인·10초 소환 권리, 봉인·오투표 시간 비례, 확인 실패 무고 공개.

이유: 결과가 즉시 눈에 보여 다음 날 토론 재료가 되고, 구금된 시민도 섬 안 작업(선반·운반)으로 놀지 않는다. **토론 수단(외부 음성 전제 여부)은 이 안과 별개로 반드시 정해야 한다(R21).**

## 7. 등대 8슬롯 — 리셋 없음, 목표 고정

```
등실 : [렌즈 모듈] [광원 코어]      ← 점화 필수
 3층 : [기반 프레임] [기어 장치]    ← 방어 강화
 2층 : [기반 프레임] [기어 장치]
 1층 : [기반 프레임] [기어 장치]
```

- 메모의 선택지 (1) 처음부터 다시 채우기, (2) 새 수리 시스템 **둘 다 쓰지 않는다.** 8슬롯 UI가 처음부터 끝까지 유일한 목표다("다 채우면 확실히 버틴다, 등실만 채워도 도전은 된다").
- 층 완성 효과(v4 25/50/75 보상 대체): 1층 = 등대 HP, 2층 = 배 속도, 3층 = 점화의 밤에 탐조등이 촉수를 주기적으로 기절시킴. 모듈 1개마다 등대 HP +25.
- 장착 순서 자유. 렌즈·광원 재료(수정·유리)는 외해에만 있어 자연스럽게 마지막이 된다.

### 스피드런 차단

- 점화는 3일차 밤부터, **시민 3명이 동시에** 점화 레버를 잡아야 개시(마피아 혼자 조기 점화로 망칠 수 없고, 시민 셋은 마피아 없이도 개시 가능).
- 외해는 4일차 자동 개방, 폭탄으로 3일차 개방 가능 → 가장 빠른 점화는 3일차 밤. 이때 심연은 약 2라 층을 덜 채워도 버틸 수 있다 → **"빨리 켤까, 더 쌓을까"가 시민의 진짜 선택**이 된다(빠른 점화는 잘한 플레이의 보상).

## 8. 물자 흐름 — 숫자가 아니라 물건

1. 채집 → 개인 가방(작음, 새벽 소실)
2. 등대 섬 **선반(신발장형)**: 레시피별 칸, 재료별 선반에 조각이 실제로 쌓인다. 화면 UI로 수량을 세지 않는다
3. 제작 → 작업대 **출력대에 실물 1개** 생성, 화면 닫힘. 출력대가 비어야 다음 제작
4. 들고 운반(1개만, 이동 −30%, 대포·채집 불가, 쓰러지면 떨어뜨림) → 등대 슬롯 설치

출력대 1칸이 "한 번에 하나만, 반드시 옮겨야 함"을 픽업 강제 없이도 만든다(메모의 "픽업이 없더라도 고려할 만함"에 해당).

## 9. 맵 진행 — 시계 + 폭탄

| 구역 | 자동 개방 | 폭탄으로 앞당김 | 폭탄 재료(가안) |
|---|---|---|---|
| 내해 | 처음부터 | — | — |
| 중간 해역 | 2일차 | 1일차 | 돌 5 + 나무 5 |
| 외해 | 4일차 | 3일차 | 철 3 + 섬유 3 + 돌 3 |

- 폭풍벽 바깥 경계는 유지하고, 구역 사이 항로에 **암초 장벽**을 둬 폭탄으로 부순다. 폭탄은 실물 운반이며 배에 실으면 느려지고 대포를 못 쏜다 → 호위가 필요하고 마피아의 표적이 된다.
- 자동 개방은 마피아가 폭탄을 계속 막아 판이 막히는 것을 방지하는 안전장치다.
- **청사진은 보류 권장**: 렌즈·광원은 이미 외해 재료로 막혀 있어 역할이 겹친다. 일정 여유가 생기면 외해 난파선의 실물 청사진(훔칠 수 있음)으로 추가.

## 10. 밸런스 초기값(5일 기준, 전부 가안)

| 값 | 가안 |
|---|---|
| 등대 HP | 100 + 25 × 설치 모듈 수(최대 300) |
| 점화의 밤 | 90초, 촉수 수 = 1 + 심연 |
| 촉수 피해 | 촉수당 90초간 90(초당 1). 시민이 대포·작살로 맞히면 10초 후퇴 |
| 시민 방어 50% 가정 시 | 심연 2 → 피해 135(모듈 2개면 생존) / 심연 3 → 180(모듈 4개) / 심연 5 → 270(모듈 7개) / 심연 6 → 315(8개로도 부족) |

해석: 끝까지 숨은 마피아는 거의 이기고, 3일차쯤 잡으면 시민이 여유 있게 이긴다. 그래서 **투표하지 않을 수 없고, 아무나 찍을 수도 없다.** 실제 수치는 4인 플레이로 조정한다(가설).

경제 목표: 방해가 없으면 5일차 낮에 8슬롯이 거의 다 차고, 마피아의 방해로 1~3개가 모자라게 맞춘다(재료 총량은 현재 레시피 기준 등대 66개 + 배 수리·폭탄).

## 11. 기존 시스템 처리

| 시스템 | 처리 |
|---|---|
| 낮밤·5일·날씨·안개·토네이도·유령선·환영 섬·특수 섬 3종 | **유지**(구금 투표가 생기면서 단서 가치가 오히려 커진다) |
| 직군 3종 | 유지. 부식 확인은 기술자 |
| 난파·조명탄·구조 | 유지. 운반 중 난파 시 실물 표류 |
| 등대 8슬롯·작업대 레시피 | 유지, 리셋·인출 진행 되돌림 삭제 |
| 비밀 투표·확인·소환·봉인·오투표 | **삭제** → 공개 구금 투표·공개 심연 |

| 촉수 공격(박태욱 `06.Monsters/Boss`) | **재사용** → 점화의 밤 공격자 |
| 마피아 인출 무제한 | 하루 2개 상한 |

## 12. 담당 영향과 일정 리스크

오늘 10/20, 기능 동결 10/25, 최종 마감 11/1. 전부를 동결 전에 넣는 것은 어렵다.

## 「점화의 밤」 대비 바뀐 점

비밀 투표·확인을 공개 구금 투표로 교체, 심연 공개, 3명 동시 점화 레버, 1일차 무투표, 구금자 섬 작업, 마피아 인출 하루 상한, 부식 단순화(재료 없이 재설치), 청사진 보류, 동결 기준 단계 분할.
