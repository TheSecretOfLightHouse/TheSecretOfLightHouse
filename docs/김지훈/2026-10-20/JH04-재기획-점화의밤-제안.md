# JH04 재기획 제안 — 「점화의 밤」 (최후 전투 폐지·일원화)

작성일: 2026-10-20 · 상태: **제안(확정 아님, 결정 문서 미반영, 코드 무변경)**

## 요청

사용자 메모(최후 전투 0% 리셋 딜레마, 스피드런, 마피아 은신 동기, 작업대 선반형, 인벤토리 다음날 초기화, 배 수리 시작·청사진·폭탄 길뚫기)를 근거로 "확정 기획 전부 반려·무시하고 새 기획 제안, 최후 전투 변환·폐지까지 고려".

## 진단

문제의 뿌리는 "들킴 → 소환 → 최후 전투"라는 **모드 전환**이다. 목표가 바뀌고(직관성), 진행을 리셋할지 이어갈지 딜레마가 생기며(노가다 vs 스피드런), 마피아에게 들키는 쪽이 유리해질 여지가 생긴다.

## 제안 A(권장) — 승리 경로 하나, 진행은 영구, 결말은 예정된 클라이맥스

- 등대: 등실 2슬롯(렌즈·광원)은 점화 **필수**, 1~3층 6슬롯은 **점화의 밤 방어 강화**(선택). 설치된 모듈은 영구(리셋·제거 없음).
- 마피아 공격 대상은 설치 **전** 물자(선반 재료·제작/운반 중 모듈)뿐 → 반복 노가다 없이 시간만 빼앗는다.
- 물자 흐름: 개인 가방은 새벽에 소실 → 작업대 선반(신발장)에 공개 적재 → 제작 시 실물 오브젝트 1개 생성 → 들고 운반(1개만, 느려짐, 대포 불가, 난파 시 표류) → 슬롯 설치.
- 심연: 마피아가 숨은 채 넘긴 밤 +1, 오투표 +1, 점화의 밤까지 숨어 있으면 +2. 정답 투표 시 동결 + 선반 인출·부식 불가(바다 몬스터 소환만 쿨다운으로 유지).
- 점화의 밤: 등실 2슬롯이 차면 시민이 어느 밤이든 개시 가능, N일차 밤에는 자동 개시(등실 미완성이면 마피아 승). 90초 동안 등대를 지키면 시민 승, 등대 HP 0이면 마피아 승. 몬스터 규모 = 1 + 심연.
- 스피드런 차단: 렌즈·광원 재료는 외해에만. 외해는 4일차 자동 개방, 폭탄(제작·운반)으로 3일차부터 앞당김 가능.
- 시작: 배가 부서진 채 시작해 첫 수리가 튜토리얼(채집→선반→제작→운반→설치를 한 번 경험).
- 청사진: 렌즈·광원 레시피는 외해 특수 섬 청사진으로 해금(선택 사항).

## 대안

- B 디펜스 전환: 마지막 2일을 웨이브 방어로. 범위 과다, 일정상 비권장.
- C 현행 유지 + 진행 이어가기·봉인 시간 비례: 변경 최소지만 마피아 은신 동기·목표 이원화가 남는다.
