# 게임 전체 재기획 제안 — 「불침번」(켜는 게 아니라 지켜야 끝난다)

작성일: 2026-10-20 · 상태: **제안(확정 아님, 결정 문서 미반영, 코드 무변경)**

## 요청

사용자 메모: JH04 8슬롯(등실 렌즈·광원 + 1~3층 기반 프레임·기어 장치)에서 소환 시 수리도 0% 리셋을 하면 (1) 8슬롯 재채우기 = 반복 노가다, (2) 새 수리 시스템(석판 등) = 목표·UI가 바뀌어 직관성이 깨지고 렌즈 등 외해 자원을 얻을 이유가 사라진다. 진행을 이어가면 100% 근처에서 스피드런이 된다. 개인 인벤토리 다음날 초기화도 검토. **확정 기획 전부를 반려·무시하고, 게임 기획 전체를 보고** 새 기획을 제안.

같은 날 [「점화의 밤」](JH04-재기획-점화의밤-제안.md)·[「마지막 불빛」](게임전체-재기획-마지막불빛-제안.md) 제안이 있다. 이 문서는 별도 대안이며 차이는 11절에 둔다.

## 1. 진단

근거: [v4](../../design/references/game-design-v4.md), [승패·투표 결정](../../design/win-vote-decisions.md), [등대·작업대 모듈 결정](../../design/lighthouse-module-decisions.md), [문제 대장](../../07-design-issue-register.md) R08·R09·R10·R21·W01·W08.

| # | 뿌리 | 증상 |
|---|---|---|
| 1 | **8슬롯이 다 차는 순간 = 결승선** | 진행을 이어가면 스피드런, 리셋하면 노가다. 두 선택지 모두 이 정의에서 나온다 |
| 2 | 승리 경로가 둘(점화 의식 / 최후 전투) | 최후 수리 0%, HP 환산, 특수 종료, K01·K04 같은 예외 규칙이 쌓인다 |
| 3 | 소환하려면 들켜야 함 | v4 1.1 "숨는 게 최우선"과 충돌. 봉인·오투표·10초 권리 보정이 겹겹이 붙음 |
| 4 | 봉인·심해·확인 결과가 전부 비공개 숫자 | 투표 결과가 토론 재료가 되지 않는다(토론 수단 R21도 미정) |
| 5 | 개인 가방이 무한 보관 | 외해 재료를 쌓아 두었다 한 번에 넣는 스피드런, 마피아의 보이지 않는 사재기 |

핵심은 1번이다. **"다 끼우면 끝"을 "다 끼우면 시작, 지켜내면 끝"으로 바꾸면** 진행을 이어가도 스피드런이 되지 않고, 8슬롯 UI가 끝까지 유일한 목표로 남는다.

## 2. 한 줄 요약

> 8칸을 모두 끼우면 등대에 불을 붙일 수 있다. 불이 붙으면 심연이 등대를 감고 올라와 모듈을 아래층부터 바다로 떨어뜨린다. 시민은 떨어진 모듈을 배로 건져 다시 끼우며, 등실이 버티는 동안 빛이 차오르면 폭풍벽이 갈라져 탈출한다. 심연의 힘은 마피아가 숨어 지낸 밤만큼 커진다.

## 3. 등대 — 8슬롯 의미 재정의

```
등실 : [렌즈 모듈] [광원 코어]      ← 빛. 둘 다 있어야 빛이 찬다
 3층 : [기반 프레임] [기어 장치]    ┐
 2층 : [기반 프레임] [기어 장치]    ├ 방벽. 촉수가 아래층부터 떨어뜨린다
 1층 : [기반 프레임] [기어 장치]    ┘
```

| 항목 | 제안 |
|---|---|
| 진행 | 장착은 영구. 리셋 없음. 마피아가 직접 떼어 갈 수 없다(부식 낙하는 아래 5절) |
| 층 완성 보상 | v4 6.1 유지: 1층 배 속도, 2층 파밍량, 3층 대포 피해. 마지막 밤에도 회수·호위에 그대로 쓰인다 |
| 점화 | **8칸이 모두 찼을 때만** 누구나 등대에서 점화 → 마지막 밤 시작. "다 끼우면 불을 켠다"는 기대를 그대로 지킨다 |
| 장착 순서 | 자유. 렌즈·광원 재료(수정·유리)는 외해에만 두어(v4 8.1 해금 유지) 자연스럽게 마지막이 된다 |

**(1)·(2) 모두 쓰지 않는다.** 마지막 밤에 하는 일은 "같은 8칸을 계속 채워 두는 것"이라 새 시스템·새 UI가 없다.

## 4. 마지막 밤 — 유일한 결말

### 4.1 시작 조건(셋 중 먼저)

| 시작 | 조건 | 의미 |
|---|---|---|
| 점화 | 시민이 8/8에서 점화 | 준비를 마친 시민의 도전 |
| 심연의 부름 | 마피아가 한 판 1회, 외해 개방(전체 일수 2/3) 이후. **사용 즉시 정체 공개** | 들키지 않아도 쓸 수 있는 마지막 한 수. 대신 숨은 채 방해할 기회를 버린다 |
| 기한 | N일차 밤 회의 직후 자동 | 마지막 밤은 반드시 온다. 덜 채웠으면 그만큼 불리할 뿐 |

어느 쪽으로 시작해도 규칙은 같다. 날씨는 심연(v4 10.1)으로 고정, 낮밤 진행 정지.

### 4.2 진행

| 요소 | 규칙(가안) |
|---|---|
| 빛 게이지 | 0→100%. 등실 2칸이 모두 있으면 초당 1/150(150초). 등실이 하나라도 비면 **멈춘다(줄지 않음)** |
| 촉수 | 감기 연출 후 K초마다 조이기 1회 → **가장 아래층의 모듈 1개를 바다로 떨어뜨린다**. 1~3층 6칸이 모두 비면 등실을 노린다 |
| 떨어진 모듈 | 등대 섬 주변 바다에 표류(심연이 깊을수록 멀리). 배로 건져 실물로 들고 와 **재료 없이 다시 장착**. 120초 안에 못 건지면 분해 → 작업대에서 다시 제작 |
| 추가 장착 | 마지막 밤에도 작업대 제작·장착 가능. 부름·기한으로 일찍 시작된 판에서는 빈 칸을 이 시간에 채운다(원래 "최후 전투"의 역할을 진행 이어가기로 흡수) |
| 시민 승리 | 빛 100% → 폭풍벽이 갈라지며 탈출 |
| 마피아 승리 | 제한 시간 L(가안 240초) 안에 빛 100% 실패 |

### 4.3 스피드런이 안 되는 이유

- 8/8에서 시작해도 최소 150초가 걸리고, 그동안 촉수가 계속 칸을 비운다. **많이 채운 진행은 승리가 아니라 방벽 두께**로 작동한다.
- 심연이 낮으면(마피아를 잘 잡았으면) 150초 안에 6칸 방벽이 버텨 빨리 끝난다 — 이것은 잘한 플레이의 보상이다.
- 외해 해금(2/3 시점) 전에는 렌즈·광원 재료가 없어 8/8 자체가 불가능하다.

### 4.4 심연(D)과 촉수 간격(가안)

| D | 조이기 간격 K | 150초간 떨어지는 칸 | 체감 |
|---|---|---|---|
| 0~1 | 30초 | 약 5 | 방벽 6칸으로 회수 없이 버팀 |
| 2~3 | 18초 | 약 8 | 2~3개는 건져야 함 |
| 4~5 | 12초 | 약 12 | 전원 회수전, 등실이 자주 비어 빛이 멈춤 |
| 6+ | 9초 | 약 16 | 거의 마피아 승 |

숨은 채 5일을 가면 D≈5~6, 2~3일차에 정답 표가 모이면 D≈2에서 멈춘다 → **숨을수록 마피아가 유리**하다. 실제 값은 4인 플레이로 조정(가설).

## 5. 마피아

### 5.1 심연(D) — 공개 수위

- 새벽마다: 마피아가 공개되지 않았으면 **+1**. 마피아를 지목한 채 유지 중인 시민 1명당 **−0.5**, 무고한 사람을 지목 중인 시민 1명당 **+0.5**. 최소 0. 마피아 공개 후 동결.
- D는 **모두에게 보인다**(등대 앞 바다의 녹색 수위). 새벽의 변화량이 "현재 시민 표의 합"을 드러낸다 → "셋 다 B를 찍었다고 했는데 +1.5가 올랐다 = 누군가 거짓말" 같은 추리가 생긴다. 마피아는 투표할 수 없으므로 거짓 주장이 합계에서 들킨다.
- 마지막 밤 시작 순간 시민 2명 이상이 마피아를 지목 중이면 **빛의 결박**: 마피아 공개, D −1.

### 5.2 숨은 방해(설치 전 물자 중심, 상한 있음)

| 방해 | 제한 | 단서 |
|---|---|---|
| 선반 인출 | 하루 2개 | 빈 자리 깜빡임, 서버 기록 시각 |
| 바다 몬스터 소환 | v4 쿨다운 유지 | 빈도·누구 옆에서 |
| 모듈 부식 | 한 판 1회, 미장착 모듈 | 장착 후 다음 새벽 그 칸이 바다로 떨어짐 → **촉수 낙하와 같은 회수 규칙**(재료 없이 재장착) |
| 환영 섬·날씨 변경 | v4 유지 | 항해사, 예보 불일치 |
| 마지막 밤(숨은 채) | 회수를 맡은 척 늦게 오기, 몬스터 소환 | 누가 건진 모듈을 분해시켰나 |

장착된 모듈은 영구이고 마피아가 지울 수 있는 것은 "시간"뿐이다. 반복 노가다가 생기지 않는다.

### 5.3 공개된 마피아

선반·작업대·부식·환영 섬·날씨 불가. 들킨 후 몬스터 소환(v4 4.2)만 남겨 마지막 밤까지 할 일이 있다.

## 6. 투표

| 항목 | 제안 |
|---|---|
| 유지 | 시민 판당 2회 지목, 마피아 투표 불가, 자기 지목 불가, 철회 불가(현재 박태욱 Rules 재사용) |
| 바뀜 | 효과가 "새벽 D 정산"과 "마지막 밤 결박" 두 곳으로 단순화. 시간 비례 봉인·오투표 누적 삭제(새벽 순간의 지목 상태만 셈) |
| 삭제 | 정체 확인·10초 소환 권리·확인 실패 무고 공개, 점화 의식의 "종료 순간 2표 = 승패" |

## 7. 물자 — 가방 새벽 초기화

- 새벽에 개인 가방에 남은 자원은 사라진다(해 질 녘 귀항 알림에 함께 경고).
- 이유: 외해 재료 사재기로 하루 만에 8칸을 채우는 스피드런 차단, 마피아의 보이지 않는 사재기 제거, 매일 밤 집결·적재 강제(→ 선반 인출 단서가 생김, "누가 안 돌아왔나"가 다시 단서).
- 등대 섬 작업대 선반이 유일한 공용 보관처. 레시피 진행도는 영구(리셋 없음).
- 위험: 외해에서 난파하면 손실이 크다 → 소실 비율(전부/절반)은 가안으로 두고 시험.

## 8. 유지하는 것

낮밤·5일 기한·지역 해금 1/3·2/3, 날씨 5종·안개·토네이도, 유령선, 특수 섬 3종, 환영 섬, 직군 3종, 난파·조명탄·구조, 작업대 레시피, 등대 8슬롯, 촉수 감기·조이기 연출.

## 11. 같은 날 두 제안과의 차이

| | 점화의 밤 / 마지막 불빛 | 불침번(이 문서) |
|---|---|---|
| 결말 | 등대 HP 방어 90초 | 8칸 방벽을 지키며 빛 150초 충전(HP 없음, UI 하나) |
| 1~3층 의미 | 방어 강화(선택) | 촉수가 떨어뜨리는 방벽. 점화엔 8/8 필수 |

| 마피아 소환 | 삭제 | 정체 공개를 대가로 하는 1회 "부름" |
| 박태욱 코드 변경량 | 큼 | 투표 Rules 유지, D·부름·촉수 콜백 위주 |

## 12. 남은 결정

1. 채택 여부와 1단계 범위
2. 수치: 빛 150초, 제한 L 240초, 촉수 간격표, D 증감(+1/−0.5/+0.5), 분해 120초
3. 부름 사용 가능 시점(외해 개방 후 vs 3일차 밤부터)
4. 가방 새벽 소실 비율(전부/절반)
5. 토론 수단(R21) — 공개 D 추리는 텍스트·외부 음성 어느 쪽이든 동작하지만 수단 자체는 정해야 함
