## 요청과 목표
김지훈 담당 Network·Interaction·Lighthouse·공용 UI에 어떤 사운드가 필요한지 기획·현재 코드·에셋 연결을 대조한다. 아래 추가안은 제작 목록 제안이며 확정 기획이나 구현 승인이 아니다.

## 진행 과정과 결정 이유
- 담당자를 사용자에게 확인한 뒤 전체 pointer → 김지훈 pointer → 제작음·승리음·공개 배너·선택 WAV 기록을 읽었다.
- CODE_OWNERSHIP·CODEOWNERS, 시스템 개요, 기술설계 관련 현황, v4 제작/등대/부식 규칙, 승패·투표 결정과 문제 대장을 대조했다.
- 담당 코드의 AudioClip·AudioSource·SoundManager 호출, 본편/시험 프리팹과 씬의 클립 필드·오버라이드, 소환 Timeline 오디오 GUID를 검색했다. 기존 미커밋 변경을 현재 조사 기준으로 포함하고 보존했다.
- 기능이 있다는 이유로 전용 효과음이 이미 있거나 반드시 별도 파일이 필요하다고 보지 않았다. 같은 UI 소리를 재사용할 수 있다.

## 기획 공백·예상 영향
- R01·R02·R16·N04: 확인 성공/소진·소환 권리는 마피아만, 확인 실패 공개는 전원이다. 공용 3D 소리나 전체 RPC로 개인 효과음을 재생하면 주변 시민에게 비밀 행동이 드러날 수 있다. 확정된 정보 수신 범위를 그대로 따른다.
- R19·W08: 작업대 인출은 화면을 보는 동안 재료 줄 깜빡임만 공개하고 인출자를 표시하지 않는다. 전역 인출 경보·범인 위치 공간음은 현행 결정을 확대하므로 본인 피드백만 제안한다. 인출 한도 등은 미정이다.
- W02·W03·W04: 낙하 시점·모듈 수명·후속 대응 계약은 부분 해결/확인 필요다. 사운드 작업이 임의 낙하 타이머나 신규 회수 규칙을 만드는 근거가 되지 않는다.
- R09: 승패 경합은 부분 결정/잔여 계약이 있다. 결과음은 확정된 최종 결과만 소비하며 별도 로컬 승패 판단을 하지 않는다.
- V01·R21: 인게임 보이스·배 무전은 삭제됐다. 관련 송수신음·무전 채널음을 필요한 작업으로 추가하지 않는다.
- `TowerMatchEffects.Play`와 `SummonRightCue`는 자체 AudioSource.PlayOneShot 경로다. SoundManager를 사용하는 기존 3개 효과와 달리 소리 설정 연동을 코드만으로 보장할 수 없다. 클립을 채울 때 효과음 볼륨·음소거 경로를 확인한다.
- 선택 WAV 10개는 로컬 ThirdParty/jihunSound에 복사된 기록이며 Git 제외 대상이다. 본편 공유용으로 연결할 파일은 기존 3개처럼 관리되는 오디오 경로와 meta를 사용한다. 이 조사에서는 복사하지 않았다.

## 담당 경계
- 최명기: SoundManager·BGM 기반, 발걸음·수영·배 이동·대포·채집·아이템 획득·난파/구조·직군 능력·인벤토리 화면·배 모듈 장착 UI. 김지훈 UI 담당이라는 이유로 이 효과음을 중복 구현하지 않는다.
- 강민서: 파도·바람·비·천둥·환경·유령선 등장/경로/침몰·토네이도. 선택한 beach_waves_ocean_calm_loop_02를 갖고 있다는 사실만으로 김지훈 담당으로 바꾸지 않는다.
- 박태욱: 몬스터·소환 규칙·투표/확인 판정. 김지훈이 유지 중인 확인 UI 코드도 실제 경로는 박태욱 영역이므로 후속 수정 때 기존 합의 범위를 확인한다.
- 제목/로비 BGM과 최후 전투 BGM 전환은 표현 제안으로 가능하나 전역 오디오 담당 최명기와 연결을 맞춘다.

## 변경 파일과 결과
- 이 조사 문서와 김지훈 pointer만 갱신. 게임 코드·오디오·씬·프리팹은 수정하지 않았다.

## 검증
- 실행: 문서·코드·프리팹/씬 텍스트·Timeline 참조 정적 확인, Git 브랜치/기준 커밋 확인.
- 미실행: Unity 컴파일·실제 청취·본편/시험 씬 재생·다인 재생·거리 감쇠·음소거. 코드 변경이 없는 조사이며 기존 작업의 컴파일 기록을 이번 실행으로 세지 않았다.
- 전용 호출 미발견은 담당 스크립트 경로의 AudioClip/AudioSource/SoundManager 검색 기준이다. 외부 에셋 전체의 가용 사운드 라이브러리 전수 청취는 하지 않았다.

## 남은 일과 차단 조건
- 우선 후보: 장착 → 보상 해금/수리 완료 → 의식 시작 → 전투 시작/피격 → 마피아 승리 → 소환 권리 획득.
- 그다음 작업대 투입/운반·투표 확정·거절·화면 열고 닫기를 채운다. 같은 소리 재사용 가능.
- 이미 연결된 소리는 본편 호스트+원격에서 실제 청취·중복·설정 반영을 확인해야 한다. 구현은 별도 요청 범위다.
