## 요청과 목표
- 등대 창 옆에 기존 버튼 스타일의 의식 시작 버튼을 배치한다.
- 수리 100%에 마피아를 최종 색출해야 탈출한다는 ScreenNotice를 표시하고 글자 넘침을 방지한다.
- 메인 씬 자체는 수정하지 않는다. 필요하면 JH04에 구성한다.
- 씬 수정 없이 가능한 경우 개발자 OnGUI에 전체 모듈 장착 버튼을 넣는다.

## 진행 과정과 결정 이유
- R06·R07과 승패·투표 결정 3·4절의 수리 100% 이후 수동 시작·의식 중 투표 잠금·60초 후 결과 규칙을 유지했다. 자동 시작으로 바꾸지 않았다. R09 경합 미정은 이번 UI에서 새로 판정하지 않는다.
- 기존 TowerScreen은 장착만 요청했고 StartRitual은 개발 패널에만 있었다. 기존 InteractionRelay → 서버 Router → TowerMatchNet 경로를 재사용한다. 서버의 거리·지원 액션·게임 진행·의식 가능 여부 검증을 우회하지 않는다.
- MainOffline이 Play 중이며 네트워크 서버/클라이언트는 꺼져 있음을 확인했다. 플레이를 중지하거나 씬을 저장하지 않고 PrefabUtility.LoadPrefabContents/SaveAsPrefabAsset으로 공용 프리팹만 갱신했다.
- 기존 장착 버튼을 복제해 동일 이미지·클릭 색상으로 ‘의식 시작’을 배치했다. ‘수리 100% 후 시작 가능 / 시작하면 투표가 잠깁니다’ 안내를 붙였다. 준비 전·요청 대기·의식/전투/종료 단계에서는 비활성화하고, 서버 승인 시 창을 닫고 기존 카메라 복귀·입력 해제를 사용한다.
- 100% 전환의 기존 준비 연출 경로에 게이지 없는 두 줄 ScreenNotice를 추가했다. 기존 공용 알림의 줄바꿈·자동 축소·영역 제한을 재사용해 Common 코드는 수정하지 않았다.
- 개발자 창에 호스트 전용 ‘등대 모듈 전체 장착 (시험)’ 버튼을 넣었다. NetworkServer.spawned에서 모듈 서버의 기존 장부를 가져와 빈 슬롯마다 실제 Installed 기록을 만들고 기존 동기화·ModuleInstalled 알림을 발생시킨다. 숨은 수리 단계에서만 허용하며 이미 완료된 등대·최후 전투에서는 실행하지 않는다. 원격 치트 Command는 만들지 않았다. 자원 비용을 건너뛰는 시험 기능이며 의식은 자동 시작하지 않는다.

## 검증
- Unity 새로고침/컴파일 후 새 필드 로드 확인, 최종 콘솔 error 0.
- 프리팹 재조회로 버튼·배경·텍스트 참조 3개 연결 확인.
- 격리 PreviewScene UI 검사: 100% 미만 비활성, 100% 활성, 요청 대기 비활성, Ritual 단계 비활성 4/4 통과. 네트워크 접속 없는 UI 상태 주입 검사이며 서버 통합 검증이 아니다. 최초 SyncList 수정은 Mirror의 비접속 쓰기 보호로 거절됐고, 재검사에서는 격리 객체의 SyncList 쓰기/기록 델리게이트만 지정했다. 실제 서버/클라이언트 전역 상태는 바꾸지 않았다.
- 격리 렌더 `output/ritual-ui/tower-ready.png`에서 버튼·안내 배치 확인. 이 이미지는 외형 시안 상태로 슬롯/게이지를 실제 서버 상태로 채운 장면은 아니다.
- `output/ritual-ui/notice.png`: 1920×1080 렌더 육안 확인. 알림 520×76 텍스트 영역에 22pt 자동 축소, 생성 글자 51/원문 51로 전체 표시. 원래 크기의 preferredHeight가 98이어도 BestFit 적용 후 두 줄이 판넬 안에 들어감을 렌더로 확인했다.
- 프리팹 저장 전후 MainGame/MainLobby/MainOffline SHA-256 모두 동일, 활성 MainOffline dirty=false 확인. 기존 MainOffline 미커밋 변경은 보존했다.
- C# diff 공백 검사 통과. 프리팹 diff에는 Unity 직렬화의 빈 m_Name/m_EditorClassIdentifier 줄 공백 8건이 있어 YAML 직접 수정 없이 보존했다.
- 미실행: 실제 호스트 전체 장착 클릭·원격 슬롯/알림 동기화, 등대 근처 버튼 클릭→서버 승인→60초 진행, 거리/난파 등 거절 경로, 다른 플레이어가 먼저 의식을 시작한 경우. 현재 MainOffline 플레이를 임의 전환하지 않았다.

## 남은 일과 차단 조건
- 실제 본편 또는 JH04의 호스트에서 개발자 창을 켜 전체 장착을 누른 뒤, 등대 E → 의식 시작 클릭을 확인한다.
- 원격 클라이언트에서도 100% 안내·버튼 활성·의식 타이머·투표 잠금을 확인한다.
- 씬 병합은 불필요하다. 실행 중인 기존 UI 인스턴스나 기존 빌드에는 새 프리팹이 소급 적용되지 않을 수 있으므로 새 실행/재빌드로 확인한다.
