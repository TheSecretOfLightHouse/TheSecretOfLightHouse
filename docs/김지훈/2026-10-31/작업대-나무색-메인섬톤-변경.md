# 작업대 나무 텍스처 색을 메인 섬 바닥 톤으로 변경

작성일: 2026-10-31 · 담당: 김지훈

## 요청
JH04TestScene의 `WorkbenchHouse.prefab`에 쓰는 나무 작업대 모델의 나무 색을 MainIslandAppearance 나무 바닥(사용자 스크린샷) 색감으로 Blender에서 바꾼다.

## 수행
- 대상: `Assets/04.Models/Object/wooden workbench 3d model low/wooden_workbench_3d_model_low.fbm/wooden_workbench_3d_model_low_basecolor.jpg` (8192², FBX가 `.fbm`에서 찾는 기본 색 텍스처). FBX·`.meta`는 바꾸지 않았다.
- 목표 색: 스크린샷 나무 바닥 평균 sRGB 약 (100, 74, 51).
- Blender 5.2.1에서 FBX를 불러와 텍스처 픽셀을 HSV로 조정. 주황 색상(5~45°)·채도 0.5 이상인 픽셀만 부드러운 마스크로 골라 색상 +5°, 채도 ×0.64, 명도 ×0.75. 금속·밧줄·컵은 채도가 낮아 거의 그대로다.
- 저장은 view transform을 Standard로 바꿔 색 변환 없이 JPEG(품질 92). 처음 AgX로 저장한 파일은 어두워져 다시 저장했다.
- 원본 백업은 세션 임시 폴더에만 있다. 되돌릴 때는 `git checkout -- <위 jpg>`.

## 2차 조정 (사용자: 더 짙은 갈색)
- 빌드로 본 1차 결과가 연하다는 피드백에 원본 백업에서 다시 계산: 색상 +5°, 채도 ×0.69, 명도 ×0.60. 나무 평균 (139,74,31) → (83,60,39). 채도 0.45 미만 픽셀(금속·컵·밧줄 대부분)은 원본과 같음을 확인.
- `Builds/JH04` 일반 빌드 성공(16:15) 후 창 4개(960x540, `client0~3.log`) 실행.
