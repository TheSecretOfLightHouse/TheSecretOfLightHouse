# 프레임 상한 60 고정
작성일: 2026-10-31

## 요청
게임 프레임 제한을 보편적인 수치와 게임에 맞는 수치로 정해 적용(사용자 지시). 다른 세션이 Unity MCP를 쓰는 중이라 에디터 조작 없이 코드만 추가.

## 결정과 이유
- **60 고정, 수직 동기화 끔.**
  - 보편 수치: PC 게임 기본 상한은 보통 60(또는 모니터 주사율 VSync).
  - 우리 게임: 배·3인칭 이동 위주로 빠른 반응 경쟁 게임이 아니다. 리슨 호스트가 서버 판정도 돌리므로 Mirror `sendRate: 60`(MainOffline)과 맞춰 호스트 틱을 고르게 둔다.
  - VSync를 쓰면 144/240Hz 모니터에서 상한이 따라 올라가고, 프레임이 늦으면 30으로 떨어질 수 있어 끈다.
  - 10-19 데모 진단: 상한이 없으면 한 PC 여러 창 시험(M2)에서 조작 창이 300FPS, 나머지 창이 3~4FPS로 떨어져 남의 이동이 끊겼다. 데모에 60을 넣자 세 창 모두 60FPS로 해결됨([기록](../2026-10-19/항해일지-데모.md)).
- 위치: 공용 에셋(`QualitySettings.asset`) 대신 코드. YAML 직접 편집 금지 규칙과 씬마다 다른 NetworkManager(시험용 포함)를 모두 덮기 위해 `RuntimeInitializeOnLoadMethod(BeforeSceneLoad)`로 앱 시작 시 한 번 적용.

## 변경 파일
