## 요청과 목표
- 지정 외부 폴더의 `MS01triumph3NL.wav`를 시민 승리 사운드로 적용하고 원본 대비 볼륨을 90%(0.9)로 설정한다.

## 진행 과정과 결정 이유
- 2026-10-31: 승리 화면·서버 결과 소비 경로와 최신 승패 결정을 대조했다. 기존 VictoryScreen에는 사운드 연결이 없었다. R09의 판정 경합 미결 사항은 이번 클라이언트 결과 연출과 독립적이다.
- 기존 `VictoryScreen.Open`에서 결과가 `CitizensWin`이면 SoundManager의 `PlayEffect`를 한 번 호출한다. 역할에 관계없이 시민 승리 화면을 보는 클라이언트에 재생된다. 매 프레임 반복하지 않고 기존 결과 단계 변경 가드를 사용한다. SoundManager가 없으면 기존 PlayerSoundManager 프리팹으로 생성한다.
- 볼륨은 0.9이며 SoundManager의 마스터·효과음 볼륨과 음소거 설정을 추가 적용한다. 승패 판정·네트워크·마피아 결과 화면은 기존 동작을 유지한다.
- 외부 폴더는 Git 제외 대상이므로 Unity AssetDatabase로 본편 오디오 폴더에 복사하고, 승리 화면 프리팹은 Prefab API로 저장했다. 외부 원본과 공용 SoundManager는 수정하지 않았다.

## 변경 파일과 결과
- `Assets/01.Scripts/04.Lighthouse/Tower/View/VictoryScreen.cs`: 시민 승리 효과음 호출·직렬화 설정.
- `Assets/01.Scripts/04.Lighthouse/Workbench/Editor/VictoryScreenSetup.cs`: 프리팹 재생성 시 오디오 연결 유지.
- `Assets/02.Prefabs/UI/Tower/VictoryScreen.prefab`: 클립·SoundManager·볼륨 0.9 연결.
- `Assets/08.Audio/Victory/MS01triumph3NL.wav`와 meta, 폴더 meta: 본편용 복사본.

## 검증
- Unity 스크립트 컴파일 후 콘솔 error 0.
- 저장한 프리팹 재조회로 MS01triumph3NL 클립·볼륨 0.9·SoundManager 참조를 확인했다.
- 원본과 본편 복사본 SHA-256 일치, 본편 WAV의 Git 제외 없음, `git diff --check` 통과.
- 실제 시민 승리 전환·청취·원격 재생은 미실행. 에디터의 기존 Play를 임의 중지하거나 씬을 저장하지 않았다.
