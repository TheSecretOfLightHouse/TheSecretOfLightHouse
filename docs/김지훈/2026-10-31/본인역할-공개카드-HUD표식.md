# 본인 역할 공개 카드와 HUD 역할 표식

작성일: 2026-10-31 · 담당: 김지훈(UI)

## 배경
- 서버는 판 시작 때 각자에게 자기 역할만 따로 보낸다(`OwnRoleMessage`, `LighthouseNetworkManager.OwnRole`). 그런데 본편 화면에는 역할을 직접 알려 주는 UI가 없었고, 시험용 `OwnRoleOverlay`(`-roleOverlay` 실행 옵션)만 있었다.
- 기획(v4·승패·투표 결정)에도 역할을 알리는 방식이 정해져 있지 않았다(기획 공백). 사용자 결정(2026-10-31): ① 판 시작 카드를 기존 UI 느낌에 맞춰 만들고, ② 상시 HUD 표식은 Alt 패널에 둔다. 마피아 표식은 작업대 인출 버튼의 가면 아이콘을 수평으로 바로 세워 쓴다.

## 구현
- `Assets/01.Scripts/09.UI/Hud/OwnRoleBanner.cs`(새 파일): 판마다 로컬 플레이어가 생기고 역할이 도착하면 1초 뒤 약 5초 동안 띄우고 사라진다. 틀은 정체 확인 실패 배너(`InnocentRevealBanner`)와 같다(테두리·붓 띠·반짝이, 같은 배치·타임라인, 일차 보드 아래).
  - 마피아: 수평으로 세운 가면(`ws_icon_mafia_mask`, -19°), "마피아"(붉은색), "정체를 숨기고 등대가 다시 밝혀지는 것을 막으세요."
  - 시민: 자기 직군 초상, "선원", "등대를 다시 밝히고 숨은 마피아를 찾아내세요."
  - 시민도 같은 틀과 같은 시간으로 띄우므로, 카드가 뜨는지 여부만으로는 마피아가 드러나지 않는다. UI는 실행 중에 만들어서 프리팹은 바꾸지 않는다.
- `Assets/01.Scripts/09.UI/Hud/HudReveal.cs`: 직군·배 패널의 역할 줄 오른쪽 끝에 역할 표식을 만든다. 마피아는 가면과 "마피아", 시민은 등불(`hud_icon_lantern`)과 "선원"이다. Alt 패널과 함께 나타나고 사라진다. 역할이 없을 때(로비)는 숨긴다.
- `JH04TestScene.unity`: 새 캔버스 오브젝트 `OwnRoleBanner`(정렬 74)를 추가하고, `HudReveal`의 역할 표식 참조를 연결했다. 에디터 API로 저장했다.
- MainGame 이식: [UI작업-MainGame-이식](UI작업-MainGame-이식.md)에서 `OwnRoleBanner` 캔버스와 `HudReveal`을 같은 참조로 옮겼다. 다시 확인한 결과, `_roleName`·`_rolePanel`은 MainGame의 InGameHud 인스턴스에 있는 `RoleName`·`Panel`을 가리키고, 가면·등불·배너 스프라이트도 모두 연결돼 있다.

## 검증
- 실행함: 컴파일 error 0. 미리보기 씬에서 InGameHud 프리팹과 카드를 렌더해 마피아·시민 두 장을 눈으로 확인했다(텍스트 잘림 없음, 가면이 수평으로 섬).
- 실행 안 함: 플레이 모드와 원격 4인 환경에서 판 시작 시 표시, Alt 토글 표시, 판 종료 후 로비에서 숨김.
