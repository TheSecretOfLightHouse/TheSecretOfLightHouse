# 유령선 장부 UI 시안 v2 적용

2026-10-31, 김지훈. 사용자 요청: 유령선 정보창을 새 시안(구성요소 아틀라스 + 완성 시안)으로 교체, 자원 아이콘은 작업대 UI 기존 것 사용, 메인 씬은 건드리지 말고 JH04TestScene 기준으로 확인, 프리팹 교체로 메인에도 바로 반영되게.

## 결과

- 장부 화면은 원래 유령선 프리팹(`GhostShipHintPopup._screenPrefab`)이 처음 쓸 때 생성하는 별도 UI 프리팹 `Assets/02.Prefabs/UI/GhostShip/GhostShipLedger.prefab`이다. 이 프리팹만 다시 만들었고 GUID가 같아서 JH04TestScene·MainGame 둘 다 씬 수정 없이 새 장부를 쓴다(두 씬 모두 `_screenPrefab` override 없음 확인). 메인 씬·`GhostShip.prefab`은 변경 없음.
- 아틀라스(`output/ghostship-ui-concept-2026-10-31/ghostship-ledger-atlas-v1.png`, 사용자 첨부와 동일)를 alpha 경계로 잘라 `Assets/03.Images/GhostShipLedger/`에 저장. 생성 이미지의 붉은 저알파 테두리(alpha 1~15)는 제거.
  - 교체: `ghl_board`(제목·유령선·부제·매듭선·열 제목·하단 문구가 박힌 통합 판넬 847x721), `ghl_day_1~5`, `ghl_divider_line`, `ghl_empty`("사라진 자원은 아직 없다").
  - 추가: `ghl_day_dim_1~5`(인출 없는 날), `ghl_nothing`("없음"), `ghl_close`(X), `ghl_esc`, `ghl_close_label`("닫기").
  - 삭제: 옛 시안 전용 `ghl_title`·`ghl_divider_knot`·`ghl_subtitle`(참조 0 확인 후 AssetDatabase로 meta와 함께).
  - 아틀라스의 자원 아이콘 4종은 쓰지 않는다.
- 판넬은 9-slice(위 320·아래 72·좌우 40px)로 머리말·꼬리말을 고정하고 가운데만 세로로 늘린다. 화면 폭 940(1920 기준).
- 행: [일차 배지 | 자원 3열 그리드]. 자원 칸은 아이콘 + "이름 × 수량"(OS 한글 폰트, 크림색). 아이콘은 빌더가 `WorkbenchScreen_Sketch.prefab`의 `_resourceIcons`(`ws_icon_*`)를 복사해 `GhostShipLedgerScreen._resourceIcons`에 넣고, 화면은 `ResourceDefinition.Id`로 찾는다.
- 인출 없는 날은 흐린 배지 + "없음". 첫 행 위 구분선은 판넬에 박혀 있어 둘째 행부터 행 구분선을 켠다. 6일차 이상·날짜 미상은 기존처럼 글자로 표시.
- X 버튼 클릭 또는 Esc로 닫는다. 게임 중 커서가 숨겨져 있어 열린 동안 커서를 보이고 닫을 때 원래 상태로 복원(작업대와 같은 저장·복원 방식). 장부가 1040(1080 기준)보다 길어지면 판넬 전체를 축소.

## 검증

- 실행함: Unity 컴파일 error 0. 빌드 메뉴 실행 성공, 프리팹 Missing 0, 자원 아이콘 6·흐린 배지 5 연결, 유령선 프리팹 연결 유지.
- 실행함: 프리뷰 씬에서 프리팹을 열어 1920x1080 오프스크린 렌더 3건 — 시안과 같은 3일(빈 날 포함), 5일·한 날 자원 5종(2줄), 인출 0건. 시안과 배치 일치 육안 확인.
- 실행 안 함: Play·JH04 빌드에서 유령선 E → 장부 열기, X 클릭·Esc 닫기, 커서 복원, 다인 접속.
