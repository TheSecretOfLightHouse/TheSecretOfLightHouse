# 등대 수리 보상 창과 Alt 버튼 (MainGame)

작성일: 2026-10-31

## 요청 (사용자, 2026-10-31)
- Alt로 펼쳐지는 오른쪽 버튼 줄에 등대 수리 보상 버튼을 추가하고, 누르면 보상 창(시안 이미지)을 띄운다.
- 기존 UI와 통일감을 맞추고, 사용자가 준 분리 이미지를 써도 된다. 메인 씬에 바로 반영한다.

## 기획·코드 대조
- v4 6.1 수리도 보상 25% 배 이동 속도, 50% 자원 파밍량, 75% 배 대포 피해, 100% 점화 의식 가능 — 시안 문구와 같다.
- 코드: `TowerLayout._rewardPercents`(25·50·75), `TowerNet.RepairRatio`·`RewardTier`·`IsComplete`. 실제 적용은 `PlayerPassiveController.TowerRewardTier`(SyncVar, 최후 전투 시작 시 고정, 소환한 마피아는 `IsJobAbilityEnabled` false로 미적용).
- 그래서 체크 표시는 탑 단계가 아니라 **본인이 받은 단계**를 읽는다. 최후 전투에서 수리가 더 올라도 새 보상은 체크되지 않는다. 100% 줄은 탑 완성 여부를 읽고, 최후 전투에서는 "수리 완료 시 시민 승리"로 바꿔 보여 준다(TowerMatchNet 주석의 승계 규칙 기준).

- 프리팹 오프스크린 렌더 확인(50%·100% 글자, 막대, 체크/동그라미, 버튼).
