# 거리 등불(street lantern) 사실적 기름 등불로 다듬기

- 작성일: 2026-10-31
- 담당: 김지훈
- 상태: 미커밋. Blender 편집·FBX 내보내기·Unity 임포트·프리팹 저장·에디터 오프스크린 렌더까지 확인함. 플레이는 하지 않음

## 요청

`street lantern 3d model`이 너무 쨍한 초록빛이라 보기 좋지 않다. 실제 등불이 빛을 어떻게 비추는지 생각해 사실적으로 다듬고, JH04TestScene에서 보이게 한다.

## 판단

실제 기름 등불은 유리가 스스로 빛나지 않는다. 안쪽 심지 불꽃 하나가 광원이다. 그래서 아래처럼 보인다.
- 빛은 따뜻한 주황(약 1900K)이다.
- 유리는 거의 투명하다. 안의 불꽃과 버너가 비쳐 보인다.
- 철틀 안쪽 면이 불빛을 받아 밝아진다.
- 바닥에 철틀 그림자가 방사형으로 생긴다. 등불 바로 아래는 받침에 가려 어둡다.
- 불꽃이 조금씩 흔들려 밝기와 그림자가 살짝 일렁인다.

이전 버전은 반대로 했다. 유리 자체를 초록으로 발광시켰고 점광원 그림자도 껐다.

## 수행

1. Blender MCP(5.2.1)로 FBX를 불러와 조사함. 안쪽이 받침 아래까지 깔때기처럼 뚫려 있었음. 10-29에 분리한 유리 68면은 가운데에 구멍이 있었음.
2. 기존 유리 면을 지움. 대신 깨끗한 사다리꼴 유리 4장(아래 0.128m → 위 0.176m, 높이 0.305~0.665m)을 `StreetLanternGlass` 슬롯으로 새로 만듦.
3. 안쪽에 아래 부품을 추가함. 바닥판, 납작한 청동 기름통, 버너 목, 심지관, 심지. 이 부품들은 본체 텍스처의 어두운 청동색 UV(0.232, 0.283)를 씀.
4. 불꽃 메시(물방울 모양 회전체, 높이 약 9cm)를 새 재질 슬롯 `StreetLanternFlame`으로 추가함.
5. 같은 경로에 FBX를 덮어씀. 처음 내보낸 파일은 Unity에서 `fileScale 0.01`·루트 회전 90°로 들어왔음. 그러면 씬 인스턴스가 1.2cm로 줄거나 눕게 됨. 그래서 변환을 적용하고 `FBX_SCALE_UNITS`·`bake_space_transform` 설정으로 다시 내보냄. 결과는 루트 회전 0, 스케일 1, 크기 0.567×1.0×0.549m로, 원래와 같음. 원본 FBX·재질은 세션 스크래치패드에 백업함(저장소 밖).
6. Unity 재질
   - `StreetLanternGlass.mat`: 초록을 없애고 거의 투명한 유리로 바꿈. BaseColor (0.86, 0.83, 0.76, a 0.1), Smoothness 0.93. 먼지가 빛을 받는 정도로만 약하게 발광 (0.09, 0.045, 0.015). ShadowCaster 패스를 끔(유리가 빛을 막지 않도록).
   - 새 `StreetLanternFlame.mat`: URP Lit, Base 검정, HDR 발광 (2.2, 1.05, 0.3). 그림자를 만들지도 받지도 않음.
   - FBX 임포터에서 `StreetLanternFlame` 재질을 리맵함.
7. 프리팹 `Assets/02.Prefabs/Lighthouse/WorkbenchHouse.prefab`을 수정함. JH04TestScene의 `StreetLantern`은 이 프리팹 안에 있음.
   - `StreetLanternLight`: 높이 0.43(불꽃 가운데), 색 (1, 0.58, 0.26), 강도 1.6, 범위 5, Soft 그림자(세기 0.9, near 0.1), 픽셀 라이트 고정.
   - `StreetLantern`에 새 컴포넌트 `LanternFlameFlicker`를 붙임.
8. 새 스크립트 `Assets/01.Scripts/04.Lighthouse/Lantern/View/LanternFlameFlicker.cs`를 만듦(`Lighthouse.Lantern.View`). 느린 숨쉬기와 빠른 미세 흔들림을 Perlin 노이즈로 섞어 라이트 강도를 바꿈. 라이트 위치도 4mm쯤 흔들어 철틀 그림자가 일렁이게 함. 불꽃 발광은 재질 슬롯 2에 대한 MaterialPropertyBlock으로 같은 값을 따라가게 함. 할당 없음. 등불마다 시드를 달리해 여러 개가 같이 깜빡이지 않게 함.

## 검증

  - 실제 게임의 밤 조명, 블룸 포스트 프로세싱이 있을 때 모습.
  - 메인 섬 화면.

## 후속: 초록 유령불로 되돌리고 빛 범위 키우기 (2026-10-31)

### 요청
완전히 투명하기만 한 유리는 원하지 않음. 초록빛으로 하되 보기 싫지 않게 하고, 빛 범위를 조금 키운다.

### 수행
1. 유리 재질을 바꿈. 투명 유리를 우윳빛 반투명 유리로 바꾸고, 불꽃 높이에서 초록빛이 번지게 함. 텍스처 2장을 새로 만듦(64×256, Clamp).
   - `StreetLanternGlass_Base.png`: 연한 초록 회색. 위쪽 30%에 그을음 띠, 가장자리에 때. 알파는 가운데 0.5, 그을음 부분 0.88.
   - `StreetLanternGlass_Glow.png`: 불꽃 높이(v≈0.38)를 가운데로 한 타원 번짐. 그을음과 가장자리에서 약해짐.
   - 유리 BaseMap과 EmissionMap에 위 두 장을 연결함. 발광 (0.25, 0.9, 0.5), Smoothness 0.75. 그림자는 계속 만들지 않음.
2. 불꽃 발광을 민트 초록 (0.5, 1.6, 0.8)으로 바꿈. 처음 넣은 (0.9, 2.6, 1.3)은 톤매핑 없이 하얗게 날아가서 낮춤.
3. 점광원을 바꿈. 색 (0.45, 1, 0.62), 강도 1.6 → 2.4, 범위 5 → 7.
4. `LanternFlameFlicker`를 바꿈. 렌더러 필드 이름을 `_renderer`로 바꾸고, 유리 슬롯(`_glassMaterialIndex` 1, `_glassEmission`)도 불꽃과 같은 흔들림 값으로 밝기가 따라가게 함. 프리팹에서 참조를 다시 연결함.

### 변경 파일 (추가분)
- 새 파일: `.../StreetLanternGlass_Base.png`, `.../StreetLanternGlass_Glow.png`와 `.meta`
- `StreetLanternGlass.mat`, `StreetLanternFlame.mat`, `WorkbenchHouse.prefab`, `LanternFlameFlicker.cs`

### 검증
- 실행함: 밤 가까이·밤 멀리·낮 렌더(JH04TestScene만, 조명 임시 전환 후 되돌림). 결과: 유리가 불꽃 쪽부터 초록으로 번짐, 철틀 안쪽이 초록빛을 받음, 바닥의 초록빛 범위가 넓어짐. 콘솔 error 0. 렌더 뒤 씬을 저장 없이 다시 열어 dirty를 지움.
- 실행 안 함: 플레이 모드(흔들림 직접 확인), 블룸이 켜진 실제 게임 화면.

### 남은 일
- 플레이로 흔들림과 밤 밝기를 확인하기.
- 범선 선미 등불도 같은 유리 재질을 쓰므로 다시 초록 번짐 유리로 보임. 그 등불 안에는 불꽃과 라이트가 없음.
- 제안 D(안쪽 빛무리)는 이번에 넣지 않음.

## 후속 2: 바뀐 등불을 두 배에 더 배치 (2026-10-31)

### 요청
바뀐 등불을 배에 조금 더 놓는다. 대상은 지금 유령선에 실제로 쓰는 배와 `sailing ship 3d model` 두 가지다.

### 판단
- 유령선이 실제로 쓰는 모델은 Synty `SM_Veh_Boat_Warship_01`(`GhostShip.prefab`의 `Visual`)이다. `GhostShip.prefab`은 강민서 폴더라 고치지 않는다. 대신 JH04TestScene에 이미 있는 복사본 `GhostShip_TranslucentPreview`에 배치한다.
- 등불을 여러 곳에 쓰도록 공용 프리팹을 하나 만든다.
- 렌더러는 Forward+(`PC_Renderer` 모드 2)라서 오브젝트당 라이트 4개 제한이 없다. 다만 점광원 그림자는 아틀라스를 크게 먹는다. 그래서 배 위 등불은 그림자를 끈다.

### 수행
1. 새 프리팹 `Assets/02.Prefabs/Lighthouse/Lantern/StreetLantern.prefab`을 만듦. FBX에 `StreetLanternLight`(초록, 강도 2.4, 범위 7, Soft 그림자)와 `LanternFlameFlicker`를 붙인 형태. `WorkbenchHouse` 안의 등불과 같은 설정임.
2. 갑판 높이를 잼. 선체 메시로 볼록하지 않은 임시 MeshCollider를 만들어 위에서 아래로 레이캐스트함(전함의 원래 콜라이더는 볼록이라 지붕 모양으로 잡힘). 임시 콜라이더는 지움.
3. 각 배 아래에 `ShipLanterns` 그룹을 만들고 프리팹 인스턴스를 8개씩 놓음(배 쪽 오버라이드: 그림자 끔).
   - 유령선 미리보기(전함, 선체 로컬 좌표):
     - 선미 뒤갑판 양쪽 (±2.6, 10.61, -13)
     - 뒤갑판 앞 난간 (±3.0, 9.08, -6.7)
     - 중앙 난간 (±3.6, 6.89, 0.6)
     - 앞갑판 (±2.9, 8.60, 8)
     - 실제 높이 약 1.2m(로컬 스케일 1.714), 범위 6, 강도 2.2
   - 범선(선체 로컬 좌표):
     - 기존 선미 등불 자리 (±0.0675, 0.223, -0.48)
     - 중앙 난간 (±0.165, 0.18, -0.15)과 (±0.165, 0.176, 0)
     - 뱃머리 쪽 (±0.07, 0.18, 0.20)
     - 실제 높이 약 0.75m(스케일 0.075), 범위 4.5, 강도 1.8
4. 범선 FBX에 박혀 있던 옛 선미 등불(`StreetLantern_L`/`_R`)은 씬 오버라이드로 MeshRenderer만 끔. 불꽃과 라이트가 없는 옛 모습이 새 등불과 겹치지 않게 하려는 것. 콜라이더는 남김.
5. JH04TestScene을 저장함. 이 씬에 이미 있던 다른 미커밋 변경은 그대로 둠.

### 변경 파일 (추가분)
- 새 파일: `Assets/02.Prefabs/Lighthouse/Lantern/StreetLantern.prefab`과 폴더·`.meta`
- `Assets/00.Scenes/Jihun/JH04TestScene.unity`

### 검증
- 실행함: 두 배를 밤 조건으로 렌더함. 이때 JH04Offline의 태양광(밝기 1)도 렌더에 섞이는 것을 발견해, 두 씬의 태양을 모두 임시로 낮추고 다시 찍음. 렌더 뒤 원래대로 되돌림. 결과: 16개 등불이 난간과 갑판 위에 놓였고 초록으로 빛남. 범선 아래 바닥에 초록 빛이 고임. 씬 저장 뒤 dirty 없음, 콘솔 error 0.
- 실행 안 함: 플레이 모드, 실제 `GhostShip.prefab` 적용, 바다 위에서의 모습.

### 남은 일
- 유령선 재질(`Lighthouse/GhostTranslucent`)은 점광원을 받지 않음. 그래서 등불이 갑판을 비추지 않고 등불 자체만 빛남. 갑판에 빛이 고이게 하려면 셰이더가 추가 라이트를 받도록 고쳐야 함.
- 실제 유령선 적용: `GhostShip_TranslucentPreview/ShipLanterns`를 그대로 `GhostShip.prefab`의 `Visual` 아래로 옮기면 됨. 단, 미리보기는 0.7배로 줄여 놓은 것이라 실제 프리팹 크기에 맞는지 확인해야 하고, 강민서 합의가 필요함.
- 등불 16개 각각 Update가 돔. 메인에 많이 쓰면 비용을 확인할 것.

## 후속 3: 실제 유령선(`GhostShip.prefab`)에 넣기 (2026-10-31)

### 요청
등불을 실제 유령선에 넣는다.

### 판단
- `GhostShip.prefab`과 `02.World/GhostShip/`은 강민서 담당 영역이다. 다만 유령선 본체는 이전부터 사용자 지시로 김지훈이 구현해 왔다([강민서 안내](../../handover/김지훈/2026-10-31/강민서-유령선현황-요청.md)). 이번에도 사용자의 직접 지시로 진행했고, 강민서에게는 결과를 알려야 한다.
- `GhostShipView`는 물속 깊이에 따라 큰 등불(`_lamp`)을 줄이고, 다 잠기면 `Visual`을 숨긴다(`fd1f755`). 새 갑판 등불도 함께 줄이지 않으면 떠오름·침몰 중에 깊은 물속에서 빛이 비쳐 보이는 문제가 다시 생긴다.

### 수행
1. `LanternFlameFlicker`에 `Brightness`(0~1) 속성을 추가함. 라이트 강도와 불꽃·유리 발광에 곱하고, 0이면 라이트를 끔. 꺼질 때(`OnDisable`)는 라이트를 다시 켠 상태로 되돌림.
2. `GhostShipView`에 `_lanterns`(`LanternFlameFlicker[]`)를 추가함. `ApplyDepth`에서 `_lamp`와 같은 깊이 배율(`1 - depth/_lampFadeDepth`)을 각 등불의 `Brightness`에 넣음.
