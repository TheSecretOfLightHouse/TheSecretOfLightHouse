# 투표창 자동 닫힘 제거·크툴루 소환 확인창 제거

작성일: 2026-10-30 / 담당: 김지훈 (박태욱 영역 `07.Mafia` View, 사용자 지시)

## 요청

- 투표창에서 지목한 뒤 잠시 후 창이 저절로 닫히는 기능을 뺀다.
- 크툴루 소환은 확인창 없이 버튼을 누르면 바로 소환 요청을 보낸다.

## 변경

- `07.Mafia/Voting/View/VotingScreen.cs`: `_autoCloseSeconds`(0.6초)·`_closeAt`·`ScheduleClose` 삭제. 지목 성공(실제·마피아 가짜) 후에도 창이 열려 있고, 닫기는 사용자가 직접 한다. 지목 가능 조건에서 닫힘 대기 조건도 뺐다. 프리팹 `VotingScreen_Sketch.prefab`에 남은 `_autoCloseSeconds` 값은 쓰이지 않으며 다음 저장 때 빠진다(YAML 직접 편집 안 함).
- `07.Mafia/IdentityCheck/View/IdentityActionScreen.cs`: 소환 버튼 클릭 시 확인창 없이 `RequestSummon` 전송(겹친 창·응답 대기 중이면 무시). 요청 전송을 `SendRequest`로 분리해 정체 확인 확인창의 수락과 함께 쓴다. 확인창의 소환 분기(문구·남은 초·만료 안내) 삭제. 정체 확인은 확인창 유지.

이유: 확인창을 읽는 동안에도 10초 소환 권리가 줄어든다. 서버가 권리·난파 여부를 판정하므로 거절은 기존 거절 알림으로 표시된다.

## 검증

- Unity 스크립트 컴파일 error 0(경고는 다른 파일 기존 것).
- 미실행: 플레이(투표 후 창 유지, 마피아 확인 성공 → 소환 버튼 즉시 소환·최후 전투 시작).
