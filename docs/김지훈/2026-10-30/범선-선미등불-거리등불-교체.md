# 범선 선미 등불을 거리 등불로 교체한 FBX와 JH04 배치

- 작성일: 2026-10-30
- 담당: 김지훈
- 상태: 미커밋. Blender 편집·FBX 내보내기·Unity 임포트·씬 저장·에디터 렌더 확인

## 요청

범선 모델(`sailing ship 3d model`)에 붙은 등불을 FBX에서 떼어 내고, 그 자리에 `street lantern 3d model`을 붙여 모델만 `JH04TestScene`에 띄운다.

## 수행

1. Blender MCP(5.2.1)로 범선 FBX와 거리 등불 FBX를 불러옴. 범선은 Tripo 단일 메시(면 5,057개)였음. 메시에서 서로 떨어진 덩어리 300개를 찾아 색을 칠해 보고, 선미 난간 양쪽 등불 2개를 찾음. 등불 하나는 기둥·몸체 40정점과 지붕 13정점으로 되어 있음. 위치는 x ±0.0675, y 0.481, 높이 0.223~0.314m.
2. 그 4덩어리(등불 2개)를 삭제하고, 거리 등불을 0.075배로 줄여 같은 자리(갑판 높이 0.223)에 `StreetLantern_L`/`_R`로 올림. 같은 메시를 함께 쓰면 FBX 재질 슬롯 경고가 나서 오른쪽 등불 메시를 따로 복사함.
3. 새 파일 `sailing_ship_street_lantern_3d_model.fbx`로 내보냄(객체 3개: `SHIP_Hull`·`StreetLantern_L`·`StreetLantern_R`). 원본 범선 FBX와 원본 등불 FBX는 바꾸지 않음.
4. Unity 임포트: 범선 텍스처는 자동으로 연결됨. 등불 본체 재질은 원본 `street_lantern_3d_model.fbx`의 본체 재질로, 유리는 `StreetLanternGlass.mat`로 재질 리맵(임포터 설정 `.meta`에 저장).
5. `JH04TestScene`을 추가로 열어 `SailingShip_StreetLantern`을 배치함(위치 (-10, 0, 8), Y 60°, 크기 10배 → 약 10.8×6.7×8.7m). 저장한 뒤 닫음. 열려 있던 `JH04Offline`은 건드리지 않음(변경 없음).

## 변경 파일

- 새 파일: `Assets/04.Models/Object/sailing ship 3d model/sailing ship 3d model/sailing_ship_street_lantern_3d_model.fbx`과 `.meta`(재질 리맵 포함)
- `Assets/00.Scenes/Jihun/JH04TestScene.unity`

## 검증

- 실행함: Blender에서 교체 전·후 선미 확대 렌더. Unity 렌더러별 재질·텍스처 연결 확인. 에디터 카메라 스크린샷 2장(전체, 선미 확대 — 유리가 초록 발광). 콘솔 error 0.
- 실행 안 함: 플레이 모드, 밤 조명에서의 모습.

## 남은 일·결정 대기

- 등불 안 Point Light는 넣지 않음(요청이 "모델링만"이라서). 필요하면 기존 `StreetLantern`처럼 넣을 것.
- 기존 `GhostShip.prefab`(강민서 폴더)은 Synty 전함 모델을 그대로 씀. 이 범선으로 바꿀지는 강민서와 합의가 필요함.
- 배치 위치·크기는 확인용으로 임의로 정함.

## 후속: 사다리 옆틀·콜라이더 (2026-10-30)

### 요청
돛대 사다리 4곳에 발판만 있고 옆틀이 없으니 4곳 모두 옆틀을 붙이고 콜라이더도 넣는다.

### 수행
1. 발판으로 보이는 작은 막대(정점 8개) 덩어리를 위치로 묶어 사다리 4개를 찾음. A·B는 가운데 돛대 좌우(y≈-0.05, 발판 5개), C·D는 뒤 돛대 좌우(y≈0.33, 발판 4개).
2. 각 사다리마다 맨 아래와 맨 위 발판의 양 끝점을 잇는 선을 따라 옆틀 2개(단면 7mm 각기둥)를 만듦. 아래로 발판 한 칸, 위로 0.6칸 늘림. 발판의 나무색 UV를 그대로 써서 `SHIP_Hull` 메시에 합침(정점 5,539 → 5,603).
3. 같은 FBX 파일에 덮어써서 내보냄. 이전 재질 리맵은 유지됨.
4. Unity 모델 임포터에서 `Generate Colliders`(`addCollider`)를 켬. 그 결과 `SHIP_Hull`·`StreetLantern_L`·`StreetLantern_R`에 볼록하지 않은 MeshCollider가 붙음. 씬 YAML은 바꾸지 않음(인스턴스가 모델 에셋을 따라감).

### 검증
- 실행함: Blender에서 사다리 두 쌍을 확대 렌더함(옆틀이 발판 끝에 붙음). Unity 에셋에서 MeshCollider 3개와 재질이 유지되는지 확인함.
- 실행 안 함: 씬 인스턴스의 콜라이더. 확인하려던 때 사용자가 플레이 모드를 실행 중이었고, 그 플레이는 재임포트 전에 시작돼 실행 중인 인스턴스에는 콜라이더가 없었음. 플레이를 다시 시작하면 반영돼야 하지만 확인하지 않음. 오르기 동작도 확인하지 않음.

### 남은 일
- MeshCollider는 돛·밧줄까지 모두 포함함. 성능이나 이동 판정에 문제가 있으면 선체·갑판용 단순 콜라이더로 나눌 것.
- 사다리를 실제로 오르는 기능은 없음(콜라이더만 있음).

## 후속 2: 사다리 → 밧줄 그물(줄사다리)로 교체 (2026-10-30)

### 요청
옆틀을 붙인 사다리가 나무 판자 사다리처럼 보인다. 그물이 되게 하고, 위가 끊긴 부분을 배와 자연스럽게 이어지도록 직접 판단해 연결한다.

### 판단
원래 Tripo 모델에는 갑판에서 돛대 꼭대기까지 이어지는 줄사다리 선이 있었음. 아래쪽은 나무 발판 4~5개였고, 위쪽은 점 덩어리(정점 15개, 삼각 점 5개)만 남아 끊겨 보였음. 실제 범선처럼 돛대로 오르는 그물 줄사다리로 다시 만들기로 함. 세로 밧줄은 갑판에서 돛대 꼭대기로 좁아지며 모이고, 가로 밧줄은 촘촘하게 둠.

### 수행
1. 지운 것: 나무 발판 18개, 후속 1에서 붙인 옆틀 8개, 위쪽 점 덩어리 4개(정점 총 268개). 지우기 전 메시는 Blender 안의 `SHIP_Hull_backup_rails`(fake user)로 남김. 저장소에는 들어가지 않음.
2. 4곳(가운데 돛대 좌우, 뒤 돛대 좌우)마다 세로 밧줄 4줄을 만듦. 아래는 옛 사다리 바닥 폭(약 4.3cm)으로 갑판 난간에 닿고, 위는 1.2cm 폭으로 돛대 꼭대기(가운데 돛대 z≈0.624, 뒤 돛대 z≈0.627)에 붙음.
3. 가로 밧줄은 2.6cm 간격으로 전체 길이의 90%까지 둠(가운데 15줄 이상, 뒤 15줄). 가운데를 살짝 처지게 함. 단면은 오각형이고, 굵기는 세로 반지름 1.6mm·가로 1.1mm(모델 단위)임.
4. 색은 범선 텍스처에서 고르게 어두운 갈색 영역(UV (0.382, 0.906), 약 RGB 0.23/0.19/0.16)을 골라 새 밧줄에 붙임. 처음 고른 회갈색은 너무 밝아서 바꿈.
5. 같은 FBX 파일에 덮어써서 내보낸 뒤 다시 임포트함. 재질 리맵과 `Generate Colliders`는 그대로임. `SHIP_Hull` 정점 수는 11,415.

### 검증
- 실행함: Blender에서 4곳을 확대 렌더하고 전체 렌더도 함. Unity 에셋에서 MeshCollider 3개와 재질을 확인함. `JH04TestScene`을 추가로 열어 씬 인스턴스에 MeshCollider 3개가 켜져 있는지 확인함(선체 bounds 10.78×6.68×8.67). 에디터 카메라 스크린샷으로 그물이 돛대 꼭대기까지 이어짐을 확인함. 씬은 바꾸지 않아 저장하지 않고 닫음.
- 실행 안 함: 플레이 중 콜라이더 충돌·이동 판정. 사다리를 오르는 동작은 없음.

### 남은 일
- 그물 밧줄도 선체 MeshCollider에 포함됨. 그물에 몸이 걸리는 문제가 있으면 콜라이더용 메시를 따로 둘 것.
- 열린 `JH04Offline`에 저장 안 된 변경이 있음. 이번 작업과 상관없으며 건드리지 않음.
