# 유령선 힌트 — 작업대 인출 장부

작성·갱신: 2026-10-30

## 요청
유령선 힌트 규칙(W22)을 정하고 구현한다. 사용자 결정은 [유령선 힌트 결정](../../design/ghost-ship-hint-decisions.md)에 정리했다.

## 결정과 이유
- 힌트 = 작업대 인출을 날짜·자원별로 합산한 장부, 이름 없음(사용자). 인출은 서버가 마피아만 허용하므로 기록이 곧 마피아 행동
- 선착순 1명 독점, 받은 사람의 재조회는 같은 내용(읽은 순간 고정). 다른 사람은 `Busy` + "이미 누군가 읽었다" 알림
- 마피아도 같은 진짜 힌트, 마피아가 가져가면 다음 밤 강제 출현(사용자 (a)안)
- 마지막 밤까지 미출현이면 마지막 밤 강제 출현, 최후 전투 시작 시 `Retire`(새 출현 없음·떠 있으면 침몰)
- 조사는 즉시 처리(`IInteractionHandler`). 실제 입력 `PlayerInteractionInput`이 길게 누르기 세션을 지원하지 않아 3초 누르기 가안은 보류(Player 영역 변경 필요)
- 유령선 쪽(강민서 영역) 변경은 사용자 지시로 김지훈이 직접 수정하고 알림
- 임시 팝업은 코드로 캔버스를 만들어 씬·프리팹 UI 없이 동작. 정식 UI는 최명기가 `GhostShipHintNet.HintReceived`/`HintAlreadyRead` 이벤트로 대체 가능
