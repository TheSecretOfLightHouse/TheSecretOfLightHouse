# 등대 화면 열 때 Cinemachine 카메라 이동

작성일: 2026-10-30

## 요청
등대 UI가 바로 열리지 않고, 플레이어 시점에서 등대 전체가 크게 보이는 쪽으로 카메라가 이동한 뒤 UI가 뜨게 한다. MainGame 수정 허용(사용자).

## 수행
- `com.unity.cinemachine` 3.1.7 설치(`Packages/manifest.json`, `packages-lock.json`). `Lighthouse.Runtime.asmdef` 참조에 `Unity.Cinemachine` 추가(공용 asmdef, 한 줄).
- 신규 `Assets/01.Scripts/04.Lighthouse/Tower/View/TowerFocusCamera.cs`
  - 이동 중에만 메인 카메라의 `CinemachineBrain`을 켜고(`ManualUpdate`, 실행 순서 400으로 `PlayerCamera`(100) 뒤), 끝나면 끈다. 평소 카메라는 그대로 `PlayerCamera`가 소유.
  - `PlayerView` 가상 카메라가 매 프레임 플레이어 카메라 자세를 따라가고, `TowerView`는 플레이어가 선 방향에서 등대 높이 전체(`_lighthouseHeight` × `_framePadding`)가 FOV에 들어오는 거리에 배치.
  - 들어갈 때 EaseInOut 1.1초, 돌아올 때 0.8초. 도착하면 콜백으로 창을 띄우고, 복귀가 끝나면 입력·커서를 푼다. 복귀 중 재오픈 시 그 자리에서 다시 등대로 향한다.
- `TowerScreen.cs`: 선택 필드 `_focusCamera`. 없으면 기존처럼 즉시 열림(JH04 등 다른 씬 영향 없음). 이동 중 F 장착 키는 막고 Esc·E 취소는 허용. 잠금 상태 플래그와 잠근 `PlayerInput` 참조를 따로 보관해 복귀 후 해제가 플레이어 재바인딩과 엇갈리지 않게 함.
- MainGame: `Main Camera`에 `CinemachineBrain`(비활성, ManualUpdate, IgnoreTimeScale) 추가, 루트 `TowerFocusCamera`(자식 `PlayerView`·`TowerView`) 추가, `TowerScreen_Sketch` 인스턴스의 `_focusCamera` 연결. `_lighthouseHeight` 8.5(섬 외형 프리팹 TowerAnchor y 3.94 ~ 첨탑 꼭대기 약 11.95 실측).
- 편집 중이던 JH04Offline(미저장 상태)을 보존하려고 MainGame은 additive로 열어 저장 후 닫음.

## 결정 이유
- 브레인을 상시 켜면 `PlayerCamera`·`SeaSummonCameraView`의 직접 카메라 제어와 충돌하므로 이동 구간에만 켠다.
- 등대 네트워크 프리팹(`MainIslandLighthouse`)에는 렌더러가 없어 바운즈를 못 구하므로 높이를 직렬화 값으로 둠.

## 검증
- Unity 컴파일 error 0, `TowerFocusCamera`가 `Lighthouse.Runtime`에 컴파일됨 확인.
- **Play 미실행**: 실제 이동 연출·프레이밍·복귀 후 입력 해제는 확인하지 않음.

## 남은 일
- MainOffline 호스트 Play로 등대 E → 이동 → 창 표시 → Esc 복귀 확인, 높이·여백·시간 수치 조정.
- 섬 지형·나무가 카메라와 등대 사이를 가리는지 확인(장애물 회피 없음).
- 공용 asmdef·패키지 추가를 팀에 공유.

## 후속 (2026-10-30): 등대 왼쪽·창 오른쪽, 다른 UI 숨김, Esc 통일

- 요청: 등대는 화면 왼쪽, 등대 UI는 오른쪽. 등대 UI가 뜨면 다른 UI는 숨김. 오른쪽 위 `F 장착`은 빼고 Esc만 상시 HUD의 Esc와 같게.
- `TowerFocusCamera`: `_screenX`(기본 0.3) 추가. 샷 거리에서 화면 반폭(`distance·tan(FOV/2)·aspect`)만큼 카메라를 옆으로 밀어 등대가 왼쪽 30% 지점에 서게 함(시선 회전 없음).
- `TowerScreen`: 열 때 다른 활성 루트 화면 캔버스(월드 공간 제외)의 `enabled`를 끄고, 닫힌 뒤 카메라가 돌아오면 그 캔버스만 다시 켬. 복귀 중 재오픈 시 중복 숨김 방지.
- `TowerScreenSketchSetup`: `Frame`을 오른쪽 기준으로 붙여 내용(스케치 651..1328)이 오른쪽 끝에서 70 떨어지게 배치. `KeyF`·`InstallHint`·`KeyESC`·`CloseHint` 제거, `Window`에 상시 HUD Esc 줄과 같은 이미지·위치의 `CloseKey`·`CloseLabel`(나가기) 추가. 메뉴 `Lighthouse/Tower/Update Sketch Screen Layout`으로 재빌드 없이 기존 프리팹에 적용. 장착 버튼 아래 F 키캡은 유지.
- `HudSketchLayout`: 키 줄 배치 `KeyRow`와 Esc 줄 상수를 공용화해 HUD·등대 창이 같은 값을 씀.
- 검증: 코드 정적 검토만. 다른 세션이 Unity MCP 사용 중이라 Unity 컴파일·메뉴 실행·Play 미실행. `TowerScreen_Sketch.prefab`은 아직 이전 배치.
- 남은 일: Unity에서 `Update In-Game HUD Keys` → `Update Sketch Screen Layout` 순서로 실행. Play로 등대 위치·창 배치·UI 숨김·복원 확인. 16:9가 아닌 화면에서는 두 캔버스의 스케일 방식(HUD Match 0.5, 등대 창 Expand)이 달라 Esc 위치가 조금 어긋날 수 있음.

## 후속 2 (2026-10-30): 창 왼쪽으로 조금, Esc 위치 HUD와 통일

- `TowerScreenSketchSetup.PlaceFrameRight`: 오른쪽 여백 70 → 130(스케치 px). 창 전체가 왼쪽으로 60 이동.
- Esc: 등대 창 프리팹은 이미 이전 메뉴 실행분(Esc top 160)이 들어가 있음. `HudSketchLayout.KeyRow` top이 24로 바뀌었으므로 `Update Sketch Screen Layout`을 다시 실행하면 HUD Esc와 같은 위치로 맞춰짐(코드 추가 변경 없음).
- 검증: 코드 정적 검토만. 메뉴 재실행·Play는 사용자 보류.
