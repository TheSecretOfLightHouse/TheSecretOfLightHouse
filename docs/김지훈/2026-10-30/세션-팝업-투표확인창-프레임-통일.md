# 세션 팝업을 투표 확인창 프레임으로 통일

작성일: 2026-10-30

## 요청

게임에서 나가기를 누를 때 뜨는 팝업을 투표 지목 확인창과 같은 프레임으로 맞춘다.

## 수행

- 대상: `SessionScreen.prefab`의 `Dialog`(`SessionDialogView`). 판 나가기·방 닫기·게임 종료·종료 사유·접속 실패 알림이 모두 이 팝업을 쓰므로 함께 바뀐다. `SessionScreen_Draft`·`_Navy` 시안 프리팹은 그대로 두었다.
- 기준: `VotingScreen_Sketch.prefab`의 `Confirm`(지목 확인창).
- 투표창 버튼 스프라이트(`vt_button_confirm`·`vt_button_cancel`)는 글자가 박혀 있어 글자만 지운 버튼을 만들었다. `Assets/03.Images/SessionUi/Dialog/`
  - `Dialog_VoteButtonYellow.png`: 기본 버튼(확인 등).
  - `Dialog_VoteButtonRed.png`: 위험 버튼(나가기·방 닫기·종료). 노랑 버튼의 명암을 유지하고 색만 기존 위험 빨강으로 바꿨다.
  - `Dialog_VoteButtonLine.png`: 보조 버튼(계속하기·취소) 테두리.
  - 임포트 설정은 `vt_button_confirm`을 복사하고 9-slice 좌우 24px 경계를 줬다(긴 라벨 대비).
- 프리팹 변경(에디터 API `PrefabUtility.LoadPrefabContents`로 수정, YAML 직접 편집 없음):
  - Dim 검정 55%, Panel 640×420 `vt_board` Sliced.
  - Title 금색 32 Bold + Outline, Message 크림색 30 Bold + Outline(투표창 Target 문구와 같은 값).
  - 버튼 200×66, 간격 36, 라벨 26 Bold. `_primarySprite`/`_dangerSprite`를 새 노랑/빨강으로 교체.
  - 투표창에 없는 X 버튼(`CloseButton`)은 비활성화. Esc는 `SessionScreen`에서 계속 팝업을 닫는다.
- 코드 변경 없음.

## 결정 이유

- 패널은 `Assets/03.Images/VotingUiSketch/vt_board.png`를 복사하지 않고 직접 참조했다. 투표창 판자가 바뀌면 함께 따라가 통일이 유지된다. 이 폴더는 박태욱(투표) 영역이므로 파일 이동·삭제 시 세션 팝업 판자가 빠질 수 있다.
- 위험 선택지를 빨강으로 구분하는 기존 `isDanger` 동작은 유지했다.

## 검증

- 실행함: 에디터에서 프리팹 팝업을 프리뷰 씬에 렌더링해 투표 확인창과 비교(두 버튼 판 나가기, 한 버튼 알림), 콘솔 error 0.
- 실행 안 함: Play·실제 Esc 메뉴 경로, 다른 해상도.

## 남은 일

- Play에서 나가기 팝업 확인.
- 박태욱에게 `vt_board` 참조 사실 공유.

## 후속: 알림 띠·운반 모듈 카드 통일

- `ScreenNotice.prefab`의 `Strip`(검정 반투명 사각형) → `vt_board` Sliced. 배경색을 코드가 `_normalBacking`/`_warningBacking`로 칠하므로 프리팹 값을 흰색(원본 그대로)·붉은 틴트(1, 0.6, 0.55)로 바꿨다. 코드 변경 없음.
- `InGameHud.prefab`의 운반 모듈 카드: 기존 `CardFrame`(`InventoryFrameGraphic`)은 비활성화하고 같은 크기의 `CardBoard`(Image, `vt_board` Sliced)를 추가했다. 카드 높이 76이 판자 테두리 40+40보다 작아 `pixelsPerUnitMultiplier` 1.4로 테두리를 줄였다.
- MainGame의 운반 모듈 카드는 `InventoryChestScreen.Hud.cs`(최명기)가 런타임에 그리므로 사용자 결정으로 이번엔 바꾸지 않았다. 통일하려면 최명기에게 `MakeFrame` 대신 `vt_board` 판자 사용을 요청해야 한다.
- 참고: `ScreenNotice`·`InGameHud` 프리팹은 현재 JH04에만 배치되어 있고 MainGame에는 없다.
- 검증: 프리뷰 렌더로 일반·게이지 알림, 경고 알림, 카드 확인. 띠 좌우 가장자리에 판자 테두리의 작은 회색 자국이 보이나 크지 않다. Play 미실행.
