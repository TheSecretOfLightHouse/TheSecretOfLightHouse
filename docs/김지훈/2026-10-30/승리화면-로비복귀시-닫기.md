# 승리 화면 — 로비 복귀 시 전원 닫기

작성일: 2026-10-30 / 담당: 김지훈

## 요청

한 명이 승리 화면에서 확인을 누르면 모두 선원 대기실로 돌아가는데, 확인을 안 누른 나머지 사람의 화면에는 승리 UI가 대기실 위에 그대로 남아 있었다. 사용자가 이를 버그로 보고 고쳐 달라고 했다.

## 원인

2026-10-29 구현은 의도적으로 결과 화면을 `DontDestroyOnLoad`로 씬 전환 너머까지 들고 가서, 각자 확인을 누를 때까지 로비 위(정렬 600)에 유지했다. 사용자가 이 동작을 원치 않는다고 판단했다(2026-10-30 결정).

## 변경

- `Assets/01.Scripts/04.Lighthouse/Tower/View/VictoryScreen.cs`: 들고 가는 로직(`_isCarried`·`_isOverLobby`·`_lobbySortingOrder`·`KeepCarried`·`DontDestroyOnLoad`·로비 Esc 막기)을 제거했다. 세션 흐름에서 `ClientState.Phase`가 `Lobby`가 되면 화면이 열려 있어도 닫는다. 로비가 커서를 관리하므로 저장한 게임 커서는 되돌리지 않는다. Lobby 단계는 씬 전환보다 먼저 오므로 게임 씬이 남아 있을 때 닫힌다.
- `LighthouseNetworkManager.cs`, `SessionScreen.cs`: 이전 동작을 설명하던 주석만 고쳤다.
- 직렬화 필드 `_lobbySortingOrder`가 빠졌다. 프리팹에 남은 값은 Unity가 무시하며 프리팹 YAML은 편집하지 않았다.

## 검증

- 실행: Unity 스크립트 컴파일, 콘솔 error 0.
- 미실행: Play·멀티 클라이언트 확인(한 명이 확인을 눌렀을 때 다른 클라이언트의 결과 화면이 닫히는지).

## 남은 일

- 2인 이상 세션으로 승리 → 한 명 확인 → 나머지 화면이 대기실로 돌아가는지, 커서가 풀려 있는지 확인한다.
