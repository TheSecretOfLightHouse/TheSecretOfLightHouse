# 등대 탐조등 — 기획 제안 데모

작성일: 2026-10-14 · 담당: 김지훈 · 상태: 코드 작성, C# 컴파일만 확인(메뉴 실행·플레이 미확인)

## 배경과 결정 이유
- 사용자가 확정 기획 범위 밖에서 퀄리티를 올릴 기획 제안을 요청했다. 제안 6개(항해일지 진술, 등대 탐조등, 귀항 기록부, 표류 유리병, 판 종료 항로 리플레이, 등대 괴물 공격 예고) 가운데 사용자가 **등대 탐조등**을 골라 데모로 만들라고 했다.
- 제안 근거: 등대가 수리 게이지에 가깝고 직접 조작하는 손맛이 없다(v4 6장). 밤 귀항(v4 2.1)과 안개(10.4)·바다 몬스터(5장)를 엮어 협동 장면을 만든다. **확정 기획이 아니며** 본편 반영은 팀 결정이 필요하다.
- 데모는 사용자가 지정한 "천둥번개 밤 맵"을 쓴다. 로컬 SVN 체크아웃(리비전 316~318)에서 해당 맵을 찾지 못해, 열려 있는 맵을 복사하는 빌더 방식(`Build From Open Scene`)으로 만들었다. 맵 이름에 의존하지 않는다.

## 변경 파일 (SVN, git 아님)
`Assets/ThirdParty/1조 Unity Asset/_Demo/Jihun/LighthouseSearchlight/`
- `Scripts/`: `Searchlight`, `SearchlightTier`, `SearchlightOperator`, `FogPatch`, `SeaThreat`, `ReturningBoat`, `HomecomingScenario`, `SearchlightHud`
- `Editor/SearchlightSceneBuilder.cs`: 메뉴 `TheLightHouse/Demo/LighthouseSearchlight/Build From Open Scene`
- `README.md`: 실행·조작·구조·조정 값

본편(`Assets/01.Scripts/`)과 다른 사람의 데모 폴더는 수정하지 않았다.

## 검증
- 실행함: Unity가 꺼진 상태에서 `Assembly-CSharp-Editor.csproj`의 참조 DLL로 Roslyn 컴파일. 오류 0(인스펙터 연결 필드의 CS0649 경고만 있음).
- 미실행: Unity 컴파일, 빌더 메뉴 실행, 플레이. Spot Light 밝기, 모델 방향, 해수면·섬 반경 자동 추정은 맵에서 확인해야 한다.

## 남은 일
1. 천둥번개 맵 SVN 업데이트 → 맵을 열고 빌더 실행 → 플레이로 손맛 확인과 값 조정
2. SVN 추가 경로: `_Demo/Jihun/LighthouseSearchlight/` (생성된 `.unity`·`Data/`·`.meta` 포함, 커밋은 사용자)
3. 본편 채택 여부를 팀과 논의: 조종 권한, 마피아 사용 시 단서, 몬스터 퇴치와 TW02(박태욱) 경계
