# 4인 멀티 캐릭터 데모 (CrewMultiplayer)

작성일: 2026-10-14 · 담당: 김지훈 · 상태: 코드·빌더 작성, C# 오프라인 컴파일만 확인(Unity 컴파일·Weaver·빌더·4인 플레이 미확인)

## 요청과 결정 이유
- 요청: 팀 캐릭터 모델·애니메이션 + 로비 생성·방 입장 + 상호작용으로 4인 멀티가 되는 **별도 데모**. 기존 코드 수정 금지, JH 구현 대신 데모 전용 동기화 허용. 탐조등 데모와 합치지 않음.
- 기존 코드 무수정 판단 근거: Mirror·Mirror.Components asmdef `autoReferenced: true`(데모 Assembly-CSharp에서 사용 가능), 본편 `RuntimeInitializeOnLoadMethod` 8곳은 정적 초기화 또는 명령 파일이 있을 때만 동작(`MppmClientDriver`).
- 모델: `Assets/04.Models` 4종 중 tech만 휴머노이드, 나머지 3종은 Generic·Avatar 없음. FBX 노드 이름 비교로 네 모델이 같은 Mixamo 뼈대(`mixamorig:*`, 메시 노드만 다름)임을 확인 → 팀 tanker 프리팹처럼 tech Avatar 공유. 팀 프리팹은 본편 스크립트가 붙어 있어 쓰지 않고, 빌더가 모델 위치·크기·머티리얼만 읽어 데모 프리팹을 만든다.
- 씬 하나 구성: 공용 Build Settings·TagManager를 고치지 않기 위해 로비/방/플레이를 UI 상태로 전환. 공유 오브젝트는 서버가 프리팹으로 스폰(scene object sceneId 의존 회피).
- 애니메이션은 동기화하지 않고 각 클라이언트가 보간 위치로 계산(모델 교체 자유, NetworkAnimator 불필요).
- 포트 분리: 게임 7788, 방 찾기 47788 — 다른 세션의 본편 시험(7777)과 충돌 방지.
- 다른 세션(로비 UI, MCP 사용)과 병렬: scratch에서 작성·오프라인 컴파일 후 한 번에 복사해 도메인 리로드를 1회로 줄임.
