# 판 진행 시험 패널의 선반⇄화면 전환 버튼 제거

작성일: 2026-10-29

## 요청과 결정

- 사용자: 선반으로 전환하는 개발자용 OnGUI는 시험용이며 폐기, 없앤다.
- 근거: 2026-10-27 결정으로 선반 방식 폐기 → 화면 방식만 사용([작업대 투입 연출](../2026-10-27/작업대-투입연출.md)).

## 변경

- `Assets/01.Scripts/99.Dev/Tower/TowerTrialPanel.cs`
  - 판 진행 패널 맨 위 `작업대: 선반 ⇄ 화면 UI` 버튼, `_isRackMode` 필드 삭제.
  - 선반 모드 전용 `Update`(선반 `CanWithdraw` 설정)·`CanWithdraw()`·`DrawWithdraw`의 선반 안내 분기 삭제. 마피아 빼기는 패널 버튼만 남음.
  - `ApplyWorkbenchMode` → `ApplyWorkbenchScreen`: 시작 때 선반을 끄고(입력·오브젝트) 상자·작업대 화면·작업대 시험 패널을 켠다. 씬에 선반 오브젝트가 남아 있고 같은 F키를 쓰므로 `_rack` 참조는 유지.
- `Assets/01.Scripts/04.Lighthouse/Workbench/Editor/WorkbenchScreenSketchSetup.cs`: 지워진 `_isRackMode` 설정 줄 삭제(남기면 메뉴 실행 때 NullReference).

씬 4개(`JH04TestScene`, `MainGame`, `TW_MainGame`, `MK_MainGame`)는 이미 `_isRackMode: 0`(화면 모드)라 동작 변화 없음. 직렬화에 남은 `_isRackMode` 값은 Unity가 다음 저장 때 버린다. 씬 YAML은 손대지 않음.

## 검증

- 실행: Unity 스크립트 재컴파일, 콘솔 오류 0.
- 미실행: 플레이 확인(패널에 버튼 없음, 작업대 화면 E 열기, 마피아 빼기 버튼).
