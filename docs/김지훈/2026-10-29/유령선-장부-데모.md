# 유령선 장부 데모 (기획 제안)

작성·갱신: 2026-10-29

## 요청
유령선 데모 맵(GatherLoop의 Ghost Fog Night)으로 유령선 힌트를 "총자원량을 알려 주는 형태"로 만든다. 시민·마피아가 보는 내용은 제안해서 바로 적용(사용자 지시: 묻지 말고 진행).

## 결정과 이유
- 위치: `_Demo/Jihun/GhostShipLedger/` (SVN). 데모 가이드대로 GatherLoop 씬을 데모 폴더로 복사하고 빌더 메뉴로 구성. 원본 GatherLoop 씬·스크립트는 수정하지 않음
- 시민: 총량 4줄(건짐·투입·가방·사라짐) + 나를 뺀 3명 중 무작위 2명의 사라진 자원 합. 한 이름을 직접 찍지 않게 (jihun-system-design 힌트 원칙: 정체 직접 공개 금지)
- 마피아: 같은 진짜 총량 + 먼저 본 선원 목록 + 덧칠 1회. 덧칠은 사라진 자원을 0으로 지우지만 등불이 붉게 바뀌어 근처에서 보임 → 증언의 신뢰 문제(v4 8.3)
- 투입 총량은 등대 게이지로 공개 대조 가능하므로 덧칠 대상에서 제외
- 장부는 읽은 순간 고정, 재열람은 같은 결과 (W22 재조회 정책 제안)
- 1인 테스트를 위해 다른 선원 3명은 숫자만 움직이는 모의 선원

## 검증
- 실행함: Unity 강제 새로고침·컴파일 → 콘솔 에러 0, `Assembly-CSharp(-Editor).dll` 갱신 확인
- 사용자 첫 빌드 실패: `Player: False` — 본편 `PlayerController`(global 네임스페이스)가 using 가져오기보다 우선해 빌더가 본편 타입을 찾음. 별칭 `GatherPlayerController`로 수정
- 실행함: 미완성 데모 씬 삭제 후 빌더 재실행 → 성공(해수면 0.0, 출현 지점 8개, Ghost Fog Night 적용)
- 실행함: 플레이 스모크(코드 호출) — 소환·시민 장부·쌍 장부·마피아 장부·덧칠·붉은 등불, 콘솔 에러·경고 0
- 실행 안 함: 실제 키 입력, 배로 유령선 접근, 연출 육안 확인
