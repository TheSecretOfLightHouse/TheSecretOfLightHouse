# 임시 등대 모델의 모듈 장착 표시·낙하 연출 제거

- 날짜: 2026-10-29
- 상태: 미커밋. 컴파일 오류 0(Editor.log 마지막 재컴파일 이후). 플레이 미확인

## 요청

등대에 모듈을 장착하면 임시 등대 모델의 칸에 모듈이 켜지고 위에서 떨어져 내려앉던 연출을 뺀다. 등대 모델은 나중에 연결하므로 레거시로 본다.

## 한 일

- `TowerView`(칸 모델 켜기·끄기, 낙하 애니메이션, 완성 시 빔 표시) 스크립트와 `.meta` 삭제(에디터 `AssetDatabase`로).
- `MainIslandLighthouse.prefab`에서 `TowerView` 컴포넌트 제거(에디터).
- `JH04TestScene`, `MainGame`의 씬 등대 오브젝트 `Lighthouse`에서 `TowerView` 제거 후 저장(추가 로드로 열어 열린 씬의 미저장 변경은 건드리지 않음). MainGame diff에는 Unity 재저장으로 생긴 오브젝트 순서 이동·사라진 필드 정리·새 필드 기본값이 함께 들어 있다.
- `MainIslandFacilitiesBuilder.Step()`에서 `TowerView.Bind` 두 줄 삭제(World·강민서 영역, 등대 연결 줄만).

## 남긴 것과 이유

- 칸 모델(`Slot0~7`)·빔·`Lighthouse_GoldenLantern` 오브젝트와 `MainIslandPresentation.SlotVisuals/CompleteVisual`은 World 프리팹·코드라 그대로 둔다. 칸·빔은 씬·프리팹에서 기본으로 꺼져 있어 보이지 않는다. `Lighthouse_GoldenLantern`(메인 섬 완성 표시)은 기본으로 켜져 있어 이제 처음부터 보인다.
- 장착 화면(`TowerScreen`)의 모듈이 칸으로 날아가는 UI 연출과 `TowerMatchEffects`는 UI라 유지.
- `TowerNet.SlotInstalled` 이벤트는 `TowerScreen`·`TowerMatchEffects`가 계속 쓴다.

## 남은 일

- `MK_MainGame`, `TW_MainGame`(최명기·박태욱 개인 씬)에 `TowerView` 컴포넌트가 Missing Script로 남는다. 각 담당자가 씬을 열어 제거해야 한다.
- 실제 등대 모델 연결 시 `MainIslandPresentation`의 칸·완성 표시 필드를 정리하거나 새 표시로 교체할지 강민서와 정한다.
- 플레이로 장착 시 오류 없는지 확인 안 함.
