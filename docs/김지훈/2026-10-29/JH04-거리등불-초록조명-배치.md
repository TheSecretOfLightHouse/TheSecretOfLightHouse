# JH04 거리 등불(street lantern) 초록 조명 배치

- 작성일: 2026-10-29
- 담당: 김지훈
- 상태: 미커밋. Unity 임포트·재질 연결·씬 저장·오프스크린 렌더 확인

## 요청

받아 둔 `street lantern 3d model`의 등불 안에 라이트를 넣고, 틀이 아니라 빛이 통과하는 4면 유리 부분만 빛이 통과하는 재질로 바꾼다. `JH04TestScene`에 유령선 테마에 맞춘 초록빛으로 배치한다.

## 수행

1. Blender MCP로 FBX를 불러옴. Tripo 단일 메시(면 18,345개)에 재질 1개라 유리 분리가 없었음.
2. 면마다 텍스처 색을 샘플링하고 위치 조건(높이 0.3~0.72m, 중심 거리 0.185m 이내, 수평 법선, 밝은 저채도)으로 4면 유리 68면만 골라 `StreetLanternGlass` 재질 슬롯으로 분리. 4방향 렌더로 틀·받침이 섞이지 않음을 확인. 등불 안쪽에 막는 형상 없음.
3. 같은 경로에 FBX를 덮어씀(텍스처 상대 경로 유지). 원본은 세션 스크래치패드에만 백업(저장소 밖).
4. Unity: `LanternGlass.mat`(10-27 `lantern 3d model` 작업)을 복제해 `StreetLanternGlass.mat`(URP Lit 투명, 양면, 발광) 생성, FBX 임포터 재질 리맵으로 연결. 색은 BaseColor (0.3, 0.95, 0.5, a 0.3), Emission (0.06, 0.75, 0.24)×1.1.
5. `JH04TestScene`을 추가 로드해 `StreetLantern`(위치 (-2.6, 0, 1.4), Y 20°, 크기 1.2) 배치, 자식 `StreetLanternLight`(Point, 로컬 높이 0.48 = 유리 중심, 색 (0.3, 1, 0.55), 강도 1.5, 범위 4, 그림자 없음 — 투명 유리가 빛을 막지 않게) 추가 후 저장·닫음. 다른 세션이 쓰던 `JH04Offline`(저장 안 된 변경 있음)은 건드리지 않음.

## 변경 파일

- `Assets/04.Models/Object/street lantern 3d model/`(새 폴더 전체: FBX·텍스처·`StreetLanternGlass.mat`·`.meta`)
- `Assets/00.Scenes/Jihun/JH04TestScene.unity`

## 검증

- 실행: FBX 재임포트 뒤 본체 재질 텍스처·유리 재질 연결 확인, `JH04TestScene`만 그리는 임시 카메라 렌더 2방향(유리로 초록빛이 새고 바닥이 초록으로 비침), 콘솔 lantern 관련 error 0.
- 미실행: 플레이 모드·밤 조명 상태에서의 밝기 확인.

## 남은 일

- 밤 장면에서 밝기·색 조정(강도 1.5, 범위 4는 낮 기준 육안값).
- 위치는 임의(시작 지점 왼쪽). 원하는 위치로 옮기기.
