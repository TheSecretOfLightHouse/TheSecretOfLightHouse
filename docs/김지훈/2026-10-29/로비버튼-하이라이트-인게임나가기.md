# 로비·대기실 버튼 하이라이트 교체, 인게임 나가기를 HUD Esc로 통일

작성일: 2026-10-29

## 요청
- 로비(첫 화면)·대기실 버튼 하이라이트(금색 링)가 버튼 크기에 맞지 않는다. 프로젝트 UI 이미지를 모두 확인해 더 깔끔한 것(딱 맞는 크기, 더 나은 연출)으로 해결.
- 인게임(JH04TestScene) 나가기 UI가 레거시다. 상시 HUD의 Esc 버튼과 통일(재사용 가능).

## 원인
- `SessionScreen.prefab` 버튼 8개의 `SelectRing`이 모두 `Dialog_SelectRing`(193×87, 9-slice 28) 하나를 버튼 사각형 −9px 바깥에 고정으로 붙였다.
- 링 그림 자체의 투명 여백이 비대칭(왼 2·오른 5·아래 3·위 6px)이고 모서리 반경 약 14px. 버튼 그림은 투명 여백 0~6px, 모서리 반경 11.5~23px로 제각각 → 한쪽은 뜨고 한쪽은 가깝고 모서리가 따로 노는 상자처럼 보였다(플레이 캡처로 확인).

## 이미지 검토 결론
- `Assets/03.Images` 전체 스프라이트에서 select·glow·highlight·hover·outline·ring·frame 계열 37개를 확인(`ws_button_outline(_active)`, `vt_button_*_hover`, `Lobby_CardHighlight`, `row_highlight`, `wb/ww/ws/vt_card_selected` 등). 서드파티 폴더에는 UI 팩이 없다.
- 모두 각 시안 전용 고정 모서리·여백이라, 어떤 것을 써도 버튼별 반경 차이(11.5~23px)를 맞출 수 없다. 버튼 그림을 수정하지 않는 한 이미지 링으로는 "딱 맞는" 결과가 불가능하다고 판단.

## 결정과 구현
- 공용 `Assets/01.Scripts/00.Common/UI/UiButtonOutline.cs`(`MaskableGraphic`, 텍스처 없음): 버튼 그림의 실제 가장자리(`_padding` L/B/R/T)와 모서리 반경(`_cornerRadius`)을 따라 금색 선(3px, 간격 3px, 가장자리 안티앨리어싱)과 바깥 부드러운 빛(12px)을 메시로 그린다.
  - `UiButtonFeedback`의 `_highlight`로 쓰면 그래픽 알파가 곧 등장 정도: 6px 바깥에서 조여 들어오며 나타나고(lock-on), 완전히 보이는 동안 빛이 천천히 숨쉰다(`_pulse` 0.35, 0.8회/초). `UiButtonFeedback` 코드는 무변경.
  - 버튼별 측정값(스프라이트 픽셀에서 불투명 경계·모서리 곡선 맞춤으로 계산): 첫 화면 3개 반경 23, 주소 복사 11.5, 방 닫기 16, 준비하기 22.5, 확인창 보조 15.5, 주 14.5(노랑 12.5·빨강 16.5 사이 공용).
- `SessionScreen.prefab`: 8개 버튼의 `SelectRing` 삭제 → 자식 `Outline`(`UiButtonOutline`) 추가·연결(프리팹 API로 편집).
- 인게임 나가기:
  - 새 `Assets/01.Scripts/01.Network/Session/View/SessionLeaveButton.cs`: 버튼 클릭 → `SessionScreen.RequestLeaveMatch()`(Esc와 같은 판 나가기 확인창). 켜져 있는 동안 `SessionScreen.SetLeaveControlShown`으로 등록.
  - `SessionScreen`: 등록된 나가기 버튼이 있거나 게임 오버레이가 열려 있으면 자체 대체 버튼(`GameMenu`)을 숨긴다. 레거시 갈색 "나가기" 사각 버튼(스프라이트 없음+Outline)은 HUD와 같은 `hud_key_esc`+`hud_label_menu` 그림·같은 위치로 교체해, HUD가 없는 씬(JH03/JH07/Main/MK_Main/WorldSession Offline 흐름)에서도 같은 모습으로 나온다.
  - `InGameHud.prefab`: `Hud/MenuButton`(투명 히트 영역 + `Button`·`UiButtonFeedback`·`SessionLeaveButton`) 아래로 `MenuKey`·`MenuLabel`을 옮기고 루트에 `GraphicRaycaster` 추가. `InGameHudSetup`(빌더)에도 `AddLeaveButton`을 넣어 재빌드해도 유지되며, 저장된 프리팹에만 적용하는 메뉴 `Lighthouse/UI/Add Leave Button To In-Game HUD Prefab` 추가.
  - `09.UI/Hud/InGameHud.cs`(최명기 경로)는 수정하지 않았다.
