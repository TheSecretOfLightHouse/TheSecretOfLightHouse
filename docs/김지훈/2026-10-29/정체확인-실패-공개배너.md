# 정체 확인 실패 — 무고 시민 공개 배너

작성일: 2026-10-29 · 담당: 김지훈 · 상태: 코드·프리팹 반영, Unity 컴파일 오류 0, 렌더링 확인. 실제 플레이 미확인

## 요청
정체 확인 실패 시 마피아에게 알림창만 뜬다. 사용자가 준 시안(초상 틀 + 붓 띠, "정체 확인 실패 / 플레이어 02 / 무고한 시민 / 이 선원은 마피아가 아닙니다.")으로 바꾸고 연출을 넣는다.

## 기획 대조
- win-vote-decisions 7절·대장 R16: 실패 시 중복 없는 무고 시민 1명 공개, "v4 실패 전체공지 유지". 그래서 배너는 마피아만이 아니라 **모든 클라이언트**에 띄운다. 이전 기록(정체확인-UI-점검)의 "무고 시민 공개가 실제 UI에 없음"을 이것으로 닫는다.
- 서버는 이미 `_revealedCitizens` SyncList → `VotingNetworkController.InnocentCitizenRevealed(actorId)`로 전원에게 보낸다. 서버 코드는 손대지 않았다.

  - 연출(unscaled 시간): 배너 전체 위에서 내려오며 페이드 → 초상 틀 0.6→1 오버슈트 → 붓 띠가 틀 뒤에서 오른쪽으로 칠해짐(Filled Horizontal) → 제목·이름·문구 왼쪽에서 슬라이드 → 배지 1.8배에서 도장처럼 찍히고 짧게 흔들림 → 반짝이 2개가 번갈아 숨쉬듯 회전 → 위로 올라가며 사라짐.
  - 배지는 이름 길이에 맞춰 이름 바로 뒤(간격 24)에 놓는다. 긴 이름은 best fit(최소 30)으로 줄고 폭 280을 넘지 않는다.
