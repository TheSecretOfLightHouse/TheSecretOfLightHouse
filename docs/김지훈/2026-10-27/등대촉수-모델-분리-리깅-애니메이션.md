# 등대 촉수 모델 분리·리깅·공격 애니메이션

작성일: 2026-10-27

## 목표

`Assets/04.Models/Object/lighthouse with tentacles 3d model/`의 등대+촉수 통짜 모델을 등대와 촉수별로 나누고, 등대 공격 이벤트(최후 전투)에 쓸 감기·조이기·내려치기 애니메이션을 만든다. 사용자 결정: 대기 꿈틀거림뿐 아니라 감아 조이기·내려치기 공격까지, 사용처는 등대 공격 이벤트.

## 기존 코드와의 관계

- `Assets/01.Scripts/06.Monsters/Boss/View/TentacleAnimationView.cs`(박태욱)는 Animator 상태 `Base Layer.Climb` → `Wrapped` → `Squeeze`를 서버 시각 기준 normalized time으로 샘플링한다. 클립 이름을 이 세 상태에 맞췄다.
- **내려치기(`Slam`) 상태는 현재 코드에 없다.** 클립만 만들었고 재생하려면 박태욱 쪽에서 타격마다 Squeeze/Slam을 고르는 연결이 필요하다(미합의).
- 기존 `Assets/02.Prefabs/Boss/Tentacle.prefab`과의 교체 여부, 새 모델에 포함된 등대 메시를 씬의 실제 등대와 어떻게 함께 둘지(겹침)는 결정되지 않았다.

## 수행

1. 원본 FBX를 블렌더(5.2.1)에 불러와 분석: 메시 1개, 2.9만 면, 텍스처 1장, 본·애니메이션 없음, 연결되지 않은 조각 158개.
2. 조각을 가장 가까운 큰 덩어리에 배정해 `Lighthouse`(몸통·랜턴·난간·회랑 바닥), `Tentacle_A`~`E`로 분리. 빨판은 붙은 촉수로. 회랑 바닥 원판(조각 47)이 처음에 촉수 C로 잘못 배정돼 등대로 옮겼다.
3. 촉수마다 바닥 단면에서 표면 측지 거리로 중심선을 구해 본 체인 생성(A 10, B 12, C 12, D 10, E 5) + `Root`, `Lighthouse` 본. 총 51본. 웨이트는 체인 방향 선형 블렌딩, 빨판은 가장 가까운 촉수 표면 정점 값 복사. 등대는 `Lighthouse` 본 100%.
4. 애니메이션(30fps, 스크립트로 키 생성):

| 클립 | 프레임 | 내용 |
|---|---|---|
| `Climb` | 0–90 | 촉수가 바다 아래에서 순차로 올라오며 펴진 상태에서 감긴 자세로 말림. 끝 프레임 = 기본 자세 |
| `Wrapped` | 0–60 | 루프. 체인을 따라 흐르는 꿈틀거림, 감은 촉수(A·C)는 작게. 0프레임 = 기본 자세 |
| `Squeeze` | 0–45 | 살짝 풀림 → 급히 조임 → 떨며 유지 → 풀림. 등대 밑동 기준 흔들림 |
| `Slam` | 0–40 | 자유 촉수 B·D가 뒤로 젖혔다가 등대로 내려침(끝부분 채찍 지연), 감은 촉수는 약하게 조임, 등대 흔들림 |

## 변경 파일

- 새 파일: `Assets/04.Models/Object/lighthouse with tentacles 3d model/lighthouse_with_tentacles_rigged.fbx`(약 3.8MB). 원본 FBX는 그대로. `.meta`는 Unity가 임포트할 때 생성된다.
- 블렌더 원본: 세션 scratchpad의 `lighthouse_kraken_rig.blend`(임시 위치. 보관하려면 SVN 등 저장소 밖 경로로 옮겨야 함).

## 검증

- 실행함: 블렌더에서 각 클립의 프레임을 렌더로 확인. 내보낸 FBX를 다시 불러와 메시 6개, 본 51개, 클립 4개(`Kraken_Rig|Climb` 등)를 확인.
- 실행 안 함: Unity 임포트·Animator 연결·게임 내 재생, 원격 클라이언트 표시.

## 알려진 한계

- 등대 텍스처에 촉수 그림자·푸른 얼룩이 그려져 있어 촉수가 크게 움직이는 `Slam`·`Climb`에서 자국이 벽에 남아 보인다. 필요하면 텍스처 덧칠.
- 촉수 밑동 단면이 열려 있다(바다 아래에 묻히면 무관).
- `Slam` 타격 순간 B 끝이 등대 표면에 살짝 겹칠 수 있다.

## 남은 일

1. Unity 임포트: Rig = Generic, 클립 이름을 `Climb`·`Wrapped`·`Squeeze`·`Slam`으로 정리, `Wrapped` Loop Time 켜기, 머티리얼은 원본 텍스처로 연결.
2. 박태욱과 합의: 기존 `Tentacle.prefab` 교체 여부, `Slam` 재생 조건(코드 추가), 모델에 포함된 등대 메시 처리.
3. 필요 시 등대 텍스처 덧칠.
