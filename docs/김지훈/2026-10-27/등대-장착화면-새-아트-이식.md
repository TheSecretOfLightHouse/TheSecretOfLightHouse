# 등대 장착 화면 새 아트 이식

작성일: 2026-10-27

## 요청

사용자가 준 이미지 두 장으로 등대 모듈 장착 화면(`TowerScreen_Sketch.prefab`)을 다시 구성한다.
- 등대 배경: 녹슨 등대는 1층이 다 채워지기 전, 중간 등대는 2층을 채우는 동안, 깨끗한 등대는 3층부터 보인다. 배경 이미지만 바뀐다.
- 나머지 구성요소(슬롯·자물쇠·모듈 아이콘·패널·버튼·키캡·진행 바·화살표)는 원래 구성·배치·크기에 맞춰 바꿔 넣는다.

## 수행

1. 원본 두 장의 알파가 깨끗해 연결 영역 단위로 잘라 `Assets/03.Images/TowerUi/`에 PNG 19개를 만들었다(meta는 Unity가 생성).
   - 등대 3장(`tw_tower_rusted`·`tw_tower_worn`·`tw_tower_restored`)은 같은 503×874 상자로 잘라 층 선 위치(250.5·401.5·548.5·697.5px)가 같다.
   - 나머지는 기존 스프라이트의 픽셀 크기·9-slice 테두리에 맞춰 크기를 조정했다(아이콘 256×256, 슬롯 폭 166, 버튼 높이 48·88, 키캡 56 등).
2. `TowerScreen`에 `_towerCard`·`_towerStages`를 추가했다. 아래층부터 완성된 층 수로 단계를 고르고, 마지막 단계는 그 뒤 층에도 쓴다.
3. `TowerSlotView`에 선택 필드 `_lockedSprite`를 추가해 잠긴 층 슬롯은 회색 테두리를 쓴다. 비어 있으면 이전처럼 일반 테두리다.
4. `TowerScreenSketchSetup`
   - 등대 카드는 기존 카드의 위·높이(715)·가운데 x를 유지한다.
   - 층 행은 아트에 그려진 층 선을 따른다. 따라서 별도 `tw_floor_line` 오브젝트는 만들지 않는다.
   - 패널·슬롯·버튼·키캡·바·자물쇠·화살표·등대 모듈 아이콘은 `TowerUi`를 쓰고, 배 모듈 아이콘은 기존 `WorkbenchUiSketch`를 유지한다.
   - 장착 불가 버튼은 회색 판(`tw_button_blocked`)으로 바꾸고, 글자색을 어둡게(0.32, 0.29, 0.24) 했다.
   - 레이아웃 층 수가 아트 행 수(4)를 넘으면 빌드를 거부한다.
5. 메뉴 `Lighthouse/Tower/Build Sketch Screen Prefab`로 프리팹을 다시 빌드했다.

## 결정 이유

- 같은 경로에 다시 빌드해도 루트 `TowerScreen`의 fileID가 유지되는 것을 임시 복사본으로 먼저 확인했다. 따라서 `JH04TestScene`·`MainGame`·`TWJH04TestScene`의 `_tower`·`_target` 연결은 그대로다. 그래서 새 프리팹을 만들지 않고 기존 프리팹을 갱신했다.
- 새 시트의 슬롯 세 종류(크림·노랑·회색)는 열림·대상/장착·잠김으로 나눴다.
- 시트의 해 아이콘은 대응하는 기존 요소가 없어 잘라내지 않았다.

## 미실행·남은 일

- 플레이 모드에서 실제 장착으로 단계가 바뀌는지는 아직 확인하지 않았다. M0 1인 호스트로 1층과 2층을 완성해 보며 확인해야 한다.
- 원래부터 있던 문제: 왼쪽 슬롯이 대상일 때 '여기' 표시가 오른쪽 슬롯 아래에 가려진다. 이번 작업에서는 고치지 않았다.
- 기존 `Assets/03.Images/TowerUiSketch/`는 이제 빌더가 쓰지 않는다. 삭제할지는 결정하지 않았다.
