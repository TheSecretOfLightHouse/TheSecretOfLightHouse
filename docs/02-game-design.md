## 1. 개요
- PC · Unity 3D · 4인 호스트-클라이언트. 시점 3인칭. 한 판 30~40분.
- 4명 모두 직군 보유, 그중 1명이 마피아 겸임. 시민 3 vs 마피아 1.
- 각자 배 1척으로 섬을 오가며 자원 파밍 → 작업대에서 모듈 크래프팅 → 배(개인) / 등대(공유)에 장착.
- 바다 몬스터가 파밍 방해. 배로 회피하거나 대포로 처치.
- 배는 난파되지만 플레이어는 죽지 않음(행동 불능 → 구조 또는 섬에서 리스폰). 수영 없음.
- 마피아는 정체가 들키면 등대 괴물 소환 가능 → 최후 전투.
- 디자인 목표: 괴물 소환은 강한 카드지만 마피아의 최우선 목표는 "들키지 않는 것". 소환은 끝까지 숨은 마피아의 마지막 한 수.

## 2. 진영과 승리 조건
| 진영 | 목표 | 승리 조건 |
|---|---|---|
| 시민 (3) | 메인 등대 활성화 | 점화 의식 성공 / 최후 전투에서 수리 완료 후 점화 |
| 마피아 (1, 직군 겸임) | 활성화 저지 | 기한(N일차 밤)까지 등대 미점등 / 괴물이 등대 파괴 |

- 기한 전에 등대가 활성화되거나 파괴되면 즉시 종료.

## 3. 하루 사이클과 전체 흐름
### 3.1 숨은 단계 (낮/밤)
낮밤은 서서히 전환. 시간 표시 + 시각 효과 동시.

| 구간 | 내용 |
|---|---|
| 낮 | 각자 배로 파밍, 몬스터 회피·전투. 마피아는 몰래 방해 |
| 해 질 녘 | 귀항 알림 (해 지기 60초 전) |
| 밤 | 파밍 가능. 밤 전용 자원 있음. 유령선 랜덤 등장(마피아 힌트). 바다는 시야 저하 + 몬스터 강화, 등대 섬 근처만 안전 |
| 밤 회의 | 밤 후반. 전원 등대 섬 집결, 근접 보이스로 토론 |

- 자원 투입은 시간대 무관, 언제든 가능하며 실시간 반영.
- 비밀 투표는 밤 포함 언제든 가능.

### 3.2 전체 흐름
1. **숨은 단계**: 낮/밤 반복. 파밍·크래프팅으로 등대 수리도 상승. 마피아는 방해하며 심해 게이지 축적.
2. **점화 의식**: 수리도 100% 도달 후 60초. 시민 과반(2명 이상)이 마피아에게 투표한 상태여야 성공.
3. **분기**: 의식 성공 → 시민 승리 / 기한 종료 → 마피아 승리 / 확인 성공한 마피아가 소환 → 최후 전투.
4. **최후 전투**: 낮밤 구분 없음(시간은 계속 흐름). 괴물이 아침에도 사라지지 않고 등대 파괴. 기상 악화로 계속 험악한 분위기. 시민은 수리 자원 파밍, 마피아는 바다 몬스터로 방해. 수리 완료 후 점화하면 시민 승리(투표 조건 없음). 등대 내구도 0 또는 기한 종료 시 마피아 승리.

## 4. 플레이어
| 상태 | 조작 대상 | 가능한 행동 |
|---|---|---|
| 배 탑승 | 배 | 항해, 회피, 대포 사격, 표류물·흔적 상호작용, 배 무전 |
| 하선 | 캐릭터 | 섬 탐색, 자원 채집, 작업대(크래프팅), 배·등대 모듈 장착, 배 수리 |

- 외부 섬에서 모은 자원은 개인 인벤토리에 담아 등대 섬으로 가져온다.
- 수영 없음. 캐릭터는 배 또는 섬 위에만 있다.
- 배 업그레이드 = 배 모듈 장착 (7장).

### 4.1 스킬 규칙
- 패시브: 항시 활성. 액티브: 횟수·조건 제한 (예: 하루 1회).
- 마피아도 들키기 전에는 직군 스킬을 그대로 사용. 직군만으로 마피아 구분 불가해야 함.

### 4.2 직군 **(미확정)**
| 직군 | 패시브 | 액티브 (예시) |
|---|---|---|
| 항해사 | 지도에 환영 섬이 뜨지 않음, 배 속도 상승 | 구조 항로 안내: 난파된 동료까지 최단 경로 (하루 1회) |
| 기술자 | 대포 재장전 속도 상승 | 장비 수리·강화 관련 (배 수리 방식 확정 후) |
| 채집가 | 희귀 자원 획득 확률·채집 속도 상승 | 섬에 남은 자원 위치 감지 (하루 1회) |

- 모듈 부식 확인 스킬: 하루 1회. 담당 직군 미정.
- 항해사만 환영 섬을 폭로할 수 있음. 마피아가 항해사면 "그 섬은 진짜"라고 거짓말 가능.

## 5. 마피아 시스템
### 5.1 투표와 확인
- 누구나 언제든 비밀 투표. 결과는 본인과 시스템만 앎. 마피아도 투표 가능.
- 투표 UI: 단축키 메뉴로 1초 안에, 화면 연출 없이.
- 마피아는 정체 확인 2회 **(가안, 팀 기획 1~2회)**. "들킴" 판정 = 1표 이상 **(가안, 2표로 조정 가능하게 설계)**.
- 확인 성공 → 10초 안에 소환 여부 결정, 확인 기회는 소모.
- 확인 실패 → 전체 공지("바다가 누군가를 불렀으나 응답이 없었다") + 무고한 시민 1명 공개.
- 2회 모두 실패 → 소환 영구 불가.

### 5.2 들키기 전 / 들킨 후 능력
| 구분 | 들키기 전 | 들킨 후 (소환 이후) |
|---|---|---|
| 직군 스킬 | 사용 | 비활성 |
| 인벤토리 | 사용 | 비활성 |
| 바다 몬스터 소환 | 작은 몬스터, 시야 안 플레이어 근처 지정 소환. 하루 3회 또는 쿨다운 90초 **(가안)** | 다른 종류, 더 공격적 |
| 등대 괴물 소환 | 불가 | 가능 |
| 환영 섬 | 하루 1개 | 불가 |
| 모듈 부식 | 한 판 1회 | — |
| 날씨 변경 | 다음 날 날씨 변경 (횟수 제한) | 불가 (소환 후 계속 폭풍우) |
| 수리도 보상 | 받음 | 못 받음 |

### 5.3 들키기 전 방해 상세
- **몬스터 소환**: 자연 스폰과 외형 동일. 단서는 "빈도"와 "누구 옆에서"만 남게.
- **환영 섬**: 시민 지도에 없는 섬을 추가(있는 섬 숨기기 아님). 도착하면 안개처럼 사라지고 몬스터 출현 또는 시간 낭비.
- 그 외: 난파 동료 늦게 구조, 투입된 자원 빼내기. 모두 무고한 실수처럼 보일 수 있어야 함.

### 5.4 심해 게이지와 봉인
괴물의 힘 = 심해 게이지 − 봉인. 충전 속도 **(미정, 밸런스 시뮬레이션으로 결정)**.

| 장치 | 규칙 |
|---|---|
| 심해 게이지 | 들키지 않은 방해 성공 시, 숨어 있는 날이 쌓일수록 증가. 몬스터가 시민 파밍을 막거나 배를 난파시키면 추가 |
| 봉인 | 시민이 마피아에게 투표한 상태를 유지하는 동안 쌓임. 같은 대상 연속 투표 시간만 인정, 대상 바꾸면 초기화 |
| 오투표 페널티 | 무고한 사람에게 투표한 시간만큼 심해 게이지 증가 |
| 점화 의식 실패 | 심해 게이지 크게 증가 |

- 오투표 페널티 근거: 시민 3명이 무작위로 찍어도 1명 이상 마피아를 찍을 확률 ≈ 70%.
- 소환 순간 시민에게 짧은 결속 버프 검토 중.
- 행동 불능(난파) 중에도 투표 가능.

## 6. 몬스터
| 종류 | 출현 | 크기·강도 | 목표 |
|---|---|---|---|
| 자연 스폰 바다 몬스터 | 정해진 영역 패트롤 | 작음 | 근처 배 공격 |
| 소환 바다 몬스터 (들키기 전) | 마피아 시야 안 플레이어 근처 | 작음, 자연 스폰과 구분 어렵게 | 특정 플레이어 파밍 방해 |
| 소환 바다 몬스터 (들킨 후) | 마피아 소환 | 다른 종류, 더 공격적 | 최후 전투 중 파밍 방해 |
| 등대 괴물 | 정체 들킨 후 소환 | 가장 큼, 힘 = 게이지 − 봉인 | 메인 등대 지속 파괴 |

| AI 상태 | 바다 몬스터 | 등대 괴물 |
|---|---|---|
| 대기·순찰 | 영역 패트롤 | 없음 |
| 추적 | 감지 범위 내 배 추적 | 등대 섬으로 접근 |
| 공격 | 돌진·물어뜯기 | 등대 우선, 방해 플레이어는 부차 |
| 이탈 | 추적 범위 이탈 또는 섬 안으로 들어가면 포기 | 없음. 해가 떠도 물러나지 않음 |

- 모든 몬스터 AI는 호스트에서만 판정. **소환/자연 스폰 여부는 클라이언트에 보내지 않는다.**
- 피격 시 배 내구도 감소, 0이면 난파.

## 7. 등대
메인 등대 하나 (보조 등대 삭제).

| 구분 | 내용 |
|---|---|
| 수리도 | 수리 자원 투입으로 상승. 언제든 투입, 실시간 반영 |
| 모듈 | 활성화에 공유 모듈 여러 개 장착 필요 |
| 불빛 | 마지막에 켜지고 게임 종료 |
| 내구도 | 최후 전투에서 괴물이 깎음. 수리도와 별개, 수리도가 높을수록 내구도도 높음 |

수리도 보상 (시민 전체, 들키기 전 마피아 포함) **(가안)**:
| 수리도 | 보상 |
|---|---|
| 25% | 배 이동 속도 상승 |
| 50% | 자원 파밍량 증가 |
| 75% | 대포 피해 상승 |
| 100% | 점화 의식 가능 |

## 8. 모듈과 크래프팅
| 대상 | 용도 | 소유 |
|---|---|---|
| 배 | 업그레이드 | 개인 |
| 메인 등대 | 활성화 | 공유 |

크래프팅 흐름: 자원 파밍 → 작업대 메뉴에서 모듈 선택 → 자원 투입(언제든, 할당량 실시간 갱신) → 모듈 완성 → 배/등대에 장착.

모듈 부식: 마피아가 등대 장착용 모듈을 부식(한 판 1회). 부식 여부는 직군 스킬로 확인(하루 1회).

## 9. 맵
- 매 판 랜덤 생성. 섬·난파선 프리팹을 랜덤 위치에 스폰. 등대 섬은 중앙 고정.
- 구역별 섬 수·종류 최소/최대를 정해 판마다 편차를 제한.
- 해금 기준은 일차. 멀수록 자원이 좋고 위험이 큼.
- 영역 확장은 정해진 일차에 시스템이 자동으로 수행하고 모든 플레이어에게 고지한다. 플레이어 행동으로 해금하지 않는다.

| 구역 | 해금 | 자원 | 위험 |
|---|---|---|---|
| 내해 | 처음부터 | 일반 자원, 적은 양 | 몬스터 적음 |
| 중간 해역 | 1/3 시점 | 일반 자원 많음, 희귀 일부 | 암초, 몬스터 증가 |
| 외해 | 2/3 시점 | 희귀 자원 | 몬스터 다수, 밤 귀항 어려움 |

| 장소 | 역할 |
|---|---|
| 등대 섬 | 메인 등대, 밤 회의 집결지 |
| 자원 섬 | 섬마다 자원 종류·생산량 다름(목재·석재·금속 등, 연료 없음). 기본 자원(목재·석재)은 대부분의 섬에서. 매장량은 하루마다 일부만 회복 **(회복량 미정)** |
| 밤 전용 자원 | 밤에만 파밍 가능 |
| 난파선 | 랜덤 스폰. 희귀 자원 소량 |
| 유령선 | 밤 랜덤 등장. 마피아 힌트 |
| 특수 기능 섬 | 맵 확장 이후. 하루 횟수 제한, 한 사람만 사용 |

특수 기능 섬:
| 섬 | 기능 | 추리 가치 |
|---|---|---|
| 레이더 섬 | 모든 배 위치 표시 (누구 배인지는 모름) | 누군가의 말 검증 |
| 관측소 | 주변 해역 몬스터 수가 평소보다 많은지 표시 | 소환 몬스터 위치 = 마피아 동선 |
| 날씨 예측 | 내일 날씨 예측 | 마피아가 날씨를 바꾸면 예측과 달라짐 |

## 10. 난파·구조
- 원인: 바다 몬스터, 암초. 플레이어는 죽지 않고 행동 불능. 수영 없음.
- 파괴된 배 수리에 자원 필요.

행동 불능(난파) 상태:
- 이동 조작 불가. 행동 불능 관련 UI만 조작 가능. 카메라 시점은 조작 가능.
- 구조 요청: 배 무전으로 전원에게, 또는 근접 보이스로 주변 플레이어에게.

| 결과 | 조건 | 아이템 | 복귀 |
|---|---|---|---|
| 구조 | 다른 플레이어가 구조 | 랜덤 1개 잃음 | 섬에서 리스폰 |
| 시간 초과 | 제한 시간 1분 **(가안)** 내 구조 못 받음 | 전부 잃음 | 섬에서 리스폰 |
| 즉시 리스폰 | 리스폰 UI 버튼 | 전부 잃음 | 섬에서 즉시 리스폰 |

- 구조 상호작용 방식(접근 거리·소요 시간)은 미정.
- 리스폰하는 섬(등대 섬 / 가까운 섬)은 미정.
- 잃은 아이템이 바다에 잔해로 남는지는 미정. (기존 "잔해 챙기기" 마피아 방해와 연결됨)
- 행동 불능 중에도 비밀 투표 가능 (5.4).

추리 단서 정리:
| 단서 | 출처 | 마피아의 대응 |
|---|---|---|
| 특정 사람 주변에 몬스터가 잦음 | 몬스터 소환 | 소환을 아끼거나 멀리서 사용 |
| 지도에 없는 섬을 본 사람/못 본 사람 | 환영 섬, 항해사 | 항해사 사칭 |
| 밤 집결에 늦음 | 하루 사이클 | 외해 파밍 핑계 |
| 이동 경로 | 목격, 레이더 섬 | 다른 사람 경로와 겹치게 이동 |
| 구조 지연 | 난파 | 먼저 구조해 신뢰 쌓기 |

## 11. 보이스 채팅
| 상황 | 방식 |
|---|---|
| 섬 위 도보 | 근접 (짧은 거리) |
| 배 위 | 배 무전 (전원에게 들림, 제약 있음) |
| 밤, 등대 섬 | 근접 (거리 더 길게, 사실상 전체 대화) |
| 난파 중 | 무전 + 근접 (구조 요청) |
| 최후 전투 | 시민 전용 팀 채널, 마피아 제외 |

배 무전:
- 1회 5초 + 쿨다운 **(가안, 쿨다운 미정)**. 실시간 위치 공유 방지.
- 말하는 사람의 위치는 표시하지 않음.
- 날씨가 악화되면 성능 저하.
- 잡음으로 목소리를 헷갈리게 하는 연출 검토 중.
