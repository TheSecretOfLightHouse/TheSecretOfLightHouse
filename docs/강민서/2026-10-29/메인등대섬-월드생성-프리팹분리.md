# 메인 등대섬 월드 생성·프리팹 분리
날짜: 2026-10-29 / 담당: 강민서 / 사용자 승인 범위: MainGame 기존 시설 비활성화 및 새 메인 섬·시설 생성 연결

## 결정과 근거
- LighthouseIsland_Reference가 메인 섬이며 LagoonIsland_Reference가 아니다.
- 외형은 로컬 프리팹, 작업대·등대는 서버가 각각 하나씩 Spawn하는 네트워크 프리팹으로 분리한다. Mirror 중첩 NetworkIdentity를 피하고 외형 변경이 게임 상태에 영향을 주지 않게 한다.
- 현재 메인 섬 위치는 기존 ZoneLayoutStep의 원점(0,0,0), Terrain 섬은 회전 0으로 생성한다. 모델 완성 후 Terrain을 메시로 바꾸면 기존 seed의 yaw를 적용할 수 있다. 변환은 이번 작업에서 하지 않았다.
- 기존 R08/R10/W01 시험용 레이아웃·레시피 규칙은 바꾸지 않았다. 원격 4인과 의식/소환은 후속 검증이다.

## 변경
- MainIslandAppearance.prefab: 현재 섬 Terrain·연못·건물·식생·등대·작업대 모델 유지. 테스트 플레이어/배/카메라/지원 시스템 제외. NetworkIdentity 0개.
- MainIslandPresentation: 작업대·등대 기준점, 슬롯8·완성등불 참조를 유지하는 외형 교체 계약.
- MainIslandWorkbench.prefab / MainIslandLighthouse.prefab: 각각 NetworkIdentity 1개. 로컬 모델과 중복되는 외형은 제거. 작업대의 기존 Rack 설정은 유지.
- MainIslandFacilitiesBuilder: 섬/암초 빌더 뒤에 실행. 서버 시설 생성, 클라이언트 prefab 등록, WorldServices로 시설 확인, 로컬 외형·작업대/등대 UI·최종전 HUD 연결 완료 후 WorldReady.
- MainIslandFacilityNet: 서버/클라이언트 시설 등록·해제.
- TowerNet.BindWorkbench, TowerMatchFlow.BindServices, TowerView/TowerScreen/WorkbenchScreen/FinalBattleHud.Bind 추가.
- MainGame: CompositeLocalMapBuilder에 시설 빌더 연결. 기존 Lighthouse·Workbench·DevTowerTools·DevWorkbenchTools는 LegacyMainIslandFacilities_Disabled 아래 보관. 단순 SetActive(false)는 Mirror SpawnObjects가 다시 활성화하므로 비활성 부모가 필요하다.
- Island_Lighthouse.asset의 첫 외형 프리팹을 MainIslandAppearance로 교체. 반경33 유지.
- IslandInstanceSet: Terrain이 있는 프리팹은 회전 0, 메시 섬은 기존 yaw 유지. Terrain에 회전하면 배치물만 돌아가 실제 지형과 분리되는 문제를 Play 화면으로 확인한 뒤 수정했다.
- TerrainCoastWaveView: 기존 CoastalShelfView는 Ground_ContinuousClosed 메시만 스캔하므로 Terrain 섬이 해안 감쇠 등록에서 누락됨. Terrain 높이와 holes를 이용해 외곽96점을 생성 시 추출하고 기존 CoastWaveRegistry에 등록한다. 섬 내부 연못은 외곽으로 취급하지 않는다. CPU/GPU 기존 감쇠 경로 공용. 방사형 외곽을 전제하므로 미래에 심하게 오목하거나 분리된 지형으로 바꾸면 추출 방식도 재검토해야 한다.
- 변경 전 MainGame/LagoonReference 백업 씬을 Assets/00.Scenes/Minseo에 저장했다.

## 작업대 비교 (비활성화 전)
MainGame Workbench와 참고 섬 Workbench_Functional의 catalog, supportedActions/상호작용 거리, 목제 모델·머티리얼, 모델 scale1.2, 루트 scale1, Rack 설정이 동일했다. 배치 위치만 다르다. 새 기능 프리팹은 MainGame 버전에서 생성했다.

## 실제 검증
- 컴파일 오류0.
- MainGame 단일 씬 Play에서 임시 Mirror NetworkManager+KcpTransport로 호스트 시작(autoCreatePlayer=false). 임시 객체는 Play 종료로 폐기.
- IsBound=true, IsLayoutReady=true, ReadyCount=1. 활성 메인 외형1·작업대1·등대1.
- 섬 위치(0,0,0), 회전(0,0,0), Terrain 원점(-13.6,0,-11.2). 두 기능 시설의 외형 anchor 위치 오차0. TowerScreen의 새 Tower 참조 확인.
- 실제 생성된 시설 서버 API로 임시 ModuleLedger Stored→Carry→Install8/8, IsComplete=true, 완성등불 활성 확인. UI 입력·재료 제작 검증과 구분한다.
- Cancel→Begin→Step 재생성 성공, 설치 상태0 초기화. 지연 Destroy 다음 프레임 네트워크 시설2/서버 spawned2 확인. 중복 상호작용 등록 오류0.
- MCP 카메라 캡처로 회전 수정 후 Terrain·계단·등대·작업대 정합 확인.
- 해안 등록 슬롯0, 중앙·작업대·등대 위치×100시각의 입력파고5/에너지10에서 내부 파고 최대0 확인. 최초 사각형 해안 등록은 holes 누락이 원인이라 수정.

## 외형을 계속 수정하는 방법
- 런타임이 쓰는 외형은 Assets/02.Prefabs/World/MainIsland/MainIslandAppearance.prefab이다. Prefab Mode 또는 이 프리팹의 Variant로 외형 수정.
- MainIslandPresentation의 WorkbenchAnchor/TowerAnchor/슬롯8/CompleteVisual 참조를 보존한다. 기능 위치 변경은 anchor를 이동한다. 기능 프리팹은 교체할 필요 없다.
- Island_Lighthouse.asset Variants의 Prefab에 새 외형/Variant를 연결하면 다음 생성부터 교체된다.
- LagoonReference의 원본 LighthouseIsland_Reference는 편집용 원본으로 보존되었지만 출력 프리팹과 자동 동기화되지 않는다. 원본 씬만 수정해서 런타임 외형도 갱신됐다고 간주하지 않는다.
- 메시로 변환할 때 Terrain 원본/TerrainData 보존, 모래·잔디 혼합 재질 베이크 및 collider 점검, anchors/표시 참조 유지. TerrainCoastWaveView는 메시 해안 등록으로 교체해야 한다.
- 해안 추출은 생성 시 1회 실행이므로 지형 변경은 다음 생성에 반영된다.

## 미검증
실제 로비→4인 원격 클라이언트 흐름, 실제 이동/상호작용 UI/재료 제작, 의식/소환/최종전, 장시간 성능. 호스트 검증을 이들 통과로 확대하지 않는다. 커밋/푸시 없음. 기존 다른 작업자의 미커밋 변경 보존.

## 해안 감쇠 범위 후속
Terrain holes 제외 후 실제 해안선 형태 확인. 기존 CoastWaveRegistry의 bounds는 width×2.2까지만 포함하지만 CoastWaveModel의 원해 혼합은 max(7,width)×5에서 완료되므로 새 섬에 범위 끝 벽이 보였다. Register에 선택적 waveReach 인자를 추가해 Terrain 섬만 전체 혼합 범위를 포함하도록 했다. 다른 기존 호출의 동작은 유지한다.

## 사용자 후속: 해안 가장자리 파도 겹침
TerrainCoastWaveView에 ShoreOverlap 1.5m를 추가해 감쇠 기준선을 육지 안쪽으로 이동했다. MCP 화면에서 해안 모래 가장자리와 포말이 맞닿는 모습 확인. 변경 후 월드 준비 완료, 중앙/작업대/등대 3점×100시각의 내부 파고 최대0 재확인. 실제 4인·해안 보행·폭풍 전 구간 검증은 하지 않았다.

## 후속: 파도가 모래 아래로 묻히는 문제
사용자 요청으로 메인 섬 ShoreLift=0.25m 추가. 감쇠 윤곽에서 바깥 거리0~0.6m에 보정 진입, 2~5m에서 보정 소멸. LagoonBuffer.y로 새 섬 보정량 전달, CPU CoastWaveModel/WaveModel과 GPU OceanCoasts.hlsl에 동일 식 적용. 기존 섬은 보정0 유지. Play에서 실제 등록0.25, 중앙/작업대/등대×100시각 내부파고0, 컴파일·콘솔 오류0. MCP 화면 확인. 실제4인·해안 이동·전날씨 GPU 정합은 미검증.

## 후속: 전 해안 파도 노출·지형 경계 완화
사용자 요청으로 원본 LighthouseTerrain.asset을 복제한 MainIslandTerrain_CoastBlend.asset을 생성해 외형 프리팹 Terrain/TerrainCollider에 연결. holes로부터 외곽거리 약1.15m 이내 높이를 smoothstep으로 수면0까지 낮추고 나머지는 원래 높이 유지. 원본 TerrainData와 holes 보존. 외곽96방향에서 holes 경계 안쪽5cm 위치를 샘플링하고 100시각 파도 높이를 비교해 96/96에서 파도 마루가 모래보다1cm 이상 높음 확인(경계 지형 최대0.01794m). 이는 시간에 따른 최대 파고 검사이며 항상 덮인다는 뜻이 아니다. MCP 앞/뒤 캡처 및 월드 준비 완료, 컴파일·콘솔 오류0. 넓은 지형 변경 시 이 복제 에셋을 편집하며 원본으로부터 자동 재계산되지 않음.

## 부두별 보트2척 배치
사용자 요청으로 LagoonReference/LighthouseIsland_Reference의 실제 Boat.prefab 원본scale3 보트를 총4척 배치. 플레이어 위치 보존. local pose: Left01(-8.66,0.15,-12) yaw180, Left02(-4.02,0.15,-12) yaw180, Right01(12.65,0.15,-5.98) yaw90, Right02(13.92,0.15,-3.55) yaw90. BoatSpawnPoints/BoatSpawn_Left_01·02/BoatSpawn_Right_01·02를 참고 씬과 MainIslandAppearance.prefab 양쪽에 저장. 오른쪽 북측은 얕은 지형과 접촉해 부두 끝으로 변경. 계류 기둥4·5·7·8을 안쪽으로 최대13cm 이동하고 부두3개를 Dock 레이어로 지정. Physics.ComputePenetration에서 모든4척 지형/부두/기둥 겹침없음(5mm 허용), 배끼리 bounds 겹침없음. 부두 collider 간격0.13415/0.12168/0.13406/0.14411m로 기존 contactTolerance0.15m 이내. MCP 화면으로 방향·간격 확인, 씬 저장. Play 실제 탑승/부력/원격 미검증. 외형 프리팹 NetworkIdentity0개 유지. 이번 작업은 배치와 기준점 저장이며 PlayerBoatSpawner의 랜덤배정·기준점 자동 바인딩은 아직 연결하지 않았다. 참고 씬의4척은 배치 확인용 실제 프리팹이며 런타임 외형에 중첩하지 않았다.

## 2026-10-29 기능별 커밋 정리
런타임 코드·외형 에셋·연결을 기능별로 분리해 로컬 커밋했다. 참고 원본 씬과 백업은 이전 작업이 섞여 있어 이번 커밋에서 제외했다. 기존 본문의 미커밋·미연결 표기는 해당 작업 시점의 기록이며, 최신 커밋 범위와 후속 검증은 [커밋 정리](야간작업-기능별-커밋정리.md)를 따른다. push와 추가 Play 시험은 하지 않았다.
