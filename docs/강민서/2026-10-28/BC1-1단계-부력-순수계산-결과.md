# BC1 1단계 부력 순수 계산 결과

작성: 2026-10-28 / 상태: 구현됨, 에디터 순수 검증 8종 통과(실행 검증). Play·씬·프리팹 변경 없음, 미커밋
원문 설계: [범용 부력과 자연 파도 재설계 검토](../2026-10-25/범용부력과-자연파도-재설계-검토.md) (BC1 모델, 2~3차 재검토)

## 결정 (사용자 확정, 모두 가안)

1. 수면 혼합식: 기준 수면 = 표본 평균 수면 + 추종도 × (국소 파면 − 평균). 수면 걸침 추종도 1.0, 잠수형 0.3.
2. 복원 강도: 목표 깊이 하나를 받으면 부력비를 0.9로 고정하고 복원 강도를 유도(`(1−0.9)/(목표 깊이 − 판 두께/2)`). 부력비·복원 강도는 고급 입력.
3. 비선박 몸체는 표류 풀을 쓴다(2단계 `BuoyantObject`에서 적용).

## 모델 요약

- 점 i의 잠김 `s = clamp01((기준수면 − y + t/2) / t)`, 힘 = `무게/N × (부력비 × s + 복원강도 × 판 아래 깊이)`.
- 평형 잠김 비율 = 1/부력비. 완전 잠김은 `부력비 + 복원강도 × 깊이 = 1`.
- 판 두께 기본값은 격자 세로 셀 높이(0이면 자동)라 수면 근처에서 힘이 선형으로 변하고 평탄 구간이 생기지 않는다.
- 목표 깊이는 점 무리 중심(대칭 격자면 몸 중심)의 수면 아래 깊이다. 몸 상단 기준이 아니다.

## 검증 (실행 검증, 에디터 `BuoyancyChecks.RunAll()` → true, 콘솔 오류 0)

| 항목 | 기대 | 결과 |
|---|---|---|
| Half (부력비 2.0) | 잠김 0.5 | 0.500 |
| Fin (부력비 1.111) | 0.9 | 0.900 |
| Floating (부력비 5.0) | 0.2 | 0.200 |
| Submerged (목표 깊이 1.0) | 중심 깊이 1.0 | 1.000 |
| Sink (부력비 0.6) | 5초 내 -2m 아래 | -4.079 |
| Follow | 추종도 0이면 힘 동일, 1이면 상이 | 차 0 / 39.24 |
| Invalid | 질량 0·길이 불일치·null 거부 | 통과 |
| Grid | 2×2×2=8점, 3×1×2=6점, 0 분할 거부 | 통과 |

시뮬레이션은 질량 10, 수직 항력 5, 고정 수면 0, dt 0.01로 40초 정착시킨 값이다.
