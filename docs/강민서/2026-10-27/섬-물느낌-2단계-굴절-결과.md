## 실행 검증 (WorldSessionGame 퀵스타트 1인, 낮 고정 Calm, 임시 카메라)

- 셰이더 오류 0, 컴파일 오류 0(`ShaderHasError=False`).
- 같은 프레임에서 런타임 수면 재질(`OceanWater_Clear (Ocean Runtime)`)의 값만 바꿔 캡처하고 픽셀 차이를 쟀다(기준: 0.002/falloff 0).

| 강도 / falloff | 가까운 시점 평균 차이 | 중간(60m) 평균 차이 | 육안 |
|---|---|---|---|
| 0.006 / 0 | 0.007 | - | 차이 없음 |
| 0.012 / 0.03 | 0.010 | - | 차이 없음, 가장자리 깨짐 없음 |
| 0.02 / 0 | 0.023 | 0.002 | 거의 차이 없음 |
| 0.06 / 0 | 0.071 | 0.007 | 해안 바위 가장자리에 점선 번짐이 생기고 윤곽이 이동 |
| 0.06 / 0.03 | 0.050 | 0.003 | 번짐 일부 감소 |

- 평균 차이는 RGB 합 기준 0~765 척도다.
- 분석: Calm에서는 수면 법선 xz가 작아 굴절 오프셋이 0.02 이하에서도 1픽셀 안팎이다. 허용 범위를 올려도 효과가 거의 없고, 0.06 부근에서는 전경 가드가 못 막는 가장자리 번짐이 생긴다.
- 거리 감쇠는 중간 시점에서 변화량을 줄이는 것을 확인했다(0.007 → 0.003).

## 한계 (미확인)

- **정지 캡처로는 바닥 일렁임의 자연스러움을 판정하지 못했다.** 시간 흐름에 따른 움직임, 카메라 이동 깜빡임은 미확인.
- Calm 한 상태만 봤다. Rain·Storm에서 큰 파도 법선으로 굴절이 커질 때의 가장자리 깨짐은 미확인. 이때는 가드를 부드럽게 하는 선택 항목(깊이 차이 비율 혼합)이 필요할 수 있다. 이번에는 넣지 않았다.
- 한 섬·한 시점만 봤다. 4인 일치·GPU 비용 미검증(추가 비용은 나눗셈 1회).
- 저장 값 0.006/0.02는 가안이다. 지금 차이가 거의 없으므로 사실상 "안전한 약한 설정"이며, 일렁임을 더 원하면 Storm에서 확인한 뒤 올린다.
