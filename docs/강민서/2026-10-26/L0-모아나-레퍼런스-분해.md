# L0 모아나 레퍼런스 분해 (2026-10-26)

사용자가 제공한 스틸 5장([폴더](L0-레퍼런스/))을 색·투명도·질감·파형·빛으로 분해한 것이다. 수치는 눈대중 가안이며 시안 비교 때 조정한다. 영화 장면 이미지는 저작권상 저장소에 커밋하지 않고 작업 PC의 `L0-레퍼런스/` 폴더에만 둔다(로컬 제외 처리). 다른 PC에서는 사용자에게 원본을 다시 받는다.

|---|---|---|

## 공통 특성 → 구현 키워드

1. **색:** 낮에는 시안~터콰이즈~에메랄드가 주색이며 깊어질수록 코발트/울트라마린으로 이동한다(채도 높음). 밤에는 인디고/네이비에 보라 하늘 반사. 어두운 회색 바다가 없다.
2. **투명도:** 물이 얕거나 파도가 얇은 곳은 빛을 투과해 안쪽 색이 밝아지고 아래 바닥(모래)이 보인다. 두꺼운 곳은 짙다. → L2에서 투과 광택(SSS), 파고·수심 기반 색 변화.
3. **질감:** 표면은 매끈한 유리/젤리 질감이고 잔물결은 부드럽다. 포말은 해안·쇄파 가장자리에만 얇게 있다(외해 흰 거품 없음). → L3에서 외해 포말은 폭풍에서만.
4. **파형:** 큰 너울은 길고 둥글다(ref4·5 배경). 말림 파도는 연출용이고 L1 범위가 아니다. 바다는 잔잔할 때 거의 거울이다.
5. **빛:** 밤에는 발광(생물발광 느낌)이 포인트이며 하늘 보랏빛이 수면에 반사된다. 낮은 태양 반짝임과 해저 빛 무늬.

6. **하늘(사용자 요청 2026-10-26):** 물과 함께 보는 한 장면이다. 낮 하늘은 청명한 파랑이 아니라 수평선으로 갈수록 연보라/분홍 기운이 도는 부드러운 큰 적운(ref1·4·5·6)이고, 밤은 인디고~보라 그라데이션과 별(ref2·3)이다. 물색(청록)과 하늘색(보라 계열)의 보색 대비가 모아나 룩의 핵심이다. 현재 게임 하늘은 단색에 가까운 파랑이라 `EnvironmentSky` 낮 팔레트(수평선·천정·구름색)와 구름 형태를 조정해야 한다(후속, 미착수).

## 아름다움 ↔ 괴물 대비 계획 (가안)

모아나 레퍼런스는 아름다움 쪽이다. 괴물 쪽은 같은 시각 언어를 어둡고 불투명하고 탁하게 뒤집는 방식으로 정한다.

| 축 | 아름답고 신비로운 바다 | 괴물 같은 바다 |
|---|---|---|
| 해역 | Inner: ref1·4 (맑은 터콰이즈, 가장 투명) / Middle: 짙은 파랑 (ref1 수평선) | Outer: 먹빛 청록~녹흑, 불투명, 투과광이 차갑고 약함 |
| 날씨 | Calm: 거의 거울, 긴 너울(L1 적용) / Overcast: 탁해진 터콰이즈 | Storm: 짙은 청회, 짧고 가파른 파(L1 적용), 거품 / Maelstrom: 흑청, 녹색 번개, 가장 불투명 |
| 최후 전투 | - | 심연 팔레트(가장 어두운 끝점)+Maelstrom 파형 |
| 밤 | ref2: 인디고에 보라 하늘 반사, 은은한 발광 | 밤+폭풍은 발광 없이 흑청 |

발광(ref2·3)은 L4(바다의 성격 층) 후보다. 플레이어에게 반응하는 연출은 만들지 않는 원칙은 유지한다.

## 해야 할 비교 (L0 산출물, 미실행)

고정 카메라 5지점 × 낮/밤/비/폭풍 × 해역 3의 캡처는 아직 찍지 않았다. L1 검증(Play) 성공 후 같은 장면을 찍어 ref와 나란히 비교한다.
