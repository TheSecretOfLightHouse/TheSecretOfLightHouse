3. **6-3 방향(정정):** 처음에는 Final 메시 섬의 yaw를 0으로 고정했으나 사용자 요청으로 되돌렸다. 섬 루트는 `plan.YawDegrees`로 회전하고, 파밍 스팟·DockZone·착지면은 섬의 자식이라 로컬 좌표 그대로 월드에서 함께 회전한다. `IslandInstanceSet.cs`는 원래 코드(Terrain 섬만 yaw 무시)로 복원했다. 에디터 확인: yaw 0/90/37°에서 스팟 로컬 좌표 불변·월드 위치 오차 0, DockZone이 같은 yaw로 돌고 착지면 중심이 존 안에 있음(`DockZone.ContainsPosition`은 `InverseTransformPoint` 기반). 6-4 Play의 섬 yaw 0 결과는 고정 코드 때문이었고, 회전 상태의 Play·접안은 미검증이다.
4. **6-4 호스트 1인 Play:** `WorldSessionOffline`에서 호스트 시작→로비 준비(런타임에서만 시작 인원 2→1)→`WorldSessionGame`.

- **결정:** Lighthouse(0번 섬)도 다른 섬처럼 판마다 회전 허용. 코드 변경 없음.
