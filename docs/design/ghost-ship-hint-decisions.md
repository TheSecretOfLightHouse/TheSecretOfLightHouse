# 유령선 힌트 결정 — W22

- 결정일: 2026-10-30 (사용자 김지훈 대화 결정)
- 관련 항목: 설계 문제 대장 [W22](../07-design-issue-register.md), v4 [8.3 유령선](references/game-design-v4.md)
- 담당: 강민서(World) 유령선 등장·경로·연출, 김지훈(Interaction) 조사 요청 경로와 힌트 생성 — [코드 소유권](../CODE_OWNERSHIP.md)

v4 8.3은 "밤에 랜덤 확률로 떠오르고, 상호작용한 플레이어만 마피아에 대한 힌트를 얻는다"까지만 정한다. 아래 결정이 빈 부분을 채우며, 충돌하면 이 문서가 v4보다 우선한다. 이 문서는 기획 결정이며 구현·실행 검증 완료를 뜻하지 않는다. 구현 상태는 [작업 기록](../김지훈/2026-10-30/유령선-힌트-작업대인출장부.md)에서 확인한다.

## 1. 힌트 내용

| 항목 | 결정 |
|---|---|
| 힌트 | 작업대에서 빠진 자원(마피아 인출)의 기록. **며칠째에 어떤 자원이 몇 개 빠졌는지**만 보여 준다 |
| 범위 | 지금까지의 인출 전부를 날짜별로 보여 준다(같은 날·같은 자원은 합산) |
| 인출 0건 | "사라진 자원은 아직 없다"로 보여 준다. 마피아가 아직 인출하지 않았다는 정보가 된다 |
| 표시하지 않는 것 | 누가 인출했는지, 그 시각 등대섬에 누가 있었는지 |

작업대 인출은 서버가 마피아만 허용하므로(v4 4장 "인출은 서버에 기록되어 단서로 쓸 수 있다") 기록된 인출은 모두 마피아의 행동이다. 투입량은 작업대 현황으로 모두가 볼 수 있어서, 힌트를 받은 사람의 말을 다른 사람이 일부 맞춰 볼 수 있다.

## 2. 받는 사람과 마피아

| 항목 | 결정 |
|---|---|
| 독점 | 한 번 출현에 **처음 조사한 1명만** 받는다. 다른 사람은 "이미 누군가 읽었다"는 사실만 안다 |
| 재조회 | 같은 출현에서 받은 사람이 다시 조사하면 처음 받은 내용이 그대로 다시 나온다(읽은 순간 고정) |
| 마피아가 먼저 조사 | 시민과 같은 진짜 힌트를 받고 그 출현의 힌트는 소진된다. 거짓 증언 여부는 마피아가 선택한다 |
| 마피아 선점 보정 | 마피아가 가져간 출현이 있으면 **다음 밤에는 확률 없이 반드시 출현**한다 |
| 읽힌 뒤 | 첫 조사 후 **8초 뒤 가라앉는다**(2026-10-30 사용자 결정, 시간은 가안) |

## 3. 출현

| 항목 | 결정 |
|---|---|
| 기본 | 밤마다 확률로 출현(현재 가안 60%, `GhostShipConfig`) |
| 최소 보장 | 마지막 밤까지 한 번도 뜨지 않았으면 마지막 밤에는 반드시 출현 |
| 소환 이후 | 최후 전투에 들어가면 더 이상 뜨지 않고, 떠 있던 배는 가라앉는다 |

## 4. 가안 수치

플레이테스트 후 조정한다. 확정 수치가 아니다.

| 항목 | 가안 | 위치 |
|---|---|---|
| 조사 거리 | 20m(+서버 여유 1.5m), 유령선 기준점에서. 배 길이 약 28m(모델 0.7배) | `GhostShip.prefab`의 `InteractionTarget` |
| 읽힌 뒤 가라앉기까지 | 8초 | `GhostShipHintNet._leaveAfterReadSeconds` |
| 조사 방식 | 즉시(한 번 누르기). 실제 입력이 길게 누르기를 지원하지 않아 3초 누르기안은 보류 | — |
| 조사 가능 구간 | 떠오르는 중·돌아다니는 중. 가라앉기 시작하면 불가 | `GhostShipHintNet` |
| 출현 확률 | 밤마다 60% | `GhostShipConfig` |

## 5. 남은 것

- 메인 게임 씬에 유령선 배치(현재 `JH04TestScene`에만 있음) — 강민서 World 씬 배치
- 힌트 화면 — 사용자 시안으로 장부 UI 구성(2026-10-30). 1일차부터 마지막 인출일까지 띠+일차 묶음을 표시하고, 인출이 없으면 "사라진 자원은 아직 없다"를 표시. 조사 안내는 작업대와 같은 E 프롬프트("유령선 확인")
