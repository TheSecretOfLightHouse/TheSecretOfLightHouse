## 1. 개요

4명의 선원이 각자 배를 몰고 섬을 오가며 자원을 모아 등대를 밝혀야 한다. 그중 한 명은 등대가 켜지는 것을 막으려는 마피아다. 낮에는 바다로 나가 파밍하고, 밤에는 모두 등대 섬에 모인다.

### 1.1 핵심 구성 [확정]

- 플레이어 4명은 각자 직군을 가진다. 그중 1명은 마피아를 겸임한다.
- 시민은 메인 등대를 활성화해야 하고, 마피아는 이를 막아야 한다.
- 플레이어는 배를 한 척씩 가지고 섬을 오가며 자원을 파밍하고, 그 자원으로 등대를 수리한다.
- 바다에는 자원 파밍을 방해하는 몬스터가 산다. 배를 몰아 피하거나 배에 달린 대포로 처치한다.
- 배는 난파될 수 있지만 플레이어는 죽지 않는다. 행동 불능이 되어 동료의 도움이 필요하다.
- 마피아는 정체가 들키면 등대를 부수는 괴물을 소환할 수 있다. 이후 게임은 낮 파밍·밤 방어의 최후 전투로 넘어간다.

### 1.2 v0.2 변경 요약

| 영역 | v0.1 | v0.2 |
|---|---|---|
| 시간 구조 | 연속 진행 | 하루 단위 낮/밤 사이클, 밤에는 전원 집결 |
| 바다 | 암초·괴물로 인한 난파 위험 | 자연 스폰 몬스터 + 마피아 소환 몬스터, 대포 전투 |
| 마피아 | 사보타주 중심 | 들키기 전/후 능력 분리, 바다 몬스터 소환, 환영 섬 |
| 소환 이후 | 괴물 vs 등대 스피드런 | 낮 파밍 · 밤 등대 방어의 최후 전투 |
| 등대 | 등대 1개 | 메인 등대(수리도에 따라 버프) + 보조 등대(밤 시야) |
| 맵 | 고정 섬 구성 | 밀물/썰물 지역 해금 + 매 판 랜덤 배치 + 특수 기능 섬 |
| 직군 | 고유 능력 1개 | 패시브 + 액티브 스킬 |

> **디자인 목표** — 괴물 소환은 압도적으로 강한 카드지만, 마피아의 최우선 목표는 "정체를 들키지 않는 것"이어야 한다. 소환은 들킨 마피아의 탈출구가 아니라, 끝까지 숨어 있던 마피아의 마지막 한 수다.

### 1.3 진영과 승리 조건

| 진영 | 인원 | 목표 | 승리 조건 |
|---|---|---|---|
| 시민 | 3명 | 메인 등대 활성화 | 점화 의식 성공, 또는 최후 전투에서 등대를 지키며 수리 완료 |
| 마피아 | 1명 (직군 겸임) | 등대 활성화 저지 | 기한(마지막 날 밤)까지 등대가 켜지지 않음, 또는 소환한 괴물이 등대를 파괴 |

- **[제안]** 기한은 "N일차 밤"으로 정한다. 한 판 30~40분 기준으로 하루 길이와 일수를 맞춘다(9장 수치 가안).

## 2. 하루 사이클과 전체 흐름

게임은 하루 단위로 진행되며, 낮에는 흩어져 파밍하고 밤에는 모두 한 자리에 모인다. **[확정]**
흩어지는 낮은 마피아에게 기회를, 모이는 밤은 시민에게 추리의 시간을 준다.

### 2.1 낮과 밤 [확정 + 제안]

| 구간 | 숨은 단계 (들키기 전) | 최후 전투 (소환 이후) |
|---|---|---|
| 낮 | 각자 배로 섬을 돌며 파밍. 바다 몬스터 회피·전투. 마피아는 몰래 방해 | 시민은 수리 자원 파밍. 마피아는 바다 몬스터로 파밍 방해 |
| 해 질 녘 | 귀항 알림. 일정 시간 안에 등대 섬으로 돌아와야 한다 | 동일 |
| 밤 | 전원 등대 섬 집결. 자원 투입, 보조 등대 연료 보충, 근접 보이스로 토론 | 등대를 부수는 괴물이 습격. 시민은 등대를 방어 |

- **[제안]** 밤 집결에 늦거나 빠진 사람은 전원에게 공지된다. 어디서 무엇을 하다 늦었는지가 그대로 추리 거리가 된다.
- **[제안]** 밤에 바다에 남아 있으면 시야가 극도로 좁아지고 몬스터가 강해진다. 보조 등대가 밝혀주는 범위 안만 안전하다(6.2).
- **[제안]** 밤에도 비밀 투표는 언제든 가능하다. 밤 토론이 투표를 바꾸는 주된 계기가 된다.

### 2.2 전체 게임 흐름

마피아가 끝까지 숨으면 점화 의식의 투표가 승부를 가르고, 소환하면 최후 전투에서 등대를 지켜내는지가 승부를 가른다.

```
[숨은 단계] 낮/밤 반복 · 파밍 · 메인 등대 수리도 상승
    │        (마피아: 직군 능력 + 몰래 방해 + 심해 게이지 축적)
    ▼
[점화 의식] 수리도 100% 도달 후 60초 · 시민 과반이 마피아를 찍었어야 성공
    │
    ├─ 의식 성공 ─────────────────────────▶ 시민 승리
    ├─ 마피아가 끝까지 숨고 기한 종료 ────▶ 마피아 승리
    └─ 확인 성공한 마피아가 괴물 소환 ────▶ [최후 전투]
                                               │ 낮: 파밍 / 밤: 등대 방어
                                               ├─ 수리 완료 후 점화 ──▶ 시민 승리
                                               └─ 내구도 0 / 기한 종료 ▶ 마피아 승리
```

1. **숨은 단계**: 낮/밤을 반복하며 파밍하고 메인 등대의 수리도를 올린다. 마피아는 직군 능력을 쓰며 몰래 방해하고 심해 게이지를 모은다.
2. **점화 의식**: 메인 등대 수리도 100% 도달 후 60초. 시민 과반이 마피아를 찍었어야 성공한다.
3. **분기**
   - 의식 성공 → 시민 승리
   - 마피아가 끝까지 숨고 기한이 끝남 → 마피아 승리
   - 확인에 성공한 마피아가 괴물 소환 → 최후 전투
4. **최후 전투**: 낮에는 파밍, 밤에는 등대 방어. 시민은 등대를 지키며 수리를 끝내고 점화하면 승리한다. 등대 내구도가 0이 되거나 기한이 끝나면 마피아 승리.

- **[제안]** 최후 전투의 점화는 투표 조건 없이 수리도만 채우면 된다. 이미 정체가 드러났기 때문이다. 괴물의 힘은 여전히 "심해 게이지 − 봉인"이다(4.5).

## 3. 플레이어

### 3.1 조작 [확정]

| 상태 | 조작 대상 | 할 수 있는 것 |
|---|---|---|
| 배를 타고 있을 때 | 배 | 항해, 몬스터 회피(무빙), 배 대포 사격, 표류물·흔적 상호작용 |
| 배에서 내렸을 때 | 캐릭터 | 섬 탐색, 자원 채집, 등대 작업, 보조 등대 연료 투입 |

- 플레이어 1명당 배 1척. 각자 따로 움직이므로 누가 어디에 있었는지가 추리의 근거가 된다.
- 섬에서 모은 자원은 개인 인벤토리에 담아 등대로 가져온다. 인벤토리 방식은 재검토 중이다(11장).

### 3.2 스킬 규칙 [확정]

- **패시브 스킬**: 항시 활성화.
- **액티브 스킬**: 횟수 제한 또는 조건 제한이 필요하다.
  - **[제안]** "하루 1회"처럼 하루 사이클에 맞춘 충전이 자연스럽다.
- 마피아도 직군을 가지며, 들키기 전에는 직군 스킬을 그대로 쓴다. 직군만으로는 마피아를 구분할 수 없어야 한다.

### 3.3 직군 [제안]

항해사의 환영 섬 면역은 확정, 나머지는 v0.1 예시를 패시브/액티브로 나눈 검토용 안이다.

| 직군 | 패시브 | 액티브 (예시) |
|---|---|---|
| 항해사 | **[확정]** 지도에 환영 섬이 뜨지 않는다. 배 속도 상승 | 구조 항로 안내: 난파된 동료까지 최단 경로 표시 (하루 1회) |
| 기술자 | 배 대포 재장전 속도 상승 | 장비 수리·강화 관련 (배 수리 방식 확정 후 결정) |
| 채집가 | 희귀 자원 획득 확률·채집 속도 상승 | 섬에 남은 자원 위치 감지 (하루 1회) |
| 등대지기 | 등대 작업 속도 상승, 보조 등대 연료 효율 상승 | 보조 등대 빛을 한 방향으로 멀리 비추기 (밤 1회) |

> **항해사와 환영 섬의 심리전** — 항해사는 환영 섬을 폭로할 수 있는 유일한 직군이다. 반대로 마피아가 항해사라면 "그 섬은 진짜다"고 거짓말을 할 수 있다. 항해사를 자칭하는 사람의 말을 얼마나 믿을지가 시민의 고민이 된다.

## 4. 마피아 시스템

마피아는 들키기 전에는 시민처럼 살며 몰래 방해하고, 들킨 뒤에는 직군을 버리고 괴물을 부린다. 두 상태의 도구가 완전히 다르다.

### 4.1 투표와 확인 [확정]

- 플레이어는 언제든지 마피아라고 생각하는 사람에게 **비밀 투표**할 수 있다. 결과는 본인과 시스템만 안다.
- 마피아는 최대 1~2회 자신의 정체가 들켰는지 **확인**할 수 있다.
- 들켰다면(누군가 자신에게 투표) 괴물을 소환할 수 있다. 들키지 않았다면 패널티를 받는다.

### 4.2 들키기 전 / 들킨 후 능력 [확정]

| 구분 | 들키기 전 (숨은 단계) | 들킨 후 (괴물 소환 이후) |
|---|---|---|
| 직군 스킬 | 패시브·액티브 모두 사용 | 비활성화 |
| 인벤토리 | 사용 가능 | 비활성화 |
| 바다 몬스터 소환 | 가능. 작은 몬스터, 시야 안에 플레이어가 있을 때 더 많이 | 가능. 이전과 다른 종류의 몬스터, 파밍 방해 |
| 등대 괴물 소환 | 불가 | 등대를 부수는 괴물 소환 |
| 환영 섬 | 시민의 지도에 거짓 섬을 띄움 | **[제안]** 불가 (이미 정체가 드러남) |

### 4.3 바다 몬스터 소환 (들키기 전) [확정 + 제안]

- 항해 중 마피아의 시야에 플레이어가 있으면 몬스터를 더 많이 소환해 그 플레이어의 파밍을 막을 수 있다.
- 이것이 시민에게는 증거가 된다. "저 사람 근처만 가면 몬스터가 쏟아진다"는 의심이 쌓인다.
- 들키기 전에는 자연 스폰인지 헷갈리게 아슬아슬하게 조절하고, 들킨 뒤에는 공격적으로 쓴다.
- **[제안]** 소환 몬스터는 자연 스폰 몬스터와 외형이 같게 해서 한 번의 소환만으로는 티가 나지 않게 한다. 단서는 "빈도"와 "누구 옆에서"로만 남는다.
- **[제안]** 하루 소환 횟수 또는 쿨다운을 둔다. 무제한이면 숨기보다 파밍 봉쇄가 더 쉬워진다.

### 4.4 환영 섬 (들키기 전) [확정 + 제안]

- 마피아는 시민 플레이어의 지도에 거짓 정보를 적을 수 있다. 지도에는 있지만 실제로는 없는 섬, **환영 섬**이 생긴다.
- 항해사의 지도에는 환영 섬이 뜨지 않는다(3.3).
- **[제안]** 환영 섬에 도착하면 섬이 안개처럼 사라지고 주변에 바다 몬스터가 나타나거나, 연료·시간만 낭비한다.
- **[제안]** 환영 섬은 있는 섬을 숨기는 것보다 없는 섬을 더하는 방식으로 제한한다. 하루 1개 등 횟수 제한도 둔다.

### 4.5 심해 게이지와 봉인 [제안]

**괴물의 힘 = 심해 게이지 − 봉인.**
들키는 것이 마피아에게 보상이고 투표가 시민에게 손해인 구조를 이 두 장치로 바로잡는다.

| 장치 | 내용 |
|---|---|
| 심해 게이지 | 들키지 않은 방해가 성공할 때마다, 그리고 숨어 있는 날이 쌓일수록 찬다. 바다 몬스터가 시민의 파밍을 막거나 배를 난파시키면 추가로 찬다 |
| 봉인 | 마피아에게 투표한 상태가 유지되는 동안 그 시민의 봉인이 쌓인다. 같은 대상에 연속 투표한 시간만 인정 |
| 오투표 페널티 | 무고한 사람에게 투표해 두면 그 시간만큼 심해 게이지가 찬다 |
| 점화 의식 | 등대 수리 완료 후 60초. 시민 과반(2명 이상)이 마피아에게 투표한 상태여야 성공. 실패 시 심해 게이지가 크게 찬다 |

> **오투표 페널티가 필요한 근거** — 시민 3명이 무작위로 찍기만 해도 1명 이상이 마피아를 찍을 확률이 1 − (2/3)³ ≈ 70%다. 페널티가 없으면 마피아의 확인이 거의 항상 성공한다.

### 4.6 확인 실패와 소진 [제안]

- **확인 실패 = 시민에게 단서**: "바다가 누군가를 불렀으나 응답이 없었다" 전체 공지 + 무고한 시민 1명 공개. 용의자가 3명에서 2명으로 줄어든다.
- **2회 모두 실패 = 심해의 문이 닫힌다**: 괴물 소환이 영구 불가. 마피아는 숨은 채 의식을 실패시키는 길로만 이길 수 있다.
- 즉시 패배는 비추천. 남은 시간을 이미 진 상태로 플레이하게 된다.

### 4.7 숨어서 하는 방해 [제안]

모두 무고한 실수처럼 보일 수 있어야 한다.

- 바다 몬스터 소환(4.3), 환영 섬(4.4)
- 필요한 자원을 쥐고 내놓지 않기, 등대에 투입한 자원 몰래 빼기
- 난파된 동료를 늦게 구조하거나 떠다니는 잔해를 몰래 챙기기
- 밤에 보조 등대 연료를 적게 넣거나 늦게 넣기

### 4.8 허점과 보완 [제안]

| 허점 | 보완 |
|---|---|
| 확인 성공 후 소환을 미뤄 게이지를 키움 | 확인 성공 시 10초 안에 소환 여부 결정, 확인 기회는 소모 |
| 투표를 바꿨다 돌리며 확인 타이밍을 피함 | 봉인은 같은 대상 연속 투표 시간만 인정, 바꾸면 초기화 |
| 투표하는 모습이 정보가 됨 | 단축키 메뉴로 1초 안에, 화면 연출 없이 처리 |
| 마피아도 투표해야 하나? | 가능하게 둔다. 투표 행동만으로는 구분 불가 |
| "들킴"을 1표로 판정하면 너무 쉬움 | 1표로 시작, 테스트 후 2표로 조정 가능하게 설계 |
| 소환 후 시민이 일방적으로 짐 | 괴물 힘 = 게이지 − 봉인. 소환 순간 시민에게 짧은 결속 버프도 고려 |
| 난파 중인 플레이어의 투표 | 행동 불능 중에도 투표 가능. 구조 대기가 추리 시간이 된다 |

> **마피아의 최선 전략** — 끝까지 숨어서 게이지를 최대로 모았다가, 시민들이 확신하고 투표한 의식 직전에 확인하고 터뜨리는 것. 단, 숨어 있는 동안 바다 몬스터를 너무 많이 쓰면 스스로 증거를 남긴다.

## 5. 몬스터

몬스터는 바다에만 살며, 역할은 **자원 파밍 방해**와 **등대 파괴** 두 가지다.
**[확정]** 바다 몬스터는 최후에 소환되는 등대 괴물보다 작고 약하다.

### 5.1 몬스터 종류

| 종류 | 출현 방식 | 크기·강도 | 목표 |
|---|---|---|---|
| 자연 스폰 바다 몬스터 | 바다에 자연 스폰, 정해진 영역을 패트롤 | 작음 | 근처 배 공격, 파밍 방해 |
| 소환 바다 몬스터 (들키기 전) | 마피아가 시야 안 플레이어 근처에 소환 | 작음 (자연 스폰과 구분 어렵게) | 특정 플레이어의 파밍 방해 |
| 소환 바다 몬스터 (들킨 후) | 마피아가 소환 | 이전과 다른 종류, 더 공격적 | 최후 전투의 낮 파밍 방해 |
| 등대 괴물 | 마피아가 정체 들킨 후 소환 | 가장 큼, 힘 = 심해 게이지 − 봉인 | 밤마다 메인 등대 파괴 |

### 5.2 플레이어의 대응 [확정]

- **회피**: 배를 몰아 무빙으로 피한다.
- **전투**: 배에 장착된 대포로 공격해 죽일 수 있다.
- **[제안]** 몬스터에게 당하면 배 내구도가 깎이고, 0이 되면 난파(8장)된다.

### 5.3 몬스터 AI [제안]

| AI 상태 | 바다 몬스터 | 등대 괴물 |
|---|---|---|
| 대기·순찰 | 정해진 영역을 패트롤 (자연 스폰) | 낮에는 심해에 잠긴 채 대기 |
| 추적 | 감지 범위에 들어온 배를 쫓는다 | 밤이 되면 등대 섬으로 접근 |
| 공격 | 배에 돌진·물어뜯기 등 | 메인 등대를 우선 공격, 방해하는 플레이어는 부차 목표 |
| 이탈 | 추적 범위를 벗어나거나 보조 등대 빛 안에 들어가면 포기 | 해가 뜨면 바다로 물러남 |

- **[제안]** 바다 몬스터는 보조 등대의 빛을 싫어한다. 밤에 보조 등대 범위가 안전지대가 되고, 연료 관리에 의미가 생긴다.
- **[제안]** 등대 괴물은 매일 밤 강해지거나 수가 늘어, 시민이 낮 파밍을 미룰수록 불리해지게 한다.
- 모든 몬스터 AI는 호스트에서만 판정한다. 소환 몬스터인지 자연 스폰인지는 클라이언트에 보내지 않는다(10장).

## 6. 등대

등대는 두 종류다. 메인 등대는 승리 조건이고, 보조 등대는 밤을 버티게 해주는 유지 시설이다. **[확정]**

| 구분 | 메인 등대 | 보조 등대 |
|---|---|---|
| 역할 | 활성화해야 하는 등대 (승리 조건) | 밤에 시야를 밝혀줌 |
| 자원 | 수리 자원을 투입해 수리도를 올린다 | 계속해서 연료를 넣어야 한다 |
| 효과 | 수리도에 따라 플레이어 능력치 향상 등 시민에게 긍정적 영향 | 밤 시야 확보, **[제안]** 빛 범위 안에서는 바다 몬스터 접근 불가 |
| 위협 | 최후 전투에서 등대 괴물의 표적 | 마피아가 연료를 적게 넣거나 늦게 넣을 수 있음 |

### 6.1 메인 등대 수리도 보상 [제안]

수리도 구간마다 시민 전체에게 보상을 주어, 등대가 "끝에만 의미 있는 게이지"가 아니라 매일 투자할 이유가 되게 한다.

| 수리도 | 보상 (예시) |
|---|---|
| 25% | 배 이동 속도 상승 |
| 50% | 배 대포 피해 상승 |
| 75% | 등대 빛이 더 멀리 닿아 밤 시야 확대 |
| 100% | 점화 의식 가능 (4.5) |

- **[제안]** 마피아도 들키기 전에는 이 보상을 받는다. 들킨 뒤에는 받지 못한다.
- **[제안]** 최후 전투에서는 등대 괴물의 공격으로 내구도가 깎이며, 수리도가 높을수록 내구도도 높다.

### 6.2 보조 등대 [제안]

- 등대 섬 주변과 항로 위에 여러 개 배치한다. 밤에는 보조 등대의 빛이 닿는 곳만 보인다.
- 연료는 시간에 따라 줄어들고, 누가 얼마나 넣었는지는 기록되지 않는다. 연료가 빨리 떨어지면 의심의 대상이 된다.
- 최후 전투에서는 보조 등대가 밤 방어의 시야를 제공한다. 낮 파밍을 메인 등대 수리에 쓸지, 보조 등대 연료에 쓸지가 시민의 고민이 된다.

## 7. 맵

맵은 매 판 랜덤으로 생성되고, 밀물/썰물에 따라 갈 수 있는 범위가 넓어진다. 멀리 갈수록 자원은 좋아지고 위험도 커진다.

### 7.1 밀물/썰물 지역 해금 [확정 + 제안]

- 진행 과정에 따라 갈 수 있는 범위가 넓어진다.
- **[제안]** 해금 기준은 "일차"와 "메인 등대 수리도" 중 하나로 정한다. 수리도 기준이면 마피아의 방해가 맵 확장도 늦춘다.
- 가까운 섬은 희귀도 낮은 자원을 적게, 먼 섬은 희귀 자원과 많은 양의 일반 자원을 준다.

| 구역 | 해금 시점 (가안) | 자원 | 위험 |
|---|---|---|---|
| 내해 | 처음부터 | 일반 자원, 적은 양 | 자연 스폰 몬스터 적음 |
| 중간 해역 | 썰물 1회차 | 일반 자원 많음, 희귀 자원 일부 | 암초, 몬스터 증가 |
| 외해 | 썰물 2회차 | 희귀 자원 | 몬스터 다수, 귀항 거리 멀어 밤 집결에 늦기 쉬움 |

### 7.2 랜덤 생성 [확정]

- 매 판 섬, 난파선 등 미리 만들어둔 프리팹을 랜덤 위치에 스폰한다.
- **[제안]** 등대 섬은 항상 중앙 고정, 구역별로 섬 수와 종류의 최소·최대를 정해 판마다 편차가 너무 크지 않게 한다.
- 맵이 매번 달라서 환영 섬(4.4)이 힘을 갖는다. 지도를 외울 수 없으니 거짓 섬을 가려낼 방법이 항해사와 직접 확인뿐이다.

### 7.3 섬 종류

| 장소 | 역할 |
|---|---|
| 등대 섬 | 메인 등대가 있는 중심 거점. 밤 집결 장소 |
| 자원 섬 | 섬마다 나오는 자원 종류가 다르다 (목재, 석재, 금속, 연료 등) |
| 난파선 | 랜덤 스폰 포인트. **[제안]** 섞인 자원을 조금씩 얻을 수 있다 |
| 특수 기능 섬 (맵 확장 이후) | 자원 파밍이 아닌 특수 기능을 주는 섬 |

### 7.4 특수 기능 섬 [확정 + 제안]

| 섬 | 기능 | 추리에 주는 것 |
|---|---|---|
| 레이더 섬 **[확정]** | 모든 배의 위치를 파악. 누구의 배인지는 알 수 없다 | "그때 저 해역에 배가 한 척 있었다"는 정보로 누군가의 말을 검증 |
| 관측소 **[제안]** | 주변 해역의 몬스터 수가 평소보다 많은지 보여줌 | 소환 몬스터가 모인 곳 = 마피아가 다녀간 곳 |
| 항로 기록소 **[제안]** | 지도에 있는 섬 하나가 진짜인지 확인 | 항해사가 아닌 시민도 환영 섬을 검증 |

- **[제안]** 특수 섬 기능은 하루 횟수를 제한하고, 한 사람만 쓸 수 있게 한다. "누가 레이더를 봤는가"가 다시 신뢰의 문제가 된다.

## 8. 난파·구조와 추리 단서

시민이 마피아를 찾는 근거는 **"누가 언제 어디에 있었나"** 다. 흔적, 몬스터 출현 패턴, 난파와 구조가 모두 이 질문에 답하는 정보다.

### 8.1 난파와 행동 불능 [확정]

- 배는 바다에서 난파될 수 있다. 원인은 바다 몬스터, 암초 등이다.
- 플레이어는 죽지 않는다. 행동 불능 상태가 되어 동료의 도움을 받아야 한다.
- 파괴된 배를 수리하려면 자원이 필요하다. 구체적인 수리 방식은 재검토 중이다(11장).

| 항목 | 제안 내용 |
|---|---|
| 화물 손실 | 난파 시 개인 인벤토리 일부가 바다에 떠다니는 잔해가 된다. 누구나 건질 수 있다 |
| 행동 불능 상태 | 잔해 위에서 표류. 조명탄 발사(위치 표시), 보이스, 비밀 투표만 가능 |
| 구조 | 동료가 배를 몰고 와서 일정 시간 상호작용하면 구조 |
| 자동 구조 (안전장치) | 일정 시간(예: 90초) 아무도 오지 않으면 가까운 섬으로 떠밀려가 자력 복귀 |
| 밤과 난파 | **[제안]** 해가 지면 표류 중인 플레이어는 자동으로 등대 섬에 옮겨진다. 밤 집결을 놓치지 않게 한다 |

> **난파가 마피아 게임에 주는 것** — 누가 구조하러 갔는지, 누가 일부러 늦게 갔는지, 잔해를 누가 챙겼는지가 모두 의심의 근거다. 난파 직전에 누가 근처에 있었는지도 소환 몬스터와 연결된다.

### 8.2 흔적 [확정 + 제안]

- 모두가 가끔 바다나 섬에서 흔적을 발견한다. 상호작용하면 누군가의 이동 경로를 살짝 보여준다.
- 횟수 제한이 필요하다. **[제안]** 하루 1인 1~2회.
- **[제안]** 경로는 일부 구간만, 주인 없이 보여준다. "누군가 환영 섬 쪽에서 왔다" 정도의 단서를 레이더 섬(7.4)과 조합해 추리하게 한다.
- **[보류]** 항해사 전용: 지도에서 발자국을 확인해 누군가 다녀갔다는 사실을 알 수 있다.

### 8.3 의심 증거 정리

| 단서 | 어디서 오나 | 마피아의 대응 |
|---|---|---|
| 특정 사람 주변에 몬스터가 자주 나타남 | 바다 몬스터 소환(4.3) | 소환을 아끼거나 멀리서 쓰기 |
| 지도에 없는 섬을 본 사람과 못 본 사람 | 환영 섬(4.4), 항해사 | 항해사를 사칭하거나 항해사의 말을 의심하게 만들기 |
| 밤 집결에 늦음 | 하루 사이클(2.1) | 외해 파밍 핑계 |
| 이동 경로 | 흔적(8.2), 레이더 섬(7.4) | 다른 사람 경로와 겹치게 움직이기 |
| 보조 등대 연료가 빨리 줄어듦 | 보조 등대(6.2) | 연료 투입을 다른 사람과 함께 하기 |
| 난파 구조 지연, 잔해 챙기기 | 난파(8.1) | 먼저 구조하러 가서 신뢰 쌓기 |

## 9. 수치 가안 [가안]

모두 플레이테스트로 조정할 초기값이다.

| 항목 | 가안 | 비고 |
|---|---|---|
| 한 판 길이 | 30~40분 | |
| 하루 길이 / 기한 | 낮 5분 + 밤 2분, 총 5일 | 마피아의 버티기 승리 기준 |
| 귀항 알림 | 해 지기 60초 전 | |
| 마피아 확인 횟수 | 2회 | 팀 기획상 1~2회 |
| "들킴" 판정 기준 | 1표 이상 | 너무 쉬우면 2표 |
| 확인 성공 후 소환 결정 시간 | 10초 | |
| 점화 의식 | 60초, 시민 2명 이상 마피아 투표 | 최후 전투에서는 투표 조건 없음 |
| 들키기 전 바다 몬스터 소환 | 하루 3회 또는 쿨다운 90초 | |

## 10. 구현 메모

- Unity 3D + Netcode for GameObjects, 호스트-클라이언트 구조. 판정은 모두 호스트에서 처리한다 (**Host Authoritative**).
- 마피아 정체, 투표 내용, 심해 게이지, 봉인, 몬스터의 소환 여부는 호스트에서만 계산하고, 필요한 정보만 타깃 `ClientRpc`로 보낸다.
- 환영 섬은 플레이어별 지도 데이터로 다룬다. 항해사 클라이언트에는 환영 섬 데이터를 아예 보내지 않는다.
- 랜덤 맵은 호스트가 시드를 정해 생성하고, 클라이언트는 같은 시드로 맵을 재현한다.
- 몬스터 AI는 상태 머신(순찰 → 추적 → 공격 → 이탈)으로 호스트에서 실행한다.
