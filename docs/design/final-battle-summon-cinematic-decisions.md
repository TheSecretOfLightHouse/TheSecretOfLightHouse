# 최후 전투 소환 연출 결정

결정일: 2026-10-30
근거: 사용자(박태욱)가 촉수 등장 연출의 진행·보호 방식을 확인했다.
상태: 메인 씬 직접 연출로 변경·로컬 호스트 검증 완료, 본편/원격 통합 검증 대기.

구현 진행: 2026-10-30 [1~3단계](../박태욱/2026-10-30/소환연출-서버보호와-난파타이머.md) 서버 상태·피해 보호·난파 복구 타이머 연결 및 격리 서버 검사 완료. Timeline·카메라·입력과 원격 통합은 대기.

후속 구현: [4단계](../박태욱/2026-10-30/소환연출-4단계-Additive-전환.md) Additive 전환/입력·UI 복구/공통 전투 개시 상태를 구현하고 임시10초 자동 해제는 준비·재생·복귀 계약으로 교체했다. 표시 씬은 정적 placeholder이며 실제 Timeline 제작과 원격/본편 통합은 남아 있다.

## 확정 범위
- 소환 승인 후 실제 메인 씬의 등대섬·촉수를 Timeline으로 보여준다. 별도 씬을 로드하지 않는다(같은 날 최종 사용자 결정으로 Additive 방식을 대체).
- 실제 섬 하위에 촉수·연출 카메라·Timeline·물보라·음향 프리팹을 연결한다. 섬·바다·조명을 복제하지 않는다. 기존 플레이어 카메라는 이동시키지 않고 렌더링 전환 후 복귀하며, 등장한 촉수는 전투 위치에 남는다.
- 전체 게임 시간은 정지하지 않는다. 파도·부력·배의 관성 등 월드와 물리 이동은 계속 진행한다.
- 연출 동안 플레이어와 배를 피해에서 보호한다. 서버 판정에서 몬스터·포탄·충돌·환경 피해 등 적용 경로를 확인해 보호를 연결한다.
- 이미 난파했거나 구조를 기다리는 플레이어의 관련 대기/복구 타이머는 별도로 정지·재개한다. 네트워크 시계 자체는 정지하지 않는다.
- 연출이 끝나고 카메라를 복귀한 후 촉수의 실제 공격을 시작한다. 등대 촉수는 기존 서버 피해 시점에 조이기 표현을 맞추고 등대 HP를 감소시킨다. 수리 진행도는 감소시키지 않는다.
- 배가 해안·바위·부두에 걸리는 문제는 우선 실제 테스트에서 확인한다. 이번 결정으로 배 이동 정지·순간이동·자동 위치 복구를 추가하지 않는다.

## 세부 설계·검증에 남은 항목
- 연출 프리팹 또는 실제 섬 연결 준비에 실패한 사람은 개인 연출만 생략한다. 다른 참가자의 연출은 취소하지 않으며, 실패자도 서버가 정한 공통 전투 시작 시점까지 피해 보호·입력 잠금을 유지한다(같은 날 후속 사용자 확정). 실패한 연출 카메라를 정리하고 메인 화면을 유지·복구한다. 무한 준비 대기를 막는 제한시간 수치는 구현 시 설정으로 둔다.
- 연출 중 이동/조향/공격 입력과 UI 클릭을 차단한다. 기존 UI/작업은 일괄 닫기·취소하지 않는다. 서버가 연출 시작 전에 이미 승인한 작업은 기존 완료/취소 조건에 따라 계속 진행하고, 연출 시작 후 도착한 새 행동 요청은 서버에서 거절한다(같은 날 후속 사용자 확정).
- 난파·구조 대기 타이머와 복구 완료 보류는 기존 결정대로 유지한다. 이미 승인한 작업 진행을 이유로 이 예외를 해제하지 않는다.
- 기존 입력 초기화, 원래 카메라·UI 표시/입력 상태 복구의 구체적인 구현.
- 카메라 복귀 직후 보호 여유 시간, 연출 길이 및 지연 클라이언트 처리.
- 난파·구조 타이머 중 정확히 보존할 기한과 재개 방식. 이미 완료된 난파/복구를 되돌리는 것으로 확대하지 않는다.
- 서버 보호 범위와 다른 무적/보호 원인이 겹칠 때 해제 처리, 중단·접속 종료 시 정리.
- 주변 촉수의 후속 배 공격은 아래 2026-10-31 결정을 따른다. 피해량·재생 속도의 실제 설정값과 타격 구간은 구현/시각 검증에서 확인한다.

## 주변 촉수 배 공격 결정 — 2026-10-31
- 공격 범위는 확대된 촉수 메쉬 크기에 맞춘 BoxCollider 범위를 사용한다. 별도 고정 거리 수치를 공격 사거리로 확정하지 않는다.
- 피해량은 설정으로 조절 가능하게 한다. 구체적인 기본 피해량은 이번에 정하지 않았다.
- 공격 주기는 공격 애니메이션 타이밍에 맞추고 재생 속도를 조절할 수 있게 한다. 속도가 바뀌면 서버 타격 구간도 같은 애니메이션 시간 기준을 따른다. 별도 쿨다운 수치는 이번에 정하지 않았다.
- 빈 배는 공격하지 않는다. 타격 시에도 탑승 여부를 검사한다.
- 주변 촉수는 배 탐지·공격·피해에서 안전지대를 무시한다. 일반 몬스터의 안전지대 정책은 유지한다.
- 범위 안의 유효 배는 모두 피격 대상이다. 서버에서 판정하며 같은 배의 복수 콜라이더 때문에 한 타격이 중복 적용되지 않게 한다.
- 구현 후속(2026-10-31): 현재 배치 방향을 유지하고 메쉬241시점의 BoxCollider Bounds 및 인접 구간 합집합으로 휘두름을 판정한다. 피해10/재생속도1/타격25~70%는 조절 가능한 시험값이다. 로컬 호스트 격리 검증은 완료했으며 본편 시각·원격 통합은 대기한다. [7단계 기록](../박태욱/2026-10-31/소환연출-7단계-주변촉수-배공격.md).
