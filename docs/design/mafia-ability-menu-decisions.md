# 마피아 능력 메뉴 결정

결정일: 2026-10-30. 사용자 요청으로 기존 바다 몬스터 소환 메뉴를 확장한다. 미변경 규칙은 [게임 기획 v4](references/game-design-v4.md)와 [승패·투표 결정](win-vote-decisions.md)을 따른다.

## 메뉴 흐름

- F 입력으로 기존 원형 UI를 재사용한 3칸 메뉴를 연다: 몬스터 소환, 날씨 조정, 환영섬 생성.
- 몬스터 소환을 선택하면 기존 탑뷰 위치 선택 → 몬스터 7종 선택 → 서버 소환 요청으로 이어진다.
- 날씨 조정은 같은 원형 UI의 2칸 메뉴로 안개·폭풍우를 선택한다. 선택 즉시 현재 날씨를 바꾸지 않고 다음 날 날씨를 예약한다.
- 사용자 추가 결정: 안개 선택은 현재 월드의 `WeatherType.Overcast`에 연결한다. 별도의 안개 날씨 타입이나 표현을 추가하는 결정이 아니다. 폭풍우는 `WeatherType.Storm`이다.
- 환영섬의 실제 생성은 강민서 담당이다. 이번에는 메뉴 진입점과 연결 준비 중 안내만 구현한다. 대상 선택·생성 요청·성공 응답을 임의로 구현하지 않는다.
- 2026-10-30 후속 UI 결정: 능력 3칸·날씨 2칸도 기존 몬스터 UI처럼 그림과 매달린 제목판을 사용한다. 모든 페이지에서 각 칸에 마우스를 올리면 중앙 원에 해당 이름을 표시한다. 기존 중앙 몬스터 그림은 이름 표시로 대체한다. 소환·예약 기능은 그대로 유지한다.

## 연결과 남은 계약

- Mafia의 `SeaSummonPermissionController`가 송신자의 기존 마피아·승선 권한과 판 진행·월드 시계 상태를 서버에서 검증한다. 기존 승선 조건은 이번에 변경하지 않는다.
- World의 기존 `IGameClock`과 `IForecastService.Tamper(현재 일차 + 1, 선택 날씨)`를 소비한다. 예약 결과는 요청자에게만 TargetRpc로 전달한다. 월드 제공자와 공용 네트워크 코드는 변경하지 않는다.
- 다음 날이 없는 마지막 날, 시작 전·종료된 판, 심연 날씨 고정 상태에서는 예약을 거절한다.
- [W19](../07-design-issue-register.md)의 예측소가 보여줄 예보와 변경 시점의 단서 계약, [N06](../07-design-issue-register.md)의 개인 환영 수신 경계는 이 UI 변경만으로 해결되지 않는다.
- 구현·검증 근거는 [작업 기록](../최명기/2026-10-30/마피아-능력메뉴와-다음날-날씨예약.md)을 따른다. UI 격리 검사와 실제 원격 플레이 검증은 구분한다.
