# 배 수리 결정

결정일: 2026-10-20 / 결정자: 최명기

## 확정 규칙
- 개인 인벤토리에서 재료를 투입하고 할당량을 충족하면 배 내구도를 회복한다.
- 배에 탑승 중일 때 수리할 수 있다. v4 3.1의 하선 상태 배 수리 조건을 대체한다.
- 현재 내구도가 최대 내구도의 30% 미만이면 수리를 허용하지 않는다. 정확히 30%이면 허용한다.
- 수리 허용 여부는 서버가 판정하며, 거절된 투입 요청은 재료를 차감하지 않는다.

## 남은 계약과 구현 상태
- 재료 종류·할당량·회복량, 초과 회복분, 타인 배 수리, 부분 투입 후 난파·수리 불가 상태에서의 재료 처리는 미정이다.
- 이번 결정은 일반 수리 조건이며 난파 복구 규칙을 확정하지 않는다.
- 현재 BoatDurability.RestoreDurability는 서버 회복·최대치 제한·난파 거절만 수행한다. 탑승·30% 검사와 재료 투입 처리기 연결은 후속 구현이다. 실행 검증 없음.
