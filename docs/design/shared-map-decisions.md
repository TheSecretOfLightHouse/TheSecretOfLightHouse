# 공유지도 결정

결정일: 2026-10-30. 출처: 최명기의 공유지도 대화와 구현 요청. 해당 지도 범위에서 v4의 완성된 개인 지도 전제를 대체한다. 환영 섬 능력 전체를 재설계하거나 항해사 판별 능력 삭제를 확정하는 문서는 아니다.

## 사용자 확정

- 판마다 등대섬만 표시된 공유지도로 시작한다. 실제 섬 위치·종류는 자동 표시하지 않는다.
- 플레이어가 직접 그린 내용을 모두에게 실시간 공유하고 같은 판 동안 유지한다.
- 저녁에 네 명 모두 지도 앞에서 E를 눌러 준비하면 전원에게 동일한 공동 편집 화면을 연다. 동시 키 입력이 아니라 누적 준비다.
- 편집 제한시간이 끝나면 전원 편집 화면을 강제로 닫는다. 그때까지 그린 내용은 유지한다.
- M은 작성된 공유지도를 열람한다. 항해 중에는 그리거나 지우지 않는다.

## 첫 구현의 조정 가능한 값과 처리

- 편집 60초·상호작용 거리 3m는 첫 테스트 값이며 사용자 확정 밸런스 수치가 아니다. `Assets/02.Prefabs/UI/SharedMap/Resources/SharedMapSettings.asset`에서 조정한다.
- 저녁은 기존 `DayPhase.Dusk`로 연결했다. 저녁 종료가 제한시간보다 먼저 오면 종료한다. **Dusk 기본 길이도 60초이므로 준비가 늦으면 실제 편집 시간은 60초보다 짧다.** 60초를 항상 보장하려면 시간 운영에 대한 후속 결정이 필요하다.
- 준비 중 거리 이탈·난파·승선·연결 해제·저녁 종료 시 해당 준비를 해제한다. 같은 저녁 편집은 한 번이며 다음 저녁에 이어 그린다.
- 편집은 이동/행동 입력을 잠그고 커서를 표시한다. 만료 시 복구한다. M 열람은 M/Esc로 닫는다. 편집 중 M/Esc로 조기 종료하지 않는다.
- 누군가 이탈해 네 명이 아니게 되면 편집 종료. 세션 자체의 이탈/판 종료 규칙은 기존 Network 계약을 따른다. 데이터 재전송 경로가 있다는 이유로 본편 재접속을 지원한다고 보지 않는다.
- 4색 붓과 가늘게/보통/굵게 3단계 굵기, 획 단위 지우개를 제공한다. 2026-10-30 후속 요청으로 기존 UI의 갈색/크림색 테두리와 양피지 바탕을 적용하고 그림판처럼 자유롭게 칠하는 래스터 붓으로 바꿨다. 지우개는 공동 기록의 다른 작성자 획도 지울 수 있다. 별도 텍스트 입력·핀·실행 취소·수정 이력 UI는 이번 범위에 없다.
- 서버 메모리에 저장하며 앱 재실행 이후 디스크 보존은 하지 않는다. 새 레이아웃/판 해제 시 초기화한다.

## 기존 기획과 남은 계약

- R18: 개인 지도 간 자동 비교 대신 공동 기록의 증언·착각·거짓 기록이 가능해졌다. 추리/항해 비용의 밸런스는 플레이 검증이 필요하다.
- N02: 실제 월드 시드 공개 범위와 개조 클라이언트의 데이터 대조 문제는 해결하지 않는다. UI가 실제 섬을 자동 표시하지 않는 것과 데이터 비밀 보장은 구별한다.
- N06: 개인 환영의 대상·3D 연출·접근 판정·몬스터 결과는 여전히 별도 계약이다. 공유지도에 환영을 시스템이 자동 기록하지 않는다.
- 항해사 판별의 유지/삭제와 공유지도상 표현은 미결정이다. 이번 구현에서 자동 판별을 추가하거나 능력을 제거하지 않는다.
