# JH04 통합 기획 제안 — 수리도 승계·고정 HP·기존 비밀 투표

작성·갱신일: 2026-10-22

상태: **JH04 시험 경로에 구현됨(2026-10-22 사용자 구현 요청, 부속 제안 2건 포함) / 승패·투표 결정 등 기준 문서 미반영 / 1인 자동 시험만 통과, 다인(M2) 검증 전**

이 문서는 대화에서 비교한 ①안인 ‘수리도 승계 + 전투 시작 HP 고정 + 심해에 따른 공격력’을 정리한다. 문서 작성 요청은 기획 채택이나 구현 착수 승인이 아니다. 본문의 규칙은 이 제안 안에서의 동작이며 기존 기준 문서를 대체하지 않는다.

기존 [승패·투표 결정](win-vote-decisions.md)을 비교 기준으로 삼고, [수리도·심해 게이지 개편 검토안](jh04-repair-abyss-decisions.md)과는 별도 대안으로 둔다. 기존 검토안의 정시 N회 투표·정답 2표 성장 중단·봉인 후 감소·소환 수리 손실·고정 붕괴선을 이 안에 합쳐 적용하지 않는다.

## 1. 기획 목표

시민은 마피아를 추리하면서 등대를 완성하고, 마피아는 정체를 숨기며 시간을 벌다가 소환 여부와 시점을 선택한다.

- 소환 전까지 만든 모듈과 수리 진척을 보존한다. 최후 전투용 수리도를 별도로 0%에서 시작하지 않는다.
- 기존 비밀 투표·확인·10초 소환권을 유지하고, 투표가 필요한 승리 조건도 유지한다.
- 소환 시 등대 HP는 수리도와 관계없이 같은 값으로 시작한다. 조기 소환에 ‘남은 수리가 많음’과 ‘등대 HP가 낮음’이라는 이점이 동시에 붙는 것을 줄인다.
- 조기 소환·지연 소환·미소환에 서로 다른 기회와 위험을 둔다. 어느 선택의 우세나 승률도 검증된 것으로 보지 않는다.

## 2. 진영별 목표와 전체 흐름

| 진영 | 목표 |
|---|---|
| 시민 3명 | 파밍·제작·운반·장착으로 등대를 완성하고, 숨은 단계에서는 올바른 지목으로 점화 의식의 승리 조건을 갖춘다. 소환 후에는 등대가 파괴되기 전에 남은 수리를 끝낸다. |
| 마피아 1명 | 시민처럼 활동하며 완성을 지연한다. 기한 초과·의식 오답으로 이기거나, 소환권을 얻어 괴물 공격으로 등대를 파괴한다. |

```text
숨은 단계: 파밍·제작·운반·장착 + 비밀 지목 + 심해/봉인 누적
  ├─ 숨은 단계 기한 초과 → 마피아 승리
  ├─ 수리 100% → 상호작용으로 60초 점화 의식
  │    ├─ 소환 없이 완료: 정답 시민 2명 이상 → 시민 승리
  │    ├─ 소환 없이 완료: 정답 시민 2명 미만 → 마피아 승리
  │    └─ 소환: 승계 수리도가 이미 100% → 시민 승리(이번 부속 제안)
  └─ 수리 100% 미만에서 소환
       → 수리도·장착 모듈 유지 / 고정 HP로 최후 전투 시작
       ├─ 남은 수리를 끝내 100% → 시민 승리
       └─ 등대 HP 0 → 마피아 승리
```

동일 판정 시점의 완성·소환·피해·마감 우선순위는 위 흐름도만으로 확정하지 않는다. K01·K02에 연결되는 후속 계약이다.

## 3. 숨은 단계의 건설과 방해

기본 자원 → 공유 작업대에서 모듈 제작 → 개인 인벤토리로 가져가기 → 등대 장착 순서를 유지한다. 기본 자원을 등대에 직접 넣는 방식으로 바꾸지 않는다.

마피아도 시민처럼 활동하면서 기존 직군 능력과 허용된 방해 행동을 사용한다. 구체적인 능력·인출·부식 권한은 기존 기준을 따르며, 이 제안으로 새 능력을 추가하거나 장착 모듈 탈착을 허용하지 않는다.

숨은 단계의 기본 기한은 기존처럼 5일로 둔다. 정확한 마지막 밤 마감은 미정이다. 소환 전 수리 100%는 의식 시작 조건이며 그 자체로 시민 승리가 아니다.

관련 기준: [등대·작업대 모듈 결정](lighthouse-module-decisions.md), [공용 인벤토리 결정](shared-inventory-decisions.md), [게임 기획 v4](references/game-design-v4.md). 충돌 범위는 최신 사용자 결정과 승패·투표 결정을 우선한다.

## 4. 시민의 비밀 투표

| 항목 | 이 안의 규칙: 기존 유지 |
|---|---|
| 투표자 | 시민만 가능. 마피아 투표 불가 |
| 횟수 | 시민마다 판당 총 2회 |
| 소비 | 첫 지목과 다른 대상으로 변경할 때 1회 소비 |
| 재클릭 | 같은 대상을 다시 누르면 소비하지 않음 |
| 금지 | 자기 지목·철회·투표권 회복 |
| 시점 | 숨은 단계에서 각자 지목. 정시 N회 공동 투표로 바꾸지 않음 |
| 공개 | 본인은 자신의 지목만 확인. 다른 사람의 지목·득표수·정답 여부 비공개 |

지목 상태를 유지한 시간이 봉인·오투표 누적에 영향을 준다. 정답표가 모였다는 것만으로 정체가 공개되거나 강제 소환되지는 않는다.

### 시민이 투표해야 하는 이유

1. 소환 없이 의식을 완료해 이기려면 시민 2명 이상이 마피아를 지목해야 한다. 수리만으로 숨은 단계 승리를 보장받지 못한다.
2. 정답표를 오래 유지하면 봉인이 쌓여 소환될 괴물의 공격력을 낮출 수 있다.
3. 무고한 시민을 오래 지목하면 오투표가 누적돼 괴물이 강해질 수 있다. 두 번의 지목을 신중하게 써야 한다.

정확한 지목이 마피아의 확인 성공과 소환도 가능하게 한다는 긴장은 남는다. 시민은 최종 승리를 위해 맞혀야 하지만, 언제 표를 쓰고 유지할지는 판단해야 한다. 추리·무작위·막판 지목 중 어느 전략이 강한지는 시험 대상이다.

## 5. 심해·봉인·괴물 공격력

| 요소 | 누적과 효과 |
|---|---|
| 기본 심해 | 하루가 끝나 아침이 되면 1일분 증가 |
| 정답 지목 유지 | 시민별 유지 시간에 비례해 봉인 누적, 공격력 감소 방향 |
| 오답 지목 유지 | 시민별 유지 시간에 비례해 오투표 누적, 공격력 증가 방향 |

```text
소환 공격력
= max(최소 공격력, 기본 심해 + 오투표 누적 − 봉인 누적)
```

- 시민별 시간을 합산하고 아침에 정산한다. 난파 중·확인 성공 후에도 기존처럼 누적한다.
- 소환 당일의 미정산 봉인·오투표를 소환 시점까지 반영한다. 아직 아침이 오지 않은 날의 기본 심해 충전분은 주지 않는다.
- 소환 순간 공격력을 한 번 확정하고 이후 고정한다.
- 봉인·심해·오투표 원본 수치는 시스템 전용이다. 시민이나 마피아에게 새 게이지 화면을 주지 않는다.
- 대상 변경 시 과거 봉인의 보존·초기화 범위는 기존 K05의 미정 계약이다. 현재 코드의 처리를 채택된 기획으로 간주하지 않는다.

이 안의 봉인은 ‘정답 2표로 성장 중단’이 아니다. 맞게 지목한 시간이 공격력을 낮추는 방식이며, 봉인 이후 자동 게이지 감소나 영구 소환권을 추가하지 않는다.

## 6. 마피아의 확인과 소환권

마피아는 제한된 확인 기회를 사용해 요청 처리 순간 현재 자신을 지목한 시민 수가 성공 기준에 도달했는지 확인한다.

| 결과·상태 | 처리: 기존 유지 |
|---|---|
| 확인 성공 | 마피아에게만 성공을 알리고 10초 소환권 부여 |
| 확인 실패 | 아직 공개되지 않은 무고한 시민 1명을 무작위로 공개. 기존 실패 공지 규칙 유지 |
| 성공 후 표 변경 | 이미 받은 10초 권리는 유지 |
| 권리 만료 | 소환 불가. 확인 기회가 남아 있으면 다시 확인 가능 |
| 마지막 확인권으로 성공 | 확인 횟수가 0이어도 받은 10초 권리는 사용 가능 |
| 난파 중 | 확인·소환 불가 |
| 확인 기회 소진 | 시민에게 소진 사실을 알리지 않음. 미소환 승리 경로는 유지 |

확인 횟수와 성공 기준의 최종 수치는 설정·시험 대상이다. 점화 승리의 ‘정답 시민 2명 이상’과 확인 성공 기준을 같은 값으로 단정하지 않는다.

소환은 마피아의 선택이다. 권리를 흘려보낸 뒤 마음대로 소환할 수 있는 것이 아니라 다시 확인에 성공해야 한다. 소환이 없었다고 시민이 자신의 지목을 오답으로 확정할 수 없다.

## 7. 수리 100%와 점화 의식

- 수리 100% 이후 누구나 등대 상호작용으로 60초 의식을 시작한다.
- 의식 시작과 함께 투표를 잠그고 숨은 단계의 게임 기한을 정지한다.
- 의식 중 모듈 낙하는 발생하지 않는다. 게임 기한 정지를 월드 시간 전체 정지로 확대하지 않는다.
- 마피아는 난파 중이 아니라면 의식 중에도 확인·소환할 수 있다.
- 소환 없이 완료하면 정답 시민 2명 이상일 때 시민 승리, 미달이면 즉시 마피아 승리다. 실패 후 재시도하지 않는다.

### 이미 100%에서 소환하는 경우 — 부속 변경 제안

수리도를 그대로 승계하고 최후 전투 승리 조건도 100%라면, 의식 도중 소환할 때 이미 승리 조건을 충족한다. 이 안에서는 이를 숨기지 않고 **100% 상태의 유효한 소환은 시민 승리로 처리하는 방향**을 제안한다. 100% 이후 의식 시작 전 소환에도 같은 논리가 적용된다.

이는 기존의 ‘의식 중 소환으로 전투 역전 가능’과 다른 결과다. 마피아가 정답표를 확인했을 때 전투로 도망가는 수단은 사라지며, 전투 승리를 노리려면 완성 전에 소환해야 한다. 소환 화면 안내와 확인권만 낭비하는 상황도 함께 검토한다.

완성 직전 99% 수준의 소환도 전투가 매우 짧아질 수 있다. 별도 강제 방어 시간을 이 안에 자동 추가하지 않는다. 늦은 소환의 실효성은 필수 시험 항목이다.

## 8. 최후 전투 — 수리도 승계와 고정 HP

| 항목 | 이 안의 제안 |
|---|---|
| 시작 수리도 | 소환 직전 수리도를 그대로 유지 |
| 장착 모듈 | 유지. 소환 자체로 손상·소실시키지 않음 |
| 시작·최대 HP | 소환 시점 수리도와 무관하게 설정한 고정 최대 HP로 시작 |
| 공격력 | 소환 순간 정산값으로 고정 |
| 공격 | 기존 촉수 감기·조이기·주기 피해 흐름 활용 방향. 주기·피해 수치는 시험 |
| 시민의 작업 | 남은 모듈을 제작·운반·장착해 기존 수리도를 완성 |
| HP 회복 | 모듈 장착으로 HP가 회복되거나 최대 HP가 증가하지 않음 |
| 수리 보상 | 기존 보상 유지. 이미 받은 구간은 재지급하지 않음 |
| 시민 승리 | 수리도 100% |
| 마피아 승리 | 등대 HP 0 |
| 의식·기한 | 기존처럼 의식 타이머와 게임 기한 제거. 별도 최후 전투 기한은 추가하지 않음 |
| 투표 | 소환 후 잠금. 정체 공개 이후 승리에 정답표를 다시 요구하지 않음 |

예: 수리도 30%에서 소환하면 남은 70%, 80%에서 소환하면 남은 20%를 채운다. 두 경우 등대 시작 HP는 같고 괴물 공격력은 소환 정산값에 따라 달라진다. 예시는 비율 설명이며 완성 시간·승률을 보장하지 않는다.

괴물을 처치하는 것은 승리 조건이 아니다. 소환에 따른 마피아의 기존 능력·인벤토리 전환은 관련 기준을 따르며, 이 문서에서 새 공개 전투 능력을 만들지 않는다. 소환 후 장착 허용과 기존 모듈 장부·존재 상한 연결은 구현 검토가 필요하다.

### 고공격력 특수 종료 — 부속 변경 제안

기존 ‘봉인 반영 공격력이 최대 기준값 이상이면 특수 연출 후 마피아 승리’는 이 안에서 제외하는 방향을 제안한다. 모든 소환을 고정 HP와 남은 수리량의 경쟁으로 비교하기 위해서다. 별도의 기획 변경이며 기존 기획에서 이미 삭제된 것으로 보지 않는다.

## 9. 마피아가 들키지 않아야 하는 이유

핵심은 **정체를 숨기는 동안 시민의 오판과 작업 지연으로 이길 가능성을 유지하고, 괴물의 힘을 준비할 수 있기 때문**이다.

| 숨는 데 성공했을 때의 기회 | 정확하게 의심·지목받을 때의 위험 |
|---|---|
| 시민이 무고한 사람에게 한정된 투표권을 소비할 수 있음 | 정답표 유지로 봉인이 쌓여 소환 공격력이 낮아질 수 있음 |
| 오투표 누적과 하루 경과로 괴물을 강화할 수 있음 | 올바른 표가 유지된 채 의식이 끝나면 패배 |
| 협력자로 신뢰받아 방해를 감추기 쉬울 수 있음 | 시민이 행동과 작업 흐름을 경계할 수 있음 |
| 기한 초과·의식 오답 승리를 노릴 수 있음 | 완성 전에 전투를 선택해야 한다는 압박이 커짐 |

행동 감시·신뢰의 효과는 플레이 경험에 대한 가설이다. 보유 모듈은 기존처럼 본인만 아는 정보이므로, 시민에게 타인의 인벤토리를 새로 보여주는 것은 아니다.

‘시민이 정답 지목함’, ‘마피아가 확인 성공함’, ‘소환으로 정체가 공개됨’을 구분한다. 정답표가 모인 순간 모두에게 정체가 확정 공개되는 구조가 아니다.

마피아에게 숨기가 언제나 최선인 것은 아니다. 아무도 지목하지 않으면 확인 성공과 소환도 어렵다. **숨는 동안 이득을 얻고, 의심받기 시작했을 때 남은 기회를 어떻게 사용할지 선택하는 구조**를 목표로 한다. 일부러 의심을 사서 조기 소환하는 전략이 우세할 가능성도 시험해야 한다.

## 10. 소환 시점의 선택과 한계

| 선택 | 이점 | 비용·위험 |
|---|---|---|
| 일찍 소환 | 남은 수리가 많아 시민을 오래 압박할 수 있음. 봉인이 더 쌓이기 전에 공격력을 확정할 수 있음 | 기본 심해가 적어 괴물이 약할 수 있음. 정체와 단계가 공개돼 숨은 방해·의식 오답 승리 경로를 포기 |
| 늦게 소환 | 기본 심해·오투표를 더 쌓고 숨은 방해를 이어갈 기회 | 정답표의 봉인도 쌓일 수 있음. 남은 수리가 적어 시민이 빠르게 끝낼 수 있으며 확인권 재확보도 필요 |
| 끝까지 미소환 | 의식 오답·숨은 단계 기한 초과 승리를 노림 | 시민이 정답 2표를 유지한 채 의식을 완료하면 패배 |

기다리면 공격력이 반드시 오르는 것은 아니다. 기본 심해·오투표 증가보다 봉인의 효과가 크면 공격력이 내려갈 수 있다.

일찍 소환하면 무조건 유리하지 않도록 하려는 안이지만, 고정 HP만으로 균형을 보장하지 않는다. 남은 수리 시간이 너무 길면 조기 소환이, 공격력 증가가 너무 빠르면 지연 소환이 우세할 수 있다. 최후 전투에는 기한이 없으므로 판 길이도 측정해야 한다.

## 11. 기존 기획·기존 개편안과의 비교

| 항목 | 기존 승패·투표 기준 | 기존 수리도·심해 검토안 | 이번 제안 |
|---|---|---|---|
| 투표 | 시민 자유 지목, 판당 2회 | 2일차부터 정시 총 N회 | 기존 자유 지목·2회 유지 |
| 확인·소환권 | 제한 확인, 성공 후 10초 | 정시 집계, 소환권 유지 방식 일부 미정 | 기존 확인·10초 유지 |
| 봉인 | 정답표 유지 시간으로 공격력 감소 | 정답 2표로 성장 중단, 대기 중 감소 | 기존 시간 봉인 유지 |
| 오투표 | 유지 시간에 따른 누적 | 별도 벌점 없음 | 기존 오투표 누적 유지 |
| 게이지 공개 | 시스템 전용 | 마피아에게 합계·게이지 공개 | 기존 시스템 전용 유지 |
| 소환 손실 | 기존 수리도를 HP로 환산 | 게이지로 수리도 일회 차감 | 수리 손실 없음, HP 고정 |
| 최후 수리 | 별도 0%부터 | 손실 반영한 같은 수리도 복구 | 소환 전 수리도 그대로 승계 |
| 소환 후 피해 | HP 감소 | 수리도 감소·고정 붕괴선 | HP 감소 |
| 소환 전 완성 | 60초 의식·정답 2표 필요 | 즉시 시민 승리 | 기존 의식·정답 조건 유지 |
| 최후 전투 기한 | 제거 | 전체 마감 유지 | 기존 제거 유지 |
| 고공격력 특수 종료 | 있음 | 없음 | 제외 제안 |

관련 문제 대장: [R01~R16·N04·W01~W08 색인과 상태](../07-design-issue-register.md). 주요 변경은 R08·R10(수리 승계·HP), R09(특수 종료 제외·승패 경계), R12·R13(공격력 정산 유지)와 연결된다. K01·K02·K03·K04·K05·K07의 미정 경계를 이 제안이 자동 해소하지 않는다.
