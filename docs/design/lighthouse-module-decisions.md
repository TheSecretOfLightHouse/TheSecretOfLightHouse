# 등대·작업대 모듈 결정

결정일: 2026-10-17
근거: 사용자(김지훈) 결정. 담당: 김지훈(작업대·모듈·등대).
상태: 아래 "확정 규칙"은 결정 완료. JH03 작업대는 구현·M0·M2 통과(2026-10-17, 제작 버튼 반영 후 재검증). 2026-10-18 레시피별 동시 진행으로 바꾼 뒤 M0·M2 통과(M2 2회, 경합 승자 양쪽 확인). JH04·JH05는 미구현. 2026-10-20 "모듈 운반과 난파·구조" 결정 추가, 2026-10-21 인벤토리 가져가기·되돌려놓기·장착 코드 반영(PR #64, 컴파일만 확인). "시험값"은 플레이 테스트로 조정한다.

## 확정 규칙

| 항목 | 결정 |
|---|---|
| 등대 구조 | 등대는 1·2·3층으로 나뉘고, **층마다 다른 모듈**을 장착한다 |
| 등대 투입 | 등대에는 **모듈만** 넣는다. 기본 자원(돌·나무·섬유·철·유리·수정)을 등대에 직접 넣을 수 없다 |
| 자원 사용처 | 기본 자원은 **작업대에서만** 쓴다(자원 → 모듈) |
| 작업대 | 등대 섬의 공유 작업대 1개. **레시피마다 진행도를 따로** 두어 여러 레시피를 동시에 채울 수 있다(2026-10-18 변경, 이전: 한 번에 1개). 이번 범위는 등대(공유) 모듈 레시피만이며 배(개인) 레시피는 배 장착 계약 뒤에 추가한다 |
| 레시피 선택 | 어떤 레시피를 볼지는 **각자 화면에서만** 고르며 다른 선원에게 공유되지 않는다. 진행도(투입량)와 보관 개수는 모두에게 동기화된다. 투입·제작 요청은 레시피 ID를 함께 보낸다(2026-10-18 변경. 이전의 "첫 투입 후 변경 불가"와 첫 투입 확인창은 폐지) |
| 제작 완료 | 재료가 모두 차도 자동으로 완성되지 않는다. 누구나 **제작**(`InteractionAction.Craft`)을 눌러야 서버가 완성해 보관한다. 동시에 눌러도 한 번만 성공한다(2026-10-17 추가) |
| 부분 투입 | 가진 만큼만 넣고 부족분은 나중에 넣는다. 서버가 요청량을 남은 필요량 이하로 제한하고 실제로 빠진 수량만 누적한다([인벤토리 API](../unity/PLAYER_INVENTORY_API.md)) |
| 완성 모듈 보관 | 꺼내기 전까지 작업대에 종류별 개수로 보관한다. 보관 중에도 다음 레시피를 시작할 수 있다. 장착하려면 먼저 개인 인벤토리로 꺼낸다(2026-10-20, 아래 절) |
| 투입 가능 시점 | 판 진행 중이면 낮·밤 모두. 쓰러짐·배 탑승 중에는 거절한다. 의식·최후 전투 중 제한은 JH04에서 정한다 |
| 제작 상한 | 레시피별 "현재 존재 개수" 상한(데이터 값, 0 = 제한 없음). 상한에 닿으면 그 레시피를 고를 수 없다 |
| 존재 기준 | 서버의 모듈 기록이 분해 전이면 존재한다. 제작 중·작업대 보관·장착·표류·건져서 든 상태를 모두 센다. 부식 여부와 무관하다. **분해될 때만** 개수가 줄고 다시 만들 수 있다 |

## 모듈 운반과 난파·구조 (2026-10-20 결정)

근거: 사용자(김지훈) 결정. 난파·구조·재스폰 규칙은 최명기에게 전달받은 최신 기획 변경으로 사용자가 확인했다. 2026-10-21 코드 반영: 장부·꺼내기(`TakeModule`=16)·되돌려놓기(`ReturnModule`=17)·1인 1개·본인에게만 보유 알림(`WorkbenchNet.OwnCarriedRecipe`)·플레이어 인벤토리에서 등대 장착·배 장착 요청·배 난파 시 장부 정리·소환 시 마피아 인벤토리 모듈 소멸(JH04 시험 판). 배 레시피 4종은 ID 101~104(탐조등·대쉬·장애물 경보·선체 안정기), 시험값. 바다에 떨어진 모듈 아이템·구조/미구조 재스폰 처리는 미반영. 사용자가 JH04TestScene에서 설정 메뉴를 실행했고 에디터 컴파일 오류 0, 플레이 검증 전이다.

용어: 이 절의 "인벤토리"는 **플레이어 인벤토리**다. 모듈은 인벤토리에 1칸으로 들어온다. 코드 이름의 `Carry`·`Carried`도 같은 뜻이다.

흐름: 작업대 보관 → **플레이어 인벤토리로 가져감** → 등대(또는 배)에 장착. 작업대에서 등대로 바로 장착하지 않는다.

| 항목 | 결정 |
|---|---|
| 가져가기 | 시민·마피아 모두 작업대 보관 모듈을 자기 인벤토리로 가져갈 수 있다. 자원 인출 제한(마피아만, [공용 인벤토리 결정](shared-inventory-decisions.md))과 별개다 |
| 보유 한도 | 인벤토리에 모듈 **1개**(등대·배 모듈 합산). 한 사람이 여러 모듈을 가지고 한꺼번에 잃게 하는 방해를 줄인다 |
| 되돌려놓기 | 인벤토리의 모듈을 작업대 보관으로 되돌릴 수 있다 |
| 보유자 비공개 | 누가 어떤 모듈을 가지고 있는지는 **본인만** 안다. 다른 PC에는 정보 자체를 보내지 않는다. 작업대 보관 개수는 공개라 "누군가 하나 가져갔다"는 모두 안다(2026-10-21 사용자 결정으로 변경. 이전: 모두에게 공개해 추리 근거로 둠. 배 모듈은 개인 장비이고, 1인 1개 한도로 가지고 버티기 피해가 1개로 묶이므로 누가 가져갔는지를 추리 대상으로 남긴다) |
| 장착 조건 | 등대 장착은 배에서 내려 등대 섬에서 한다. 쓰러짐·배 탑승 중에는 거절한다(기존 처리와 같음) |
| 기록 위치 | 모듈은 `PlayerInventory` 자원 수량에 넣지 않는다. 모듈 상태는 서버 모듈 장부(`ModuleLedger`), 누가 가졌는지는 서버 `WorkbenchNet`이 기록하고 본인 PC에만 `OwnCarriedRecipe`로 보낸다. 인벤토리 화면은 이 값을 읽어 모듈 칸을 표시한다 |
| 배 모듈 | 같은 작업대·같은 장부를 쓴다. 인벤토리의 배 모듈을 자기 배에 탄 채 장착 요청하면 김지훈 모듈 처리기가 검사한 뒤 최명기 `BoatModuleEquipment.TryInstall`을 불러 장착하고 장부에 "배에 장착"으로 기록한다. **배에 장착한 모듈은 난파하면 전부 소실**되고 장부에서도 지워 다시 제작할 수 있다(2026-10-21 사용자 결정으로 정정. 이전 문구 "난파해도 배에 남는다"는 [배 모듈 기획](boat-module-decisions.md) 2절과 충돌해 폐기) |
| 난파 순간·쓰러짐 중 | 자원·모듈 모두 인벤토리에 그대로 둔다 |
| 구조됨 | 메인 섬에서 재스폰하고, 인벤토리의 자원 전체와 모듈을 종류(칸)별 후보로 놓고 **무작위 1칸을 통째로** 잃는다(예: 나무 10개가 뽑히면 나무 10개 모두. 2026-10-21 사용자 결정). 모듈이 뽑히면 장부에서 지운다(분해와 같은 처리, 레시피 다시 제작 가능) |
| 구조 못 받음 | 메인 섬에서 재스폰하는 **그 순간** 인벤토리 전부(자원+모듈)가 바다에 떨어진다. 떨어진 것은 바다에서 주울 수 없고(배 위 채집 기능 없음), 시간이 지나면 근처 섬 가장자리로 밀려가 그곳에서 줍는다. 모듈은 줍는 모듈 아이템으로 떨어지며 줍기 전까지 장부에는 표류 상태로 남는다 |
| 자동 구조 비용 | v4 9.1의 공동 자원 소모는 **폐기** |
| 떨어진 모듈의 분해 | 구조 못 받아 떨어진 모듈에는 표류 분해 타이머를 적용하지 않는다(부식 낙하 모듈 JH05에만 적용) |
| 마피아 소환 | 소환으로 마피아 인벤토리가 비활성화되는 순간 마피아 인벤토리에 있던 모듈은 사라진다(장부에서 지움, 레시피 다시 제작 가능) |

담당: 장부·가져가기·되돌려놓기·등대 장착·바다에 떨어진 모듈 아이템은 김지훈. 재스폰 이벤트(구조됨/미구조)·재스폰 시 떨어뜨리기·섬 가장자리 이동·인벤토리 화면 모듈 표시·배 장착은 최명기. 섬 가장자리 위치는 강민서 제공.

## 가안·시험값

| 항목 | 값 | 상태 |
|---|---|---|
| 등대 모듈 레시피 | 기반 프레임 = 돌 5 + 나무 5 + 철 2 · 기어 장치 = 철 3 + 섬유 3 · 렌즈 모듈 = 유리 3 + 철 2 + 수정 2 · 광원 코어 = 수정 3 + 유리 2 | 시험값. 재료 조합은 [자원·섬·맵 생성 결정](world-resource-island-decisions.md) 4장 후보 |
| 레시피별 존재 상한 | 각 1 | 시험값. 층 배치 확정 후 조정 |
| 분해 기준 | 표류 시작 시 서버 타이머 시작, 120초(데이터 값). 건지면 종료, 다시 표류하면 재시작. 잠긴 구역·폭풍벽 밖으로 밀리면 경계 안쪽으로 되돌린다 | 가안(JH05). v4 7.4 "일정 시간 안에 회수 못 하면 분해"의 구체값 |

| [v4 9.1](references/game-design-v4.md) | "화물 일부가 표류 잔해", "자동 구조는 공동 자원 소모" | 2026-10-20: 난파 순간에는 잃지 않는다. 구조되면 인벤토리 자원·모듈 중 무작위 1칸 통째 소실, 구조 못 받으면 재스폰 때 전부 떨어져 섬 가장자리로 밀려간다. 공동 자원 소모는 폐기 |
| [공용 인벤토리 결정](shared-inventory-decisions.md) | "등대 수리에 이미 반영된 자원도 마피아가 회수" | 등대에는 자원이 없으므로 등대 쪽 회수 대상은 모듈이 된다. 모듈 탈착 권한·진행도 되돌림은 미정. 작업대 투입 자원의 마피아 인출 결정은 그대로 |
