# 스피노크록 공격 패턴 결정

갱신일: 2026-10-24

## 재등장 위치 — 2026-10-24 사용자 결정

- 잠수한 자리에서 다시 올라오는 방식 대신, 타겟 보트 주변의 랜덤 위치에서 재등장한다.
- 위치 선정 기준은 **잠수 시작 시점의 타겟 보트 위치**다. 잠수 중 보트가 움직여도 기준 위치를 갱신하지 않는다.
- 보트 기준 최소·최대 수평 거리는 설정으로 노출하고 수치를 조절하며 시험한다. 최종 거리 수치는 확정하지 않았다.
- 현재 코드의 12~20m는 초기 시험값이다. 몬스터 루트와 보트 루트 사이의 X/Z 거리이며 모델 표면 사이의 간격이 아니다.
- 재등장 위치 기준과 돌진 조준은 별개다. 조준·방향 고정은 기존 구현을 유지한다.

## 구현과 검증 경계

- 서버가 잠수 시작 때 기준 위치와 재등장 지점을 한 번 선택한다. 완전히 잠긴 뒤 목적지의 잠수 깊이로 이동하고 수직으로 재등장한다.
- 기존 안전구역·섬 조회로 거절된 후보는 사용하지 않는다. 16회 시도해도 후보가 없으면 해당 준비를 시작하지 않는다. 이동 직전 거절된 위치는 준비를 취소한다.
- 위 후보 검사는 기존 World 조회 연결 범위에 의존한다. 실제 맵·섬·장애물 전체 배치 검증이나 W17 계약 완료를 뜻하지 않는다.
- 구현 결과·실제 검사와 미실행 시험은 [작업 기록](../박태욱/2026-10-24/스피노크록-재등장-위치.md)을 따른다.

## 돌진 후 감속·회복 — 2026-10-24 진행 승인

- 사용자가 랜덤 재등장을 확인했다고 알리고, 앞서 안내한 4단계 감속·회복 구현을 요청했다. 이 확인을 원격 다인 검증 완료로 확대하지 않는다.
- 돌진 완료 또는 정면 장애물 종료 후 감속·회복을 거쳐 배회로 돌아간다. 장애물 종료는 초기 이동 속도 0으로 회복한다. 보호 구역 취소·사망은 회복을 새로 시작하지 않고 정리한다.
- 회복 총시간에는 감속 시간이 포함된다. 현재 총 2초·감속 0.6초는 조절 가능한 시험값이며, 감속 이후 남은 시간은 정지한 채 반격에 노출된다.
- 회복 중 공격 피해는 끄고 기존 대포 피격은 유지한다. 몸통 콜라이더를 유지하면서 배·플레이어와의 개별 물리 접촉만 제외한다. 지형·다른 몬스터·대포탄의 충돌은 유지한다.
- 회복 종료 때 여전히 겹친 충돌 쌍은 분리된 후 복구한다. 배·플레이어를 강제로 옮기지 않고, 기존에 다른 기능이 무시해 둔 충돌 쌍도 유지한다. 루트 비활성화·네트워크 종료에는 이 기능이 변경한 쌍을 정리한다.
- 회복 전용 애니메이션은 미제작이다. 임시로 배회 클립의 첫 자세를 멈춰 표시한다. [4단계 작업 기록](../박태욱/2026-10-24/스피노크록-4단계-감속과-회복.md)의 실제 검증·한계를 따른다.
