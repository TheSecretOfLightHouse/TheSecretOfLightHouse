# 공용 인벤토리 투입·인출 결정

결정일: 2026-10-17
근거: 사용자(최명기)의 공용 인벤토리 인출 권한 명시.

## 확정 규칙
- 공용 인벤토리에 자원을 투입할 수 있다.
- 공용 인벤토리에서 자원을 인출할 수 있는 역할은 마피아뿐이다.
- 적용 대상은 작업대와 등대다. 등대 수리에 이미 반영된 자원도 마피아가 회수할 수 있으며, 회수한 자원에 해당하는 수리 진행도를 되돌린다(2026-10-17 추가 사용자 결정).
- 다른 플레이어는 자신이 넣은 자원이라도 투입 완료 후 꺼낼 수 없다.
- 서버가 요청자의 역할을 확인해 인출을 승인/거절한다. UI 버튼 숨김만으로 권한을 판정하지 않는다.

## 실패 복구와의 구분
- 투입 자체가 실패했을 때 차감 전 상태로 되돌리는 처리는 게임 내 인출과 구분한다. 실패한 투입의 개인 자원 유실을 방지하는 기술적 복구이며, 시민에게 인출권을 주는 의미가 아니다.
- 개인 인벤토리의 TryAdd는 일반 추가 수단이다. 마피아 여부는 공용 인출 처리기가 검증하며 개인 API 자체에 모든 추가를 마피아로 제한하지 않는다.

## 남은 계약과 검증
- 마피아 인출 한도·속도·시점, 제작 확정과 인출의 경합, 취소·레시피 변경 시 처리, 인출 이력 공개 범위는 이번 결정으로 확정하지 않는다.
- 회수 자원 종류·수량과 진행도 감소의 환산, 소환 전/최후 전투 진행도별 회수 대상, 의식 도중·승패 확정과 회수의 경합은 추가 계약이 필요하다. 이미 사용한 같은 자원이 반복 회수되지 않도록 서버가 회수 가능한 잔량/기여를 관리해야 한다.
- 자원 인출은 해당 수리 진행도를 되돌리지만 등대 HP는 감소시키지 않는다(2026-10-17 추가 사용자 결정). 완성 모듈 탈착 권한과 인출에 따른 보상 회수는 이번 결정으로 확정하지 않는다. 기존 최후 전투 HP·보상 규칙을 임의 변경하지 않는다.
- W08은 인출 역할과 작업대·등대/수리 반영 자원까지의 범위가 부분 결정됐고 N09 거래 보존·중복 방지는 여전히 연결이 필요하다. 구현·팀 합의·실행 검증 완료를 뜻하지 않는다.
- 시험 추가: 유효한 수리 자원 회수 시 개인 자원 증가와 해당 수리 진행도 감소를 함께 확정하고, 시민 요청·중복 회수·개인 추가 실패 시 양쪽 상태가 보존되는지 확인한다. 수리100%로 이미 승패가 확정된 뒤 이를 소급 취소한다고 가정하지 않는다.
- 시험: 시민 본인 투입분 인출 거절/무변경, 마피아 유효 인출 승인, 위조·중복·동시 요청 수지 보존. 비밀 역할을 전체 클라이언트로 보내 검증하지 않는다.
