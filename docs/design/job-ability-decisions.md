# 직군 능력 후속 결정

결정자: 최명기 / 결정일: 2026-10-24

사용자가 제공한 v4 3.3 표에 아래 변경을 지시했다. 변경 범위에서 v4보다 우선하며, 구현·실행 검증 완료를 뜻하지 않는다.

| 직군 | 패시브 | 액티브 |
| --- | --- | --- |
| 항해사 | 지도에 환영 섬이 뜨지 않음, 배 속도 상승 | 구조 항로 안내: 난파 동료까지 최단 경로 표시, 하루 1회. 원래 표 유지 |
| 정비공 | 같은 수리 재료로 배 내구도를 더 많이 회복 | 모듈 부식 여부 확인 |
| 경비병 | 대포 재장전 속도 증가 | 지정 배에 쉴드 부여. 모든 피해를 1회 전부 방어하고 쉴드 소멸 |
| 채집가 | 자원 8칸 유지, 한 스택 최대 20개 | 제한시간 동안 채집하는 자원 획득량 2배(피버타임) |

- 기술자 표기는 정비공으로 변경한다. 채집가의 기존 희귀 자원 확률·채집 속도 패시브와 자원 위치 감지 액티브를 위 내용으로 대체한다.
- 경비병 쉴드를 과거 ‘10초간 몬스터 피해 50% 감소’ 구상으로 구현하지 않는다.
- 최종 사용자 정리에서 재장전 패시브는 경비병으로, 부식 확인은 정비공으로 확정했다. 앞선 정비공 재장전·수리/강화 액티브 설명을 대체한다.
- 정비공 패시브는 같은 재료에 대한 내구도 회복량 증가로 사용자 확인됐다. 예시는 일반20→정비공30이며 실제 레시피·기본 회복량·최종 증가 배율까지 확정한 것은 아니다. 수리 속도·최대 내구도 증가가 아니다.
- 2026-10-25 최명기 결정: 채집가의 자원 스택 한도는 칸당 20개다. 기본 직군은 칸당 10개, 자원 칸 수는 기존 8칸을 유지한다. 능력 해제 후 초과 보유분 처리는 별도 결정이 필요하다. 피버타임 지속시간은 아래 2026-10-25 결정의 10초다. 피버 보상은 아래 2026-10-25 결정에 따라 공유 잔량1 감소·자원2개 드롭이다. 액티브 사용 제한은 아래 하루 1회 공통 결정을 따른다.
- 쉴드 대상 선택·자기 배 허용·하루1회 제한은 아래 2026-10-25 후속 결정을 따른다. 거리·지속시간·중첩·직군 배정 중복 허용 및 소환 후 잔여 효과 정책은 미정이다.
- 부식 확인은 v4의 하루 1회·사용자 본인에게만 결과 공개 규칙을 유지한다. 대상 모듈 상태·거리·실패 소비 정책은 별도 확인한다.
- 항해사 배 속도 증가량, 경비병 재장전 배율의 최종 밸런스 값은 별도다. 코드의 기본 재장전 시간 배율 0.5를 최종 기획 수치로 승격하지 않는다.

조사 결과와 단계별 작업은 [최명기 구현 안내](../최명기/2026-10-24/직군4종-구현순서.md)를 참고한다.


## 경비병 쉴드 대상 선택 — 2026-10-25
- 최명기 결정: Q키로 보호할 플레이어 선택 UI를 열고, 선택한 플레이어의 배에 쉴드를 부여한다. 자기 배도 선택 가능하다.
- 대상 선택을 조준/레이캐스트 방식으로 구현하지 않는다. 거리·지속시간·재부여 소비·소환 후 잔여 효과 정책은 아직 미정이다.

- 최명기 추가 결정: 경비병 쉴드 사용 제한은 게임 내 하루 1회다. 성공/실패/취소 시 사용권 소비의 세부 정책은 별도 확인한다.


## 액티브 공통 사용 제한 — 2026-10-25
- 최명기 결정: 모든 직군 액티브는 게임 내 하루 1회다. 항해사·정비공·경비병·채집가 모두 같은 제한을 사용한다.
- 공통 규칙 코드를 재사용하되 사용 기록은 플레이어와 능력별로 분리한다. 전원의 사용권을 공유하는 static 장부로 구현하지 않는다.
- 성공/실패/취소 시 소비, 미사용분 이월과 이미 부여된 효과의 일차 변경 후 수명은 별도 결정이며 이번 제한 결정으로 확정하지 않는다.


## 경비병 사용권 소비 — 2026-10-25
- 최명기 승인: 실제 쉴드 부여에 성공한 경우에만 해당 일차 사용권을 소비한다. 대상 선택 취소·대상 없음·난파·이미 쉴드가 있는 배에 대한 거절은 사용권을 소비하지 않는다.
- 이 소비 정책을 다른 직군의 실패/취소 정책으로 자동 확대하지 않는다.

## 경비병 요청 구현 범위 — 2026-10-25
- 최명기 지시: 공용/타 담당 코드를 수정하지 않고 Player 내부에서 쉴드 요청을 처리한다. 이 작업의 쉴드 요청은 Player 전용 Mirror Command/TargetRpc로 구현한다. 기존 다른 상호작용 요청의 공용 경로를 바꾸지 않는다.

## 채집가 피버타임 지속시간 — 2026-10-25
- 최명기 결정: 채집가 액티브 피버타임은 우선 10초로 진행한다. 채집 자원 획득량 2배·하루1회 규칙은 유지한다.
- 공유 잔량 차감·공유 드롭 보상의 수거자 범위·난파/소환 등 중단 조건은 이번 지속시간 결정으로 확정하지 않는다.


## 채집가 피버타임 보상 — 2026-10-25
- 최명기 결정: 피버타임 중 채집1회는 자원지점 공유잔량1을 소비하고 자원2개를 드롭한다. 공유잔량2를 소비하는 빠른채집 방식이 아니다.
- 현재 공유 드롭 경로를 유지하므로 떨어진 보너스 자원도 다른 사람이 주울 수 있다는 안내 후 사용자가 1번 방식을 선택했다. 수거 시 추가2배를 적용하지 않는다.


## 항해사 구조 항로 — 2026-10-26
- 사용자 승인: Q키로 난파 동료 선택 UI를 열고 선택한 동료까지 섬·암초를 우회하는 항로를 바다 위 선으로 표시한다. 항로는 항해사 본인에게만 표시한다.
- 게임 내 하루1회이며 항로 생성 성공시에만 사용권을 소비한다. 선택 취소·유효한 대상 없음·항로 탐색 실패는 소비하지 않는다.
- 대상이 구조되거나 복귀하면 안내를 종료한다. 이번 구현의 항로는 사용시점에 계산한 경로이며 실시간 재탐색은 포함하지 않는다. 격자해상도/탐색범위는 계산 설정이고 연속공간의 엄밀한 최단거리를 보장하는 규칙이 아니다.
- 이 절은 사용자 승인 동작을 기록하며 실제 Q·서버 요청·수면표시·원격 통합검증 완료를 뜻하지 않는다. 연결/검증 범위는 최명기 직군4종 구현순서 기록을 따른다.

## 항해사 속도 배율 — 2026-10-26
- 사용자 결정: 항해사 배 속도 패시브를 2배로 적용한다. Captain 1의 NavigatorPassive._speedMultiplier=2로 에디터 API 저장. 실제 물리 이동속도가 정확히 기본의 2배임을 검증한 것은 아니다.
