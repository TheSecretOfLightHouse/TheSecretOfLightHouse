# 일반 몬스터 안전지대 결정

갱신일: 2026-10-29

- 사용자가 결정: 일반 몬스터는 안전지대 안에 있는 배를 탐지·추적하지 않으며, 공격 중 대상 배가 안전지대에 들어가면 해당 공격을 취소한다.
- 안전지대 안의 배에는 이미 발사된 일반 몬스터 투사체나 범위 공격의 피해도 적용하지 않는다. 기존 공격으로 입힌 피해를 소급 취소하지 않는다.
- 2026-10-31 후속: 최후 전투 주변 촉수는 배 탐지·공격·피해에서 안전지대를 무시한다. [주변 촉수 결정](final-battle-summon-cinematic-decisions.md#주변-촉수-배-공격-결정--2026-10-31)을 따른다. 다른 보스·소환·위협 전체로 확대하지 않는다. [W17 문제 대장](../07-design-issue-register.md)과 기존 보스별 규칙을 참고한다.
