# 승패·투표 누락 사항 결정 정리

- 결정 정리일: 2026-10-10
- 저장소 반영일: 2026-10-11
- 기준: 사용자 작성 「누락 내용 검토.txt」와 이후 사용자가 제공한 추가 결정
- 관련 항목: 설계 문제 대장 R01~R13, R16, N04, N11~N12

사용자의 기존 결정과 추가 결정을 주제별로 통합했다. 중복 내용은 한 번만 기록하고, 새 결정으로 해소된 보류 문구는 해당 결정으로 교체했다. 이 문서는 기획 결정 정리이며 구현·실행 검증 완료를 뜻하지 않는다.

## 적용 기준

사용자가 제공한 「승패·투표 누락 사항 결정 정리.md」를 이번 문서 갱신 요청에 따라 공유 기준으로 반영했다. 아래 결정이 [제공된 v4 원문](references/game-design-v4.md)과 충돌하면 이 문서가 우선한다. 이 문서에서 바꾸지 않은 규칙은 최신 사용자 결정과 v4를 따른다. v4·이전 기획·검토 원문의 본문은 변경 이력으로 보존한다.

v4의 시민 지목 제한 2회와 첫 지목의 1회 소비는 유지한다. 아래 1절은 마피아의 투표 금지와 자기 지목·철회·재클릭·대상 변경 계약을 보완한다. 확인 기회와 시민 투표권은 서로 다른 자원이다. 담당자는 [코드 소유권](../CODE_OWNERSHIP.md)을 유지하며, 규칙 확정은 API 합의나 코드 구현 완료를 뜻하지 않는다.

## 1. 투표권과 지목 — R03·R04·R05

| 항목 | 결정 사항 |
|---|---|
| 마피아의 투표권 | 마피아는 투표할 수 없다. 규칙의 빈틈을 이용하는 플레이를 막기 위한 결정이다. |
| 지목 가능한 대상 | 자기 자신은 투표 대상에서 제외한다. |
| 투표권 회복 | 소진한 투표권은 회복되지 않는다. 투표 남발을 막으며, 투표권 소진은 플레이어의 선택과 책임으로 본다. |
| 투표 철회 | 허용하지 않는다. |
| 같은 대상 재클릭 | 투표 횟수를 차감하지 않는다. |
| 대상 변경 | 현재 지목 대상과 다른 대상을 선택할 때 투표 횟수를 차감한다. |

## 2. 정체 확인과 소환 권리 — R01·R02·R16

- 시민의 투표와 마피아의 확인이 겹치면, 서버가 확인 요청을 처리하는 순간의 현재 표로 성공 여부를 판단한다.
- 확인에 성공하면 이후 표 변경과 관계없이 소환 권리를 10초간 유지한다.
- 10초가 만료된 뒤에도 확인 횟수가 남아 있으면 다시 확인할 수 있다.
- 마지막 확인권으로 성공했다면 남은 확인 횟수가 0이어도 이미 받은 10초 소환 권리는 사용할 수 있다.
- 난파 중에는 정체 확인과 소환을 할 수 없다.
- 확인 가능 횟수와 성공 판정 기준은 설정값으로 관리한다. 최종 수치는 플레이테스트 후 조절한다.
- 확인 성공 결과는 마피아에게만 공개한다.
- 확인 실패 시 무고한 시민 중 한 명을 무작위로 공개하며, 이전에 공개한 시민과 중복되지 않도록 한다.
- 확인 기회를 모두 소진했다는 사실은 시민에게 알리지 않는다. 마피아만 해당 상태를 안다.

## 3. 점화 의식의 시작과 진행 — R06·R07·R09

| 항목 | 결정 사항 |
|---|---|
| 시작 조건 | 등대 수리도 100% 이후 등대 상호작용으로 시작한다. |
| 시작 주체 | 누구나 상호작용할 수 있다. |
| 의식 시간 | 60초. |
| 게임 기한 | 점화 의식이 시작되면 게임 기한이 멈춘다. |
| 투표 변경 | 의식이 시작되면 모든 투표를 잠가 변경할 수 없게 한다. |
| 마피아 능력 | 의식 중에도 정체 확인과 소환은 가능하다. 단, 난파 중에는 둘 다 불가하다. |
| 모듈 낙하 | 의식 도중에는 발생하지 않는다. |
| 의식 중단 | 괴물 소환이 발생했을 때만 중단한다. 최후 전투로 넘어간다. |

의식은 괴물 소환으로 중단되어 최후 전투로 전환되거나, 60초를 완료해 승패를 판정하고 게임을 종료한다. 중단 후 숨은 단계의 의식을 다시 시작하는 흐름은 두지 않는다.

## 4. 소환 없이 완료한 점화 의식의 결과 — R07

괴물 소환으로 최후 전투에 전환되지 않고 의식 60초를 완료하면, 종료 순간의 투표 상태로 결과를 판정한다.

| 종료 시점의 상태 | 결과 |
|---|---|
| 시민 2명 이상이 마피아를 지목 | 시민 승리, 게임 종료. |
| 위 조건을 충족하지 못함 | 기한이 남아 있어도 즉시 마피아 승리, 게임 종료. |

기존 기획의 ‘의식 실패 시 심해 게이지가 크게 증가한다’는 규칙은 삭제한다. 의식 실패 후 잠금을 해제하고 경기를 계속하는 기존 보류 문구도 실패 즉시 종료 결정으로 정리한다.

## 5. 최후 전투 전환과 등대 — R08·R09·R10·R11

| 항목 | 결정 사항 |
|---|---|
| 전환 시점 | 괴물을 소환하면 최후 전투가 시작된다. |
| 기존 점화 의식 타이머 | 최후 전투가 시작되면 제거한다. |
| 전환 이후 승패 | 아래 R09의 최후 전투 종료 조건으로만 판정한다. 기존 점화 의식 타이머의 완료로 판정하지 않는다. |
| 등대 최대 HP | 고정된 설정값으로 관리한다. |
| 소환 전 수리도 | 아래 R10 환산 공식으로 소환 시 현재 HP를 결정한다. |
| 최후 전투용 수리 진행도 | 소환 전 수리도와 구분하며, 최후 전투 시작 시 0%부터 시작한다. |
| 등대 괴물 처치 | 등대 괴물은 처치할 수 없다. 처치는 승패 조건에 포함되지 않는다. |

### R09 — 숨은 단계의 기한과 최후 전투의 승패 확정

숨은 단계의 기본 게임 기한은 5일로 설정한다. 숨은 단계에서 기한에 도달하면 마피아 승리로 게임을 종료한다. 기한 일수는 설정값으로 관리하고, 밸런스 테스트를 통해 조절한다.

점화 의식이 시작되면 기한을 정지한다. 최후 전투가 시작되면 아래 규칙에 따라 기한을 제거한다.

최후 전투가 시작되면 게임 기한을 제거한다. 의식 중 소환했는지, 의식 시작 전에 소환했는지와 관계없이 적용한다. 최후 전투에는 기한 종료에 따른 패배가 없으며, 기존 점화 의식 타이머도 승패 판정에 사용하지 않는다.

최후 전투용 수리 진행도는 소환 전 수리도와 구분하는 새로운 진행도이며, 최후 전투 시작 시 0%부터 시작한다. 다음 두 조건 중 먼저 도달한 조건으로 즉시 승패를 확정한다.

| 먼저 도달한 조건 | 승패 결과 |
|---|---|
| 새로운 최후 전투용 수리 진행도가 100%에 도달 | 즉시 시민 승리, 게임 종료. |
| 등대 HP가 0에 도달 | 즉시 마피아 승리, 게임 종료. |

수리 진행도 100% 도달 자체로 시민 승리를 판정하며, 별도의 점화 완료를 기다리지 않는다. 승패는 먼저 도달한 조건으로 한 번만 확정하며, 이후 다른 조건이 발생해도 결과를 변경하지 않는다.

### R10 — 소환 시 등대 HP 환산과 기존 수리 보상

등대의 최대 HP는 고정된 설정값으로 관리한다. 소환 시 현재 HP는 소환 전 수리도를 반영해 다음 공식으로 결정한다. 공식의 최대 HP는 완성 상태 HP를 의미한다.

```text
소환 시 현재 HP
= 기본 HP + (최대 HP − 기본 HP) × 소환 전 수리도 비율
```

- 소환 전 수리도 비율은 0~1로 계산한다. 예를 들어 수리도 50%는 0.5다.
- 수리도 0%에서 소환하면 기본 HP로 시작하고, 100%에서 소환하면 최대 HP로 시작한다.
- 최후 전투용 수리 진행도는 이 HP 환산과 별개로 0%부터 시작한다.

최후 전투에서 자원 투입은 새로운 수리 진행도만 올린다. 수리 진행도가 증가해도 등대의 현재 HP는 회복되지 않으며, 최대 HP도 증가하지 않는다.

기존 수리 보상은 다음과 같이 처리한다.

- 최후 전투가 시작되어 새로운 수리 진행도가 0%로 초기화돼도, 소환 전에 이미 획득한 수리 보상은 그대로 유지한다.
- 최후 전투용 수리 진행도가 올라가도 보상을 새로 받거나 중복 지급받지 않는다.
- 최후 전투에서는 소환 전에 획득한 보상까지만 적용된 상태를 유지한다.

## 6. 봉인·오투표와 괴물 공격력 — R12·R13

‘괴물의 힘’은 등대 괴물의 공격력을 결정하는 값이다.

- 봉인과 오투표는 시민별 투표 유지 시간을 기록하고 시민 전체에 걸쳐 합산해 계산한다. 마피아는 계산 대상에서 제외한다.
- 밤이 지나 아침이 되면 기본 심해 게이지를 1일분 충전한다.
- 봉인·오투표는 시민별 정답·오답 투표 유지 시간에 비례해 계산하고, 아침에 합산해 정산한다.
- 난파 중이거나 접속이 끊긴 상태에서도 시간 기록과 누적 계산을 계속한다.
- 정체 확인에 성공한 뒤에도 누적한다.
- 소환 시 그날 소환 시점까지의 미정산 봉인·오투표를 반영해 공격력을 계산한다. 기본 심해 게이지는 완료된 하루만 인정하며, 아직 아침이 오지 않은 날의 기본 충전분은 지급하지 않는다.
- 계산된 공격력은 설정한 최소값을 보장하며, 소환 이후에는 고정한다. 봉인이 심해 게이지보다 커져도 최소 공격력 아래로 내려가지 않는다.
### R12 — 규칙 확정과 수치 조정

괴물의 공격력 계산 방식, 최소값 보장 및 소환 후 고정 규칙은 확정한다. 최소 공격력, 하루 기본 심해 게이지 충전량, 투표 유지 시간당 봉인·오투표 증가량은 설정값으로 관리하며, 최종 수치는 플레이테스트 후 결정한다.

## 8. 접속 단절과 재접속 — N11·N12

2026-10-13 사용자(김지훈) 결정으로 2026-10-11의 "끊긴 캐릭터를 허수아비처럼 남긴다"를 아래로 바꿨다.

- 판 진행 중 참가자가 한 명이라도 끊기면 판을 종료한다. 호스트가 나간 경우도 같다. 승패는 기록하지 않는다. 전원을 판 밖으로 돌려보내고 누가 나가서 끝났는지 알린다.
- 판 시작 전(로비)에 나가면 자리만 비우고, 판을 시작하지 않는다.
- 판이 시작된 뒤에는 새 참가를 받지 않는다.
- 판 시작: 로비에서 4명이 모두 준비하면 자동으로 판을 시작한다. 준비는 다시 눌러 취소할 수 있다. 게임 씬은 4명 모두 로딩을 마친 뒤 시계와 입력을 연다. 설정 시간(시험값 60초) 안에 모두 마치지 못하면 판을 종료한다. 시작 인원은 설정값(기본 4)이며 4 미만은 개발 시험용이다.
- 이유: 4인 마피아에서 한 명이 빠지면 진영 구성이 무너져 판이 성립하지 않는다. 기능 동결(10/25) 전에 단절 보존과 재결합을 모든 기능에 넣을 시간이 부족하다.
- 재접속은 10/25 이전 범위에서 뺀다. 나중에 넣으면 판 한정 복귀 토큰으로 같은 참가자인지 확인하고, 유예 시간 안에 돌아오면 판을 이어가도록 이 규칙을 바꾼다.
- 접속은 현재 방식(KCP, IP 직접 접속)을 유지한다. Steam은 인터넷 플레이가 필요하다고 결정될 때 따로 검토한다.

## 10. 확정하지 않은 경계 계약

아래는 문서 대조에서 확인한 잔여 질문이다. 위 결정의 예외나 새 게임 규칙을 승인한 목록이 아니다. 해당 처리에 필요한 사용자 결정과 기능 담당자 간 API 합의를 먼저 확인한다. 독립적인 구현·문서 작업은 진행할 수 있다.

| ID | 남은 계약 | 관련 항목·영향 |
|---|---|---|
| K01 | 의식 완료와 소환, 최후 전투 수리 100%와 HP 0이 동일 판정 시점에 발생할 때의 처리. 확인 10초·마감 경계 요청 채택 기준도 구현 계약으로 닫아야 함 | R02·R09 / 최명기 최종 판정, 김지훈 등대, 박태욱 소환·피해 |
| K02 | 숨은 단계의 마지막 날 밤 중 정확한 마감 시점과 마감·의식 시작·소환 경합 | R09 / v4의 N일차 밤 표현은 유지하며 임의로 밤 시작·종료를 선택하지 않음 |
| K03 | 게임 기한 정지·제거와 별개인 월드 시간·일차, 의식 중 및 최후 전투의 일일 효과 처리 | W15·W16 / 기한 제거를 월드 시간 전체 정지로 확대하지 않음. 강민서 시간과 각 기능의 일일 제한 계약 |
| K04 | 의식 중 발생하지 않은 부식 모듈 낙하를 최후 전투 전환 뒤 어떻게 처리할지, 잔여 낙하 타이머·모듈 조건 승계 | W01~W03 / 즉시 낙하·타이머 연장·영구 취소 중 어느 것도 새로 확정하지 않음 |
| K05 | 대상 변경 때 v4의 연속 투표 시간 초기화와 이 문서의 시민별 시간 합산·아침 정산을 연결하는 방식 | R13 / 이미 누적·정산된 양의 보존·초기화 범위와 변경 전 구간 정산을 임의로 정하지 않음 |
| K06 | 인터넷 플레이 필요 여부(접속 방식) | N13 / 이탈·호스트 종료·중도 참가·로비 시작 조건은 2026-10-13 8절 결정으로 닫힘 |
| K07 | 수리 100% 외 필수 모듈 조건, 확인 창의 명시적 거절·만료·난파 전후 능력/공개 상태의 세부 전환 | W01·R01·R02·R23 / 기존 관련 미정 중 위 결정으로 닫히지 않은 범위 |

기본 HP·최대 HP 및 공격력 관련 계수는 설정으로 전달하며, 이 문서에 없는 숫자·반올림·지원 범위를 출시 규칙으로 정하지 않는다. 봉인·심해 비공개 정책을 다른 비밀 정보(부식·힌트·예보 등)의 미정 수신 계약까지 해결한 것으로 확대하지 않는다.

## 11. 팀원별 연결 계약과 반영 위치

기획은 위 절을 단일 기준으로 사용한다. 아래는 기존 담당 경계에 따른 제공·소비 책임이며 구체적인 신규 API 이름·시그니처·처리 순서를 합의한 기록은 아니다. 실제 API와 구현·검증 상태는 [기술설계](../03-technical-design.md), [김지훈 상세 설계](jihun-system-design.md), [로드맵](../05-implementation-roadmap.md), [담당 작업표](../06-owner-work-plan.md)에서 구분한다.

| 계약 | 제공 책임 → 소비·최종 책임 | 기준·반영 위치 |
|---|---|---|
| 개인 표·투표 가능 여부·의식 잠금 | 박태욱 투표 상태 ↔ 최명기 단계/UI, 김지훈 의식 | 1·3절 / TW03·MK06·JH04, D04·D10 |
| 확인 결과·10초 권리·소환 승인 | 박태욱 확인·소환 → 최명기 단계/UI·김지훈 등대·강민서 날씨 | 2·5·7절 / TW05·MK06·JH04·MS08 |
| 등대 상태·의식 결과·승패 후보 | 김지훈 수리·HP·의식 및 박태욱 유효 피해·표 판정 → 최명기 승패 최종 확정 | 3~5절 / JH04·TW02~05·MK06. 후보와 최종 결과를 구분, K01·K02 미정 |
| 시민별 시간·아침 정산·소환 공격력 | 강민서 서버 시간·아침 경계 → 박태욱 누적/공격력 → 박태욱 등대 괴물 공격 | 6절 / MS03·TW04·TW02·TW05. K03·K05 미정 |
| 소환 전 보상·최후 수리·HP 분리 | 김지훈 등대/보상 상태 → 최명기 인벤토리·배 효과·UI | 5절 / JH04·MK02(속도/대포 피해)·MK03(파밍량)·MK06(UI). 기존 보상 유지·추가 지급 없음 |
| 판 진행 중 이탈 | 김지훈 이탈 감지·전원 종료 통지·판 종료 → 최명기 게임 상태 중단·종료 사유 UI | 8절 / JH07·MK06. 판 진행 여부는 최명기 게임 단계에서 받음, 재접속은 10/25 이후 선택 |
| 공개/개인/서버 전용 데이터 | 각 기능 판정 → 최명기 UI 및 해당 기능 Net/View | 7절 / N04·TW03~05·MK06. 봉인·심해 원본은 클라이언트에 보내지 않음 |

검수는 각 행의 입력·출력, 판정 책임, 발생 시점, 중복 요청·종료 후 요청, 단절 처리와 허용 수신자를 양쪽 문서에서 대조한다. [멀티플레이 시험](../ai/04_MULTIPLAYER_TEST_PROTOCOL.md)의 기대값을 정리하는 것은 시험 실행 완료와 별개다. [문제 대장](../07-design-issue-register.md)은 결정 완료·부분 결정·남은 구현/검증을 추적한다.
