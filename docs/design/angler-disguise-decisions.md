# 아귀 직군별 위장 외형

결정자: 박태욱 / 결정일: 2026-10-31

## 요청과 적용 범위

기존 정비공과 배 한 가지의 가짜 배 외형을, 기존 플레이어의 직군별 캐릭터·배4세트 중 무작위 한 세트로 표시한다. 실제 직군/능력/플레이어 또는 배 객체 생성 규칙은 변경하지 않는다.

| 직군 | 캐릭터 원본 | 배 원본 |
|---|---|---|
| 정비공 | Tech 1 | Boat |
| 항해사 | Captain 1 | captainBoat |
| 채집가 | Farm 1 | gardenBoat |
| 경비병 | Tanker 1 | TankerBoat |

짝은 [직군 능력 결정](job-ability-decisions.md)의2026-10-27 연결과 실제 PlayerController 프리팹 참조로 대조했다.

## 구현 선택

- 아귀 생성 시 서버가4종 중 하나를 동일 확률로 선택하고 선택 인덱스를 SyncVar로 동기화한다. 같은 아귀는 모든 클라이언트가 같은 세트를 사용한다. 재위장 때 다시 뽑지 않으며 서로 다른 아귀의 중복 선택은 허용한다.
- 캐릭터는 기존 boatidle 클립0초의 탑승 자세를 베이크한 정적 외형, 배는 원본 Model 메시·재질, 탑승 위치는 원본 BoardingAnchor를 사용한다. 애니메이션 재생·직군 능력·별도 네트워크/물리/상호작용 기능은 추가하지 않는다.
- 가짜 배의 수면 높이 보정·공개 페이드·몸체 부상 동작은 기존 연결을 유지한다. 실제 플레이어 프리팹은 수정하지 않는다.
- N06의 개인 환영/공유 몬스터 일반 경계는 계속 미정이다. 이번 외형 선택 공유만 명확히 하며 해당 문제 전체를 해결한 것으로 보지 않는다.

구현/직렬화·격리 검사와 실제 다인 검증은 [작업 원문](../박태욱/2026-10-31/아귀-직군별-랜덤위장.md)에서 구분한다.
