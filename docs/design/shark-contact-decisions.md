# 상어 접촉 반응

결정자: 박태욱 / 결정일: 2026-10-31

상어의 실제 물리 충돌에 의한 과도한 배/플레이어 밀침을 비활성화한다. 공격에 쓰는 접촉 판정은 유지하고, BoatCollisionRecoilSource의 설정형 반동(현재3)은 별도 유지한다.

구현은 BlueShark에 한정된 MonsterContactResponse로 접촉쌍에서 배/플레이어 쪽 inverse mass/inertia scale만0으로 제한한다. Rigidbody의 실제 질량은 바꾸지 않는다. 서버와 배 소유 클라이언트 모두 적용되며 다른 지형/포탄 접촉에는 적용하지 않는다. Inspector Suppress Physical Push를 끄면 원래 물리 반응으로 돌아간다. 공격력·돌진속도·피격 규칙은 변경하지 않는다.

최초 최대임펄스0 구현은 상어가 배를 관통하는 회귀를 만들어 폐기했다. 수정 후 배는 상어의 힘으로 움직이지 않고 동적 상어는 배 앞에 막히는 접촉을 유지한다. 본편 공격 피해와 원격 소유배 통합 확인은 필요하다. 일반 물리 권위 계약 전체를 바꾸는 결정은 아니다.
