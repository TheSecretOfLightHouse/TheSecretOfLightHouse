## 요청과 목표

- 사용자: "랜덤 재등장 확인 했으니까 4단계 진행해". 앞서 안내한 감속·회복, 반격 시간, 공격 끔·피격 유지, 몸통 접촉 제외와 겹침 후 복구를 구현한다.
- 시작 시 기존 pointer 변경과 미추적 재등장 기록·공유 결정 문서가 있었고 보존했다. 사용자 재등장 확인은 해당 기록에 구분해 반영했다.
- 현재 기준은 [스피노크록 공격 패턴 결정](../../design/spinocroc-decisions.md)이다. 회복 전용 애니메이션과 본편 스포너 연결은 범위 밖이다.

## 진행 과정과 결정 이유

- SpinocrocRecovery가 서버의 실제 종료 속도를 받아 수평으로 선형 감속한다. 초기 총 회복2초에 감속0.6초를 포함하며, 나머지는 속도0으로 반격에 노출된다. 두 값은 설정 에셋에서 조절한다. 회복 시간은 감속 시간보다 길어야 한다.
- enum 기존 값은 보존하고 Decelerating·Recovering·RecoveryCompleted를 뒤에 추가했다. 준비 컴포넌트의 단계·시각 동기화 경로와 기존 Animator를 재사용한다.
- 정상 돌진 완료·정면 장애물 종료는 회복으로 이어진다. 장애물 종료는 속도0으로 시작한다. 감속 중 새 정면 지형에 닿아도 벽 쪽 속도를 반복 주입하지 않는다. 사망·보호 구역 취소는 회복을 시작하지 않고 정리한다.
- 회복 시작 때 공통 이동을 잠그되 실제 종료 속도를 보관·복원한다. BT 노드 종료의 Motion.Stop이 감속 속도를 지우지 않도록 기존 잠금 계약을 사용했다. 회복 중 공격 플래그는 false이고 피해 구간 검사를 실행하지 않는다.
- 현재 대포탄은 비트리거 몸통 충돌에서 SeaMonster.TryApplyDamage를 호출한다. 몸통 활성·트리거 상태를 바꾸는 대신 Physics.IgnoreCollision로 배·플레이어와의 쌍만 제외해 대포 피격·지형 충돌을 유지한다.
- 접촉 제외 여부는 SyncVar로 동기화하고 각 클라이언트에서도 근처 접촉 쌍을 관리한다. 초기 주변 조회 버퍼256개, 접촉 여유3m를 사용한다. 원격 실기와 고밀도 콜라이더·고속 접근은 별도 검증 사항이다.
- 처음부터 이미 무시된 쌍은 이 기능의 복구 목록에 넣지 않는다. 회복 종료·일반 취소·사망 시 여전히 겹친 쌍은 분리 후 복구하며, 루트 비활성화·네트워크 종료에는 이 기능 소유의 쌍을 정리한다. 배나 플레이어의 위치·권위를 강제로 바꾸지 않는다.
- 회복 전용 클립이 없어 배회 클립 첫 자세를 Animator speed0으로 표시한다. 배회 복귀 시 speed1로 복구한다.
- Unity MCP execute_code의 에디터 API로 전용 프리팹에 회복 컴포넌트를 추가하고, 마지막 BT의 Authoring 노드 타입·ID를 회복 노드로 바꿨다. 기존 노드 연결·Blackboard 변수 연결은 유지하며 런타임 그래프를 재생성했다. 총6노드다.
- 기존 시험 종료 C#·meta는 에셋 참조가 없음을 검색한 뒤 MCP manage_asset delete로 제거했다. 새 C#의 meta는 에디터가 생성했다. .unity·.prefab·.asset YAML은 직접 편집하지 않았다.
- 설정 에셋 저장 시 앞선 재등장 거리12·20 초기값도 에디터가 직렬화했다. 원본 Cube 배·Player·World·Network 코드·공용 asmdef는 이번 단계에서 수정하지 않았다.

## 검증

### 실제 수행

- Unity MCP HTTP 연결, TheSecretOfLightHouse / Unity6000.0.83f1 / MonsterTestScene 확인. 시작 상태 Play=false·scene dirty=false.
- 에디터 리프레시·컴파일·Weaver 후 신규 코드 오류 없음. 첫 scripts-only 갱신에서는 신규 파일 미임포트로 타입 누락 오류가 발생했고, all refresh로 새 스크립트와 meta를 임포트한 뒤 해소했다. 기존 BoatController CS0414·MCP WebSocket 경고와 구분했다.
- 프리팹 회복 컴포넌트, 유효 설정(감속0.6·총2), Authoring/Runtime BT 회복 노드 연결을 에디터 API로 확인했다. 씬 직접 저장은 필요하지 않았고 scene dirty=false였다.
- 기존 LighthouseNetworkManager/KCP로 Play→Host를 시작했다. 원본 Cube 배 자동 접촉 승선 후 해상 위치로 런타임 배치해 시험했다. 첫 관찰 준비에서 승선 전에 배를 옮겨 IsOccupied=false였던 시도는 성공 시험에 포함하지 않았다. 배를 원위치로 돌려 기존 접촉 승선을 완료하고 재시도했다.
- 정상 전체 흐름: Diving→Reappearing→Windup→DirectionLocked→ReadyForCharge→Charging→ChargeCompleted→Decelerating→Recovering→RecoveryCompleted→Patrol. 실제 감속 약0.62초, 총 회복 약2.02초. 서버 이동 잠금·공격false·배회 복귀 확인. 배에 막힌 돌진의 실제 종료 속도0.324가 감속 중 감소한 시험과 구분해 기록했다.
- 별도 정상 설정 시험에서 방향 고정 뒤 배를 옆으로 옮겼다. 실제 종료 속도2.031→1.693→1.354→0으로 감소하고 정지를 유지했다. 종료 직전 속도는 기존 돌진의 남은 시간·거리 보정에 따라 달라지며 임의12로 재설정하지 않았다.
- 실제 Ball 대포탄 프리팹을 서버에서 생성·초기화하고 회복 중 몸통에 물리 충돌시켰다. 몬스터 HP100→90, 배 HP100 유지, 공격false, 몸통 Collider enabled=true, Animator speed0 확인. 발사 입력·BoatCannon 요청을 통한 사격 시험은 아니다.
- 회복 중 배를 몸통에 겹치게 배치해 해당 쌍 무시 확인. 회복 종료 직후 겹침이 남으면 무시·pending1 유지, 분리 후 pending0·무시false로 복구. 별도 미리 무시한 시험 쌍은 끝까지 true로 유지했다. 배회 복귀 시 Animator speed1 확인.
- 런타임 복제 설정으로 준비 시간을0.04초·돌진0.2초로 줄여 BT 중단·루트 비활성화/재활성화·회복 중 서버 사망 주입을 시험했다. 각각 회복false·passfalse·이동 잠금false·속도0·공격false·BT 정지, 이후 배 추가 피해0 확인. 겹침 쌍은 분리 후0, 루트 비활성화에서는 즉시0으로 정리됐다. 저장 설정을 바꾸지 않았다.
- 정상 설정의 임시 고체 벽 접촉에서 Obstacle→Decelerating→Recovering→Patrol, 속도0, 약2.02초 회복, 지형 쌍 무시false 확인.
- 플레이어 하위의 독립 kinematic 시험 콜라이더로 플레이어 분류 경로를 확인했다. 회복 중 무시true, 콜라이더 비활성화/재활성화 뒤 다시 true, 종료 때 겹침 유지, 분리 후 무시false·pending0. 실제 보행 시험과 구분한다. 최초 시험 콜라이더는 탑승 플레이어의 detectCollisions=false Rigidbody에 속해 조회되지 않아 통과로 세지 않았고 독립 시험 Rigidbody로 보완했다. 관찰용 이동 잠금을 해제하지 않은 한 차례 재시도도 흐름 검증에 포함하지 않았다.
- 마지막 장애물·시험 플레이어 콜라이더 회귀와 종료 후 콘솔 오류·경고0건. 과거 컴파일·MCP WebSocket 경고가 있던 구간과 구분한다.
- 최종 Play/호스트/클라이언트 종료 후 저장 씬을 재로드했다. scene dirty=false, 스피노크록 위치(15,-5,0), 프리팹·씬 회복 컴포넌트 유효, 전체 프리팹 Missing Script0, 정상 돌진2초·감속0.6초·회복2초, 총6노드, Authoring/Runtime 그래프 ID 일치 확인. 시험 객체·복제 설정·관찰 콜백은 Play 종료로 정리했다.
- C#·문서와 수정된 설정/그래프의 git diff --check 통과. 프리팹의 Unity 생성 빈 문자열 행 끝 공백은 YAML 직접 편집 금지에 따라 보존한다.

### 검증 한계와 남은 일

- 실제 원격 클라이언트·M2/M3·늦은 참가·지연/손실·소유 클라이언트 운전 접촉은 미실행이다. SyncVar·각 클라이언트 처리 코드의 존재를 원격 통과로 보고하지 않는다.
- 실제 보행 플레이어와의 접촉·회복 전용 애니메이션·본편 MapStateNet/안전구역·섬·장애물 전체 분류·스포너·난파 복귀는 남는다. W17 계약 확인·N07 원격 명중·W18 복합 위협 검증은 완료하지 않았다.
- 회복 시간·감속·거리·피해는 시험값이다. 보상·경고 정책을 새로 확정하지 않았다.
