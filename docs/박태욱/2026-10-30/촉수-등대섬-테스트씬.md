- 카메라·Directional Light·단순 바다 평면 포함. 기존 서버 피해·승패·소환 코드는 변경하지 않았다.

## FBX 오류 수정
- 이전 확인은 본/클립 개수만 검증해 움직임 누락을 발견하지 못했다. Unity 자세 적용에서 본이 정지한 문제가 드러났다.
- Blender 5.2에서 복제된 리그에 액션을 할당할 때 액션 슬롯이 null이었다. 명시적으로 action_slot을 연결하여 개별 FBX를 재내보내고, 프로젝트의 액션 FBX 4개를 GUID 유지한 채 갱신했다.
- 외부 통합 All FBX도 개별 FBX로부터 재생성했다. 재가져온 통합 파일에서 변화하는 FCurve 수: 등대 등장616·조이기572, 채찍 공격361·Idle327.

## 검증
- Unity MCP 실제 Play: 모든 Animator Avatar 유효. 0.5초 동안 조이기 끝 본 약0.209m, Idle 약0.321m 이동. 축소한 주변 촉수는 약0.241m.
- 별도 구간 등장 0.3초 약1.464m, 채찍 공격 0.2초 약3.812m 이동 확인. 최종 클립의 실제 본 움직임이 존재함을 검증했다.
- Unity 콘솔 error 조회 0개. 카메라 렌더로 섬·등대 감기·촉수 텍스처 확인.
- Play 종료 후 테스트 씬 저장, dirty=false 확인. 캡처: `Captures/TentacleIslandTest_Final.png`.
