## 요청과 목표
MonsterAudio에 추가된 거품거북 충전/발사와 등대주변촉수 등장/타격의4개 음원을 연결한다. 기존4종 공격음 작업을 이어가며 새 게임 규칙은 추가하지 않는다.

## 구현과 판단 이유
- 기존 review-design-code-gaps 검토와 서버권위/코딩/에셋 규칙을 재사용했다. W17 주변촉수 안전지대 예외와 실제 WhipTentacleBattleNet의 성공피해 지점을 대조했다. 피해·대상·타이밍 규칙은 유지한다.
- BubbleTurtleAttack: 동기화된 공격순번/시각/준비길이를 이용해 전용3D AudioSource로 충전음을 한 번 재생한다. 음원3.625초를 기존 준비2.479초에 맞춰 pitch약1.462로 재생한다(설정 변경 시 pitch0.01~3 제한). 늦게 관측하면 해당 음원 위치에서 시작한다. 발사/취소/사망/비활성/클라이언트종료 때 정지한다.
- 실제 NetworkServer.Spawn 성공 후 ClientRpc로 발사음 위치/시각/순번을 보낸다. 발사 RPC를 받은 순번은 지연된 충전 SyncVar로 재시작하지 않는다. 발사음은0.125초로 짧아 정상 지연으로 유실되지 않도록 최소1초의 과거이벤트 허용창을 사용한다.
- WhipTentacleBattleNet: 성공한 배 피해마다 기존 로컬 Rig의 WhipTentaclePresentation으로 타격3D 효과음을 전달한다. 기존 중복피해 방지 재사용. 원격으로는 ClientRpc, 호스트도 같은 수신 경로를 사용한다.
- 주변촉수 등장음은 기존 Timeline Summon_WaterRise의5개 AudioPlayableAsset을 새 mp3로 교체했다. 시작0.45/1/1.55/2.1/2.65초 유지, 각 길이를3.082449초로 지정하고 loop=false. 기존 저음/감기는소리/애니메이션/물보라 트랙은 유지했다.
- WhipTentaclePresentation은 기존 등장 AudioSource에 마스터×효과음×개별0.7/음소거를 반영한다. 버블 충전과 일회성 발사/타격도 같은 볼륨을 따른다. 매니저 부재 시 기존 프리팹을 생성한다. 공용 SoundManager·ThirdParty 원본은 수정하지 않았다.
- Unity API로 BubbleTurtle.prefab/MainSceneSummonRig.prefab/Timeline만 연결·저장했다. BubbleTurtle의 기존 assetId0은 Mirror가 GUID 기반4011876296으로 지정했다. 기존 폰트 미커밋 변경은 작업 시작부터 있었으며 복원하지 않았다. 씬은 저장하지 않았다.
