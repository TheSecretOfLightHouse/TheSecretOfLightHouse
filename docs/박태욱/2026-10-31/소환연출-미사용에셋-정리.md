## 요청과 목표
- 사용자 요청으로 연출 완성 전까지 보류했던 미사용 항목 정리를 시작한다. 실제 메인 씬 연출과 편집·미리보기 경로를 보존한다.

## 진행 과정과 결정 이유
- 현재 `SummonCinematicView`는 실제 섬에 `MainSceneSummonRig`를 연결한다. 별도 Additive 씬 로드가 없으며 구형 씬은 빌드 목록에도 없다.
- GUID 참조 검색과 Unity의 메인 Rig·실제 등대 프리팹·테스트 씬 재귀 의존성 조회를 대조했다. 코드·ProjectSettings·Packages에서 삭제 대상의 이름 기반 참조도 검색했다.
- 구형 씬만 사용하는 바다/물보라, 참조 없는 placeholder, 외부 소비자가 없는 옛 촉수 컨트롤러와 그 클립을 삭제했다. Unity `manage_asset delete`로 에셋과 meta를 함께 삭제했다.
- `TentacleIslandTest`, `SummonCinematicPreview`, 해당 씬의 테스트 프리팹·컨트롤러는 실제 편집/미리보기 의존성이 있어 유지했다. 테스트 씬에는 Rig가 2개 있으며 이번 작업에서 배치·활성 상태는 변경하지 않았다.
- 공격·보호·입력 계약은 변경하지 않는다. W17의 주변 촉수 안전지대 예외 및 기존 원격 검증 대기 상태도 유지한다.

## 검증
- Unity 에디터 연결·비 Play 상태 확인. 활성 MainOffline 씬은 dirty=false, 저장하지 않았다.
- 메인 Rig와 실제 등대 프리팹의 컴포넌트 직렬화 참조 검사: Missing Script 및 끊어진 ObjectReference 0개. Timeline 길이 12초 유지.
- 테스트 씬을 PreviewScene으로 열고 닫음: Missing Script 0개. 씬 저장 없음.
- 삭제 8개 모두 meta 동반 확인. `git diff --check` 통과.
- 전체 에셋의 AssetDatabase 역참조 일괄 조회는 응답 실패하여 성공으로 세지 않음. GUID 검색과 핵심 3개 진입점 의존성 조회로 확인했다.
- 콘솔에 `TowerFocusCamera.cs`의 Cinemachine namespace/type 참조 오류 4건 존재. 삭제 대상과 별개인 코드/패키지 오류이며 이번 작업에서 수정하지 않았다. Play·본편·원격 회귀 검증은 미실행.

## 남은 일과 차단 조건
- Cinemachine 참조 오류 해소 뒤 메인 씬 연출 재생·전투 복귀 확인. 원격 통합 검증은 기존 대기 상태 유지.
- 작업 시작 git status는 clean이었으나 에디터 작업 중 World 메타 3개와 EditorBuildSettings 변경이 별도로 나타났다. 해당 내용을 읽고 이번 삭제와 구분하여 보존했다. 정리 커밋에 임의 포함하지 않는다.
