# 등대 촉수 타격 먼지·파편 효과
작성자: 박태욱
작성일·갱신일: 2026-10-31
상태: 구현·로컬 호스트 기능 및 근접 렌더 확인, 실제 본편/원격 시각 확인 대기

## 요청과 목표
- 사용자가 등대 촉수 공격 때 외벽이 부서지는 느낌의 먼지와 떨어지는 파편을 요청했다.
- 등대 형태·HP/수리 판정은 유지하며, 실제 HP 감소에 맞춘 시각 효과만 추가한다. HUD 보류 방침은 유지한다.

## 구현과 변경 파일
- `Assets/01.Scripts/06.Monsters/Boss/View/LighthouseImpactParticles.cs`와 meta: 로컬 클라이언트에서 등대 HP 감소를 관찰해 발생시킨다. 최초 상태·연출 시퀀스 변경·재바인딩은 기준값만 저장해 지난 피해를 재생하지 않는다. 연출 중·특수 종료·시민 승리 뒤에는 발생시키지 않으며 HP0 마지막 피해는 허용한다.
- `SummonTentacleCombatView.cs`: 기존 보스 바인딩 때 효과에도 보스/등대 참조를 전달한다. 서버 공격·HUD 코드는 변경하지 않았다.
- `Assets/02.Prefabs/Boss/LighthouseImpact.prefab`: 등대 네트워크 앵커를 기준으로 외벽4개 지점 중 타격마다2개를 사용한다. 먼지26개·작은 파편16개씩 방출한다. 같은 ParticleSystem을 월드 좌표로 재사용하므로 이전 먼지가 다음 위치로 순간이동하지 않는다.
- `Assets/02.Prefabs/Boss/MainSceneSummonRig.prefab`: 효과 프리팹 중첩 및 참조 연결. 등대 실제 위치·회전으로 발생 원점을 갱신하며 모델을 움직이지 않는다.
- `Assets/06.Textures/Boss/Lighthouse_Dust.asset`: 직접 생성한64×64 부드러운 노이즈 먼지 텍스처.
- `Assets/04.Models/Boss/Lighthouse_Fragment.asset`: 직접 생성한 작은 불규칙 저폴리 파편 메쉬.
- `Assets/07.Materials/Boss/Lighthouse_Dust.mat`, `Lighthouse_Fragment.mat`: 자체 먼지/돌 파편 재질. 각각 URP Particles/Unlit, Particles/Lit 사용.
- 이번에 만든 에셋은 자체 본편 VFX이므로 Git 경로에 둔다. 외부 NamuFX 원본과 SVN 경로는 수정하지 않았다. 새 에셋/스크립트 meta는 Unity에서 생성했다.
- 파편은 파티클이며 Collider/Rigidbody나 피해 판정이 없다. particle collision도 비활성이다. 먼지는 퍼지며 사라지고 파편은 중력·회전·크기 축소 후 사라진다.

## 실제 검증
- 컴파일 오류0 확인. 먼지·파편 셰이더 supported=true, 프리팹 Collider0개·자동재생/루프/파티클 충돌 모두false 확인.
- TentacleIslandTest 단독 Play에서 정면/측면 외벽의 근접 카메라 렌더를 확인했다. `Captures/Lighthouse_Impact_Preview-1.png`는 미리보기 정지 화면이다. 카메라 조작·수동 방출은 Play에서만 수행했고 씬에 저장하지 않았다.
- 실제 KCP 로컬 호스트 로비에 본편 등대/작업대/Rig 프리팹·임시 투표 fixture를 만들고 실제 TryBeginFinalBattle·연출 복귀·서버 조이기를 실행했다. 정상 로비→맵 전체 흐름 시험은 아니다.
- 실제 공격 순번1/2의 HP1000→990→980 각각에서 먼지52개·파편32개 확인. 재바인딩 후0.25초에서 먼지0·파편0으로 과거 효과 재생 없음 확인.
- 이어 서버 ApplyDamage로 남은 HP를0으로 만들었다. EndReason.LighthouseDestroyed에서 먼지52·파편32개, 2초 후 모두0 확인. 이 마지막 검사는 새 조이기 한 타격의 피해량을 바꾼 시험이 아니다.
- 검사 시 콘솔 오류/경고0. Play 종료로 임시 fixture 제거, 기존 TentacleIslandTest Edit 모드로 복귀했다. 기존 World meta 변경은 보존했다.

## 남은 일
- 사용자 크기 피드백 후 StoneFragments의 startSize를0.08~0.18에서0.04~0.09로 절반 축소했다. Unity Prefab API 저장·값 재조회로 확인했고 먼지 설정은 유지했다. 축소 후 실제 재생 시각 확인은 대기한다.
- 실제 본편의 플레이어 카메라·조명·시야 가림에서 먼지 농도/파편 크기를 확인하고 필요하면 prefab 수치를 조정한다.
- 별도 원격 클라이언트에서 HP 동기화에 맞춰 발생하는지 확인한다. 로컬 재바인딩 시험을 실제 원격 접속 시험으로 확대하지 않는다.
- 높은 지연으로 여러 HP 변경이 한 프레임에 합쳐지면 한 번의 표시로 처리한다. 시각 효과는 별도 네트워크 피해나 결과를 만들지 않는다.
