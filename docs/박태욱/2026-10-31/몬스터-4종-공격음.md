## 요청과 목표
사용자가 지정한 `Assets/ThirdParty/1조 Unity Asset/MonsterAudio`의 상어·아구·청새치·manta 음원을 각 몬스터의 공격 시점에 연결한다.

## 진행 과정과 결정 이유
- review-design-code-gaps 적용. 기존 서버 피해 권위, 실제 공격 소비자와 프리팹을 확인했다. W17 일반 몬스터 안전지대 취소 계약은 그대로 사용한다. 별도 음향 정책을 임의 게임 규칙으로 추가하지 않았다.
- 상어와 아귀는 공통 TrackingAttack의 성공한 접촉 피해에서, 청새치는 StraightAttack의 성공한 돌진 피해에서 MonsterAttackAudio.PlayImpact를 호출한다. 기존 중복 피해 방지와 안전지대 검사를 재사용하며 공격력·이동·애니메이션은 바꾸지 않는다. 음원이 충격음이므로 공격 준비 시작이 아닌 접촉 시점에 연결했다.
- MonsterAttackAudio는 ClientRpc로 관찰 클라이언트에 위치와 서버 시각을 전달하고 각 PC의 SoundManager 풀에서 3D 효과음을 재생한다. 클립 길이보다 오래된 이벤트는 생략한다. 아직 매니저가 없는 테스트 경로도 프리팹 참조를 통해 생성한다.
- 만타는 동기화된 전기 궤적이 유효한 동안 전용 3D AudioSource를 반복한다. 설치 중에는 꼬리, 설치가 끝나면 마지막 궤적 지점을 기준으로 재생한다. 마지막 점의 수명 만료·목록 비움·사망·컴포넌트 비활성·클라이언트 종료 시 중단한다. 이동 중인 반복음이므로 공용 일회성 풀 대신 별도 소스를 사용하고 매니저의 마스터/효과음/음소거를 매 프레임 반영한다.
- Unity 에디터 API로 4종 프리팹에 컴포넌트와 음원·매니저 참조를 저장했다. 원본 ThirdParty 음원/메타와 공용 SoundManager 코드는 수정하지 않았다. 기본 볼륨0.7, 거리2~40m.
- LoadPrefabContents 저장 시 Mirror가 기존3종의 assetId를0으로 초기화한 것을 diff에서 발견해 실제 프리팹 assetId getter로 재생성하고 SavePrefabAsset으로 저장했다. 기존3종 ID는 동일하고 청새치는 기존0에서 GUID 기반3136613021로 정상 지정됐다. YAML 직접 편집 없음.

## 검증
- Unity 컴파일 완료(isCompiling=false), 콘솔 error0. 경고7개는 수정 범위 밖 Player/외부 에셋 파일에서 발생한다.
- 4종 프리팹 각각 음원/매니저 참조 존재, 컴포넌트1개, Missing Script0, Mirror GUID 기반 assetId 일치 확인. 에디터 프리팹의 NetworkBehaviour.netIdentity는 Awake 이전 null이므로 누락 판정에 쓰지 않았다.
- PreviewScene 편집 모드 격리 검사: 3종 Weaver 생성 RPC 사용자 본문을 호출하여 올바른 클립·3D 위치·볼륨0.7, 클립 길이를 초과한 과거 이벤트 무시 확인. 실제 소켓 RPC/청취 검증은 아니다.
- 만타 PreviewScene 검사: 마스터0.5 × 효과음0.4 × 개별0.7 =0.14, 음소거0, 반복/3D 설정, 마지막 궤적 위치 추종, 궤적 비움/OnStopClient 정지 경로 확인. 최초 시도는 비접속 SyncList 쓰기 제한으로 실패했고 격리 인스턴스의 IsWritable/IsRecording만 시험용으로 설정한 재검사 통과. 원본 Mirror 코드는 미변경. 모든 임시 PreviewScene을 finally에서 닫고 기존 SoundManager.Instance 복원.
- C# git diff --check 통과. 기존 씬 저장·Play 전환 없음.
- 실제 공격 충돌부터 소리까지의 본편 청취, 취소/사망/연속 공격 체감, 원격 M2 동시 청취는 미실행이다. 편집 모드 AudioSource 속성 검사는 실제 재생 시점 검증을 대신하지 않는다.

## 남은 일과 다음 행동
본편에서 4종 공격을 유도하여 충돌 순간/전기 궤적과 청취 시점, 거리 감쇠, 볼륨/음소거, 만타 궤적 만료 후 정지를 확인한다. 호스트와 원격 M2에서 동일 공격이 각 PC에 한 번만 들리는지 확인한다. 음량0.7은 청취 후 조정 가능하다.
