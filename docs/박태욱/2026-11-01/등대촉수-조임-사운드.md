# 등대 촉수 조임 사운드
작성일·갱신일: 2026-11-01
담당 영역: 박태욱 / Monsters
상태: 구현됨(실제 전투 청취·원격 M2 검증 대기)

## 요청과 검토
사용자가 MonsterAudio/등대촉수에 둔 01_foley_leather_stretch_couch_chair_01.wav를 조임 공격에 맞춰 적용 요청. 기존 review-design-code-gaps 검토를 재사용하고 BossTestEnvironment의 AttackStartedAt/AttackSequence, SummonTentacleCombatView의 피해 비율 기반 조임 정점 매핑을 대조했다. 서버 공격·피해·승패 규칙은 변경하지 않았다. 구형 TentacleAnimationView가 아닌 본편 공용 MainSceneSummonRig의 실제 전투 표현에 연결했다.

## 구현과 이유
- SummonTentacleCombatView에 전용3D AudioSource를 추가. 서버 AttackStartedAt 기준 경과시간을 사용해 조임 시작부터 SqueezeDuration × DamageNormalizedTime(조임 정점/피해 시점)까지 재생한다.
- 원본1.066479초를 조임 구간에 맞춰 pitch 조정(0.01~3 제한). 기본 조임1초에서 pitch1.06648. 늦게 수신하면 elapsed×pitch 위치로 seek하며 동일 AttackSequence는 재시작하지 않는다.
- 볼륨0.25. 원본 peak0.88931/RMS0.06267 측정, 개별 gain 적용 peak약0.22233. SoundManager 마스터·효과음·음소거를 매 프레임 반영, 거리2~40m 선형 감쇠/도플러0/반복없음. 조임 정점 이후·전투 중단·비활성·클라이언트 종료·소환 연출/특수엔딩 시 정지한다.
- Unity SerializedObject/SavePrefabAsset으로 MainSceneSummonRig.prefab의 음원/매니저/볼륨3필드 연결. 원본 WAV 수정 없음. 신규 ThirdParty 음원의 Unity import/meta는 SVN 관리 대상이다.
