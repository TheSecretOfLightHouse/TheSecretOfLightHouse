## 요청과 목표
사용자가 지정한 MonsterAudio 음원 6개를 행동에 연결하고 너무 크지 않게 균일하게 조절한다.

## 진행 과정과 결정 이유
- review-design-code-gaps 적용. W17 일반 몬스터 안전지대 계약과 기존 서버 판정 유지. 사용자 지정이 이번 음향 매핑 기준이다.
- MonsterBehaviourAudio를 두 프리팹에 추가했다. 서버 이벤트를 ClientRpc로 관찰 클라이언트에 전달하며 SoundManager 기존 3D 풀·마스터/효과음/음소거를 사용한다. 만료된 이벤트는 재생하지 않는다. 원본 ThirdParty 음원과 공용 SoundManager는 수정하지 않았다.
- 스피노크록: 성공한 TargetDamaged에 Heavy Object Impact, Diving 진입에 SPLASH, Charging 진입에 Dragon Roar. 서버 이벤트 구독/해제를 OnStartServer/OnStopServer에 배치했다.
- 모사웨일: 보호구역을 제외한 유효 목표 선정 성공에 Whale Vocalizations. Movement의 실제 월드 수면 높이와 애니메이션 머리 위치를 비교하여 상승 출수/하강 재입수를 공격 주기당 각각 한 번 재생한다. 단계 변경 자체를 물 접촉으로 간주하지 않는다. 공중 장애물 복귀도 같은 수면 비교 경로를 따른다.
- PCM 16/24bit WAV 측정: 100ms 구간 RMS의 90백분위 목표0.065, peak 상한0.23, gain 상한0.5로 개별 gain 산출. 스피노 타격0.2013/잠수0.2436/돌진0.4264, 모사 탐지0.3701/입수0.2436/출수0.2436. 출력 상한을 우선하므로 모든 음원의 RMS가 동일한 것은 아니며 실제 지각 음량은 청취 확인이 필요하다.
- Unity Prefab API로 저장. Spinocroc 기존 직렬화 assetId0은 GUID 기반1800373155로 초기화됨. MosaWhale1993206875 유지. YAML 직접 수정 없음.

## 검증
- 신규 스크립트 임포트 전 최초 컴파일에서 타입 미발견2건 발생. 전체 AssetDatabase refresh 후 해결, 최종 컴파일 완료/콘솔 error0.
- 두 프리팹 컴포넌트 각1개, 음원6개/매니저 참조 존재, 루트 Missing Script0.
- PreviewScene에서 Weaver 생성 RPC 사용자 본문 6종 호출: 실제 풀 AudioSource의 클립/개별 볼륨/3D 위치 일치. 만료 이벤트6종 모두 생략. 테스트용 SoundManager 정적 참조는 finally에서 원상복구하고 PreviewScene 종료.
- C# git diff --check 통과. 전체 diff --check는 Unity가 생성한 신규 컴포넌트의 빈 m_Name/m_EditorClassIdentifier 뒤 공백4줄을 보고함. YAML 직접 수정 금지에 따라 유지.
- 실제 공격 이벤트→소리의 전체 Play 검증, 사용자 청취, 호스트+원격 M2는 미실행. 편집 격리 속성 검사는 실제 오디오 출력이나 네트워크 통과의 증거가 아니다.
- 시작 시 git status 변경 없음. 최종 변경은 위 파일만. 씬/원본 음원 저장·커밋·푸시 없음.
