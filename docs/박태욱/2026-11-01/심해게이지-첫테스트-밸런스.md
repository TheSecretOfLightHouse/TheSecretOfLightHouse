# 심해 게이지 첫 테스트 밸런스

- 사용자 승인: 추천한 첫 테스트 조합을 적용한다. 기존 계산식과 소환 시점의 특수승리 판정을 유지한다.
- 변경: `Assets/02.Prefabs/Mafia/Data/AbyssSettings.asset` 하루 기본 충전 100→20, 오투표/봉인 증가량 각각 초당 1→0.05. Unity SerializedObject API로 저장했다.
- 유지: 최소 공격력2, 공격주기3초, 특수승리 기준100. 기본 심해+오투표−봉인이 소환 순간100 이상이어야 특수승리로 진입한다.
- 검증: Unity 저장 후 CreateSnapshot 재조회로 세 설정과 최소값 확인. Boss 설정의 기준100/주기3 확인. 하루420초 동안 정투표1명/오투표2명인 계산은 약41로 확인(허용오차0.0001).
- 예상: 같은 표를 하루 내내 유지하면 전원 오투표 +83/일, 정답1명 +41/일, 정답2명 −1/일, 전원 정답 −43/일. 투표 변경 시 봉인 초기화와 오투표 보존 때문에 실제 플레이는 달라진다.
- 실제 본편/호스트·원격 플레이 및 재미 검증은 미실행. 플레이 결과로 후속 조정한다. 커밋/푸시 미실행.
