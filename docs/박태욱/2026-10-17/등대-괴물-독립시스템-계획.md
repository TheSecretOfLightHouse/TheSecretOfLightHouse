## 2026-10-18 — 5단계 특수 연출 연결만 준비

- 사용자 결정: 크툴루가 바다에서 천천히 올라와 등대 앞에 나타나는 특수 연출. 실제 표현 제작은 미루고 연결만 준비한다. 앞선 강한 조이기 제안은 채택하지 않는다.
- `BossTestEnvironment`에 서버 전용 `TryStartSpecialEnding`/`TryCompleteSpecialEnding`, 시작·완료 이벤트를 추가했다. 특수 승인 시 시작 상태와 서버 시작 시각을 동기화하며, 표현이 없으므로 자동 완료 타이머는 두지 않는다. 완료는 서버 진행자가 명시적으로 전달한다.
- `SpecialEndingStarted`/`SpecialEndingCompleted` 이벤트는 서버 내부 알림이다. 원격 표현은 `IsSpecialEnding`, `SpecialEndingStartedAt`, `Phase` 동기화 상태를 소비해야 하며, 서버 이벤트를 클라이언트 콜백으로 간주하지 않는다. 클라이언트가 완료를 요청하는 Command는 추가하지 않았다.
- enum 끝에 `SpecialEndingPlaying`/`SpecialEndingCompleted`를 추가하고, 준비 상태에서만 시작·진행 상태에서만 완료하도록 제한했다. 중복 요청·중단/비활성화 후 완료는 거절한다. 완료 알림은 승리 확정 API가 아니며 결과 잠금·K01·Systems 최종 승패는 미정/미연결이다.
- 특수 분기에서는 기존 `TentacleAnimationView`를 숨긴다. 크툴루 대신 일반 촉수가 감기는 표현을 재생하지 않는다. 일반 분기는 기존 동작을 유지한다. UI에 표현 미구현/승패 연결 대기를 표시했다.
- 변경 파일: `BossTestEnvironment.cs`, `BossPhase.cs`, `TentacleAnimationView.cs`, 승패·투표 결정 문서, 이 원문과 pointer. 씬·프리팹·설정 에셋과 Systems 코드는 수정하지 않았다. 기존 문서 미커밋 변경을 보존했다.
- 검증: Unity 컴파일 오류 없음. 에디터 호스트에서 서버 승인 메서드에 시험 스냅샷을 주입해 10개 검사 통과(서버 활성, 대기 중 호출 거절, 기준100 시작, 중복 승인/시작 거절, 특수 촉수 숨김, 완료1회, HP 유지·일반 피해 없음, 비활성 중단, 외부 종료 후 완료 거절, 기준99 일반 분기 유지). 실제 소환 Command와 원격 다인 검증은 이번 변경 후 실행하지 않았다.
- 시험 환경: 첫 시도는 호스트가 유지되지 않아 Server 가드에서 거절됐다. Play를 재진입하고 같은 실행 안에서 호스트 시작·검사를 수행해 통과했다. 원인을 확정하지 않았으며 제품 기능 통과로 오인하지 않았다. Play 진입 시 `The referenced script (Unknown) on this Behaviour is missing!` 경고도 관찰했고 이번 범위에서 원인 조사·수정하지 않았다.
- 정리: 시험 이벤트 구독 해제·보스 초기화·호스트와 Play 종료. `git diff --check` 통과(줄바꿈 변환 안내만 표시). 5단계 개발 빌드·M2/M3, 실제 크툴루 연출, 결과 잠금·자동 승리·본편 종료는 미검증/미구현으로 남는다.
