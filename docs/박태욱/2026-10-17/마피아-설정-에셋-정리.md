## 요청과 결정
사용자 요청으로 실제 사용하는 설정 두 개에서 VotingTest 접두어를 제거하고 사용자가 만든 Assets/02.Prefabs/Mafia/Data 폴더로 이동했다.

## 변경과 검증
- Unity manage_asset 이동 API 사용. 응답은 실패로 표시됐지만 실제 이동되었으며, 후속 get_info로 두 에셋의 경로·이름·타입·기존 GUID 보존을 확인했다.
- VotingTestAbyssSettings.asset → Assets/02.Prefabs/Mafia/Data/AbyssSettings.asset
- VotingTestIdentitySettings.asset → Assets/02.Prefabs/Mafia/Data/IdentitySettings.asset
- 기존 meta GUID는 각각 ef713f448d17e3a4cbfe09a4068f9fb3, b95929fea02909a4ab72bb4442b9796e로 유지됐다.
- VotingTestScene의 두 설정 참조가 같은 GUID를 사용함을 확인했다.
- 기존 씬·스크립트·기획 문서 등 다른 작업 변경은 보존했다. 플레이 검증은 실행하지 않았다.
