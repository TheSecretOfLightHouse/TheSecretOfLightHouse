# 버블터틀 물 이펙트 교체

- 요청: 투사체와 발사 전 응축 표현을 Magic Arsenal 물 이펙트로 교체.
- `BubbleProjectile.prefab`의 Visual 메시를 `WaterOrbitSphere` 중첩 프리팹으로 교체. 저장 과정에서 Mirror `_assetId`가 400111750에서 0으로 변했고 원래 값 복구 시도는 자동 승인 검토에 의해 거부됨. 네트워크 생성 확인 및 복구 승인 대기.
- `BubbleTurtle.prefab`의 AttackFX에서 기존 응축 메시 렌더러 27개를 비활성화하고 기존 애니메이션의 거대 버블 자식에 `WaterCharge`를 연결. 기존 공격 시간 및 발사점 정렬 사용. 편집 전후 에디터에서 괴물의 ID 4011876296 확인.
- Unity MCP 프리팹 계층과 콘솔 오류 0건 확인. 플레이 시각, 충전 크기 및 원격 클라이언트 검증 미실행.

- 충전 VFX 과대 표시 수정: 기존 버블 애니메이션의 최대 약 29배 확대가 자식 파티클에 적용되어 WaterCharge 로컬 배율을 0.004로 조정. 에디터 저장값 확인, 실제 플레이 시각 검증 대기.

- 사용자 승인 후 투사체 Mirror ID 400111750 복구 및 에디터 직렬화 값 확인. 충전 VFX를 애니메이션 버블의 확대에서 분리하고 발사점으로 이동시키며 준비 진행도에 따라 로컬 배율 0.04~0.12로 증가하도록 변경. Unity 컴파일 및 콘솔 오류 0건 확인, 실제 플레이 및 원격 시각 확인 대기.

- 사용자 정정: 원래 물방울이 모이는 애니메이션을 유지하고 외형을 물 VFX로 교체. 26개 응축 물방울과 중앙 버블에 WaterOrbitSphere 연결, 작은 물방울은 부가 파티클 비활성화. 이전 단일 WaterCharge 연출과 스케일 코드 제거. 프리팹 연결과 투사체 ID 확인, 실제 시각 및 성능 검증 대기.

- 충전 구와 발사체 나선 연결: 공격 시작 시각을 투사체 SyncVar로 전달하고 두 WaterOrbitSphere에 같은 시드와 경과 시간을 적용. Unity 컴파일 및 프리팹 참조·투사체 ID 확인, 1.5초 시뮬레이션에서 4개 파티클 시스템의 입자 수·로컬 상태 일치 확인. 실제 발사 전환과 원격 시각 검증은 미실행.

- 실행 중 파티클 시드 변경으로 Assert가 반복된 문제 수정: 시드 설정 전에 각 파티클을 정지하고 지움. Unity 컴파일 완료, 재생 중 파티클에 동기화 메서드를 호출한 에디터 검사에서 오류 0건 확인. 실제 공격 재실행은 미검증.

- 사용자 요청에 따라 충전 및 투사체 물 파티클 시작 색상을 동일한 어두운 청색 계열 배율 (0.72, 0.78, 0.85)로 조정. 구매 에셋 원본은 유지. 실제 플레이 화면 색감 확인 대기.

- 이전 색 변화가 보이지 않는다는 사용자 피드백으로 색과 알파 배율을 (0.38, 0.48, 0.62, 0.85)로 강화. 충전·발사체 저장값 및 투사체 ID 확인, 실제 화면 색감은 미검증.

- 요청에 따라 충전·발사체 파티클의 시작 알파를 원래 값 1로 복원하고 색상 배율을 (0.32, 0.41, 0.53)으로 소폭 더 어둡게 조정. 플레이 시각 검증 대기.

- 원래의 투명한 정도 복구 요청: 가산 블렌딩에서 어두운 RGB가 더 희미해 보이므로 충전·발사체의 시작 색상과 알파를 원본 흰색으로 복원. 어두운 색 조정은 해제됨. 플레이 화면 확인 대기.

- 불투명도 원본 유지 요청에 따라 시작 알파와 파랑 채널을 1로 유지하고 빨강·초록만 낮춘 색상 (0.65, 0.78, 1, 1)을 충전과 발사체에 적용. 가산 블렌딩 특성상 밝기 차이는 발생할 수 있으며 플레이 시각 검증 대기.
