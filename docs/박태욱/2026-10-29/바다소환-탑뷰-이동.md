# 바다 소환 탑뷰 가장자리 이동

날짜: 2026-10-29

- 사용자 요청으로 마우스가 화면 가장자리에 닿으면 탑뷰를 부드럽게 이동시키고, 배 중심 반경 12m로 제한했다. 속도 10m/s, 화면 가장자리 8%, 보간 0.2초는 SeaSummonSettings에서 조정 가능하다. 몬스터 선택 메뉴가 열린 동안 이동 입력을 받지 않는다.
- 서버의 기존 배 중심 탑뷰 검증을 이동 반경까지 확장해, 이동 후 보이는 지점을 선택할 수 있게 했다. 안전지대·육지 검증은 유지한다. 서버는 이동 가능한 화면들의 합집합을 허용하며 실제 클라이언트 카메라 위치를 신뢰하지 않는다.
- Unity 컴파일 및 콘솔 오류 0 확인. 기존 설정 에셋에서 기본값과 TryValidate 정상 확인. Unity 에디터 임시 월드 조회로 기존 화면 바깥 11m 허용, 13m 거절, 대각선 10m+10m 거절을 확인했다. 첫 임시 검사에서 EditMode에 Awake가 자동 호출되지 않아 초기화 오류가 났고 명시 초기화 후 재실행했다.
- 실제 플레이 및 원격 클라이언트의 마우스 이동 느낌, 지점 선택·소환은 미검증이다. 기획 v4의 시야 내 플레이어 조건은 기존 바다 소환 구현의 별도 미검증/미구현 범위이며 이 작업에서 추가하지 않았다.
