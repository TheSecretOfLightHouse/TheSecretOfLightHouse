## 요청과 목표
- 등대섬 불과 연기를 대포의 입체 연기처럼 자연스럽게 조정.
- 사용자가 강민서 담당 공용 MainIslandAppearance.prefab의 모닥불 표현 수정을 명시적으로 허용.

## 진행 과정과 결정 이유
- v4 분위기 지침·시스템/기술설계·승패 결정 및 문제 대장을 대조했다. 모닥불 외형을 위한 별도 게임 규칙은 찾지 못했으며 승패/대포 판정 변경은 필요 없다. N07/R11의 기존 이동·몬스터 연결 검증은 이번 범위 밖이다.
- 기존 모닥불은 Legacy Particles/Additive 재질의 큐브 입자(수명4초)와 고정 VisibleFlame 메시3개를 사용했다. 고정 메시를 비활성화하고 입체 메시 입자를 사용하도록 변경.
- 기존 CannonParticle 셰이더의 MeshSmoke 모드와 CannonShot_RoundSmoke 메시를 재사용했다. 대포 재질을 복제해 World용 불꽃/연기 재질을 에디터 API로 생성했으며 대포·외부 원본은 수정하지 않았다. 기존 미커밋 CannonParticle 셰이더 변경에 의존한다.
- 불꽃은 수명0.35~0.7초·초당22개·작은 세로형 입자·상승/노이즈/축소/색상 페이드. 연기는 수명2.2~3.4초·초당7개·완만한 상승/측면 흐름·팽창/페이드. 불꽃이 장작에 가려지는 첫 결과를 확인해 높이와 밝기를 후속 조정했다.
- CLI 업데이트 요청은 사용자 거절로 미실행. 샌드박스 밖 status 조회는 승인받아 실행, Unity 연결 도구로 편집했다. 실제 열린 MainOffline 씬은 저장하지 않았다.

## 2026-10-31 실제 적용 경로 수정
- 사용자 실제 화면에 큰 사각 불꽃이 그대로 나타났다. 최초 수정한 MainIslandAppearance는 실제 생성 설정에서 참조되지 않아 적용되지 않았음이 확인됐다. 위 최초 미리보기는 실제 게임 적용 증거가 아니다.
- 실제 Island_Lighthouse.asset의 _variants[0]._prefab은 ThirdParty/1조 Unity Asset/World/Final/Island/Island_Lighthouse/Island_Lighthouse.prefab이었다. 초기 조사에서 이 연결 확인을 누락했다.
- 외부 원본을 보존하고 Assets/02.Prefabs/World/MainIsland/Island_Lighthouse_NaturalFire.prefab 및 .meta를 Prefab API로 생성했다. 원본을 상속하는 variant이며 기존 Campfire_Flame(큐브)과 고정 불꽃을 비활성화하고 Campfire_NaturalFlame/Smoke를 추가했다. 다른 장식과 시설 참조는 원본에서 상속한다.
- Assets/02.Prefabs/World/Data/MapGeneration/Islands/Island_Lighthouse.asset의 프리팹 참조를 새 variant로 SerializedObject API로 교체했다. diff는 해당 참조1개 변경이다. 사용자의 공용 등대섬 모닥불 수정 허용 범위에서 처리했다.
- 저장 후 재조회: 기존 큐브 불꽃 active=false, 새 불꽃/연기 active=true 및 CannonShot_RoundSmoke 메시. 실제 사용될 variant의 격리 렌더를 [실제 프리팹 미리보기](등대섬-실제프리팹-모닥불.png)로 확인했다. 실제 게임 시각 검증은 아니다.
- 실행 상태 조회 시 MainOffline/입자0개였고 사용자가 시작 화면·로비 상태라고 확인했다. 최종 조회는 Play=false였다. 실제 등대섬의 효과를 관찰했다고 보고하지 않는다.
- 사용자가 “테스트 내가 할게”라고 요청하여 추가 실행 테스트를 중단했다. 다음 판에서 새 생성 프리팹으로 검증하며 이미 생성된 섬에 소급 적용했다고 주장하지 않는다. 실제 낮밤·거리별 외형·성능은 사용자 확인 대기.

## 2026-10-31 캠프파이어 불꽃 재제작
- 사용자 피드백: 연기는 괜찮지만 불이 이상하고 너무 작음. 연기는 보존하고 불만 재제작 요청.
- 기존 MeshSmoke 재질에 주황색을 곱하던 불꽃을 전용 CampfireFlame.shader로 교체했다. 밝은 노란 중심·주황/붉은 끝·높이에 따른 끝 흔들림·경계/끝 투명화 적용. 연기용 셰이더와 대포는 수정하지 않았다.
- Editor Mesh API로 CampfireFlameTongue.asset 및 .meta 생성: 끝이 좁아지는 16단/16면 입체 불꽃. 작은 구형 연기 메시를 대체한다.
- 실제 생성 variant의 Campfire_NaturalFlame만 변경: 기본 높이0.5~0.85m→1.05~1.75m(수명 크기 곡선 적용 전), 폭0.4~0.7m·초당16개·수명0.65~1.1초·바닥 반경0.26m. 장작 위에서 여러 갈래 불꽃이 생성되도록 배치. Campfire_NaturalSmoke 설정은 변경하지 않았다.
- 변경: Assets/07.Materials/World/CampfireFlame.shader 및 .meta, CampfireFlame.mat, Assets/02.Prefabs/World/MainIsland/CampfireFlameTongue.asset 및 .meta, Island_Lighthouse_NaturalFire.prefab.
- 검증: 에디터 동기 임포트 및 ShaderHasError=false, Prefab API 저장 성공. 사용자의 테스트 직접 수행 요청을 유지하여 Play/추가 렌더는 수행하지 않았다. 앞선 PNG는 이번 불꽃 외형을 보여주지 않는다. 실제 시각 품질은 사용자 검증 대기.

## 2026-10-31 꽃잎 형태 피드백·회전 설정 수정
- 사용자 화면에서 불꽃이 꽃잎처럼 사방으로 벌어졌다. 조사 결과 재사용한 시스템에 rotationOverLifetime와 rotationBySpeed가 모두 enabled=true로 남아 있었다. 최초 재제작에서 시작 회전만 설정하고 두 모듈을 해제하지 않은 누락이다.
- 실제 생성 variant의 Campfire_NaturalFlame에서 두 회전 모듈 비활성, 렌더 정렬 Local→World·로컬 회전 identity·초기 X/Z 회전0·flipRotation0으로 설정했다. 함께 상속된 sizeBySpeed/forceOverLifetime/inheritVelocity/limitVelocityOverLifetime를 비활성화했다.
- 높이1.15~1.7m로 유지하면서 폭0.25~0.42m·방출 반경0.2m·초당12개로 집중. 셰이더 중심 밝기와 알파를 낮추고 흐르는 농도 변화를 추가했다. 연기는 수정하지 않았다.
- 에디터 저장 결과 두 회전false/정렬World 확인, 셰이더 동기 임포트 오류false. Play/시각 검증은 사용자 요청대로 미실행. 꽃잎 현상 제거를 실제 화면에서 관찰했다고 주장하지 않는다.

## 2026-10-31 한 갈래 연속 불꽃으로 변경
- 사용자 확정 방향: 여러 불꽃의 생성/소멸 대신 한 갈래가 계속 타야 함. 입자 수명에 의한 생성·소멸 방식 자체가 요청과 맞지 않아 제거했다.
- 실제 variant의 Campfire_NaturalFlame 입자 오브젝트 비활성. 같은 위치에 Campfire_ContinuousFlame 단일 MeshFilter/MeshRenderer 추가, 기존 불꽃 메시/재질 재사용·스케일(0.85,1.65,0.85). 계속 존재하는 단일 불꽃이며 입자 방출/수명 없음.
- 셰이더는 작은 높이 변화와 기존 끝 흔들림으로 움직임을 유지한다. 입자 색상 알파 의존 제거·농도 변화 하한0.88로 조정해 생성/소멸처럼 끊어지는 변화를 줄였다. 연기 설정 유지.
- 첫 API 호출은 시간초과 응답이었으나 후속 저장 에셋 재조회로 변경 완료를 확인: 입자 불false/단일 불true/연기true·초당7개, 셰이더 오류false. 실제 Play/미리보기는 사용자 테스트 방침에 따라 실행하지 않았다.
