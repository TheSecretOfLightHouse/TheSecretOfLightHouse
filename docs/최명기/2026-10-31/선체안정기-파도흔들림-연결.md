## 요청과 판단
- 사용자가 파도 외형 흔들림에 안정기 효과를 연결하도록 요청했다. World(강민서)의 WaveTiltVisual과 Player(최명기)의 StabilizerModule 연결 범위를 안내하고 진행했다.
- W03은 효과·수명 계약 부분 결정 상태다. 배4종의 Rigidbody X/Z 회전 잠금과 별개로 파도 외형 기울기가 적용되므로 기존 AddTorque만으로는 보이는 파도 흔들림을 줄이지 못했다.
- 감소율 30%는 조정 가능한 초기값으로 사용한다. 충돌 흔들림까지 줄이는 규칙은 채택하지 않았다.

## 2026-10-31 후속 — 밀림 감소가 빠지는 방향 오류 수정
- 사용자 실제 체감: 기본과 밀림 차이가 없어 보임. 기존 함수 단독 추가 넉백 검사로 실제 충돌 충격 상쇄까지 검증하지 못한 한계를 재확인했다.
- Unity 6000.0 참조 소스의 Collision.impulse는 접촉 pair의 impulseSum 그대로이며 GetContact normal은 수신자에 따라 반전된다. 기존 Max(0, Dot(impulse, normal))은 둘의 부호가 반대인 경우 감소량을0으로 만든다. [Unity 원문](https://github.com/Unity-Technologies/UnityCsReference/blob/6000.0/Modules/Physics/Managed/Collision.cs).
- Player BoatCollisionRecoil.cs 한 곳을 Abs(Dot(...))로 수정했다. 외향 방향은 수신자의 접촉 법선을 유지하고 충격 크기만 부호와 독립적으로 계산한다. World·몬스터·씬·프리팹 추가 변경 없음.
- MCP로 기본 Boat 프리팹 격리 인스턴스에 실제 Unity Collision/ContactPair/ContactPoint 데이터를 구성하고 ReduceContactPush를 호출했다. 법선 ±X와 impulse ±X 네 조합: 수정 전 두 조합은 외향 속도2.5m/s 그대로, 수정 후 네 조합 모두1.25m/s. 수직2m/s·접선3m/s 보존 확인. 임시 인스턴스/PreviewScene 정리.
- MCP 재컴파일 completed/failed=false/errors=[]/compilationFailed=false, C# diff --check 통과. 재컴파일 직후 첫 eval 시간초과 후 focus/재요청으로 위 결과 확보.
- 별도 PreviewScene 물리 시뮬레이션은 장착/미장착 모두 위치1.25m·속도2.5m/s였으나 EditMode 충돌 콜백 발동을 입증하지 못해 실제 경로 검증으로 세지 않는다. 최초 SceneManager.CreateScene 요청은 EditMode 불가 오류여서 PreviewScene으로 변경했다.
- 이 부호 오류는 재현·수정됐지만 사용자가 본 실제 충돌의 유일 원인으로 단정하지 않는다. 실제 장착 상태/콜백·몬스터 접촉 Play·M2는 미검증이며 다음 행동은 동일 몬스터 접촉 재확인이다.
