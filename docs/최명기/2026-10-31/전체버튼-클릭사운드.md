상태: 구현됨(미검증)

## 요청과 목표
- 모든 UI 버튼 클릭에 SFX_UI_Button_Click_Generic_3을 사용하고 크게 들리지 않는 기본 크기로 연결한다.

## 진행 과정과 결정 이유
- 시스템/기술설계·v4·승패/투표 결정·문제 대장의 요청 관련 범위를 검색했다. 클릭 음원/크기에 대한 별도 규칙이나 대응 문제 ID는 찾지 못했다. 이번 사용자 지정이 구현 기준이며 게임 규칙·서버 판정에는 영향이 없다.
- 기존 SoundManager는 음량/음소거 저장과 2D 효과음 재생을 제공하지만 버튼 공통 연결은 없었다. SfxType.Click은 존재하나 실제 호출자는 검색 범위 Assets/01.Scripts에서 발견되지 않았다.
- UiButtonAudio를 오디오 도메인에 추가했다. BeforeSceneLoad에 Resources 프리팹을 생성하고 활성 Selectable 목록에서 uGUI Button의 onClick에 한 번씩 연결한다. 씬 로드 및 실행 중 생성/활성화된 버튼을 갱신하고 파괴된 버튼 참조를 정리한다. 보통 프레임에는 할당/Find/GetComponent 없이 재사용 배열과 HashSet을 사용한다.
- 실제 승인된 onClick을 사용하여 비활성/우클릭/취소된 누름에 별도 소리가 나지 않는다. 버튼별 화면·공용 UI·네트워크 파일은 수정하지 않았다.
- 기본 배율0.5. 기존 SoundManager.Instance가 있으면 재사용하고 첫 화면처럼 아직 없으면 기존 PlayerSoundManager 프리팹을 생성한다. 마스터/효과음/음소거 설정을 그대로 사용한다.
- Unity Prefab API로 Resources/Audio/UiButtonAudio 프리팹을 생성하고 SVN PlayerAudio의 지정 wav를 참조했다. 원본 음원은 수정하지 않았다. SVN 음원 배포가 필요하며 새 Git 프리팹만으로 음원이 다른 PC에 제공되지는 않는다.

## 검증
- Unity 6000.0.83f1 에디터 연결, Play stopped 확인.
- Unity recompile completed, failed=false, errors=[], compilationFailed=false.
- 저장된 Resources 프리팹의 음원 이름/길이0.202154189초·배율0.5·SoundManager 참조 확인.
- 격리 PreviewScene에서 BindButtons를 두 번 호출한 뒤 좌클릭이 한 번만 호출됨, 비활성 버튼·우클릭은 무음, 나중에 생성한 버튼도 연결됨을 확인했다. 실제 AudioSource 청감 검증을 대신하지 않는다. 프리뷰 씬은 finally에서 닫았다.
- 전체 git diff --check는 기존 미커밋 MK_MainGame.unity·Dig.fbx.meta의 공백 때문에 실패했다. 해당 파일은 수정하지 않았다.
- 실제 Play 입력·키보드 submit·씬 전환·마스터/효과음 설정 변경 및 청감은 미검증.
- CLI 업데이트 요청은 사용자 거절로 수행하지 않았다. 에디터 확인/컴파일/프리팹 생성은 연결된 Unity 도구로 수행했다.
