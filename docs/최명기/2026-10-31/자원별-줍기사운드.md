## 요청과 목표
- 새로 추가한 오브젝트별 줍기 음원을 실제 자원 획득에 연결한다.

## 진행 과정과 결정 이유
- 채집 결정·기존 ResourcePickup.TryCollect/PickupInteractionHandler/PlayerInventory 경로 대조. 서버 인벤토리 추가 성공 뒤 드롭이 회수되며 줍기 사운드는 미연결이었다.
- N09 공유 거래 잔여 계약은 이번 사운드 연결로 해결됐다고 보지 않는다. 기존 서버 획득 판정·수량·실패 복구는 유지한다.
- ResourceDefinition 실제 ID 확인: 돌1·나무2·섬유3·철4·모래/유리5·수정6. 섬 종류 대신 획득한 자원의 ID를 사용한다. 동일 ID5의 모래/유리는 같은 음원을 쓴다.
- PlayerInventory에 ID/AudioClip 설정과 기본 볼륨0.65 추가. ResourcePickup의 TryAdd 성공 후, 드롭 회수/풀 초기화 전에 NotifyResourcePickedUp 호출. 실패·중복·수집 잠금에서는 호출되지 않는다.
- 소유 연결에 TargetRpc로 자원 ID만 보내고, 수신자의 SoundManager.PlayEffect로2D 재생한다. 본인만 듣고 마스터/효과음 볼륨·음소거 설정을 따른다. 일반 인벤토리 수량 증가에는 연결하지 않아 제작 반환/복원 등의 증가를 줍기음으로 처리하지 않는다.
- 음원: 돌=흙섬/02_stones_gravel_small_dirt_movement_01, 나무=숲/01_Wood Item Pickup, 철=광산섬/01_SFX_Rattle_Metal_Single_1, 모래/유리=모래섬/01_Glass Pickup, 수정=수정섬/03_coin_ring_gemstone_item_01. 모두 PlayerAudio 아래 wav. 섬유 음원은 확인되지 않아 미지정한다.
- Unity Prefab API로 플레이어5종 Captain 1/Farm 1/Tanker 1/Tech 1/tech에 설정 저장·NetworkIdentity assetId 보존. 외부 음원·World 프리팹/정의·씬은 수정하지 않았다. 기존 미커밋 변경 보존.
