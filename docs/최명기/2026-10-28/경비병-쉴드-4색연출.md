## 진행 과정과 결정 이유
- 기존 BoatShield에는 서버 bool만 있고 클라이언트 연출이 없었다. SyncVar hook은 유지 상태, ClientRpc는 부여/소모 순간 효과를 담당하도록 연결했다.
- 같은 서버 틱에서 부여·소모가 끝나 SyncVar가 합쳐져도 두 순간 효과가 전달되도록 RPC에서 표시/숨김도 처리한다. 훅은 펄스를 재생하지 않아 호스트 이중 재생을 피한다. 늦은 접속은 OnStartClient로 현재 유지 상태만 복원한다. 실제 네트워크 순서는 미검증이다.
- Shield01_Blue/Orange/Purple/Green과 vfx_Impact_v1을 게임용으로 복제했다. 원본에 붙어 있던 Rigidbody·Collider·데모 스크립트·반복 성장 Animation·Light는 게임용 쉴드에서 제거했다. 판정을 가로채는 충돌체를 추가하지 않는다.
- 기존 Orange/Purple 원본의 내부 FrontColor/BackColor는 파란색이어서 게임용 복사 머티리얼에서 내부·외곽 모두 해당 색 계열로 맞췄다. 외부 원본은 수정하지 않았다.
- 쉴드는 배를 따라가는 비네트워크 시각 객체다. 펄스도 각 클라이언트의 로컬 객체이므로 NetworkManager 스폰 등록·공용 코드 변경은 없다.
