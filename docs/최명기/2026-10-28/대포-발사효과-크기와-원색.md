## 2026-10-28 후속: 원판 표현 폐기·연기와 섬광 분리
- 사용자 피드백: 연기와 섬광으로 보이지 않는다. 앞서 적용한 불투명 Alpha Clip은 둥근 텍스처를 원판으로 만들었으므로 이 표현을 대체했다.
- Player/CannonParticle.shader와 CannonFlashBurst.mat / CannonSmokeSoft.mat(+Unity 생성 meta)를 추가하고 배 4종 8개 효과에 연결했다. 앞선 CannonBoldPuff는 이번 효과에서 더 이상 사용하지 않는다.
- 섬광: 밝은 중심·주황색 뾰족한 불꽃, 3~4입자·0.075~0.12초·크기0.7~1.1, 빠른 팽창 후 축소/소멸. 연기보다 나중 렌더 큐로 중심이 연기에 즉시 가려지지 않게 했다.
- 연기: 흰색 유지, 노이즈 기반 불규칙 구름 외곽·부드러운 가장자리·명암, 12~16입자·0.75~1.2초. 시작 크기0.28~0.42에서 점차3.5배까지 팽창하고 위로0.45m/s 이동·회전하며 사라진다. 발사0.025초 후 시작한다.
- 프리멀티플라이드 알파·ZWrite Off로 원판 경계를 제거했다. 중심 밀도는 높이되 외곽과 소멸에는 투명도를 사용한다. 발사 판정·주기·피해·소리·반동·사용자 포구 위치는 변경하지 않았다.
- Unity MCP shader import 메시지0, 4종8개 전용 셰이더/흰 연기 연결 및 1.6초 후 잔류입자0 확인.
- 동일 카메라·난수123의 격리 [섬광0.035초](대포-효과-재작업-섬광.png)·[연기0.38초](대포-효과-재작업-연기.png)를 렌더하고 직접 확인했다. 이전 변경 후 이미지는 폐기된 표현의 이력이다.
- 실제 Play의 시간 흐름·조준 가림·바다 조명·원격 표현은 미검증이다. 씬 저장 없음.
