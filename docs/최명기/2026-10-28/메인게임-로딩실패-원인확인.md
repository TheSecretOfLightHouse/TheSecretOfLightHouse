## 요청과 목표
- 오류로 메인 게임에 들어가지 못하는 원인을 확인한다.

## 진행 과정과 결정 이유
- 현재 Unity Editor 로그의 최근 4인 접속 시도를 확인했다. MK_MainGame 씬 로드는 완료됐으나 MapServerBuilder가 `LighthouseIsland(Island_Lighthouse): Variants[0] 프리팹 없음 또는 가중치 0 이하`를 기록했다. 이후 Match 1이 `LoadTimeout`으로 종료됐다.
- MK_MainGame의 MapStateNet 설정 GUID가 MapGenerationConfig.asset과 일치하고, 그 설정의 LighthouseIsland 참조가 Island_Lighthouse.asset과 일치함을 확인했다.
- Island_Lighthouse.asset의 첫 variant는 가중치1이며 프리팹 GUID `75342fc031568914caeb6960a13ec92c`를 참조한다. Assets 내 meta 검색에서 해당 GUID가 발견되지 않았다.
- 해당 GUID는 삭제 전 `Assets/02.Prefabs/Player/Island_Lighthouse_V12.prefab.meta`와 일치한다. 원격 커밋 `6bea02db`(chore: 잘못 추가된 프리팹 삭제)에서 프리팹과 meta가 삭제됐지만 설정 참조는 남아 있다.
- ArchetypeVariantValidator는 Prefab null 또는 가중치0 이하를 거절하며, MapStateNet.OnStartServer는 MapServerBuilder.TryBuild 실패 시 반환한다. 따라서 월드 준비를 완료하지 못하고 판 시작 로딩 기한에 걸리는 흐름과 일치한다.
- 대장 N13은 전원 로딩·월드 준비 뒤 시작, 시간 초과 시 종료라는 부분 결정 상태다. 현재 문제는 이 기획의 미정이 아니라 삭제된 등대 섬 에셋 참조다. 로딩 기한을 늘려도 누락된 프리팹은 복구되지 않는다.

## 변경 파일과 결과
- 이 기록과 담당자 pointer만 갱신했다. 게임 코드·씬·에셋 수정 없음.

## 검증
- 기존 실행 로그와 현재 직렬화 참조·삭제 커밋·실패 경로를 대조했다. 조사 중 신규 Play/컴파일/재현은 실행하지 않았다.
- 로그에 나타난 씬은 MK_MainGame이며 다른 메인 씬 전체의 정상 여부로 확대하지 않는다.

## 남은 일과 차단 조건
- World 설정 담당 강민서와 등대 섬의 정상 대체 프리팹을 확인하고 Unity 에디터에서 variant를 재연결하거나, 삭제 전 프리팹을 원래 meta와 함께 복원하는 방향을 결정한다. 삭제 커밋의 의도를 무시해 임의 복원하지 않았다.
- 재연결/복구 후 월드 생성 성공·4인 준비 완료·InProgress 진입을 실제 확인해야 한다.
