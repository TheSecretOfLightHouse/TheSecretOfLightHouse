# 월드맵·미니맵 문서와 구현 현황 점검
작성자: 최명기
작성일: 2026-10-28
갱신일: 2026-10-28
상태: 조사 완료(정적 확인), 게임 실행 미검증
브랜치·기준 커밋: feature/myeongki / fae7bd8

## 요청과 목표
- 사용자 확인: 최명기가 월드맵과 미니맵을 담당한다. 관련 문서와 최명기 작업 현황을 확인한다.

## 진행 과정과 결정 이유
- 전체 pointer → 최명기 pointer → 10/15 현황점검·10/17 작업우선순위·10/24 직군 구현순서의 관련 내용을 읽었다.
- docs와 자체 스크립트에서 지도·월드맵·미니맵·WorldMap·MiniMap을 검색하고 Assets 파일명도 검색했다. 처음 pointer 검색만으로 관련 기록이 없다고 안내한 범위를 정정한다.
- 담당 작업표 MK06은 지도 UI를 최명기 범위에 포함한다. 10/15·10/17 개인 기록에도 같은 담당 범위가 있다.
- v4 §3.3·4.4·8.2는 항해사의 지도 환영 면역, 시민 지도에 거짓 섬 추가, 랜덤 맵의 추리 목적을 설명한다. 월드맵과 미니맵을 나눈 전용 화면 명세는 이번 검색에서 미발견이다.

## 변경 파일과 결과
- 이 조사 기록과 개인 pointer만 추가·갱신했다. 코드·씬·에셋은 수정하지 않았다.
- 지도 UI: 자체 코드 키워드·파일명 검색과 09.UI 파일 열거에서 구현을 찾지 못했다. 다른 이름의 씬 구성까지 실행 조사한 결과는 아니다.
- 기반 데이터: `MapStateNet`에 Layout/Config/IsLayoutReady 및 LayoutReady/LayoutReleased가 존재한다.
- 항해사 구조 항로: `NavigatorRouteMapData`가 실제 섬·암초를 장애물로 수집하고 `NavigatorRouteView`는 LineRenderer로 항로를 표시한다. 월드맵·미니맵 화면 구현과는 구분한다.
- 환영 면역: `NavigatorPassive`는 배 속도 배율을 제공한다. 확인한 `IIllusionService`는 TryCreate 계약만 제공한다. 개인 지도 정보 전송과 항해사 제외는 10/24 기록에서도 강민서 연결 필요로 남아 있다.

## 검증
- 실행한 확인과 결과: 문서·코드 정적 읽기, 검색, Git 브랜치/커밋/상태 확인. 아래 상대 링크 대상 존재 확인.
- 실행하지 못한 확인과 이유: 이번 요청은 현황 조사로 Unity 컴파일·Play·원격 M2·화면 동작 시험은 수행하지 않았다.
- 기존 Build Profile 수정 및 10/22 인수인계 미추적 파일은 보존했다.

## 남은 일과 차단 조건
- 월드맵·미니맵의 표시 정보(타인 위치·섬 공개·발견 상태 등), 입력과 확대/회전 규칙은 상세 명세 미확인이다. 임의 확정하지 않는다.
- 강민서의 실제 월드 데이터와 개인 환영 정보 제공 경계를 확인해야 한다.
- R18은 개인 지도 비교의 환영 판별 가능성에 대한 검증 가설, N02는 실제 맵 시드 대조 검증 가설, N06은 개인 환영과 공유 결과의 계약 확인 필요 상태다. 지도에 서버 전용 진위 구분을 그대로 전달하면 환영을 식별할 위험이 있다(예상 영향).
