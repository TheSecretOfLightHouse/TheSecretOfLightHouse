## 요청과 목표
- 사용자가 제공한 sound.txt의 음원 중 플레이어 담당 범위부터 적용한다.
- 기존 공용 SoundManager를 사용해 걷기·달리기·점프·승선·하선·배 수리·장애물 경보를 연결한다. 날씨·바다 환경음·거품거북이는 제외한다.
- 초기 설명만 요청했던 단계에서는 수정하지 않았으며, 이후 사용자가 구현 범위를 플레이어로 지정하고 Assets/08.Audio/Player에 음원을 제공했다. 에디터 연결은 사용자 요청대로 Unity MCP를 사용했다.

- 관련 설계 항목은 W03(배 모듈·기존 장애물 경보)·W09(배 수리 조건)이다. 이번에는 경보 거리/판정, 탑승 중 수리·30% 경계·재료 소비·회복량을 변경하지 않았다. 부분 투입만으로 수리음이 나지 않도록 실제 내구도 회복 뒤 재생한다. 정비공 긴급 수리도 성공 후 같은 배 수리음을 사용한다.
- 걷기/달리기는 공유 .anim 클립의 Animation Event를 사용한다. Captain 프리팹의 발 본 높이를 한 주기 20지점에서 샘플링해 걷기 0.3/0.8, 달리기 0/0.5 정규화 시점을 초기값으로 선택했다. 최종 시각/청감 동기화는 실제 플레이 확인이 필요하다.
- 로컬 이동/접지와 복제된 Animator 상태를 이용해 정지·점프·낙하·탑승·다운 중 발소리를 차단한다. 블렌드 가중치와 최소 간격으로 중복 이벤트를 억제한다. 원격 Rigidbody는 kinematic이므로 로컬 접지 판정을 원격에 강제하지 않는다.
- 점프는 Animator의 실제 점프 상태 진입, 승하선은 PlayerController의 확정 이벤트를 소비한다. 난파 복귀에서는 일반 하선음을 생략한다. 이동음은 3D이며 별도의 발소리 RPC를 추가하지 않는다. 배 수리는 서버에서 회복 성공 뒤 관찰자 ClientRpc를 한 번 호출한다.
- 플레이어가 참조하는 PlayerSoundManager 프리팹을 생성했다. 첫 클라이언트/오프라인 플레이어가 생성하고 기존 싱글톤이 있으면 재사용한다. 씬은 저장하지 않았다.
- 장애물 경보는 지정 음원으로 교체하고 원래 중지/숨김 처리를 유지했다. 매니저의 전체·효과음 볼륨/음소거를 반영하며 0.933초 음원이 기존 0.6초 간격에 겹치지 않도록 음원 길이 이상 간격을 적용한다. 미지정 프리팹의 기존 합성 경고음 fallback은 보존했다.
- 프리팹 저장 전 현재 파일을 작업 외부 검증 폴더에 백업해 세션 시작 전 변경과 비교했다. 실제 4직군과 배 4종만 변경했다. 구형 tanker/tech에 생긴 이번 변경은 작업 직전 백업으로 복원했다. PrefabContents 저장 시 Mirror assetId가 0으로 직렬화되는 현상을 확인해 영구 프리팹 에셋을 에디터 API로 다시 저장했다. 기존 비영(非零) ID 6개는 유지했고, 원래 0이었던 Captain 1/Tanker 1의 값은 Mirror가 기존 에셋 GUID에서 생성한 값으로 저장됐다. GUID 자체는 변경하지 않았다.

## 2026-10-29 후속: 기존 HFSM·애니메이션 구조로 통합
- 요청: 이미 구성된 플레이어 HFSM과 애니메이션 스크립트를 읽고 그 구조에 사운드를 연결할 것. 별도 오디오 상태 감시 컴포넌트를 사용하지 않는다.
- 확인한 기존 계약: PlayerController가 HFSM과 PlayerAnimationSource를 생성해 Driver.Initialize에 주입한다. HFSM의 MotionChanged가 AnimationSource.Changed로 전달된다. 로컬 이동은 PlayerController.Update가 실제 PlayerMotor.IsJumping/입력을 HFSM에 공급한다. 원격 이동은 HFSM을 따로 Tick하지 않고 기존 NetworkAnimator 결과를 소비한다.
- PlayerAnimationDriver.HandleChanged에서 기존 상태 전이를 소비해 로컬 Jump 진입·OnBoat 진입/이탈에 재생을 요청한다. 초기 구독/재활성화의 현재 상태 전달은 동작 시작으로 세지 않는다. 마지막 OnBoat의 배 참조로 난파 복귀를 구분한다. HFSM·상태 클래스·AnimationSource의 규칙은 변경하지 않았다.

## 2026-10-29 후속: 배 탑승 이동 물소리
- 사용자 지정: Audio 폴더의 03_Ambience_River_Water_Movement_High_Intensity_Loop를 배에 탑승해서 움직이는 동안 재생한다. 파일은 Assets/08.Audio/Player의 30초·스테레오·44100Hz WAV로 확인했다.
