# 점프 준비 동작 단축

## 요청·원인·변경
- 사용자가 점프 애니메이션의 긴 준비 동작 확인 후 변경 요청.
- 같은 세션 review-design-code-gaps 검토 재사용. 이번 최신 사용자 결정은 점프 표현 반응 단축이며 물리 점프·이동 권위(N07) 변경이 아니다.
- Jump.fbx 1.9초 클립을 프리뷰 씬에서 시간별 자세 샘플링: 약0.3~0.4초까지 몸을 낮추고 약0.5초 이후 도약 자세. 기존 Movement→Jump는 Fixed Duration0.25초/offset0. 물리는 입력 처리 시 바로 상승해 준비 자세가 늦게 보일 조건이다.
- `Assets/05.Animations/Player/PlayerAnimator.controller`를 Unity AnimatorController API로 수정·저장. Movement→Jump duration0.25→0.05초, normalized offset0→0.2105263(클립0.4초 시점). 클립 원본·상태 재생 속도1·Jump→Movement 복귀0.25초·점프 물리 값은 유지.
- 앞선 Pickup 이동 중단 전환 보존. C#·씬·프리팹 수정 없음.

## 실제 검증
- Unity 호스트 단독, 런타임 시작 인원만1로 임시 설정 후 로비 Ready→MKTestScene. 호스트 첫 호출은 시간초과 후 서버 미시작 확인, 재호출로 시작했다.
- Input System Space 입력: t0.052에 Y=-0.812/상승속도4.608, IsJumping=true 및 Jump 전환 중(next normalized0.223). t0.100에 Jump 상태/전환 완료, normalized0.248로 준비 구간 이후부터 재생 확인.
- 약0.5초에 Y=0.225 정점, 이후 하강. t1.003 IsJumping=false·복귀 전환, t1.261 Movement 복귀 확인. 기존 접지 거리로 바닥 이전에 착지 판정이 나오는 현상은 별도이며 이번에 변경하지 않았다.
- 시험 입력 자동 해제, 기존 시작 인원 복원, Play 종료. 시험 설정·위치 씬 저장 없음. 대상 에셋 git diff --check 통과. scriptCompilationFailed=false.
- 한계: 호스트 입력·Animator 상태 표본 검증. 실제 키보드 체감·원격 화면·이동 중 점프·경사 점프는 미검증. 준비 동작 시작점0.4초는 체감 조정을 위한 값이며 전체 클립 속도는 유지했다.
