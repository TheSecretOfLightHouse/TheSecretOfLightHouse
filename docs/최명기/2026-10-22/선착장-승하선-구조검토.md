## 진행 과정과 결정 이유
- BoatContactBoarding의 충돌 기반 자동 요청과 BoatController의 서버 승인·하선 위치 탐색을 확인했다. 현재 하선은 육지 접촉과 출항 보호 조건을 요구한다.
- 선착장 영역·하선 지점·출항 방향을 제공하는 DockPoint(가칭), 자동 요청과 수동 요청을 조율하는 Player 측 제어, 기존 BoatController 서버 판정 재사용을 제안한다. 기존 육지 충돌 탐색을 그대로 E키에 붙이면 같은 조건으로 실패할 수 있다.
- E키 시 선착장 후보를 물리 질의로 재탐색하고 안전 지점은 서버가 검증한다. 자동/수동은 같은 명시적 승선 또는 하선 요청으로 합류하며 중복·역전환을 차단한다. E키는 기존 상호작용과 한 번만 소비해야 한다.
- NETWORK_AUTHORITY §2.2는 자기 이동·승하선을 기능 자체 Command로 명시한다. N07은 소유 클라이언트 이동 권위만 부분 결정되어 있으며 접안 허용 오차는 시험이 필요하다.
- 자동 승선은 선착장 진입만으로 발동하기보다 자기 배 근처 승선 구역 진입 조건을 권장한다. 자동 하선 후 즉시 재승선 방지를 위해 구역 이탈 후 자동 재무장하는 방식을 제안한다. 선착장 밖 기존 승하선 유지 여부·속도 조건은 미확정이다.
