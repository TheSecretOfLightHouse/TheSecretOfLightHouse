## 요청과 목표
- 현재 폴더에서 알아야 하는 내용, 적용해야 할 연결, 남은 일을 최명기 담당 기준으로 정리한다. 구현·설정 변경·커밋·외부 연락은 요청 범위에 포함하지 않는다.

## 진행 과정과 결정 이유
- 2026-10-15: 전체 pointer에서 개인 기록이 없음을 확인하고 사용자에게 담당자를 확인했다. 사용자가 최명기라고 답했다.
- 작업 지침, 읽기 안내, 소유권과 CODEOWNERS, 시스템·기술·아키텍처·로드맵·담당 작업표, 승패·투표 결정과 v4, 문제 대장, 최명기 대상 인수인계를 대조했다.
- 본편 코드 목록과 기능 호출자를 검색하고 Player 제어·입력·카메라·배·내구도·암초 피해·인벤토리 및 Interaction·Voting·세션 연결 코드를 집중 확인했다.
- Player 프리팹과 담당 씬의 스크립트 GUID 참조, 입력 에셋·기본 맵, 빌드 씬·프로젝트 버전을 읽기 전용으로 확인했다.
- 전체 원본 파일을 전부 정독한 감사는 아니다. 본편 C# 목록은 278개, Player는 36개다. 외부 에셋·Mirror 원본·캐시·모든 바이너리·모든 월드 계산 구현을 전수 검증하지 않았다.

## 알아둘 기준과 현재 상태
- 최명기 범위는 Player뿐 아니라 Systems·UI, 직군 배정, 게임 단계와 최종 승패 확정까지다. 각 기능의 서버 검증·동기화도 해당 기능 담당 책임이다.
- 첫 화면·로비·준비·로딩 표시·접속 종료 사유 화면은 2026-10-13 결정으로 김지훈 담당이다. 게임 HUD·인벤토리·투표·지도·정상 승패 통합은 최명기 범위다.
- 플레이어·배 이동은 소유 클라이언트, 자원·피해·난파·승패 결과는 서버 판정이다(N07). 부력·외력은 소유 PC에서만 계산한다.
- 판 중 한 명이라도 이탈하면 승패 없이 판을 중단하고 첫 화면으로 간다. 재접속은 10/25 전 필수가 아니다(N11~N13). 인게임 보이스·배 무전은 삭제됐다(V01).
- 현재 브랜치에 JH02 코드가 존재한다. 인수인계의 'develop PR 전' 문구는 작성 당시 상황이며, 이번 조사에서는 원격 develop 반영 여부를 조회하지 않았다.

## 이미 존재해 다시 만들 필요가 없는 기반
- BoatController의 소유권·승하선 Command, PlayerBoatSpawner의 ActorJoined 기반 개인 배 생성.
- BoatDurability의 서버 피해·SyncVar·난파 이벤트. RestoreDurability는 난파된 배를 복구하지 않으므로 별도 구조/복구 규칙은 여전히 필요하다.
- ReefCollisionDamage의 서버 OverlapBoxNonAlloc 접촉 검사. 원격 Kinematic 배에 OnCollision을 기대하는 방식은 이미 피하고 있다. 씬 연결·원격 피해 실행 결과는 별도 검증이다.
- Cube 프리팹의 BoatDurability와 BoatBuoyancyAuthority 참조. 부력 권위 컴포넌트는 isOwned에 따라 IsSimulating을 바꾼다.
- JH02 요청·검증·세션 기반과 VotingNetworkController의 개인 응답·확인/소환 API. 기반 존재와 본편 연결 완료는 구분한다.

## 먼저 팀과 정할 것
- 직군 배정 시점·4인 배정 방식과 부식 확인 담당 직군(R17/D06).
- 구조 거리·시간·취소, 화물 손실 비율, 자동 구조 비용·자원 부족 시 처리와 복귀 후 배 상태(W10~W13).
- 인벤토리 용량·자원/레시피·소비 단위와 동시 거래 실패 처리(D02/N09).
- 의식완료/소환 및 최후수리100%/HP0 동시 판정, 마지막 밤 기한 경계(K01·K02).
- 의식·최후전투의 월드 일일 효과, 모듈 승계·낙하, 필수 모듈 조건(K03·K04·K07).
- 물리 피해·대포·파도 충격·강제 이동 제안은 최명기 확인 대기 문서가 있다. 코드 존재만으로 팀 합의 완료로 기록하지 않는다.

## 게임 단계·UI에서 지킬 확정 규칙
- 시민만 2회 투표, 자기표·철회 금지, 같은 대상 재클릭 무료. 타인의 표는 공개하지 않는다.
- 의식은 60초, 시작 시 표 변경 잠금·게임 기한 정지·모듈 낙하 억제. 소환 없이 완료하면 정답 시민표2명 이상 시민 승리, 아니면 즉시 마피아 승리.
- 확인 성공의 소환 권리는 10초이며 마지막 확인권을 써도 유효한 권리는 유지한다. 성공/소진은 마피아 개인 응답, 실패 무고 시민만 공개.
- 소환하면 의식 타이머·게임 기한 제거, 최후 수리0% 시작. 새 수리100% 또는 HP0으로 한 번만 승패 확정. 수리로 HP 회복·추가 보상 없음, 기존 보상 유지.
- 봉인·심해 원본은 모든 플레이어에게 비공개. UI에 표시할 진행도로 쓰지 않는다.

## 문서가 현재 코드보다 뒤처진 부분
- 로드맵/아키텍처/기술설계 일부의 'VoteService int ID, 역할·자기표·잠금 미구현'은 현 코드와 다르다. 현재 uint ID와 해당 검사가 있다. 같은 로직을 새로 만들지 말고 연결 API부터 확인한다.
- 아키텍처의 PlayerController MonoBehaviour 표기와 단절 상태 보존 지시는 현 코드·2026-10-13 결정과 다르다. 현 타입은 NetworkBehaviour, 판중 이탈은 판 종료다.
- 01 시스템 개요 6절의 단절 상태 보존 문구도 최신 결정과 충돌한다.
- 인수인계에 적힌 '직군 프리팹 선택 훅'은 합의 방향이며 실행 코드에서 구현을 확인하지 못했다.
- 기본 입력 에셋과 tech의 실제 연결도 달라 문서의 과거 일괄 설명만으로 판단하면 안 된다.
- 이 조사에서는 공유 기준 문서를 수정하거나 미정 계약을 결정하지 않았다.
