# Cube 기능 컴포넌트 Boat 프리팹 이전

## 요청과 목표
- Cube의 기능 컴포넌트를 Boat 프리팹에 모두 옮기고 Muzzle 위치를 처리한다.

## 진행 과정과 결정 이유
- pointer와 최신 폴더 조사, 담당표·씬 에셋 안전·검증 기준 및 보트/대포 코드와 관련 기획을 확인했다. 이번 요청은 프리팹 연결이며 R17 직군 배정·R23 마피아 전환 계약 미정은 변경하지 않았다.
- 기존 미커밋 Cube 변경과 신규 Boat/모델/재질/텍스처를 확인하고 보존했다. 원본과 MPPM 에디터 모두 ready, CLI beta.13 최신 확인. 원본 프로젝트의 에디터 API로 처리했다.
- Boat 루트의 X -90도 모델 회전을 Model 자식으로 분리하여 외형 bounds를 보존하고 기능 루트 축을 정규화했다. BoardingAnchor의 기존 월드 위치/회전을 유지했다.
- Cube 루트의 시각 컴포넌트를 제외한 13개 기능 컴포넌트와 직렬화 설정을 복사했다. Rigidbody·탑승·동기화·대포의 내부 참조는 Boat 대상으로 치환했다. 부력/몬스터 컴포넌트 구현 파일은 수정하지 않았다.
- Boat 고유 GUID에 맞는 Mirror assetId를 유지했다. Muzzle 위치는 Boat 로컬 (0, 0.2, 0.69), 월드 방향과 기존 크기 및 자체 컴포넌트 설정을 보존했다.
- 기존 사용처를 깨지 않도록 Cube 원본은 유지했다. 스포너/NetworkManager의 사용 프리팹 교체는 요청 범위에 추가하지 않았다.

## 변경 파일과 결과
- Assets/02.Prefabs/Player/Boat.prefab: 13개 기능 컴포넌트·참조 연결, 모델 축 분리, Muzzle 위치.
- 본 기록과 최명기 POINTER 갱신. 프리팹 YAML 직접 편집 없이 PrefabUtility/SerializedObject 사용.

## 검증
- 저장 후 에디터 API 재조회: 기능 컴포넌트 13개, Missing Script 0, 기능 필드의 Cube 참조 0, BoatCannon Muzzle 동일 참조 확인.
- Boat assetId 2808386830 / Cube 3601438752로 서로 다름. Boat 모델 bounds 중심 (0,0.2,0), extents (0.34,0.2,0.49)로 변경 전과 동일.
- 실행하지 못한 확인: 실제 Play 항해·부력·승하선·발사·원격 동기화. 컴파일/빌드 통과나 M2 통과로 보고하지 않는다.

## 남은 일과 차단 조건
