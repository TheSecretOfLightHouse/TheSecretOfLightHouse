## 요청과 목표
- 폴더를 읽고 최명기 담당의 남은 일과 알아야 할 사항을 정리한다. 사용자가 최명기임을 확인했다.

## 진행 과정과 결정 이유
- 전체 pointer, 담당자 pointer와 최근 조사 원문, Ability 기록, 담당표·작업표·시스템/기술설계·v4·승패/채집 결정·문제 대장을 확인했다.
- 최근 개인 기록과 실제 호출 경로를 우선해 과거 로드맵의 미구현 설명을 재검토했다. 외부 에셋 전수 검수·다른 브랜치·원격 저장소 확인은 하지 않았다.

## 현재 근거와 권장 순서
1. 실제 입력 2인 회귀: 승하선·조향·충돌·카메라·채집 좌클릭·E키·행동 애니메이션을 확인한다. 10/18 공유 드롭 시험은 실제 Relay/Command 경로의 같은 PC 2인 기록이며 실제 키 입력과 다른 PC 통과를 뜻하지 않는다. WaterSamplerHost 오류가 당시 재현됐으나 오늘 해결 여부는 확인하지 않았다.
2. MK06 단계·단일 승패: 08.Systems/09.UI의 C#은 현재 목록에서 미발견. 다른 폴더에도 UI가 있으므로 전체 UI 부재라는 뜻은 아니다. Network MatchPhase와 본편 숨은 단계/의식/최후 전투를 구별하고 등대·투표·월드 제공자와 종료 계약을 연결한다. K01~K03 및 R09의 경합·기한·월드 시간은 확정 필요다.
3. 본편 자원·작업대: Probe와 HarvestInteractionHandler는 LocalHarvestTestSpot 경로다. 개인 TryConsumeOne과 생성 실패 RestoreOne은 이미 있다. WorkbenchNet은 PlayerInventory.TryRemoveTo를 호출하므로 소비 API를 처음부터 만들 작업이 아니다. 강민서 실제 월드 대상/지점 ID와 김지훈 소비·반환의 본편 통합 확인이 남는다(W05/N09/N10).
4. 난파·구조: BoatController의 난파 드롭/Downed 경로는 존재한다. SetMafiaDowned 검색 결과는 선언·Rules와 Dev 시험 호출이며 본편 Player 호출은 미발견이다. 난파 중 마피아 확인/소환 금지 연결을 확인해야 한다. RestoreDurability는 난파 배를 거부하므로 구조·배 복구를 일반 수리로 대체할 수 없다. W10~W13 손실·구조 비용/시간·동시 구조 규칙을 확인한다.
5. 대포·직군: BoatCannon은 송신자·탑승·난파·서버 재장전을 검사하고 NetworkServer.Spawn한다. Cannonball은 서버 충돌에서 SeaMonster.TryApplyDamage를 호출한다. PlayerPassiveController/ReloadPassive와 서버 발사 간격 배율 조회도 존재한다. 다만 SetJobAbilityEnabled의 외부 C# 호출은 검색에서 미발견이며 직군 배정·소환 제한 연결은 별도다. 액티브 Runner는 로컬 실행이고 구체 PlayerAbility 파생형은 이번 자체 코드 검색에서 미발견이다(R17/R23/K07). BoatDamageType과 몬스터/암초 분류는 이미 있으나 BoatDurability.ApplyDamage는 타입별 감소를 계산하지 않는다. 엄호 효과를 구현 완료로 볼 수 없다.

## 알아야 할 규칙
- 본인 범위: 05.Player·08.Systems·09.UI 및 기능의 서버/동기화. 로비·로딩·종료 사유 화면과 작업대 화면은 김지훈 담당이다.
- 개인 채집 잔량과 공유 드롭을 구별한다. 잔량 0에도 원본을 유지하는 10/18 결정이 우선한다. 원본 숨김은 할 일이 아니다.
- 이동·배 물리는 소유 클라이언트, 피해·자원·승패는 서버 판정이다. 개인 수량/표는 본인만, 심해/봉인은 전원 비공개다.
- 판 중 이탈은 판 종료, 보이스/무전은 삭제 범위다. 기능 동결 10/25·최종 마감 11/1과 정기 시험은 기획 일정이며 달성 증거가 아니다.
- pointer의 10/18 직군스킬 준비 링크는 현재 파일이 없다. 2026-10-20/Ability-역할과-확장설계.md가 존재하며 본문 작성/갱신일은 10/19다. 기존 미추적 파일은 보존했다.

## 변경 파일과 결과
- 이 조사 원문과 본인 POINTER만 갱신. 코드·씬·프리팹·공유 기획은 수정하지 않았다.

## 검증
- 실행: 문서·코드 읽기, 타입/호출 검색, 자체 C# 파일 목록, Git 상태/브랜치/HEAD 확인.
- 같은 세션 직전 MCP 확인: Unity 6000.0.83f1 ready, compiling=false, Play stopped. 최신 CLI beta.13 확인.
- 미실행: 이번 조사에서 컴파일·Play·빌드·M2/M3. 과거 기록을 오늘의 통과로 보고하지 않는다.

## 남은 일과 차단 조건
