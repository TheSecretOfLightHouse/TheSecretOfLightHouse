## 요청과 목표
- 카메라가 휙 돌아가기보다 움직임을 늦게 또는 부드럽게 따라오도록 요청했다. 작성 담당자는 사용자에게 최명기로 확인했다.

## 진행 과정과 결정 이유
- 작업 pointer → 보행 위치 추적 철회 원문과 보행 이동 방향 회전 원문 → 현재 미커밋 코드·기준 설계를 확인했다.
- v4 §3.1은 3인칭을 정하지만 완충 수치는 정하지 않는다. N07은 이동 권위 부분 결정 상태이며 이번 변경은 로컬 카메라 표현으로 해당 권위를 변경하지 않는다.
- 앞선 위치 지연은 사용자 떨림 보고로 반복 철회됐고 원인이 미확정이다. 이번에는 위치 직접 추종을 유지하고 시선 회전 완충부터 적용한다고 안내했다. 플레이어 이동에 따른 위치 지연까지 구현한 것은 아니다.
- 목표 yaw/pitch와 표시 yaw/pitch를 분리했다. LateUpdate에서 좌우는 최단 각도 SmoothDampAngle, 상하는 SmoothDamp로 추종한다. 초기 완충 시간0.08초는 조정 가능한 구현값이며 0이면 즉시 추종한다.
- 보행·배 자유 시점/자동복귀에 적용한다. 부착·승하선 때 각도·속도 이력을 초기화하고 deltaTime=0에서는 완충을 진행하지 않는다. 기존 보행 방향 회전·배 복귀·대포 반동·해제 복구 코드를 보존했다.

## 남은 일과 차단 조건
- 실제 플레이의 빠른 마우스 회전·방향전환·승하선·자동복귀·대포 반동·원격 소유자 카메라 확인이 필요하다.
- 보행 이동 기준은 입력 목표 yaw를 유지하므로 표시 시선은 잠시 뒤따른다. 조작 불일치 체감 여부를 확인해야 한다.
- 위치 지연과 기존 떨림 원인 진단은 수행하지 않았다.
