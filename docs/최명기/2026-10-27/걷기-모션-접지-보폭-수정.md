# 걷기 모션 접지·보폭 수정

## 요청과 목표
직접 이동 관찰 뒤 사용자가 미끄러짐/부양감 해결을 요청했다. 앞서 철회한 이동속도 저하와 런타임 IK를 반복하지 않고, 현재 체형에 맞는 걷기 모션 자체를 수정한다. 사용자 직접 Play 테스트 방침을 유지한다.

## 근거와 범위
- 실제 이동중 Walk_ShortLeg_Candidate100%/약2.9m/s/재생약1.44배 확인. Idle 오연결이나 Falling 지속으로 단정할 근거 없음.
- 현재 후보의 Humanoid 다리·발 근육과 FootT/Q 곡선은 이미 수정된 상태다. 기존 클립과 원본 FBX를 보존하고 Tanker만 별도 클립/OverrideController를 사용한다. N07 물리 권위·서버 판정 변경 없음.

## 구현·결정 이유
- Tanker 실제 Avatar/본 길이(다리 약0.12747m)에서 기존 걷기 상체 동작을 샘플링하고, 지면0 기준 발바닥 접촉/스윙 목표를 정해 두 본 다리를 오프라인으로 맞췄다. 발 방향은 Idle의 중립 자세를 사용한다. 무릎 굽힘은 전방으로 일관되게 고정하여 굽힘 방향 뒤집힘을 방지한다.
- 접촉60%/스윙40%, 스윙 높이0.04m, 발 전후 반경0.08668m, 도달 범위에 필요한 골반 하강 최대0.055m 제한. 91개 자세를 HumanPoseHandler로 95개 근육/RootT/Q 곡선에 구워 저장했다. 매 프레임 IK 스크립트가 실행되는 구조가 아니다.
- 주기를0.96667→0.72초로 바꾸고 발 전후 이동량을 약0.11861→0.17296m(약46% 증가)로 수정했다. 기존 재생 약1.44배에서는 약2주기/초가 된다. 기존2/3 클립속도 기준과 Driver 계산은 수정하지 않았다.
- Tanker_GroundedWalk override는 기존 공통 Animator를 부모로 쓰며 Walk_ShortLeg_Candidate 하나만 새 클립으로 대체한다. 달리기·점프·낙하·탑승·행동 클립과 전환은 기존 그대로다.
- Tanker 프리팹 Animator 컨트롤러만 새 override로 연결했다. 목표걷기3/달리기4.5(배율1.5), Mirror assetId3114722876, 배 참조는 유지한다. 다른 직군에는 연결하지 않았다.

## 제작 검수와 실제 검증 한계
- Unity Editor API 생성·저장, 기존 파일/GUID 직접 편집 없음. 새 클립 기존 GUID 보존 갱신.
- 실제 Tanker 메시를 BakeMesh로 90자세 샘플링한 평지0 기준 최저점 오차: 기존 평균절댓값0.04833m·범위-0.08386~-0.01621m, 최종후보 평균0.00321m·범위-0.00984~0.00314m. 전체 메시 최저점을 쓰는 평지 제작 검수이며 각 발 모든 접촉면·실제 경사/동적 지형의 검증은 아니다.
- 동일 실제 이동속도2.88228m/s와 LocomotionRate1.44114를 사용한 전후 미리보기72장·GIF 생성, 접촉시트 시각 확인. 바닥선 이동으로 전진을 나타낸 미리보기이며 실제 Play 녹화가 아니다. 화면 제작 중 바닥 높이도0으로 맞췄다.
- 연결 확인: Tanker_GroundedWalk / Walk_Grounded_Tanker / Run_ShortLeg_Candidate, speed3, runMultiplier1.5, assetId보존, Base IK Pass=false, playing=false. PlayerAnimationDriver와 공통 PlayerAnimator diff 없음.
- C# 런타임 코드 변경이 없어 새 런타임 컴파일 대상 없음. 임시 제작 코드 메모리 컴파일 성공. 프리팹 diff --check 통과. Unity 프리팹 재저장 시 일부 본 Quaternion 최하위 자릿수 정규화 발생, 의도적인 본 구조·길이 수정 없음.
- 사용자 지시에 따라 Play 시작/입력 주입/자동 동작 테스트를 하지 않았다. 실제 보행 체감·경사·회전·걷기/달리기 전환·점프·승하선·원격 M2는 미검증.

## 남은 일·다음 행동
사용자가 새 Play에서 Tanker의 걷기 접지감과 미끄러짐을 비교한다. 현재 속도 대비 짧은 다리의 제한으로 완전한 무미끄러짐을 보장하지 않는다. 이번 제작 수치는 발 높이·보폭 개선 근거이며 실제 게임에서 문제가 해결됐다는 판정은 사용자 관찰 후 한다. 피드백 전 다른 직군으로 확대하지 않는다. 커밋·푸시·씬 저장 없음.

## 사용자 요청에 따른 원복
- 새 모션이 어색하다는 사용자 피드백과 원복 요청에 따라 Tanker Animator를 기존 PlayerAnimator.controller로 복구했다.
- 새 Walk_Grounded_Tanker.anim과 Tanker_GroundedWalk.overrideController 및 각 메타를 Unity AssetDatabase로 제거했다.
- 걷기3m/s·달리기4.5m/s와 이전 PlayerMotor 접지·경사 변경은 유지했다. 다른 작업자의 변경은 원복 대상에서 제외했다.
- Unity Editor API 원복 실행 성공. 게임 플레이 검증은 사용자 방침에 따라 실행하지 않았다.
