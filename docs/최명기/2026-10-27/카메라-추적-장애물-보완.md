## 진행 과정과 결정 이유
- v4 §3.1은 3인칭을 정한다. 기술설계 §3.1의 배 자유 시점·자동 복귀와 기존 대포 반동을 대조했다. 감쇠/충돌 수치는 기획 확정값이 없어 Inspector 조정 가능한 구현 초기값으로 두었다.
- 문제 대장에 카메라 관통 직접 항목은 확인되지 않았다. 관련 N07은 소유 클라이언트 이동 권위 부분 결정 상태이며, 이번 변경은 로컬 카메라 표현만 수정한다.
- 기존 PlayerCamera는 카메라를 앵커의 자식으로 붙여 즉시 따라가며 장애물 질의가 없었다. 직접 부착을 해제하고 LateUpdate에서 위치·회전을 완충한다.
- 위치 SmoothDamp 0.12초, 회전 지수 감쇠 0.08초, 장애물 해제 후 거리 복귀 0.25초를 초기값으로 적용했다. SphereCast는 near plane 외접 반경과 설정 반경 중 큰 값으로 현재 pivot부터 완충된 목표까지 검사하며 충돌 시 즉시 당긴다. 대포 반동도 검사에 포함한다.
- 플레이어 PhysicsScene을 사용하고 자기 하위 콜라이더·현재 탑승 배·트리거를 제외한다. 시작점 중첩과 64개 질의 버퍼 포화 시 거리를 0으로 제한해 장애물 너머에 남지 않게 한다. 시작점 자체가 환경 내부면 시야 보장은 불가능하며 별도 배치 확인이 필요하다.
- 기존 미커밋 코드/씬/프리팹/문서 변경을 보존했다. 씬·프리팹을 저장하거나 Play에 진입하지 않았다.
- 담당자 pointer의 과거 대포 피드백 원문 링크는 현재 체크아웃에 없어 해당 실행 결과를 재사용하지 않고 실제 코드와 새 검사로 확인했다.

## 2026-10-27 벽 관통 후속 보완
- 사용자 새 요청: 벽이나 오브젝트를 카메라가 뚫고 나간다고 보고했다. 앞선 중단 상태에서 해당 관통 처리만 재개했다.
- 현재 PlayerCamera·미커밋 diff·이전 철회 기록·씬 안전 규칙을 대조했다. 현재 카메라에는 장애물 질의가 없었다. v4의3인칭과 N07 이동 권위 부분 결정을 유지하며 로컬 표현만 수정한다.
- 직전 시선 회전 완충은 유지하고 카메라는 앵커 자식으로 둔다. 위치 지연은 추가하지 않는다. 매 LateUpdate 반동 오프셋을 포함한 목표 위치를 계산한 뒤 pivot부터 SphereCast한다. 충돌 시 즉시 당기며 장애물 해제 후 원래 거리로 즉시 복귀한다.
- 실제 카메라 near plane 모서리를 포함하는 반경과 설정 반경0.2m 중 큰 값을 사용한다. 벽 여유0.05m, Physics.DefaultRaycastLayers, 트리거 제외. 자기 캐릭터/현재 탑승 배 하위 콜라이더 제외, 시작점 환경 중첩 또는64개 버퍼 포화 시 pivot으로 제한한다. PhysicsScene은 플레이어 소속 씬 기준이다.
- 반동 종료 이후에도 카메라 위치/회전을 매 프레임 재계산해 충돌 보정이나 반동 잔여 위치가 남지 않게 했다.
- 변경: PlayerCamera.cs·기술설계§3.1·이 원문·최명기 POINTER.md. 씬/프리팹 저장·Play 진입/중단 명령은 실행하지 않았다. 다른 미커밋 변경 보존.
- 검증: MCP recompile completed / failed=false / errors=[] / compilationFailed=false. 독립 PreviewScene에서 실제 비공개 충돌 메서드를 호출해 정상4m, 중간 벽1.65m, 트리거4m, 자기 하위 벽4m, pivot 환경 중첩0m 확인(pass=true). finally로 PreviewScene 정리. 현재 에디터 ready/stopped 확인.

- 미검증: 실제 맵의 벽 모서리·승하선/탑승 배 제외·대포 반동·원격 소유자·시각적 떨림. 격리5조건이 실제 플레이 검증을 대체하지 않는다.
- 한계: 콜라이더 없는 메시와 제외 레이어는 감지하지 않는다. pivot 자체가 환경 내부면 pivot으로 당겨도 시야를 보장할 수 없다. 넓은 near plane/좁은 통로에서는 카메라가 많이 당겨질 수 있다.

## 2026-10-27 벽 밀착 시 머리 가림 수정
- 사용자 현재 화면을 MCP Game View로 캡처했다. 머리 윗부분이 화면을 크게 가리고 있었으며 카메라 위치=pivot(5.79,3.15,-2.51), near0.3/FOV60/aspect1.7778이었다. SM_Bld_Shanty_Preset_02 ClosestPoint가 pivot과 같아 환경 내부인 것을 확인했다. 직전의 시작점 중첩→pivot 반환이 이 조건에서 잘못된 확대 화면을 만들었다.
- 현재 기획/이동 권위 검토 재사용, 로컬 카메라만 보완. SphereCollider 검사 형상을 캐시해 ComputePenetration으로 중첩 시작점을 최대4회 밀어내고 해당 위치부터 원래 목표까지 검사한다. 검사 형상은 Ignore Raycast·trigger·먼 위치에 두어 일반 충돌과 분리하며 파괴 시 정리한다.
- 초기 비활성 SphereCollider 계산은 작동하지 않아 활성 trigger로 수정했다. 원점 PreviewScene 검사는 계속0m로 나와 통과로 처리하지 않았다. Play 중 기존 맵과 겹치지 않는(10000,10000,10000) 격리 상자 검사에서는 벽 내부 시작 후 카메라 오프셋(0,0,-4), 벽 표면 여유3.90039m로 벽 밖 복구를 확인했다. 원점 검사 실패 원인은 확정하지 않는다.
