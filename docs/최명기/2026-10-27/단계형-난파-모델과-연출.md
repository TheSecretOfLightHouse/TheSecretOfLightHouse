갱신일: 2026-10-28
상태: 구현됨(미검증)

## 요청과 목표
- 사용자가 제공한 난파 참고 이미지처럼 부분 파손 → 선체 분리 → 개별 침몰 → 작은 잔해가 남는 흐름을 모델과 연출로 구현한다.
- 기존 배 외형을 바탕으로 Unity 메시를 생성했다. 참고 이미지의 배를 그대로 복제한 신규 조형 모델은 아니다.

## 진행 과정과 결정 이유
- 기존 BoatWreckEffect는 앞·뒤 두 조각을 분리한 다음 루트 전체를 침몰시키고 있었다. 지연 시간만 늘려서는 평평한 분리 인상을 줄이기 어렵다.
- Boat.prefab의 Model 메시를 배 로컬 좌표로 변환한 뒤 굴곡 있는 경계로 8개 영역으로 분할했다. 외부 UV·법선·재질을 보존하고 파손 가장자리에 얇은 목재 두께를 추가했다.
- 초기 단면 중심 부채꼴 면이 대포·난간의 빈 공간을 가로질러 보이는 문제를 렌더에서 발견하여 얇은 안쪽 테두리 방식으로 교체했다. 노출 목재 색도 별도 재질로 설정했다.
- 앞·뒤 선체의 파손면에 목재 가시 22개, 비산 목재 14개, 거품 호 12개를 추가했다. 조각별 시작·분리·기울기·침몰 시점을 다르게 설정했다.
- 연출 수명은 최대 9초다. 선체는 먼저 침몰하고 작은 목재는 약 5초대까지 남은 뒤 침몰한다. 거품은 단순 메시 표현이며 참고 이미지의 고밀도 물 시뮬레이션은 아니다.
- BoatWreckPiece는 경과 시간에서 자세를 직접 계산한다. 물리 조각·새 네트워크 스폰을 추가하지 않는다. 배가 기울어져도 침몰 방향은 월드 아래쪽이다.
- 사용자 확인: 담당자 최명기. Unity MCP 사용 요청에 따라 기존 연결로 편집했다. CLI 업데이트는 실행하지 않았다.
- 이전 기술설계의 `난파-배-분리모델.md` 링크는 현 체크아웃에 없어 과거 작업 원문은 확인할 수 없었다.

## 검증
- Unity MCP 연결: Unity Editor 편집 모드, MK_MainOffline 씬 확인. Play는 시작하지 않았다.
- Unity 재컴파일 성공, compilationFailed=false.
- 생성 스크립트 실행·프리팹 저장 성공. Missing Script·누락 메시/재질 0.
- 8개 시점 × 34조각: 60Hz 누적 자세 갱신과 해당 시점 지연 초기화 비교. 위치 차이 최대 0, 회전 차이 허용 범위 이내. 기울어진 루트(12,43,-8도)에서도 동일 결과.
- 같은 시점 반복 적용·초기화 재호출에서 누적 위치 드리프트 없음.
- 원본 대비 분할 모델 외부 표면적 비율 1.0000003125. 초기 외형 보존을 확인했다.
- 6단계 격리 렌더를 직접 확인하고 단면·목재·표류 자세를 조정했다.
- 미리보기 정리 과정에서 RenderTexture 해제 오류가 발생해 PreviewScene을 먼저 닫도록 수정했다. 수정 후 재렌더 성공, 콘솔 cursor 339921 이후 신규 오류 0. 기존 PlayerRescuePrompt 예외와 과거 콘솔 기록은 통과로 간주하지 않는다.
- diff 공백 검사에서 Unity 자동 직렬화 프리팹의 빈 필드 뒤 공백과 기존 RepairPassive/POINTER 공백이 보고된다. YAML을 직접 정리하지 않았다.
- 실제 Play의 프레임 진행·자동 수명 종료·게임 바다 셰이더/파도·원격 M2·성능은 미검증이다.

## 남은 일과 차단 조건
- 실제 난파를 일으켜 카메라 거리, 수면 높이, 파손 속도와 구조 중 표시를 확인한다.
- 공용 난파 프리팹은 기존 연결대로 Boat/captainBoat/gardenBoat/TankerBoat에서 참조한다. 이번 모델의 원본은 기본 Boat다. 직군별 다른 정상 모델과 난파 외형의 일치는 미검증이며 각 모델 전용 분할 모델은 생성하지 않았다.
- W13의 회수 가능한 표류물 수명·회수 영역은 계약 확인 상태다. 이번 작은 잔해는 시각 효과로 구현했고 실제 픽업/손실 정산을 추가하지 않았다. W10~W12의 구조 규칙은 바꾸지 않았다.

## 2026-10-27 후속: 나무 판자 표류 유지
- 사용자 요청: 앞·뒤 선체의 침몰은 유지하고 나무 판자만 떠 있게 한다. 위 최초 구현의 최대9초 수명·목재 후속 침몰 설명은 이 변경으로 대체한다.
- BoatWreckPiece에 `_stayAfloat`·`_floatHeight`를 추가하고 FlyingTimber 14개만 활성화했다. 선체8조각과 거품은 기존 침몰 설정을 유지한다.
- 판자는 분리 이후 난파 원점 기준 수면 높이(로컬0.03)에 수평으로 놓여 계속 상하 흔들린다. 실제 파도 샘플을 따라가는 부력은 아니며 원래 보트의 난파 위치를 수면 기준으로 사용한다.
- 떠 있는 판자가 있으면 연출 루트를 시간 만료로 제거하지 않는다. 같은 씬의 오브젝트이므로 씬 언로드에서 정리된다. 별도 판 종료 이벤트나 구조 완료와의 제거 연결은 추가하지 않았다. 반복 난파 시 장면 내 시각 잔해는 누적된다.
- 생성 스크립트·공용 프리팹·검증 스크립트를 함께 갱신하고 미리보기를 재생성했다. Unity 컴파일 성공. 30초를 포함한9시점에서 누적/지연 초기화 일치(위치차0), 9/30초에 앞뒤 침몰·판자 수면 유지·자동 만료 없음 확인. 누락 스크립트/메시/재질0.
- 실제 Play/M2·파도 수면 일치·장기 반복 난파 성능은 미검증이다.

## 2026-10-27 최종 후속: 속이 드러나지 않는 찌그러짐·난파 동시 파손 복원
- 사용자 지적: 앞머리를 제거해 내부가 휑하게 보이며, 앞선 동시 파손 요청과 달리 다시 순차 파손으로 바뀌었다. 직전 절의 앞머리 절단과 난파 시차를 폐기한다.
- 내구도75/50/25% 표시는 선체 면을 제거하지 않고 앞머리를 뒤쪽으로 압축·하향 변형·굴곡시키는3단계 찌그러짐으로 변경했다. 원본 외부 삼각형 수/UV를 보존하고 손상 시에도 원래 외부 재질 하나만 사용한다. 수리 시정상 외형 복구 및 난파 시작 시 동일한 찌그러진 앞부분 전달은 유지한다.
- 난파의 선체·판자·거품 시작을 전부0.015초로 통일했다. 중앙0.16초·판자0.2초·앞뒤0.22초에 빠른 분리를 완료하는 impulse 곡선을 복원했다. 이전의 작은 횡변위를 유지하여 크게 폭발하듯 멀리 흩어지지는 않는다. 앞뒤 침몰·판자 표류는 유지한다.
- 기본배/직군3종 손상·난파 모델 및 프리팹을 Editor API로 재생성했다. 기존 GUID 유지. 생성 메시 저장을 Clear/vertices/normals/uv/tangents/triangles 명시 갱신으로 바꿔 CPU 데이터뿐 아니라 렌더링 버퍼도 갱신되게 했다. 저장 에셋의 이름과 파일명도 일치시켜 생성 시명칭 경고를 제거했다.
- 변형 표면 법선을 미분해 갱신하는 과정의 작은 벡터 정규화 문제를 렌더로 발견해 수정했고 접선도 재계산했다. 미변형 영역의 법선은 원본 그대로 둔다. 초기 얼룩/잘린 외형 캡처는 최종 결과가 아니다.
- BoatHullDamage.cs의 절단면용 추가 재질을 제거하고 기존 외부 재질을 유지한다. 생성·미리보기·검증 스크립트를 같은 기준으로 동기화했다. 게임 규칙·충돌·내구도 값은 변경하지 않았다.
- Unity 컴파일 성공.4종28개 피해/수리경로·전체 손상 메시의 원본 삼각형 수 보존·유효 법선·동시 고속 파손·손상 유지·30초 선체 침몰/판자 표류 확인. 기존12시점 지연/누적 초기화 비교 차이0 및 누락 참조0 검사도 통과했다.
- [최종 외형](난파-단계-미리보기.png):100/75/50/25%와난파0.4/6.2초. [동시 파손 확인](난파-순간-미리보기.png):난파0/0.04/0.08/0.12/0.22/6.2초. 두 격리 렌더를 직접 확인했다.
- 콘솔에는 Mirror 에디터 미리보기 NullReferenceException 및 Unity ObjectPreview 정리 오류가 남아 있다. Assets/Mirror는 수정하지 않았으며 컴파일 실패와 구분한다. 실제 Play의 충돌 체감/파도/원격 M2는 여전히 미검증이다.

## 2026-10-27 후속: 내구도별 앞머리 손상과 이어지는 붕괴
- 최신 사용자 요청: 내구도가 줄면서 앞머리부터 부서진 외형을 보여주고, 난파 시 그 손상이 이어져 무너지게 한다. 직전의 강한 동시 폭발 방향은 폐기한다.
- 기존 BoatDurability는 현재/최대 내구도와 변경 이벤트를 제공하지만 외형 단계는 없었다. 기존 내구도0 난파·30% 미만 수리 금지·서버 피해/수리 판정은 변경하지 않는다.
- BoatHullDamage를 추가했다. 기본 연출 기준은 내구도비율75%/50%/25% 이하에서1/2/3단계이며 Inspector로 조정 가능하다. 앞끝에서 뒤쪽으로 불규칙 절단면이 확장되도록 정상 모델3개를 생성하고 내구도에 맞춰 메시/단면 재질만 교체한다. 수리 시 높은 내구도에 해당하는 외형으로 복구한다.
