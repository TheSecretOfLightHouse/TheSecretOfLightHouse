## 요청과 목표
발이 지면에 닿지 않고 공중을 걷는 듯한 느낌을 개선한다. 이전 발 고정·골반 IK에서 다리가 흐물거렸다는 사용자 피드백을 반영한다. Tanker 하나에 먼저 적용하며, 후속 사용자 지시에 따라 실제 플레이 테스트는 사용자가 맡는다.

## 진행 과정과 결정 이유
- 앞선 실제 Play 관찰에서는 물리 접지가 유지됐다. 경사에서 한쪽 발이 높고 반대쪽 발이 지면 아래인 표본만으로 평지 전체 부유를 확정하지 않았다. [관찰 원문](보행-발미끄러짐-보정.md)의 실제 Play 절 참조.
- 이전 IK는 약 0.127m 다리에 최대 0.16m 발 높이 보정, 0.06m 골반 보정과 월드 발 고정을 사용했다. 이번에는 런타임 IK·발 고정·무릎 재계산을 추가하지 않는다.
- 실제 Tanker Avatar에 현재 걷기를 재생하면서 발목·발가락 방향만 Idle 중립 방향으로 맞추는 비교를 했다. FootIK=false 조건의 전체 메시 최저점 평균 절대오차가 0.0483m에서 0.0183m로 감소했다. 발목 기울기만으로도 관통의 상당 부분이 감소하므로 기존 다리 동작을 보존하는 방향을 택했다.
- 기존 걷기 클립을 복제하고 121개 시점에서 중립 발목/발가락 자세를 HumanPose로 변환했다. 수정한 곡선은 좌우 Foot Up-Down, Foot Twist In-Out, Toes Up-Down 및 RootT.y의 7개뿐이다. RootT.y는 실제 메시 최저점이 평지 0에 닿도록 보정하며 최대 수직 이동은 약 0.03166m다. 캐릭터 Transform·Rigidbody·충돌체의 이동은 변경하지 않는다.
- 상체·허벅지·무릎 곡선, 클립 길이, 기존 이동속도3/4.5, 재생률 계산과 네트워크 파라미터는 보존한다. 공통 Animator 대신 Tanker 전용 override에서 Walk 하나만 대체한다. N07의 소유 클라이언트 이동 권위는 변경하지 않는다.

## 변경 파일과 결과
- `Assets/05.Animations/Player/Prototypes/Walk_AnkleLevel_Tanker.anim` 및 `.meta`: 기존 후보에서 7개 곡선만 수정한 전용 걷기 클립.
- `Assets/05.Animations/Player/Prototypes/Tanker_AnkleLevel.overrideController` 및 `.meta`: 기존 공통 controller의 걷기 클립 하나만 대체.
- `Assets/02.Prefabs/Player/Tanker 1.prefab`: Animator controller 연결 변경. Unity 재직렬화로 본 Quaternion 최하위 자릿수 정규화가 일부 있다. 기존 배 참조·접지 설정을 보존했다. 저장 뒤 Mirror assetId가 0으로 기록된 것을 발견해 Editor SerializedObject로 기존 3114722876을 복구했다.
- `docs/03-technical-design.md`, 본 원문과 담당자 pointer.

## 실제 검증과 한계
- Unity MCP의 실제 Tanker 프리팹을 PreviewScene에 복제해 FootIK=false로 평가했다. 180자세의 전체 메시 최저점 범위가 기존 -0.08397~-0.01621m에서 -0.00161~+0.00093m, 평균 절대오차가 약0.04833m에서 0.000371m로 감소했다. 이는 평지 제작 검수이며 양발의 모든 접촉면이나 지지발의 수평 미끄러짐 검증이 아니다.
- 기존/수정 4위상씩 총8장 비교 렌더를 생성해 시각 확인했다. 평면 기준 발 관통 감소를 확인했으며 실제 게임 녹화나 체감 검증은 아니다.
- 원본/복제 클립의 모든 곡선 키를 비교해 위 7개만 바뀐 것을 확인했다. Leg 곡선 변경0, 루프 RootT.y 양 끝 차이 약1.2e-7, 공통 controller와 점프/낙하/달리기 클립 유지.
- 저장 연결 Tanker_AnkleLevel, 걷기3/달리기배율1.5, RootMotion=false 확인. 새 런타임 C#은 없다. 메모리 제작 코드 컴파일 성공, Unity compilationFailed=false. 콘솔에는 앞선 입력 주입 진단의 bitfield delta-event 예외와 도구 timeout 이력이 있어 오류0으로 보고하지 않는다.
- 실제 Play의 임시 평지 이동 검사를 준비하던 중 MCP 메인 스레드 timeout이 발생했다. 사용자에게 테스트를 맡긴다는 지시를 받아 자동 테스트를 중단했다. Play 종료 후 MK_MainOffline 한 씬만 남은 상태 확인. 실제 보행·회전·전환·경사·원격 검증은 미실행이다.
- 임시 PreviewScene/PlayableGraph/메시/렌더 자원은 정리했다. 씬 저장·커밋·푸시 없음. 기존 RepairPassive의 공백 등 요청 밖 미커밋 변경을 수정하지 않았다.

## 남은 일과 차단 조건
사용자의 실제 Tanker 보행 체감 확인이 필요하다. 이번 수정은 발 높이·방향 보정이며 짧은 보폭과 높은 이동속도로 생기는 수평 미끄러짐의 완전 제거를 보장하지 않는다. 지형을 실시간으로 따라가는 IK가 없어 경사·계단에서의 발 높이 차이도 남을 수 있다. 다른 직군에는 적용하지 않았다.

## 다음 행동
사용자가 새 Play에서 Tanker의 걷기·정지·회전과 걷기↔달리기·점프 전환을 확인한다. 결과를 바탕으로 후속 범위를 정하며 테스트와 다른 직군 확대를 임의 진행하지 않는다.

## 사용자 요청에 따른 원복
- 사용자가 이번 변경을 처음 상태로 되돌리도록 요청했다. Tanker의 Animator를 기존 `PlayerAnimator.controller`로 복구하고 `Walk_AnkleLevel_Tanker.anim`, `Tanker_AnkleLevel.overrideController`와 각 `.meta`를 Unity AssetDatabase로 제거했다.
- Editor API 반환값으로 controller=PlayerAnimator, 두 에셋 삭제 성공, Mirror assetId=3114722876, playing=false 확인. 기존 속도3/4.5·이전 접지 코드·배 연결과 다른 미커밋 변경은 유지했다. 이번 발목 보정은 현재 적용되지 않는다.
- 사용자 테스트 방침에 따라 추가 Play·동작 검증은 하지 않았다. 씬 저장·커밋·푸시 없음.
