## 요청과 목표
- 사용자가 지정한 `Ship hitting another ship 4`를 배끼리 충돌할 때 재생한다.

## 진행 과정과 결정 이유
- 기존 BoatCollisionSplash의 소유 클라이언트 접촉 감지·속도 제한·서버 보고 검증을 재사용했다.
- 상대 배 netId를 보고하고 서버에서 실제 배 컴포넌트·난파 여부·상대 선체 인근 접점을 검사한다. 양쪽 배에 쌍별 0.18초 제한을 함께 기록해 중복 보고를 걸러 전체 관찰 클라이언트에 사운드 Rpc를 보낸다. 소유자도 해당 Rpc로 한 번 재생한다.
- 기존 SoundManager.PlayEffectAt으로 충돌 위치에서 재생하여 음량·음소거 설정을 적용한다. 피해·이동 판정은 변경하지 않았다.
- SVN 원본 WAV는 Unity 에셋 검색에서 미등록으로 확인되어 본편 Assets/08.Audio/Boat에 복사·임포트하고 외부 원본은 수정하지 않았다.

## 변경 파일과 결과
- Assets/01.Scripts/05.Player/Boat/View/BoatCollisionSplash.cs: 배 충돌음 클립/음량, 상대 배 확인과 서버 중복 제한·Rpc 재생 추가.
- Assets/02.Prefabs/Player의 Boat, captainBoat, gardenBoat, TankerBoat: 에디터 API로 클립 연결·저장.
- Assets/08.Audio/Boat 및 meta: 지정 WAV와 Unity 생성 meta.
- 프리팹 저장 시 기존 코드의 미직렬화 기본값(_windProfile=null 및 안정기 4개 값)도 에디터가 함께 직렬화했다. 해당 기능 코드는 수정하지 않았다.

## 검증
- Unity recompile: completed, compilationFailed=false, errors=[] 확인.
- 4종 프리팹 저장 후 에셋 재조회: 지정 클립 연결, 음량1, 루트 Missing Script0 확인. 클립 길이 약0.523초.
- 변경 코드와 배 프리팹 git diff --check 통과.
- 실제 Play 청감·물리 접촉·호스트/원격 중복 방지 검증은 미실행.
- 기존 World 에셋/meta, 폰트, 빌드 프로필 및 develop 병합 작업의 미커밋 변경은 보존했다. 커밋·푸시 없음.
