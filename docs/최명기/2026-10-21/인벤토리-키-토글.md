## 요청과 목표
I 또는 Tab으로 인벤토리 창 열기·닫기.

## 진행 과정과 결정 이유
- 기존 인벤토리 GUI 기록과 실제 InventoryDebugPanel 대조. 기존 창은 항상 표시되고 키 연결은 없었다.
- 기존 수량·차감 시험 창을 재사용하고 처음 숨김 처리. PlayerInput의 기존 SendMessages 입력 경로에 OnInventory를 연결해 본인 창만 토글한다. 비활성화·로컬 플레이어 종료 시 닫는다.
- 실제 플레이어는 루트 InputSystem_Actions가 아닌 Player/Control/View/InputActions의 PlayerActions 맵을 사용한다. 해당 에셋에 Inventory 버튼과 PC 그룹 I/Tab 바인딩을 추가했다.
- R22는 소환 후 마피아 인벤토리 기본 자원 처리 계약이 남아 있다. 이번 변경은 창 표시 입력이며 단계 제한 구현이나 완성된 슬롯 UI를 의미하지 않는다.
- 기존 PlayerInventory·모듈 바인더·씬·프리팹·pointer 변경은 보존했다.
