## 진행 과정과 결정 이유
- 전체/담당자 pointer, 10/20 현황 원문, 최근 커밋, 시스템·기술설계·v4·승패 결정·배 모듈 기획·문제 대장과 Player 코드를 확인했다.
- 최신 커밋 b687f36의 대쉬·안정기와 26e7ba3의 모션 조정을 반영했다. 과거 탐조등만 구현됐다는 기록은 현재 상태에 적용하지 않는다.
- DashModule은 서버 승인·쿨다운을 동기화하고 BoatController가 속도 배율을 사용한다. StabilizerModule은 소유 클라이언트에서 수평 회전축 각속도를 감쇠한다. 상세 제안 전체 구현 완료로 보지 않는다.
- BoatModuleEquipment.TryInstall 호출은 자체 C# 검색에서 시험 메뉴만 확인했다. 제작품 소비 연결은 남아 있다. 장애물 경보 구체 효과는 Player 파일 목록에서 미발견이며 DepthAlarm 식별자는 남아 있다.
- 채집 Probe/Handler는 LocalHarvestTestSpot에 의존한다. 개인 잔량 차감·실패 복구와 작업대 TryRemoveTo 소비 호출은 이미 존재하므로 재작성 대상이 아니다.
- SetMafiaDowned는 Rules/Net·Dev 시험에서만, SetJobAbilityEnabled는 선언만 확인했다. 본편 난파·직군 제한 연결을 완료로 판단할 수 없다.
- 08.Systems/09.UI에서 C# 미발견. 다른 도메인의 UI 부재를 뜻하지 않는다. 단계·단일 최종 승패와 제공자 연결이 큰 잔여 작업이다.

## 변경 파일과 결과
- 이 조사 원문과 담당자 POINTER만 추가·갱신했다. 게임 코드·씬·에셋 수정 없음.

## 검증
- 실행: Git 상태·브랜치·최근 커밋, 문서 읽기, Player 타입·호출 경로 검색. 조사 시작 시 미커밋 변경 없음.
- Unity 이름의 프로세스는 확인했지만 대상 에디터의 준비 상태·콘솔·실행 상태는 확인하지 않았다.
- 미실행: Unity 컴파일·Play·빌드·실제 입력·M2/M3. 기존 기록의 격리 시험·과거 2인 결과와 구분한다.

1. 호스트+원격 실제 입력 회귀: 선회·반동·대쉬·안정기·사격/Stumble·수리·모듈 난파 소실·채집/줍기.
2. MK06 단계·승패 계약 정리: K01 동시 판정/특수 결과 잠금, K02 정확 마감, K03 월드 시간과 기한 분리. 김지훈 등대·박태욱 소환/피해·강민서 시간과 합의 필요.
3. 본편 채집 대상 연결, 제작품 보관 결정 후 소비/장착 연결. 기존 API 재사용.
