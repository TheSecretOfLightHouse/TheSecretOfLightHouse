## 2026-10-17 후속 결정 — 인출 시 HP 불변
- 사용자 명시: 자원 인출 시 등대 HP는 감소하지 않는다. 수리 진행도 되돌리기와 등대 HP를 분리한다.
- 공유 결정·API·김지훈 인수인계·W08·pointer의 HP 미정 표기를 갱신했다. 보상 회수와 나머지 경합은 확정하지 않았다. 위/아래 과거 결정 이력의 HP 미정 설명은 이 후속 결정으로 대체된다.
- 문서 변경만 수행했으며 코드·씬·Downloads 사본은 수정하지 않았다. diff 공백·상대 링크 검수, Unity·원격 시험 미실행.

## 2026-10-17 추가 결정 — 등대 수리 반영 자원 회수
- 사용자가 작업대·등대의 마피아 전용 인출에 이미 수리된 자원 회수/진행도 되돌리기까지 포함한다고 명시했다. 공유 결정의 종전 제외 문구를 정정하고 API·인수인계·W08을 동기화했다.
- 개인 TryAdd는 진행도를 되돌리지 않으므로 김지훈 등대 처리기에서 회수 가능한 자원과 진행도 감소·개인 지급을 함께 확정해야 함을 명시했다. 게임 코드 변경이나 김지훈과의 합의 완료는 아니다.
- 환산·단계별 회수 대상·보상/HP 영향·의식/승패 경합은 이번 발언으로 확정하지 않았다. 기존 최후 전투 규칙을 임의 변경하지 않는다.
- 검증: 관련 문서·기존 규칙 대조와 문서 diff/링크 검사. Unity·M2/M3 미실행. Downloads 첨부 사본은 수정하지 않았으며 전달은 저장소 최신 인수인계를 사용한다.
