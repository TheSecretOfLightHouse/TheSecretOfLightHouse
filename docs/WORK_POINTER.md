# 담당자별 작업 pointer

새 세션은 이 문서에서 확인된 담당자의 pointer로 이동한다. 진행 중 작업·남은 일·다음 행동과 날짜별 이력은 각 담당자 pointer에서 확인한다. 읽기·저장 절차는 [작업 기록과 재개](ai/11_WORK_RECORDS.md)를 따른다.

| 담당자 | 작업 pointer |
|---|---|
| 김지훈 | [김지훈/POINTER.md](김지훈/POINTER.md) |

표에 없는 담당자는 기록이 없다는 뜻이며 실제 작업을 하지 않았다는 뜻은 아니다. 담당자를 확인한 첫 기록 작성 시 해당 폴더와 pointer를 만들고 이 표에 연결한다.
